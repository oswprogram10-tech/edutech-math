- **정답 노출 금지:** 발문·힌트·라벨에 백분율 값, "2반이 더 많아요" 같은 결론, 예시 그래프의 왜곡 항목을 쓰지 않는다.

- **③:** 오개념 규칙은 레지스트리 backtrack, 일반 규칙은 그 과제의 첫 concept다.

### A1 `g6s1u5.A1` "띠그래프를 말아 원그래프 만들기" (C→P→A, 5과제)
2. **자료:** 좋아하는 과일 `사과 9, 포도 6, 딸기 3, 기타 2`(전체 20, 백분율 45·30·15·10). `title` "좋아하는 과일", `valueLabel` "명".
3. **A1.T1 백분율 표 채우기** (concept `g6s1u5.band-graph`): `percentEntry:"student"`, `band:"auto"`, `morph:"none"`. 판정 `all(percentsMatch, percentSumIs 100)`. PERCENT-AS-COUNT ① "전체를 몇 칸으로 나눈 띠였지?", ② `band-frame`.
4. **A1.T2 띠그래프 완성** (band-graph): `percentEntry:"given"`, `band:"student"`, `morph:"none"`. 판정 `bandMatch`. PERCENT-AS-COUNT 같은 ①·②.
5. **A1.T3 원그래프로 말기 + 어림** (circle-graph): `percentEntry:"hidden"`, `band:"given"`, `morph:"drag"`, `sliceLabels:"name"`, `table:"hidden"`. 응답 칸 `number` 분수 `grape` "포도는 전체의 약 몇 분의 몇인가요?". 판정 `all(circleShown, responseCompare grape ge 1/4, responseCompare grape le 7/20)`(3/10, 1/3 둘 다 통과).
6. **A1.T4 막대 vs 원 질문 나누기** (choose-graph): `morph:"none"`, `startAs:"circle"`, `band:"given"`. 응답 칸 `sort` 카드 4장 → 바구니 "막대그래프가 나아요" / "원그래프가 나아요".
   - 막대: "사과를 좋아하는 학생은 몇 명일까?", "포도와 딸기를 좋아하는 학생 수의 차는?"
   - 원: "사과는 전체의 몇 %일까?", "포도는 전체의 어느 정도를 차지할까?"
   - 판정: 분류 일치(기존 sort 콘텐츠의 GoalSpec 모양을 찾아 따른다).
7. **A1.T5 두 반 원그래프 비교** (choose-graph): `startAs:"circle"`, `morph:"none"`, `band:"given"`, `circleTitle` "1반 (20명)", `compare {title:"2반 (40명)", data: 사과 12, 포도 16, 딸기 8, 기타 4}`(30·40·20·10%). 응답 칸 `choice` `apple` "사과를 좋아하는 학생은 어느 반이 더 많을까요?" 1반 / 2반 / 같아요. 정답 2반. trap 1반 → AREA-AS-AMOUNT ① "두 반의 전체 학생 수는 같을까?", ② `total-bars`.

### A2 `g6s1u5.A2` "같은 자료, 다른 그래프" (P, 4과제)
8. **자료:** 두 반 도서 대출 수 `1반 52, 2반 48`, `valueLabel` "권", `title` "도서 대출 수". `yStartOptions [0, 40, 45]`, `yStepOptions [1, 2, 5]`.
9. **A2.T1 차이가 커 보이는 그래프** (critical-reading): `controls ["yStart","yStep","wavyLine"]`, `headlineCards` 4장(T167 스냅샷과 같은 뜻의 짧은 문장). 응답 칸 `choice` `really` "실제로 1반은 2반보다 얼마나 많이 빌렸나요?" 거의 같아요 / 2배쯤 / 3배 넘게. 판정 `all(yStartAbove 0, really = same)`. trap 2배쯤·3배 넘게 → TRUNCATED-AXIS ① "세로축 맨 아래 숫자는 몇이야?", ② `zero-axis`.
10. **A2.T2 차이가 작아 보이는 그래프** (critical-reading): 같은 설정. 판정 `yStartIs 0`.
11. **A2.T3 예시 그래프 3개에서 왜곡 찾기** (critical-reading): `checklist` 4개 모두, `examples`:
    - 예시 1 막대 `가 52, 나 48`, `yStart 45`, flaws `["y-zero"]`
    - 예시 2 막대 `가 20, 나 30, 다 45, 라 100`, `ticks [0, 10, 20, 50, 100]`, flaws `["even-step"]`
    - 예시 3 원 `사과 50, 포도 30, 딸기 30`(합 110), flaws `["sum-100"]`
    - 판정 `marksMatch`(모든 예시). 일반 ①은 "체크리스트 질문을 하나씩 그래프에 물어보자", ②는 없다.
12. **A2.T4 공정한 그래프 조건** (critical-reading): 그래프 없이 응답만 두려면 `distortion` 내 그래프를 읽기 전용으로 둔다(`controls []`). 응답 칸 `choice multiple:true` `fair` 4개: 세로축이 0에서 시작한다(○) / 눈금 간격이 일정하다(○) / 막대 색이 화려하다 / 제목이 짧다. 판정 두 개 일치.
