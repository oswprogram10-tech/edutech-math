**핵심 아이디어:** (자연수)÷(자연수)의 몫은 분수로 나타낼 수 있다. (분수)÷(자연수)는 "n등분한 것 중 하나"이고, 이는 "1/n만큼"을 구하는 것과 같다. 그래서 ÷n은 ×1/n과 같은 결과다.

### 활동
#### g6s1u1.A1 피자 나누기에서 분수 몫 — E05 `discrete`·`partition` · C→P
- **원 계획서:** (분수의 나눗셈 도입) 똑같이 나누기
- **화면과 조작:** 피자(원) 3판을 4명이 나눈다. 학생이 각 피자를 4등분하는 칼선을 긋고(등분 검사 적용), 조각을 4개의 접시로 끌어다 놓는다. 한 접시에 모인 양이 "1/4이 3개 = 3/4"으로 표시된다.
- **설정 예시:**
  ```json
  { "mode": "partition", "variant": "share", "wholes": 3, "shape": "circle", "people": 4, "equalPartsCheck": true }
  ```
- **과제:**
  1. 3 ÷ 4 = ? / 판정: 접시별 양 동일, 입력 3/4
  2. 5 ÷ 3 / 판정: 5/3 = 1 2/3
  3. 2 ÷ 5와 5 ÷ 2 중 1보다 큰 것 / 판정: 5 ÷ 2
- **CPA 페이딩:** C: 직접 자르고 나르기 / P: 등분 그림 자동 / A: 식만

#### g6s1u1.A2 ÷n → ×1/n 모핑 증명기 — E05 `partition` · C→P→A
- **원 계획서:** 분수 타일 가로 등분 슬라이더를 통한 ÷n → ×1/n 모핑 증명기
- **화면과 조작:** 4/5이 세로 칼선으로 색칠된 정사각형. "÷ 3" 카드를 넣으면 가로 등분 슬라이더가 생기고, 학생이 슬라이더를 3칸으로 맞추면 가로선이 그어져 색칠 부분이 3등분된다. 그중 한 줄만 진하게 남기면 4/15이 된다. 화면 위 식 `4/5 ÷ 3`이 애니메이션으로 `4/5 × 1/3`으로 모핑되며 E05 `multiply`의 겹침 그림과 같은 모양임을 겹쳐 보여 준다. 분자가 n의 배수일 때(6/7 ÷ 3)는 색칠 칸을 그대로 3묶음으로 나누는 지름길도 보여 준다.
- **설정 예시:**
  ```json
  { "mode": "partition", "variant": "divide-whole", "fraction": "4/5", "divisor": 3, "morphToMultiply": true }
  ```
- **과제:**
  1. 6/7 ÷ 3 (분자가 나누어떨어짐) / 판정: 2/7
  2. 4/5 ÷ 3 (가로 등분 필요) / 판정: 가로 등분 이벤트 + 4/15
  3. 모핑 후 같은 값이 되는 곱셈식 쓰기 / 판정: `equivalent-expr` 4/5 × 1/3
  4. 2 1/4 ÷ 3 / 판정: 3/4
  5. A 단계: 5/8 ÷ 4, 3 1/3 ÷ 5 / 판정: 5/32, 2/3
- **CPA 페이딩:** C: 슬라이더 조작 / P: 그림+식 모핑 / A: 식 줄 입력(E08과 같은 수식 키패드 위젯)

## g6s1u2 각기둥과 각뿔
| 항목 | 내용 |

### 활동
#### g6s1u2.A1 수직 엘리베이터 vs 한 점 수렴 — E12 `prism-pyramid` · C→P→A
- **원 계획서:** 다각형 수직 엘리베이터(기둥) vs 한 점 수렴(뿔) 3D 압출 생성기 + 구성 요소(n+2, 2n, 3n) 자동 카운터
- **화면과 조작:** 바닥에 밑면 다각형(변의 수 3~8 슬라이더). "엘리베이터" 핸들을 위로 끌면 밑면이 복제되어 올라가며 각기둥이 생기고, "모으기" 핸들을 끌면 위쪽이 한 점으로 수렴하며 각뿔이 된다. 오른쪽 카운터 표에 면·모서리·꼭짓점 수가 n별로 한 줄씩 쌓인다. 면·모서리·꼭짓점을 누르면 3D에서 강조.
- **설정 예시:**
  ```json
  { "mode": "prism-pyramid", "baseSides": { "min": 3, "max": 8 }, "handles": ["extrude", "apex"], "counterTable": true }
  ```
- **과제:**
  1. 오각기둥 만들고 구성 요소 세기 / 판정: 면 7, 모서리 15, 꼭짓점 10
  2. 육각뿔 / 판정: 7, 12, 7
  3. 카운터 표에서 규칙 쓰기: 각기둥 꼭짓점 = □ × n / 판정: 식 동치 2n
  4. 그림 없이: 십각기둥 모서리 수 / 판정: 30
  5. 모서리 18개인 각뿔의 이름 / 판정: 구각뿔
- **CPA 페이딩:** C: 핸들 끌기 / P: 표 / A: 규칙 식만

#### g6s1u2.A2 각기둥 전개도 — E12 `net-fold` · P→A

- **화면과 조작:** 삼각기둥·오각기둥 전개도를 모눈(등각·사각 혼합 아님: 사각형 옆면 + 다각형 밑면 템플릿 조각)으로 조립한 뒤 접는다. 겹침·빈 면 판정은 g5s2u5와 같다.
- **설정 예시:**
  ```json
  { "mode": "net-fold", "target": "prism", "baseSides": 3, "pieces": ["triangle", "triangle", "rect", "rect", "rect"], "collisionHighlight": true }
  ```
- **과제:**
  1. 삼각기둥 전개도 조립 / 판정: 유효
  2. 옆면 직사각형의 가로 합 = 밑면 둘레 확인 / 판정: 입력값 일치
  3. 접히지 않는 각기둥 전개도 고르기 / 판정: 선택 일치
- **CPA 페이딩:** P: 조립과 접기 / A: 그림만 보고 판단

**핵심 아이디어:** (소수)÷(자연수)는 자연수 나눗셈과 같지만, 똑같이 나눌 수 없는 큰 자리를 *더 작은 단위(0.1, 0.01)로 풀어서* 계속 나눈다. 몫의 각 자리 숫자는 그 자릿값 단위가 몇 개씩 돌아가는지이므로 자리가 비면 0을 써야 한다.

### 활동
#### g6s1u3.A1 십진 모형 세분화 — E01 `decimal`·`divide` · C→P
- **원 계획서:** 십진 모형 세분화
- **화면과 조작:** 1을 판, 0.1을 막대, 0.01을 낱개로 해석하는 E01 `decimal` 모드. 6.24를 접시 3개에 똑같이 나눈다. 판 6개를 2개씩, 막대 2개를 접시에 1개씩 놓다가 남으면 망치로 막대를 낱개 10개로 풀어 계속 나눈다. 접시 하나에 모인 양이 몫이다. 4.2 ÷ 5처럼 일의 자리를 나눌 수 없으면 판을 막대 10개로 풀어야 한다.
- **설정 예시:**
  ```json
  { "mode": "divide", "interpretation": "decimal", "dividend": "6.24", "divisor": 3, "plates": 3 }
  ```
- **과제:**
  1. 6.24 ÷ 3 / 판정: 접시별 2.08, 풀기 이벤트 존재
  2. 4.2 ÷ 5 / 판정: 0.84, 판 풀기
  3. 3 ÷ 4 (자연수 ÷ 자연수를 소수로) / 판정: 0.75, 판 → 막대 → 낱개 풀기
- **CPA 페이딩:** C: 블록 / P: 평면 그림 / A: A2로

#### g6s1u3.A2 몫의 0을 찾는 소크라테스 코치 — E07 `div`·`decimal` · P→A
- **원 계획서:** 세로셈 몫의 0. 및 내림 0 누락 포착 소크라테스식 반례 코치
- **화면과 조작:** 나눗셈 세로셈 격자. 몫 칸·소수점 칸·곱 줄·뺄셈 줄·내림 칸이 따로 있다. 학생이 칸을 채우면 칸 단위 판정. 몫의 0이 필요한 자리(6.24 ÷ 3의 소수 첫째 자리)에서 빈칸으로 넘어가려 하면 그 칸이 노랗게 깜빡이고 발문이 뜬다. 오른쪽 작은 창에 A1 모형 그림이 같은 단계로 동기화된다.
- **설정 예시:**
  ```json
  { "mode": "div", "decimal": true, "dividend": "6.24", "divisor": 3, "linkedBlocks": "E01", "flagSkippedZero": true }
  ```
- **과제:**
  1. 8.16 ÷ 4 / 판정: 몫 2.04, 0 칸 입력
  2. 9.3 ÷ 6 / 판정: 1.55, 0 내림 줄 존재
  3. 0.45 ÷ 5 / 판정: 0.09, 일의 자리 0과 소수점
  4. 친구 풀이 6.24 ÷ 3 = 2.8 고치기 / 판정: 오류 칸 지목 + 2.08
  5. 어림 먼저: 19.5 ÷ 6은 3쯤? 30쯤? / 판정: 어림 선택 + 결과 3.25

- **화면과 조작:** 컵에 우유(흰 블록)와 초코 시럽(갈색 블록)을 넣는다. 색 진하기는 비율(시럽 ÷ 우유)로 결정된다. 기준 컵(우유 4 : 시럽 1)과 같은 색을 2배 큰 컵에 만들기. 학생이 "+1씩" 넣으면 색이 달라지고 "×2"로 넣으면 같은 색이 된다. 색 비교 막대(채도 띠)에 두 컵의 위치가 표시된다.

### 활동
#### g6s1u6.A1 3D → 전개도 페인트칠 → 복셀 쌓기 — E12 `surface-volume`·`net-fold` · C→P→A
- **원 계획서:** 6단계 기하 융합(3D 회전 → 2D 전개도 페인트칠 → 1cm³ 복셀 적층 및 침수 실험)
- **화면과 조작:** 단계형 화면(위쪽 단계 표시줄 6칸): ① 직육면체(4×3×2)를 돌려 보기 ② 펼치기 버튼으로 전개도로 펼침 ③ 전개도 면을 페인트로 칠하면 칠한 넓이가 누적(같은 면 쌍은 같은 색 제안) ④ 겉넓이 식 입력 ⑤ 빈 상자에 1cm³ 쌓기나무를 층별로 채우기(한 층 채우기 버튼 제공: 가로×세로) ⑥ 부피 식 입력. 침수 실험(물 높이 변화로 부피 재기)은 선택 단계.
- **설정 예시:**
  ```json
  { "mode": "surface-volume", "solid": { "w": 4, "d": 3, "h": 2 }, "steps": ["rotate", "unfold", "paint", "surface-expr", "fill-voxels", "volume-expr"], "layerFill": true }
  ```
- **과제:**
  1. 전개도 모두 칠하고 겉넓이 / 판정: 칠한 넓이 52, 입력 52
  2. 겉넓이 식(합동인 면 쌍 이용) 쓰기 / 판정: 식 동치 (4×3 + 4×2 + 3×2) × 2
  3. 부피: 층별로 채우기 / 판정: 24, 층 수 = 높이
  4. 정육면체 한 모서리 5cm 겉넓이·부피 / 판정: 150, 125
  5. 1m³는 몇 cm³? / 판정: 1,000,000 (100×100×100 시각화: 한 줄 → 한 층 → 전체 줌아웃)
- **CPA 페이딩:** C: 칠하기·쌓기 / P: 단계 그림 / A: 치수만 보고 식

#### g6s1u6.A2 최소 포장지 상자 설계 — E12 `cubes`·`surface-volume` · P→A
- **원 계획서:** 최소 포장지 상자 설계
- **화면과 조작:** 1cm³ 쌓기나무 24개를 직육면체 상자 모양으로 배열하는 방법(가로·세로·높이 슬라이더, 곱이 24가 되는 조합만 허용)을 바꿔 가며 겉넓이(포장지 넓이)를 기록표에 모은다. 가장 적은 포장지가 드는 상자를 찾는다.
- **설정 예시:**
  ```json
  { "mode": "surface-volume", "variant": "fixed-volume", "volume": 24, "log": ["w", "d", "h", "surface"] }
  ```
- **과제:**
  1. 부피 24인 상자 4가지 / 판정: 서로 다른 조합 4개
  2. 겉넓이가 가장 작은 상자 / 판정: 2×3×4(52) 또는 그보다 작은 조합 없음 확인
  3. "부피가 같으면 겉넓이도 같다"는 맞을까 / 판정: "아니다" + 예시 두 상자
- **CPA 페이딩:** P: 기록표 / A: 계산만
