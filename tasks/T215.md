## 목표
E13 `length` 모드에 `roll-circle` 변형을 더한다. g6s2u5.A1(T216)에 쓴다.
- 지름을 고른 굴렁쇠를 한 바퀴 굴리면 바닥 자에 물감 자국 두 개가 찍힌다.
- 자국 사이(원주)에 지름 막대를 이어 놓아 몇 번 들어가는지 본다.
- 기록표에 지름, 원주, 원주 ÷ 지름이 쌓인다.

## 구현 결정 (2026-11-20 Claude 작성 — 여기 적힌 대로 하고, 바꿔야 하면 메모에 이유를 적고 멈춰서 묻는다)

### 1. 공통
- 앞 카드의 E13 공통 규칙을 따른다(Rational 측정값, 판 맞춤, T199 CSS, 입력, 정답 노출 금지).
- 새 코드는 `length/roll-circle/` 폴더에 둔다. 기존 `length` 파일은 변형 나누기 줄만 고친다. `variant`가 없으면 지금 동작 그대로다.
- 샌드박스 모드 상자에 "굴렁쇠"를 더한다(설정은 `length` + `variant:'roll-circle'`). 도구 줄만 밀린 기준 이미지는 다시 찍어도 된다(메모에 적는다).

### 2. 설정
`{ mode:'length', variant:'roll-circle', diameters:string[], unit:'cm', precision:'0.01'|'0.001', diameterStickTool?:boolean, log?:boolean }`
- `diameters`: 정수 cm 문자열 1~10, 1~6개, 중복 없음. 어기면 설정 오류다.
- `precision`: 기록표 "원주 ÷ 지름" 칸의 반올림 자리다. 기본 `'0.01'`.
- `diameterStickTool`, `log`: 기본 true.

### 3. 측정 규칙 (부동소수 금지)
- 원주율 근삿값은 Rational 상수 `PI_APPROX = "3.14159265358979"`로 둔다(`roll-circle/pi.ts`).
- **측정 원주** = 지름 × PI_APPROX를 **0.1cm(바닥 자 mm 눈금)로 반올림**한 값이다. 실제 자로 잰 값처럼 보이게 하려는 것이다.
  - 2 → 6.3, 3 → 9.4, 5 → 15.7, 8 → 25.1, 10 → 31.4
- **비** = 측정 원주 ÷ 지름을 `precision`으로 반올림한다.
  - 0.01이면 3.15, 3.13, 3.14, 3.14, 3.14 / 0.001이면 3.150, 3.133, 3.140, 3.138, 3.140
  - 값이 조금씩 다른 것이 의도다(MC-CIRCLE-PI-EXACT 토론 재료). 단위 테스트로 위 값을 고정한다.
- 반올림은 기존 `rat.ts`나 `src/core/math` 함수를 쓴다(없으면 `roll-circle/` 안에 순수 함수로 만든다, `src/core/` 수정 금지).

### 4. 화면 (논리 판 1000×600, 높이를 E2E에서 가정하지 않는다)
- **위 구역(굴리기)**: 바닥 자 0~35cm(1cm 숫자, 1mm 작은 눈금), 자 왼쪽 0에 굴렁쇠가 서 있다. 굴렁쇠 둘레 맨 아래에 물감 점 하나.
- **지름 고르기**: 조작 칸에 `diameters` 단추("지름 2cm" 등). 고르면 굴렁쇠 크기가 바뀌고 굴리기 상태가 처음으로 돌아간다(기록표는 남는다).
- **굴리기**: [굴리기] 단추 또는 굴렁쇠를 오른쪽으로 끌기(포인터가 굴렁쇠 지름의 절반 넘게 움직이면 한 바퀴 굴리기로 확정).
  - 애니메이션 1초(굴렁쇠가 돌며 이동), reduced-motion이면 바로 끝 상태.
  - 끝나면 자 위 0과 측정 원주 자리에 물감 자국 둘, 그 사이를 굵은 선으로 잇는다.
  - 굴린 뒤 다시 굴리기는 거절한다(지름을 다시 고르거나 [처음으로]).
- **지름 막대(`diameterStickTool`)**: 굴린 뒤 [지름 막대 잇기] 단추가 켜진다. 누를 때마다 지름 길이 막대를 자국 0부터 이어 놓는다(번호 1, 2, 3…). 최대 4개. 4번째 막대는 자국을 넘어가며 넘친 부분을 빗금으로 보인다. [막대 하나 빼기]도 둔다.
- **기록표(`log`)**: 판 아래 구역에 SVG 표로 그린다(오버레이 정렬 때문에 DOM 표가 아니라 판 안). 칸: 지름(cm) · 원주(cm) · 원주 ÷ 지름. 굴린 뒤 [기록하기]를 누르면 한 줄이 쌓인다. 같은 지름은 한 번만(다시 누르면 거절 안내). 최대 6줄.
- 숫자 노출: 측정 원주·비는 **학생이 굴려 기록한 뒤에만** 보인다. 시작 화면 DOM에는 지름 단추 글 말고 원주·비 숫자가 없다.
- 키보드: 지름 단추·[굴리기]·[지름 막대 잇기]·[막대 하나 빼기]·[기록하기]·[처음으로] 모두 Enter/Space.

### 5. Action·Observation·Predicates
- **Action:** `choose {d}`, `roll`, `stick {delta:1|-1}`, `record`, `reset`(굴리기·막대만 처음으로, 기록표는 남김)
- **Observation:**
  - `mode`, `variant:'roll-circle'`, `diameter`(현재, 문자열)
  - `rolled`, `measuredCm: string|null`
  - `sticks`(놓은 막대 수), `sticksFit`(자국 안에 다 들어간 막대 수 = min(sticks, 3))
  - `log: { d, c, ratio }[]`(문자열), `logCount`
  - `misconceptions: []`
- **Predicates:** `rolled`, `logCountAtLeast {n}`, `logged {d}`, `sticksAtLeast {n}`

### 6. 오버레이
- `diameter-column`(MC-GEO-RADIUS-DIAMETER ②): 기록표 "지름" 칸 전체를 굵은 점선 테두리로 두르고 위에 "지름" 꼬리표를 단다. 기록이 0줄이어도 머리칸에 그린다.
- `pi-precision`(MC-CIRCLE-PI-EXACT ②): 기록표 오른쪽에 "더 자세히(0.001)" 칸을 덧그려 기록된 줄마다 비를 0.001로 보인다. 기록이 2줄보다 적으면 그리지 않는다(빈 그림 대신 아무것도 없음).
- 둘 다 `CanvasAlignedOverlay`로 판과 1px 정렬.

### 7. 테스트
- **단위**
  - 측정 원주 5개 값, 비 0.01·0.001 값(3번 표)
  - 설정 오류: 11, 0, 소수, 중복, 7개
  - 굴리기 전 막대·기록 거절, 다시 굴리기 거절, 같은 지름 기록 거절, 막대 0 아래·4 위 거절
  - `choose`가 굴리기·막대를 처음으로, 기록표는 유지
  - JSON 왕복, predicates
  - View: 시작 DOM에 6.3·15.7·31.4·3.14가 없다.
  - `variant` 없는 `length` 설정은 기존 테스트 그대로 통과
- **E2E**(`measure-lab.spec.ts`에 더함, 3 뷰포트, 샌드박스)
  - 지름 고르기 → 굴리기(단추) → 막대 4개 → 기록, 끌어서 굴리기 한 번
  - 키보드 경로 하나
  - 오버레이 둘 1px 정렬
  - 새 화면 스냅샷(굴린 뒤 + 기록 2줄) × 크롬북·아이패드

### 구현 메모 (Sonnet, 2026-11-21)
- **구조**: `length/roll-circle/`(pi·types·settings·reduce·observe·events·layout·useRollUi·RollBoard·RollView·overlays/diameter-column·pi-precision). 기존 파일은 등록·나누기 줄만 고쳤다(`modes.ts`: `isTrain`을 `variant==='unit-train'`으로 좁히고 `isRoll`·`isPlainLength` 추가, emit의 merges 검사를 `isPlainLength`로, `ModeView.tsx`, `index.ts`, `overlays/adapt.tsx`(`forLength`·`Meter100Overlay`가 roll을 거른다, `forRoll` 추가), `strings.ko.ts`, `View.module.css`에 `.rollMove`·`.rollMarks`). variant 없는 length·mergeRule·unit-train 동작 불변.
- **구현 결정과 다르게 한 것(검수 확인 필요)**
  1. **샌드박스 모드 상자에 "굴렁쇠" 항목을 더하지 않았다.** Observation `mode`가 `'length'`여야 하는데 `fit-canvas`·`openMode`가 `"mode":"<상자 값>"`을 요구해 상자 항목과 어긋난다. unit-train·capacity 변형과 같이 `?config={"variant":"roll-circle"}`로 연다(설정이 `mode`·`variant`뿐이면 지름 2·3·5·8·10 기본). 상자에 꼭 넣어야 하면 Opus 결정 필요. 그래서 기존 기준 이미지를 다시 찍지 않았다.
  2. **판 좌표**: 1cm = 논리 20px, 자 0 눈금 x=125(가장 큰 굴렁쇠가 왼쪽에 걸쳐도 판 안, 지름 10cm 막대 4개가 오른쪽 안). 논리 높이는 설정만으로 정한다: 가장 큰 지름 굴렁쇠 + 자 + (막대 줄) + (기록표: 줄 수 = 지름 수, 최대 6), 600 이하(기본 설정 약 560). 판 최소 높이는 0.6×높이, 오버레이도 같은 `boardHeight`.
  3. **끌어 굴리기**: 포인터가 오른쪽으로 반지름(= 지름의 절반)보다 더 움직이면 끌기 도중 바로 굴린다. 굴린 뒤 [굴리기]·끌기는 "이미 굴렸어요" 안내(Action 안 보냄).
  4. **조작 칸 순서**: 첫 줄에 지름 단추, 둘째 줄에 [굴리기]·[지름 막대 잇기]·[막대 하나 빼기]·[기록하기]·[처음으로], 그 아래 안내 글(첫 줄이 첫 화면에 보이게).
  5. 같은 지름을 다시 고르면(굴리지 않은 상태) 아무 일도 없다. 굴린 뒤 같은 지름을 고르면 처음으로 돌아간다. `reset`은 지름·기록표를 남긴다.
  6. 물감 자국은 DOM에는 굴린 즉시 생기되 CSS로 1초 뒤에 보인다(움직임 줄이기면 바로). 굴렁쇠는 CSS 전환(이동 1초 + 한 바퀴 회전).
  7. 측정 원주 문자열은 소수 첫째 자리까지 쓴다("22.0"도 그대로). 지름 단추·표 머리·막대 번호만 학생 화면 글이고, 굴리기 전 DOM·aria·data-에 원주·비 숫자가 없다(단위 테스트 + E2E 검사). 굴린 뒤 기록 전에도 없고, Observation `measuredCm`은 굴린 뒤에만 값이 있다.
