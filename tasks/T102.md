3. **circle 상태·Action:**
   - **상태 `CircleState`:** `mode: 'circle'`, `tool: 'rope' | 'radius' | 'chord' | 'compass'`, `ropeLength`, `traces: Record<string, number[]>`(밧줄 길이별로 지나간 부채꼴 번호, 정렬·중복 없음), `radii: number[]`(반지름 끝의 `pos`, 0~47, 중복 없음), `measured: number[]`(길이를 잰 반지름 `pos`), `chord: [number, number] | null`(두 끝의 `pos`), `compass: { center: [number, number]; width: number }`(반 칸 단위 정수), `circles: { id, center: [number, number]; radius: number }[]`(반 칸 단위), `nextId`, `settings`.
   - **도구:** 설정에서 켠 것만 도구 단추로 나온다(`ropeLength`→rope, `measureTool`→radius, `chordExplorer`→chord, `compass.enabled`→compass). 첫 도구가 처음 도구다.
   - **Action:** `select-circle-tool {tool}`, `set-rope {length}`(`ropeLengths`에 있을 때만), `trace {sector}`(0~71 정수, 5°마다 한 칸), `clear-trace`, `add-radius {pos}`, `measure-radius {pos}`, `set-chord {end: 0 | 1, pos}`(chord가 null이면 `[0, 17]`에서 시작), `set-compass {center?, width?}`, `draw-circle`, `remove-circle {id}`.
   - **밧줄(`traceDots`):** 말뚝에서 손가락 방향으로 밧줄을 그린다. 손가락이 밧줄 길이의 0.9배 이상 멀 때만 "팽팽"이고, 그때 밧줄 끝(정확히 r 거리, 화면 계산)에 점을 찍고 그 방향의 부채꼴 번호로 `trace`를 보낸다(새 칸에 들어갈 때만 → 한 바퀴에 Action 최대 72개). 더 멀리 가도 끝은 r에서 멈춘다(늘어나지 않음). 가까우면 밧줄을 처진 곡선으로 그리고 점을 찍지 않는다. 화면 궤적 좌표는 저장하지 않는다(부채꼴 번호만).
   - **커버리지:** `coverage = floor(traces[r].length × 100 / 72)` 정수 퍼센트. 판정은 `traces.length × 100 ≥ percent × 72` 정수 비교.
   - **원 위의 점:** 모두 `circlePoint(stake, (r, 0), pos)`(T101). 그래서 좌표가 유리수이고 반지름 길이²는 정확히 r²이다. `pos`와 `pos+24`는 정확히 지름의 양 끝이다.
   - **반지름(`measureTool`):** 원 위를 누르면 가장 가까운 `pos`로 `add-radius`. `measureTool`이면 반지름을 누르거나 Enter로 `measure-radius` → 그 반지름 옆에 길이 글자(`dist2`의 정확한 제곱근이 정수면 "4칸"). 학생이 잰 것만 보인다.
   - **현(`chordExplorer`):** 두 끝 손잡이를 원 위로 끈다. 길이 막대(`data-testid="chord-bar"`)는 현 길이에 비례하고, 막대 틀은 지름의 1.25배 길이로 둔다(막대 끝이 "최대"를 알려 주지 않게). 숫자는 쓰지 않는다. `snapDiameter`면 끈 끝이 맞은편 끝의 반대 자리(`pos ± 24`)에서 2칸 안일 때 그 자리로 붙이고, 현이 중심을 지나면(`pointOnSegment(stake, P1, P2)`) "지름" 이름표를 단다. `snapDiameter`가 없으면 붙임·이름표 없음(판정은 똑같이 정확).
   - **컴퍼스(`compass`):** 침(중심)과 연필 다리를 따로 끈다. 침은 `gridSnap` 간격 점에, 벌린 폭은 `gridSnap` 단위로 붙는다(반 칸 정수로 저장). "원 그리기" 단추가 `draw-circle`. 같은 원은 다시 만들지 않는다. 최대 8개. 컴퍼스 다리 그림의 침~연필 거리가 곧 반지름으로 그려진다.
   - **무늬(`targetPattern`):** 제시 원들을 회색 점선으로만 그린다(중심 점·반지름은 그리지 않는다 — 찾는 것이 과제다). 학생 원이 제시 원과 중심·반지름이 정확히 같으면 그 제시 원을 실선 + 체크 무늬로 바꾼다(학생 조작의 결과). `three-circles-in-row`는 반지름 R = `radius ?? 3`, 중심 (c−R, c), (c, c), (c+R, c), c = 격자 가운데.
4. **circle 키보드:** 도구는 Tab으로 가는 단추. 캔버스 포커스에서:
   - rope: ←/→가 밧줄 끝을 한 부채꼴(5°)씩 돌리며 팽팽하게 `trace`. `[`/`]`가 `set-rope` 이전/다음 길이.
   - radius: ←/→가 원 위 커서 `pos` ±1, Enter `add-radius`, `M` `measure-radius`.
   - chord: `1`/`2`로 끝 고르기, ←/→로 `set-chord`.
   - compass: `N`(침)·`P`(연필) 고르기, 침은 방향키로 `gridSnap`씩, 연필은 ←/→로 폭 ±`gridSnap`, Enter `draw-circle`.
5. **circle Observation:** `mode`, `tool`, `ropeLength`, `coverage: Record<string, number>`, `radii: { pos, length2 }[]`, `distinctRadii`, `measuredCount`, `chord: { length2: string, throughCenter: boolean } | null`, `compassWidth: string`(Rational 문자열, 칸 단위), `circles: { center: [string, string], radius: string }[]`, `patternTotal`, `patternMatched: number[]`(1부터).
6. **circle Predicates·이벤트:**
   - `coverageAtLeast {percent, ropeLength?}` — 그 밧줄 길이(없으면 현재)의 커버리지

7. **`angle` 모드 — 각도는 정수 도(°)로 정의한다:**
   - 격자 좌표로 만든 각의 도 값은 대개 무리수다. 그래서 이 모드의 각은 **설정이 정수 도로 준다.** 수학 값(각 크기, 읽은 값, 어림값, 발사 각)은 모두 정수이고 비교도 정수로 한다. 변을 그릴 때만 `Math.cos`/`Math.sin`(화면 number)을 쓴다.
   - **설정 `AngleConfig`:** `mode: 'angle'`(필수), `tool?: 'protractor'`(유일한 값), `angles?: { id?: string; degrees: number; base?: number; arms?: [number, number] }[]`(1~6개, `degrees` 1~180 정수, `base`는 첫 변 방향 0~359 정수(0 = 오른쪽, 화면에서 반시계), `arms`는 변 길이 비율 0.4~1, 기본 [1, 1]. 없으면 `[{id:'a1', degrees: 50}]`), `highlightActiveScale?: boolean`(기본 false), `estimateFirst?: boolean`(기본 false), `puzzle?: { type: 'laser-mirror'; targetAngle: number }`(1~179 정수).
   - **화면:** 각 하나씩 크게 그린다(각 고르기 단추 "각 1, 각 2 …"). 꼭짓점은 캔버스 아래쪽 가운데. 각의 크기·종류 글자는 쓰지 않는다.
   - **각도기(`views/Protractor.tsx`):** 반원판. 기준선 오른쪽 끝 방향 = `rotation`(정수 도). 두 눈금 트랙: 바깥 트랙은 오른쪽 끝에서 0 → 반시계로 180, 안쪽 트랙은 왼쪽 끝에서 0 → 시계로 180. 10° 숫자, 5°·1° 눈금. 판은 반투명.
     - 트레이에서는 숫자 없는 작은 아이콘이다. 끌어 각에 올린다. 중심이 꼭짓점에서 터치 반경 안이면 꼭짓점에 붙는다(`place-protractor`). 손잡이를 끌어 돌린다. View는 변 방향과 4° 안이면 그 방향으로 붙인다(화면 편의).
     - **맞춤(aligned):** 한 변 방향이 `rotation`(→ 바깥 트랙이 활성) 또는 `rotation+180`(→ 안쪽 트랙이 활성)과 정확히 같고, 다른 변이 판이 덮는 반쪽(`rotation`~`rotation+180`)에 있을 때. 정수 비교.
     - `highlightActiveScale`이면 맞춤일 때 활성 트랙만 굵게·배경 띠, 다른 트랙은 흐리게(투명도 + 가는 글자 — 색만이 아님). 맞춤이 아니면 둘 다 보통.
   - **어림·읽은 값:** `NumberStepper`(−10, −1, +1, +10 단추와 값 칸, 처음 "?") 두 개: "어림한 각"과 "잰 각". `estimateFirst`면 어림을 정하기 전에는 "잰 각"이 비활성이고 reduce도 거절한다. 0~360 정수.
   - **상태 `AngleState`:** `mode: 'angle'`, `current`(각 인덱스), `protractor: { on: string | null; rotation: number }`(`on`은 각 id 또는 `'launcher'`), `entries: Record<string, { estimate: number | null; reading: number | null; readingAligned: boolean | null }>`, `puzzle: { estimate: number | null; fired: number[] } | null`, `settings`.
   - **Action:** `select-angle {index}`, `place-protractor {on}`, `lift-protractor`, `rotate-protractor {rotation}`(0~359 정수), `set-estimate {angle, value}`, `set-reading {angle, value}`(그때의 맞춤 여부를 `readingAligned`에 저장), `set-launch-estimate {value}`, `fire {angle}`.
   - **예각·직각·둔각 판정:** `kind = degrees < 90 ? 'acute' : degrees === 90 ? 'right' : degrees < 180 ? 'obtuse' : 'straight'`. Observation에만 둔다. g4s1u2.A1-3의 "분류 6장"은 응답 `sort` 위젯 몫이다(엔진이 카드를 만들지 않는다, 메모).
8. **레이저 퍼즐 (`puzzle.type: 'laser-mirror'`) — 가장 단순한 판으로 좁힌다:**
   - 명세 과제 A1-4는 "입력 135 또는 거울 각 일치"다. **발사 각 입력만 만든다. 거울(반사)은 이번 카드에서 만들지 않는다**(W3 과제는 발사 각만으로 판정 가능, 메모).
   - 화면: 왼쪽 아래 발사대, 오른쪽으로 바닥선(0° 쪽 변), 과녁 별은 발사대에서 `targetAngle` 방향 먼 곳. 과녁까지의 선은 그리지 않는다.
   - 학생은 각도기를 발사대에 올릴 수 있다(`place-protractor {on: 'launcher'}` — 첫 변 = 바닥선, 둘째 변 없음, 맞춤은 바닥선으로만 판단).
   - "발사 각" 스테퍼 + "쏘기" 단추 → `fire {angle}`. `estimateFirst`면 `set-launch-estimate` 먼저. 빛은 그 각으로 화면 끝까지 그린다(반사 없음). `angle === targetAngle`이면 별이 채워지고 체크 무늬. `prefers-reduced-motion`이면 애니메이션 없이.
9. **angle 키보드:** 캔버스 포커스에서 Enter는 각도기를 현재 각(또는 발사대)에 올리기/내리기, 올린 동안 ←/→ 1°, Shift+←/→ 15° 돌리기. 스테퍼·쏘기·각 고르기는 Tab 단추.
10. **angle Observation:** `mode`, `current`, `protractorOn`, `protractorAligned: boolean`, `activeScale: 'outer' | 'inner' | null`, `angles: { id, degrees, kind, estimate, reading, readingError, estimateError, readingAligned, flipped }[]`(`flipped`는 `reading === 180 − degrees && degrees !== 90`), `puzzle: { targetAngle, estimate, fired: number[], hit: boolean } | null`. `degrees`·`kind`는 Observation에만 있고 화면 글자로 쓰지 않는다.
11. **angle Predicates·이벤트:**
    - `readingsWithin {tolerance}` — 모든 각에 읽은 값이 있고 |오차| ≤ tolerance(A1-1은 1)
    - `readingWithin {angle, tolerance}`, `estimatesWithin {tolerance}`(A1-2는 30), `estimatedBeforeReading`
    - `readingFlipped` — 하나라도 `flipped`(MC-ANGLE-WRONG-SCALE 감지용)
    - `readWithoutAlign` — 하나라도 `readingAligned === false`(MC-ANGLE-ZERO-LINE 감지용)
    - `laserHit` — 마지막 발사가 맞음
    - 이벤트: `reading-set {angle, value}`, `laser-fired {angle, hit}`
12. **오버레이 (힌트 ②, 학생이 만든 것만, 정답 값·지름·목표를 그리지 않는다, 모두 `CanvasAlignedOverlay`):**
    - `radius-pair` (MC-GEO-RADIUS-DIAMETER): 학생이 마지막으로 그은 반지름(없으면 현의 한 끝)의 방향으로 중심 양쪽에 반지름 두 개를 이어 붙여 그리고 각각 "반지름" 이름표. 숫자 없음. 그은 것이 없으면 아무것도 그리지 않는다.
    - `chord-gap` (MC-GEO-DIAMETER-ANY-CHORD): 학생의 현에서 중심 점을 강조하고, 중심에서 현까지 점선 수선과 "중심에서 떨어져 있어요" 글자. **명세의 "중심 통과 선분을 겹쳐 비교"는 A2-1의 답(지름 자리)을 그리므로 하지 않는다(메모).**
    - `compass-width` (MC-GEO-COMPASS-WIDTH): 학생이 마지막에 그린 원(없으면 현재 컴퍼스)에 침~연필 선분을 굵게, 같은 선분을 원의 반지름 자리에 겹쳐 그리고 "컴퍼스 폭" 이름표.
    - `active-scale` (MC-ANGLE-WRONG-SCALE): 각도기를 올린 상태에서 학생이 맞춘 변(맞춤이 아니면 0° 선에 더 가까운 변) 쪽에서 0으로 시작하는 트랙만 남기고 다른 트랙을 흐리게 덮는다. 읽을 값 자리는 표시하지 않는다.
    - `zero-gap` (MC-ANGLE-ZERO-LINE): 각도기 0° 선과 가장 가까운 변 사이를 빗금 부채꼴로 칠한다(빨강 + 빗금). 맞춤이면 아무것도 그리지 않는다.
    - `equal-arms` (MC-ANGLE-SIDE-LENGTH): 설정 각이 2개 이상일 때 처음 두 각을 두 변 길이를 같게 잘라 같은 꼭짓점에 겹쳐 그린다(반투명 두 색 + 선 무늬 다르게).
