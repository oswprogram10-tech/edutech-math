## 목표
g1s1u2.A2 「굴리고 쌓아 보기」를 위해 E12에 확장 모드 `shapes-sort`를 더한다.
- 학생은 상자·둥근기둥·공 모양을 경사로에 올려 ▶를 누르고, 굴러가는지 멈추는지 본다. 둥근기둥은 세우거나 눕힐 수 있다.
- 쌓기 탑에 모양을 올리면 쌓이거나 굴러떨어진다.
- 가린 상자 속 모양을 "만져 보기"로 단서를 모아 맞힌다.

물리 엔진은 쓰지 않는다. 결과는 정해진 규칙의 결정적 연출이다. 1학년 화면이라 저학년 모드(64px 타깃)를 기준으로 한다.

### 2. 모양과 규칙 (`shapes/rules.ts`)
- 모양 `ShapeKind`: `'box' | 'cylinder' | 'sphere'`. 놓는 방향 `Pose`:
  - box: `'flat'`만
  - cylinder: `'standing'` 또는 `'lying'`
  - sphere: `'any'`만
- 물건 `ShapeItem`: `{ id, kind, color: 'red'|'blue'|'yellow'|'green', size: 'small'|'large' }`
  - 색과 크기는 판정에 쓰지 않는 방해 속성이다(MC-SHAPE-BY-COLOR-SIZE).
- **경사로 결과 `rampResult(kind, pose)`**
  - sphere → `'roll'`
  - cylinder lying → `'roll'`
  - cylinder standing → `'stay'`
  - box → `'stay'`
- **쌓기 `canStackOn(below, item)`** (below가 null이면 바닥)
  - 위가 평평한 받침: 바닥, box, standing cylinder
  - 아래가 평평한 물건: box, standing cylinder, lying cylinder
  - sphere는 바닥에만 머문다. 다른 물건 위에 올리면 떨어진다.
  - 평평한 받침 위에 아래가 평평한 물건을 올리면 머문다. lying cylinder는 평평한 받침 위에 머문다.
  - sphere나 lying cylinder 위에는 아무것도 머물지 않는다.
  - 떨어진 물건은 탑에 들어가지 않고 탑 옆 바닥으로 굴러간다(연출). 상태에는 `fallen` 기록으로 남는다.
- **만져 보기 단서 `cluesOf(kind)`**
  - box: `['flat', 'pointy']`(평평한 곳, 뾰족한 곳)
  - cylinder: `['flat', 'round']`
  - sphere: `['round']`
  - 단서는 순서가 정해진 목록이다. 학생이 "만져 보기"를 한 번 누를 때마다 하나씩 드러난다. 다 드러나면 더 누를 수 없다.
- **그림자** (`mystery.shadow`가 있을 때): 가린 상자 옆에 그 모양의 정해진 방향 그림자를 그린다.
  - 위에서: box 사각형, cylinder 원, sphere 원
  - 옆에서: box 사각형, cylinder 사각형, sphere 원
  - 단서와 그림자는 정답 모양의 이름을 쓰지 않는다. 그림자 하나만으로는 답이 하나로 정해지지 않도록 콘텐츠가 고른다.

### 3. 설정 `ShapesSortConfig`
| 키 | 형 | 기본 | 뜻 |
| --- | --- | --- | --- |
| `mode` | `'shapes-sort'` | — | 필수 |
| `scene` | `'ramp' \| 'tower' \| 'ramp-and-tower' \| 'mystery'` | `'ramp-and-tower'` | 명세 예시의 `ramp-and-tower`도 받는다 |
| `objects` | `ShapeItem[]` 또는 `ShapeKind[]` | `["box","cylinder","sphere"]` | 선반에 놓일 물건. 종류만 주면 색과 크기를 차례로 정한다(빨강 큰 것부터) |
| `towerMax` | 1~5 | 4 | 탑 칸 수 |
| `mystery` | `{ kind, shadow?: 'top'\|'side' } \| null` | null | `scene:'mystery'`일 때 가린 모양 |
| `physics` | | | 받기만 하고 무시한다(`"scripted"`) |

### 4. 상태·Action
```ts
ShapesState = {
  mode:'shapes-sort'; settings;
  selected: string | null;               // 선반에서 고른 물건 id
  pose: Record<id, Pose>;                // 둥근기둥 방향(기본 standing)
  rampItem: string | null; rampPlayed: boolean;
  trials: { id; kind; pose; result: 'roll'|'stay' }[];   // ▶ 기록(최대 20)
  tower: string[];                        // 아래부터
  fallen: { id; kind; pose }[];           // 떨어진 기록(최대 20)
  cluesShown: number;                     // mystery
}
```
| Action | 동작 |
| --- | --- |
| `ss-select {id}` | 선반 물건 고르기. 같은 것을 다시 누르면 고르기를 푼다 |
| `ss-set-pose {id, pose}` | 그 모양에 허용된 방향일 때만 |
| `ss-place-ramp` | 고른 물건을 경사로 꼭대기에 둔다(이미 있으면 바꾼다). `rampPlayed=false` |
| `ss-play` | 경사로에 물건이 있으면 `trials`에 결과를 더하고 `rampPlayed=true` |
| `ss-reset-ramp` | 경사로를 비운다 |
| `ss-stack` | 고른 물건이 탑에 없을 때 `canStackOn(맨 위, 물건)`이면 탑에 올리고, 아니면 `fallen`에 더한다. `towerMax`를 넘으면 무시한다 |
| `ss-unstack` | 맨 위 하나를 내린다 |
| `ss-clear-tower` | 탑과 `fallen`을 비운다 |
| `ss-touch` | mystery 단서 하나 더 보기 |

- 한 물건은 경사로와 탑에 동시에 있을 수 없다. 탑에 올리면 경사로에서 빠지고, 경사로에 두면 탑에서 빠진다(맨 위일 때만, 아니면 무시).
- 상태는 JSON 직렬화가 되어야 한다.

### 5. 화면 `ShapesView`
- **물건 그림 `ShapeIcon`(SVG):**
  - box: 직육면체 등각 그림
  - cylinder: 세우면 위에 타원, 눕히면 옆에 타원
  - sphere: 원과 하이라이트
  - 색은 4가지, 크기는 2가지다.
  - 색만으로 알리지 않는다. 모양 자체가 다르고, 고른 물건은 굵은 테두리와 ✓로 표시한다.
- **선반:** 아래쪽 줄에 물건 단추를 둔다. 64px 이상이고 `aria-label`은 "빨간 큰 상자 모양"처럼 쓴다. 둥근기둥을 고르면 "세우기/눕히기" 두 단추(그림 포함)가 나온다.
- **경사로(`RampScene`):**
  - 왼쪽 위에서 오른쪽 아래로 내려가는 경사로와 바닥이 있다. "경사로에 올리기"와 ▶ 단추를 둔다.
  - ▶를 누르면 1.2초 연출을 한다. roll이면 굴러 내려가 바닥 끝까지 가고, stay면 그 자리에 머물며 살짝 흔들린다.
  - `prefers-reduced-motion`이면 끝 위치로 바로 간다.
  - 결과 글("굴러가요"/"멈춰 있어요")은 쓰지 않는다. 학생이 보고 판단한다. 대신 지난 시도 기록을 작은 그림 줄로 보인다(물건 그림 + 끝 위치 그림).
- **탑(`TowerScene`):**
  - 바닥 위에 탑 칸을 그린다. "탑에 올리기"·"맨 위 내리기"·"모두 내리기" 단추를 둔다.
  - 떨어지는 물건은 0.8초 동안 미끄러져 탑 옆으로 굴러간다. reduced-motion이면 바로 옆에 놓는다.
  - 탑 높이 수는 쓰지 않는다.
- **가린 상자(`MysteryBox`):**
  - 천을 덮은 상자 그림과 "만져 보기" 단추를 둔다.
  - 드러난 단서는 큰 그림 카드로 보인다: 평평한 곳(평평한 손바닥 그림), 뾰족한 곳(모서리 그림), 둥근 곳(곡선 그림). 짧은 글도 함께 쓴다.
  - 단서 문구는 `strings.ko.ts`에 둔다(예: "평평한 곳이 있어요").
  - `shadow`가 있으면 그림자 칸을 둔다.
- **배치:**
  - `ramp-and-tower`: 왼쪽 경사로, 오른쪽 탑, 아래 선반
  - 단일 장면이면 장면이 넓게 차지한다.
  - 크롬북 `?stage=fit`과 아이패드 세로에서 장면·선반·주요 단추가 `ratio:1`이어야 한다.
- **키보드:**
  - 선반: 좌우 방향키로 고르기
  - S/L: 세우기/눕히기
  - R: 경사로에 올리기
  - Space: ▶
  - T: 탑에 올리기
  - U: 내리기
  - M: 만져 보기
- **test id:** `ss-shelf-{id}`(`aria-pressed`), `ss-pose-standing`/`lying`, `ss-ramp`, `ss-ramp-place`, `ss-play`, `ss-ramp-item`(`data-result`는 넣지 않는다), `ss-tower`, `ss-tower-stack`, `ss-tower-unstack`, `ss-tower-clear`, `ss-tower-slot-{i}`, `ss-mystery`, `ss-touch`, `ss-clue-{i}`, `ss-shadow`
- **문구:** 모두 `strings.ko.ts`의 `solid3dStrings.shapes`에 둔다. 1학년이 읽을 수 있는 쉬운 말을 쓴다.

### 구현 메모 (소넷, 구현 결정과 다르거나 명세가 열어 둔 곳)
- **장면 막기:** `ss-place-ramp`·`ss-play`·`ss-reset-ramp`는 `scene`에 경사로가 없으면, `ss-stack`·`ss-unstack`·`ss-clear-tower`는 탑이 없으면, `ss-touch`는 `mystery` 장면이 아니거나 `mystery` 설정이 없으면 무시한다(명세는 말이 없어 가장 안전하게 막았다).
- **탑 위 물건은 방향을 못 바꾼다:** 쌓인 물건의 모양이 바뀌는 것을 막으려고 `ss-set-pose`는 탑에 있는 물건이면 무시한다. 경사로에 있는 물건의 방향을 바꾸면 `rampPlayed`를 false로 되돌린다.
- **탑이 가득 찼을 때:** `tower.length >= towerMax`이면 `ss-stack`은 쌓이는지 떨어지는지와 상관없이 무시한다.
- **`ss-stack`은 경사로에서도 뺀다:** 경사로에 있던 물건을 탑에 올리면(떨어져도) 경사로에서 빠진다.
- **`towerAllFlatStackers`는 탑이 비어 있으면 false**(빈 탑이 저절로 통과하지 않게).
- **`towerKinds`·`triedKinds`·`rolledKinds`는 중복 없이 처음 나온 순서**다. `trials`·`fallen`은 20개를 넘으면 오래된 것부터 버린다.
- **`objects`에서 종류만 줄 때:** id는 종류 이름(`box`), 같은 종류가 또 나오면 `box-2`. 색은 빨강·파랑·노랑·초록 순환, 크기는 큰 것·작은 것 번갈아.
- **움직임 줄이기 판정:** `matchMedia`가 없으면(jsdom) 줄이기로 본다(다른 E12 모드와 같음).
- **접근성 글:** 지난 시도 그림(끝 위치)에만 `aria-label`로 "경사로 위쪽/바닥 끝"을 달았다. 화면에 보이는 결과 글은 없다.
- **fixed-volume 앵커(10번):** 무대(상자 그림)를 `sv-fixed-stage` 칸으로 감싸고 그 안에 빈 `sv-fixed-stage-anchor` svg를 `position:absolute; inset:0`으로 두었다. 기존 스냅샷은 바뀌지 않았다.
