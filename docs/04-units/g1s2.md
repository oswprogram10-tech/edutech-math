## g1s2u1 100까지의 수
| 항목 | 내용 |
| --- | --- |
| 영역 | 수와 연산 |
| 엔진 | E01 수 모형, E15 규칙·패턴, E02 셈돌·텐프레임·구슬셈판 |
| 선수 단원 | g1s1u5 50까지의 수 |
| 차시 규모(참고) | 약 9~10차시 중 앱 활용 3~4차시 (교과서 확인) |

**핵심 아이디어:** 99 다음은 10개씩 묶음 10개 = 100. 수 배열표에서 오른쪽은 1씩, 아래는 10씩 커진다. 둘씩 짝지을 때 남는 것이 없으면 짝수, 하나 남으면 홀수.

### 활동
#### g1s2u1.A1 십 모형으로 99와 100 — E01 `count`, `regroup` · C→P→A
- **원 계획서:** (100까지의 수 단원 공통 표상 — 원 계획서 십모형 조작을 이 단원에 확장)
- **화면과 조작:** 10막대·낱개를 끌어 수 만들기. 10막대 10개를 올가미로 감싸면 처음으로 '100' 표시(1학년은 100판 합체 연출만, 백 모형 용어 없이 "백"). 자릿값 표는 두 칸(묶음/낱개).
- **설정 예시:**
  ```json
  { "mode": "count", "allowedBlocks": [1, 10], "maxValue": 100, "lasso": true, "chart": ["tens", "ones"], "allowHundredReveal": true }
  ```
- **과제:**
  1. 68 만들기 / 판정: 값 == 68, 정규형
  2. "75는 10개씩 묶음 몇 개?" / 판정: 입력 == 7
  3. 99에 1을 더 놓고 묶어 보기 / 판정: 최종 묶음 10개 상태 → "100" 입력
  4. 57과 75 중 큰 수 블록으로 비교 / 판정: 선택 == 75
- **CPA 페이딩:** C: 사탕 블록 / P: 막대·점 / A: 표 숫자만

#### g1s2u1.A2 백 수 배열표 숨바꼭질 — E15 `hundred-chart` · P→A
- **원 계획서:** 10×10 백 수 배열표 십자(±1, ±10) 숨바꼭질
- **화면과 조작:** 1~100 배열표에서 일부 칸이 나뭇잎으로 가려짐. 가려진 칸을 누르고 수 입력. 십자 모양(위·아래·왼쪽·오른쪽)만 보이고 가운데를 맞히는 '십자 퀴즈'.
- **설정 예시:**
  ```json
  { "mode": "hundred-chart", "range": [1, 100], "hidden": "cross", "center": 46, "revealOnAnswer": true }
  ```
- **과제:**
  1. 가로줄 빈칸(41, 42, □, 44) / 판정: 43
  2. 세로줄 빈칸(23, 33, □, 53) / 판정: 43
  3. 십자 퀴즈: 위 36·아래 56·왼 45·오른 47 → 가운데 / 판정: 46
  4. "68보다 10 큰 수 칸을 눌러요." / 판정: 누른 칸 == 78
  5. 가려진 수 3개 동시(무작위) / 판정: 모두 일치
- **CPA 페이딩:** P: 배열표 전체 / A: 배열표 없이 십자만

#### g1s2u1.A3 둘씩 짝짓기 행진 — E02 `pairing` · C→P
- **원 계획서:** 짝수·홀수 둘씩 짝짓기 행진
- **화면과 조작:** 아이 캐릭터 n명이 '짝 만들기' 버튼을 누르면 둘씩 손을 잡고 행진(결정적 애니메이션). 짝 없는 아이가 남으면 깃발이 섬. 학생은 먼저 "남을까?"를 예측.
- **설정 예시:**
  ```json
  { "mode": "pairing", "count": 13, "predictFirst": true, "labels": ["짝수", "홀수"] }
  ```
- **과제:**
  1. 8명 짝짓기 → 짝수/홀수 / 판정: 선택 == 짝수
  2. 13명 예측 후 확인 / 판정: 예측 == 홀수
  3. 20까지 짝수 칸 색칠(배열표 연동) / 판정: 칠한 칸 == {2,4,…,20}
  4. "끝자리가 7인 수는?" / 판정: 홀수
- **CPA 페이딩:** C: 캐릭터 / P: 점 2열 / A: 수만 보고 판단

**핵심 아이디어:** 두 자리 수끼리 더할 때는 묶음끼리, 낱개끼리 더한다. 수직선에서는 10씩 크게 뛰고 1씩 작게 뛰어 더하고 뺄 수 있다.

| g1s2u2.jump-strategy | 수직선에서 10씩·1씩 뛰어 더하고 빼기 | g1s2u1.chart-structure |

### 활동
#### g1s2u2.A1 자석 스냅 수 모형 덧셈·뺄셈 — E01 `add-sub` · C→P→A
- **원 계획서:** 십모형·일모형 자석 스냅 조립기
- **화면과 조작:** 두 수를 블록으로 놓고 '모으기' 칸으로 끌면 묶음은 묶음 칸, 낱개는 낱개 칸에 자석처럼 붙는다. 뺄셈은 뺄 만큼 블록을 끌어 휴지통으로. 화면 아래 덧셈식 카드가 블록과 동기화.
- **설정 예시:**
  ```json
  { "mode": "add-sub", "op": "add", "a": 32, "b": 25, "regroupAllowed": false, "snapColumns": true, "equationCard": "sync" }
  ```
- **과제:**
  1. 32 + 25 / 판정: 결과 블록 값 == 57, 입력 57
  2. 40 + 30 / 판정: 70
  3. 68 − 23 / 판정: 남은 블록 == 45
  4. 57 − 7 / 판정: 50
  5. 블록 없이 식만 `24 + 15 = □` / 판정: 39
- **CPA 페이딩:** C: 블록 / P: 막대·점 그림 / A: 식만

#### g1s2u2.A2 수직선 개구리 점프 — E03 `integer` · P→A
- **원 계획서:** 수직선 점프 개구리 시뮬레이터
- **화면과 조작:** 0~100 수직선 위 개구리. '10칸 점프' 큰 버튼과 '1칸 점프' 작은 버튼, 또는 화살표를 끌어 점프 그리기. 점프 기록이 식으로 바뀐다(`35 → +10 → +10 → +3 = 58`).
- **설정 예시:**
  ```json
  { "mode": "integer", "min": 0, "max": 100, "unit": "1", "labels": "tens-only", "jumps": { "allowed": [1, 10, -1, -10], "drawFreeArrow": true } }
  ```
- **과제:**
  1. 35에서 23만큼 뛰기 / 판정: 마지막 위치 == 58
  2. "10 점프를 가장 많이 써서" 46 + 32 / 판정: 위치 == 78, 10 점프 수 == 3
  3. 87 − 34 (뒤로 뛰기) / 판정: 53
  4. 점프 기록을 보고 식 고르기 / 판정: 선택 식이 점프 합과 동치
- **CPA 페이딩:** P: 눈금 모두 / A: 빈 수직선(10의 배수만) → 식만

### 활동
#### g1s2u3.A1 칠교·패턴 블록 그림자 퍼즐 — E11 `tangram` · C→P
- **원 계획서:** 칠교판·패턴 블록 그림자 퍼즐
- **화면과 조작:** 그림자(실루엣) 위로 조각을 끌어 넣기. 조각 두 번 탭 = 45° 돌리기, 뒤집기 버튼. 맞는 자리 근처에서 자석 스냅. 다 채우면 실루엣이 그림(집, 고양이, 배)으로 변신.
- **설정 예시:**
  ```json
  { "mode": "tangram", "pieceSet": "pattern-blocks", "silhouette": "house", "snapTolerancePx": 24, "rotationStep": 30, "showPieceOutlines": "first-task-only" }
  ```
- **과제:**
  1. 세모 2개로 네모 만들기 / 판정: 외곽이 정사각형, 조각 2개
  2. 집 실루엣(조각 테두리 보임) / 판정: 실루엣 넓이 100% 채움, 겹침 없음
  3. 고양이 실루엣(테두리 없음) / 판정: 위와 같음
  4. "뾰족한 곳이 3개인 조각을 모두 눌러요." / 판정: 선택 == 모든 세모 조각
- **CPA 페이딩:** C: 색 조각 / P: 실루엣만 / A: 해당 없음

#### g1s2u3.A2 톱니 연동 시계 — E14 `clock` · C→P→A
- **원 계획서:** 내부 투명 기어 연동 정시·30분 시계
- **화면과 조작:** 시계 판이 반투명해서 안의 톱니가 보인다. 긴바늘을 끌어 돌리면 짧은바늘이 톱니로 천천히 따라 돈다(1바퀴 = 숫자 한 칸). 1학년 설정은 긴바늘이 12와 6에 자석 스냅.
- **설정 예시:**
  ```json
  { "mode": "clock", "granularity": "half-hour", "showGears": true, "snapMinuteTo": [0, 30], "digitalReadout": "after-submit" }
  ```
- **과제:**
  1. "3시를 만들어요." / 판정: 시 == 3, 분 == 0
  2. 시계를 보고 몇 시? (7시) / 판정: 입력 7
  3. "8시 30분을 만들어요." / 판정: 8:30 (짧은바늘이 8과 9 사이)
  4. 짧은바늘만 보이는 시계(4와 5 사이 가운데) → 몇 시 30분? / 판정: 4시 30분
  5. 하루 일과 그림(아침 먹기 등) 순서에 맞는 시계 고르기 / 판정: 순서 일치
- **CPA 페이딩:** C: 톱니 보임 / P: 톱니 숨김 / A: '7:30' 같은 디지털 숫자 ↔ 시계 짝짓기

- 13 − 5: "10에서 빼기" vs "차례로 빼기" 두 학생 화면 비교.
