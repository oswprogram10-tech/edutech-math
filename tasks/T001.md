- 엔진 간 import 금지는 `no-restricted-imports` 대신 자체 ESLint 규칙 `eslint/no-cross-engine-imports.js`로 했다. `no-restricted-imports`는 '지금 파일이 어느 엔진인지'를 몰라서 `../E03-x` 같은 상대 경로를 정확히 막지 못한다. 규칙 테스트: `eslint/no-cross-engine-imports.test.js`.
- 오프라인: `tests/e2e/offline.spec.ts`가 빌드본(preview 서버)에서 서비스 워커 설치 → 오프라인 전환 → 새로고침을 3개 뷰포트에서 자동 검사한다. 실기기 비행기 모드 확인은 별도로 필요.
- **GitHub Pages 주의:** GitHub 무료 계정은 비공개 저장소에서 Pages를 쓸 수 없다(공개 저장소이거나 유료 플랜이어야 함). `docs/08`은 비공개 저장소를 권하므로, 비공개를 유지하려면 배포를 Cloudflare Pages(무료, 비공개 저장소 가능)로 바꿔야 한다.
- 처음 배포 전에 저장소 Settings → Pages → Source를 'GitHub Actions'로 바꿔야 한다(README 배포 절).
- 아이콘은 SVG 자리표시 하나다. iOS 홈 화면 아이콘은 PNG가 필요하므로 정식 아이콘 작업 때 PNG 180/192/512를 추가한다.
- `npm audit`: 개발 의존성(vite-plugin-pwa → workbox-build 빌드 도구)에 moderate 경고 20건. 브라우저 번들에는 들어가지 않는다.
- 셸 JS 46KB(gzip) — 예산 200KB 이내.
- 한글·공백 경로에서도 모든 명령이 동작했다. 단 Git Bash에서 `BASE_PATH=/x/ npm run build`처럼 주면 MSYS가 경로를 `C:/Program Files/Git/x/`로 바꿔 버린다. 로컬에서 base 경로를 시험할 때는 PowerShell을 쓴다(CI는 Linux라 무관).
