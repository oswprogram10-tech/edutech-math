### 활동
#### g4s1u1.A1 4자리 컬러 슬라이서 — E01 `big-number` + `place-chart` · P→A
- **원 계획서:** 한국어 4자리(만·억·조) 컬러 슬라이서
- **화면과 조작:** 긴 숫자 띠(예: 3528007140000)가 나타난다. 학생이 오른쪽에서부터 슬라이서 칼을 끌어 네 자리씩 자르면 각 덩어리가 색(일 회색·만 초록·억 파랑·조 보라)으로 칠해지고 단위 이름표가 붙는다. 덩어리 안의 숫자는 "천·백·십·일" 칸으로 펼쳐 볼 수 있다. 읽기 버튼을 누르면 TTS가 읽어 준다. 역방향: 학생이 "삼조 오천이백팔십억 칠백십사만"을 듣고 자릿값 표에 숫자 카드를 놓아 수를 만든다(빈 자리는 0 카드).
- **설정 예시:**
  ```json
  { "mode": "big-number", "value": "3528007140000", "slicer": "student", "groupColors": ["gray", "green", "blue", "purple"], "tts": true, "reverse": { "spoken": "삼조 오천이백팔십억 칠백십사만" } }
  ```
- **과제:**
  1. 52840000을 네 자리씩 잘라 읽기 / 판정: 자른 위치 일치 + 읽기 선택지 "오천이백팔십사만"
  2. "이천삼십만 오" 를 숫자로 / 판정: 20300005
  3. 3528007140000에서 숫자 5가 나타내는 값 / 판정: 500000000000
  4. 억이 10000개이면 / 판정: 1조
- **CPA 페이딩:** P: 색 덩어리 + 자릿값 표 / A: 숫자만 쓰기·읽기

#### g4s1u1.A2 스케일 줌 수직선 — E03 `log-zoom` + `skip-count` · P→A
- **원 계획서:** 행성 거리·국가 예산 스케일 슬라이더
- **화면과 조작:** 줌아웃하면 수직선 눈금이 1만 → 10만 → 100만 → 1억 … 으로 바뀌며 "우리 학교 학생 수", "우리 시 인구", "대한민국 인구", "지구~태양 거리(km)" 같은 이정표가 차례로 나타난다(이정표 값은 출처와 함께 데이터 파일로 관리). 뛰어 세기 모드에서 10만씩, 100억씩 점프하며 바뀌는 자리를 강조한다. 두 수를 수직선 위에 놓아 크기를 비교한다.
- **설정 예시:**
  ```json
  { "mode": "log-zoom", "range": ["1e4", "1e13"], "landmarks": "data/landmarks-ko.json", "skipCount": { "start": "2340000", "step": "100000", "count": 5 } }
  ```
- **과제:**
  1. 234만에서 10만씩 5번 뛰어 세기 / 판정: 마지막 값 284만, 바뀌는 자리 = 십만 자리 선택
  2. 이정표 3개를 작은 순서로 / 판정: 순서 일치
  3. 4억 2천만과 42억 비교 / 판정: <
  4. 자릿수가 같은 두 수 7억 3500만, 7억 5300만 비교 (A) / 판정: <
- **CPA 페이딩:** P: 줌 수직선 / A: 부등호만

## g4s1u2 각도
| 항목 | 내용 |
| --- | --- |
| 영역 | 도형과 측정 |

| 선수 단원 | g3s1u2 평면도형 |
| 차시 규모(참고) | 교과서 약 10차시 중 앱 활용 4차시 (교과서 확인) |

**핵심 아이디어:** 각의 크기는 변의 길이가 아니라 "벌어진 정도(돌아간 양)"이고, 1°를 단위로 센다. 각도기는 한 변을 0°에 맞추고 그 눈금에서부터 센다. 삼각형 세 각을 모으면 언제나 180°, 사각형은 360°다.

### 활동
#### g4s1u2.A1 각도기 레이저 반사 퍼즐 — E09 `angle` · C→P→A
- **원 계획서:** 시작 변(0°) 눈금 트랙 하이라이팅 가상 각도기 레이저 반사 퍼즐
- **화면과 조작:** 가상 각도기를 각에 올리면 중심점이 꼭짓점에 자석 스냅된다. 학생이 한 변을 0°에 맞추면 그 0°에서 시작하는 눈금 트랙(안쪽 또는 바깥쪽)만 밝게 강조된다. 퍼즐: 레이저 발사대의 각도를 입력(또는 거울 각도를 각도기로 맞춤)해 빛이 목표에 닿게 한다. 입력 전에 어림값을 먼저 쓰게 한다.
- **설정 예시:**
  ```json
  { "mode": "angle", "tool": "protractor", "highlightActiveScale": true, "estimateFirst": true, "puzzle": { "type": "laser-mirror", "targetAngle": 135 } }
  ```
- **과제:**
  1. 각 3개 재기(그중 하나는 0° 변이 왼쪽) / 판정: 측정값 ±1° 이내
  2. 어림 후 재기: 어림과 측정 차이 30° 이내 / 판정: 두 값 기록
  3. 예각·직각·둔각 분류 6장 / 판정: 분류 정오
  4. 레이저 퍼즐: 135°로 발사 / 판정: 입력 135 또는 거울 각 일치
  5. 60° + 45°, 150° − 85° 각도 계산(A) / 판정: 105, 65
- **CPA 페이딩:** C: 레이저·각도기 조작 / P: 각도기 그림 위 눈금 읽기 / A: 각도 계산식

#### g4s1u2.A2 꼭짓점 잘라 모으기 — E11 `angle-gather` · C→P→A
- **원 계획서:** 다각형 내각 잘라 모으기(180°, 360°) 불변성 실험
- **화면과 조작:** 학생이 삼각형 꼭짓점을 끌어 모양을 마음대로 바꾼 뒤(무작위 삼각형), 가위로 세 꼭짓점을 잘라 한 점에 모으면 일직선(180°)이 된다. 삼각형을 다시 바꿔도 결과가 같음을 여러 번 확인하고, 사각형은 대각선으로 삼각형 2개로 나누거나 네 각을 모아 한 바퀴(360°)를 만든다.
- **설정 예시:**
  ```json
  { "mode": "angle-gather", "shape": "triangle", "deformable": true, "showSum": "after-gather", "repeatTrials": 3 }
  ```
- **과제:**
  1. 삼각형 세 각 모으기 / 판정: 모은 각 합 180
  2. 모양을 바꿔 2번 더 / 판정: 서로 다른 삼각형 3개에서 180 확인
  3. 사각형 네 각 모으기 / 판정: 360
  4. 두 각이 50°, 75°인 삼각형의 나머지 각 (A) / 판정: 55
  5. 세 각이 80°, 95°, 70°인 사각형의 나머지 각 (A) / 판정: 115
- **CPA 페이딩:** C: 잘라 모으기 / P: 각도 표시된 그림 / A: 식만

## g4s1u3 곱셈과 나눗셈
| 항목 | 내용 |
| --- | --- |
| 영역 | 수와 연산 |
| 엔진 | E07 세로셈 격자, E04 배열·넓이 모델 |

**핵심 아이디어:** 세 자리 × 두 자리도 3학년과 같은 부분곱의 합이다. 두 자리 수로 나눌 때는 "나누는 수의 몇 배가 가장 가까운가"를 어림해 몫을 정하고, 어림이 크면 줄이고 작으면 늘린다.

### 활동
#### g4s1u3.A1 배수 높이 어림 바 — E07 `div` + `estimate` · C→P→A
- **원 계획서:** 두 자리 나눗셈 배수 높이 어림 바
- **화면과 조작:** 나눗셈 세로셈 옆에 나누는 수(예: 23)의 배수 막대가 1배, 2배, 3배 … 로 쌓이는 "배수 사다리"가 있다. 나누어지는 수(예: 95)의 높이 선이 가로로 그어져 있어, 학생이 몫 후보를 고르면 그만큼 막대가 쌓여 선을 넘는지(너무 큼) 모자란지 보인다. 몫을 정하면 세로셈 칸에 곱과 나머지를 쓴다.
- **설정 예시:**
  ```json
  { "mode": "div", "dividend": 95, "divisor": 23, "estimateBar": { "show": "C-P", "maxMultiple": 9 }, "remainderAlarm": true }
  ```
- **과제:**
  1. 95 ÷ 23 / 판정: 몫 4, 나머지 3
  2. 168 ÷ 24 (몫 어림을 고쳐야 하는 문제: 처음 8 → 7) / 판정: 몫 7, 나머지 0, 어림 수정 이벤트 기록(선택)
  3. 589 ÷ 27 / 판정: 몫 21, 나머지 22
  4. 815 ÷ 40 (몫의 일의 자리 0) / 판정: 몫 20, 나머지 15, 몫 일의 자리 칸 0
  5. 739 ÷ 36 (A) / 판정: 몫 20, 나머지 19
- **CPA 페이딩:** C: 배수 막대 쌓기 / P: 배수 표(23, 46, 69, 92 …) / A: 세로셈만

### 활동
#### g4s1u6.A1 입출력 블랙박스 추리 — E16 `black-box` + `table` · P→A
- **원 계획서:** 입출력 블랙박스 함수 추리 게임
- **화면과 조작:** 상자에 수를 넣으면(학생이 키패드로 입력) 다른 수가 나온다. 시도 결과가 대응표에 자동 기록된다. 학생은 규칙이라고 생각하는 것을 "□ + 7", "□ × 3" 같은 식 카드 또는 수식 키패드로 입력해 시험한다. 정답 규칙이면 표의 모든 쌍이 초록으로 바뀐다. 입력 횟수가 적을수록 별을 받는다(그러나 정답에는 영향 없음).
- **설정 예시:**
  ```json
  { "mode": "black-box", "rule": "x*3", "inputRange": [0, 20], "ruleInput": "expression-keypad", "levels": ["x+7", "x*3", "x*2+1"] }
  ```
- **과제:**
  1. 규칙 □ + 7 찾기 / 판정: 학생 식이 표의 모든 쌍에서 성립(E08 파서)
  2. 규칙 □ × 3 찾기 / 판정: 동일
  3. 규칙 □ × 2 + 1 찾기 / 판정: 동일
  4. 출력이 25일 때 입력 예측(규칙 □ × 2 + 1) / 판정: 12
- **CPA 페이딩:** P: 대응표 / A: 식만으로 예측

#### g4s1u6.A2 블록 피라미드와 계산식 1:1 뷰어 — E15 `calc-pattern` · C→P→A
- **원 계획서:** 기하 블록 피라미드와 대칭 계산식 1:1 매칭 뷰어
- **화면과 조작:** 계단·피라미드 모양 블록 배열(1, 1+2+1, 1+2+3+2+1 …)이 단계별로 있고, 옆에 계산식 배열(1 = 1×1, 1+2+1 = 2×2, 1+2+3+2+1 = 3×3)이 있다. 블록 한 줄을 누르면 해당 식의 수가 강조되고, 식의 수를 누르면 블록이 강조된다(1:1 매칭). 다음 단계를 블록으로 쌓고 식을 쓴다. 다른 계산식 배열(11 × 11 = 121, 111 × 111 = 12321 등)의 다음 식도 예측한다.
- **설정 예시:**
  ```json
  { "mode": "calc-pattern", "pattern": "symmetric-sum-square", "stepsShown": 3, "predictStep": 5, "linkHighlight": true }
  ```
- **과제:**
  1. 4단계 블록 쌓기 / 판정: 블록 배열 일치(1+2+3+4+3+2+1)
  2. 4단계 식 쓰기 / 판정: 합 16, 4 × 4
  3. 5단계 블록 수 예측 / 판정: 25
  4. 1111 × 1111 예측(계산식 배열) / 판정: 1234321
  5. 규칙을 설명하는 문장 카드 고르기 / 판정: 정답 카드
- **CPA 페이딩:** C: 블록 쌓기 / P: 블록 그림 / A: 식만
