2. **등록 표:** 아래 표가 기준이다. `label`·`units`·`backtrack`은 표 그대로 쓴다. `units`는 W1처럼 docs/05 §5 표의 단원 열 전체다(W3 이후 단원도 포함). 표는 단원 명세에서 자동으로 모은 것이고, backtrack이 모두 concepts.json·units.json에 있음을 확인했다. W1 단원과 겹치는 코드는 이미 등록돼 있다(아래 3번).

4. **감지 함수 공통 규칙(W1과 같음):**
   - 입력은 `{ value, raw, args }`이다. args 값은 모두 **문자열**이고, 목록이면 문자열 배열이다. 콘텐츠는 `"args": { "a": "46", "b": "27" }`처럼 쓴다.
   - 수 계산은 `Rational`·`BigInt`로만 한다(number 연산 금지).
   - 감지 함수는 "그 오개념대로 답했는가"만 본다. 학생 값이 정답과 같으면 언제나 false다. 정답 값이 따로 없는 코드는 args에서 계산한다.
   - args가 없거나 읽을 수 없으면 false를 돌려주고, 예외를 던지지 않는다.
   - 부등호 코드(BIGNUM-FIRST-DIGIT, COMPARE-DIGIT-COUNT)는 `value`가 `'<' | '=' | '>'` 문자열이다. 콘텐츠가 `path: "response.<id>.symbol"`로 넘긴다.
