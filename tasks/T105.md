2. **core 기하 도우미 추가 (`geometry.ts`, Rational만 씀):**
   - `export type PlaneMetric = 'euclid' | 'hex'`
     - `'euclid'`: 정사각 격자. 거리² = dx² + dy².
     - `'hex'`: 삼각 격자의 축 좌표(3번). 거리² = dx² + dx·dy + dy².
   - `metricDist2(a: GPoint, b: GPoint, metric: PlaneMetric): Rational`
   - `isMirrorPair(p, q, a, b, metric): boolean`: q가 직선 ab에 대한 p의 거울상인지.
     - 조건: a까지 거리²가 같고, b까지 거리²가 같고, `orientation(a, b, p) = −orientation(a, b, q)`이다. 둘 다 0이면 p와 q가 같은 점이어야 한다.
     - 두 원의 교점은 많아야 두 개이고 서로 직선 ab의 거울상이다. 그래서 이 조건이 정확한 판정이다. 축 좌표도 기저의 외적이 양수라 방향 부호가 보존된다.
   - `polygonMirrorSymmetric(points, a, b, metric): boolean`
     - `simplifyPolygon` 뒤 꼭짓점마다 `isMirrorPair`인 꼭짓점 j를 찾는다.
     - 대응이 일대일이고 `map(i+1) ≡ map(i) − 1 (mod n)`이면 참이다(거울은 순서를 뒤집는다). `a = b`면 false다.
   - `pointReflect(p: GPoint, center: GPoint): GPoint` = `2·center − p`. 아핀이라 축 좌표에도 그대로 쓴다.
   - `polygonPointSymmetric(points, center): boolean`: 각 꼭짓점의 `pointReflect`가 꼭짓점이고 `map(i+1) ≡ map(i) + 1 (mod n)`이다.
   - `samePolygon(p, q): boolean`: 단순화한 두 꼭짓점 열이 시작점 회전이나 역순으로 같다.
   - `reflectPoint(p, a, b): GPoint`: 유클리드 직선 ab에 대한 거울상이다(화면에 접은 그림을 그릴 때 정사각 격자에서 쓴다).
   - `lineKey(a, b): string`: 직선 `A·x + B·y = C`의 계수를 정수로 만들고 최대공약수로 나눈 뒤, A(0이면 B)가 양수가 되게 한 `"A,B,C"`다. 같은 직선을 다른 두 점으로 그어도 같은 키다.
   - **테스트** (`src/core/math/__tests__/geometry.test.ts`에 추가):
     - 직사각형 `(2,3)(6,3)(6,5)(2,5)`: 축 x=4, y=4는 참, 대각선은 거짓
     - 평행사변형 `(3,3)(7,3)(5,6)(1,6)`: 대각선·가운데 선 모두 거짓. 중심 `(4, 9/2)` 점대칭 참, `(4,4)`는 거짓
     - 정육각형(`'hex'`, 3번 좌표): 축 6개 모두 참, 꼭짓점 하나와 중심이 아닌 점을 잇는 선은 거짓
     - `lineKey((0,0),(2,2)) = lineKey((1,1),(3,3))`
     - `samePolygon`: 시작점 회전·역순은 참, 한 점이 다르면 거짓
     - 좌표 10⁹, 넓이 0 다각형
3. **삼각 격자 (`tri.ts`, 정확한 표현):**
   - 격자점은 축 좌표 `(a, b)` 정수다. 화면 위치는 `a·e1 + b·e2`이고 `e1 = (1, 0)`, `e2 = (1/2, √3/2)`(아래로 갈수록 b가 커짐)이다. √3은 `layout.ts`의 화면 계산에만 나온다.
   - 단위 삼각형은 **세 배 무게중심 좌표**로 둔다.
     - 위로 뾰족한 `U(p,q)`(꼭짓점 `(p,q)(p+1,q)(p,q+1)`) → `(3p+1, 3q+1)`
     - `D(p,q)`(꼭짓점 `(p+1,q)(p,q+1)(p+1,q+1)`) → `(3p+2, 3q+2)`
     - 모두 정수이고 변환은 격자점과 같은 일차식에 중심을 세 배로 넣으면 된다.
   - 변환(모두 정수):
     - 시계 60°: `(a, b) → (−b, a+b)`
     - 반시계 60°: `(a, b) → (a+b, −a)`
     - 각은 60의 배수(60~300)다. 중심은 격자점이다.
     - 세로축 뒤집기(격자점 `(a0,b0)`을 지나는 세로선): `a' = 2a0 + b0 − a − b`, `b' = b`
     - 가로축 뒤집기: `b' = 2b0 − b`, `a' = a + b − b0`
     - 뒤집기 축은 T104처럼 도형의 맨 왼쪽·오른쪽·위·아래 꼭짓점을 지나는 선이다. 가로 방향 비교값은 `2a + b`(정수)를 쓴다.
   - `TriFigure = { outline: Pt[]; tris: Pt[] }`(`tris`는 세 배 무게중심), `applyTriMove(figure, move)`
   - `Move`의 `turn.angle`을 `number`(정수 도)로 넓힌다. 정사각 격자는 90·180·270, 삼각 격자는 60의 배수만 받는다.
   - **정육각형(한 변 1, 중심 `(a,b)`):**
     - 꼭짓점 `(a+1,b)(a,b+1)(a−1,b+1)(a−1,b)(a,b−1)(a+1,b−1)`
     - 단위 삼각형 6개: 중심의 세 배 `(3a,3b)`에 `(1,1)(−2,1)(1,−2)(−1,2)(2,−1)(−1,−1)`을 더한다.
     - `a − b ≡ 0 (mod 3)`인 중심들로 평면을 겹침 없이 덮는다(테스트로 확인).
4. **`tessellation` 모드:**
   - **설정:**
     - `baseTiles?: ('square' | 'triangle' | 'hexagon' | 'pentagon-regular')[]`(기본 넷 다)
     - `customize?: 'none' | 'edge-translate'`(기본 `'none'`). `'edge-translate'`면 타일 목록에 `'custom'`(변 깎은 정사각형)이 더해진다.
     - `gapCheck?: boolean`(기본 true)
   - **판:**
     - 정사각 계열(`square`·`custom`): 작은 칸 모눈. 타일 한 변 `SQUARE_TILE = 6`칸, 틀(frame)은 `0 ≤ i, j < 18`(타일 3×3)이다. 도장은 틀 밖 6칸까지 나갈 수 있다(`−6 ≤ i, j < 24`). 틀 밖은 흐리게 그린다.
     - 삼각 계열(`triangle`·`hexagon`): 틀은 줄 `0 ≤ b < 6`, 줄마다 `a0 = −floor(b/2)`, `a0 ≤ a < a0 + 8`의 `U`·`D` 96개다. 도장은 틀 밖 2칸까지 나갈 수 있다.
     - `pentagon-regular`: 격자 없음(5번).
   - **타일 시작 자리:**
     - `square`: 칸 `[0,6)²`
     - `custom`: 같은 자리에 `customCells`
     - `triangle`: `U(0,0)`
     - `hexagon`: 중심 `(1,1)`
   - 처음 `tile`은 `baseTiles[0]`이다.
   - **상태:** `{ mode, tile, stamp: { outline: Pt[]; cells: Pt[] }, placed: { id, tile, cells: Pt[] }[], customCells: Cell[], movesUsed: string[], checked: boolean, hub: number, center: number, nextId, settings }`
     - `cells`는 정사각 계열이면 `[i,j]` 칸, 삼각 계열이면 세 배 무게중심이다. 어느 것인지는 `tile`로 정한다.
     - `stamp.outline`은 돌리기 중심·뒤집기 축에만 쓴다. 정사각·변형 타일은 바탕 정사각형의 네 꼭짓점, 정삼각형·정육각형은 그 꼭짓점이다.
     - 타일 테두리는 칸 경계 가운데 한쪽만 덮인 변을 선분으로 그린다(화면 계산). 변형 타일도 같은 방식이다.
   - **Action:**
     - `select-tile {tile}`: 놓인 타일이 있으면 다른 계열(정사각·삼각·정오각) 타일은 무시한다. 화면에서도 그 버튼은 `aria-disabled`이고 "다른 모양을 쓰려면 먼저 모두 지우기"를 띄운다.
     - `move {move}`: 도장에 T104 `Move`를 건다. 밀기 병합은 하지 않는다. 종류를 `movesUsed`에 더한다.
     - `place`: 도장을 복사해 `placed`에 넣는다. 도장은 그 자리에 남는다.
     - `remove-last`, `clear-tiles`(`movesUsed`도 비움)
     - `check-gaps`: `checked = true`. `place`·`remove-last`·`clear-tiles`는 `checked = false`로 둔다.
     - `toggle-notch {cell}`(6번), `select-center {index}`, `hub-add`, `hub-remove`
   - **밀기 단위:** 정사각 계열은 "칸 수" 입력(기본 6). 삼각 계열은 여섯 방향 × 1칸이다(`→ (1,0)`, `← (−1,0)`, `↘ (0,1)`, `↖ (0,−1)`, `↙ (−1,1)`, `↗ (1,−1)`).
   - **빈틈·겹침 판정 (정확함):**
     - 모든 타일이 그 격자 단위 칸의 정확한 합집합이다. 그래서 래스터 근사가 아니라 단위 칸을 정확히 센다.
     - 틀의 단위 칸마다 덮은 타일 수를 센다. 1 이상은 덮임, 2 이상은 겹침이다.
     - `coverage = Rational(덮인 칸, 틀 칸)`이다.
   - **화면:**
     - `gapCheck`이면 겹친 칸을 늘 빨강 + 엇갈린 빗금 `[data-overlap-cell]`으로 그린다.
     - 빈 칸은 `checked`일 때만 빨강 + 점 무늬 `[data-gap-cell]`로 그린다. 처음부터 틀 전체가 빨갛게 보이지 않게 하기 위해서다.
     - `checked`이고 빈틈·겹침이 모두 0이면 "빈틈도 겹침도 없어요"를 띄운다(학생 조작의 결과).
   - **조작:**
     - C: 도장 끌기 → 가장 가까운 격자 벡터로 반올림한 `move slide`
     - P: 버튼·키보드만
     - 버튼: 타일 고르기(정사각형·정삼각형·정육각형·정오각형·변형 도형), T104 `MovePanel`(정사각 계열 90°, 삼각 계열 60° 단위), "놓기", "마지막 타일 빼기", "모두 지우기", "빈틈 살펴보기"
   - **키보드 (캔버스):**
     - 방향키: 밀기. 삼각 계열은 ←→↓↑가 `←→↘↖`, Shift+↓가 `↙`, Shift+↑가 `↗`다.
     - F 다음 방향키: 뒤집기. F를 누르면 다음 방향키 한 번이 그쪽 뒤집기가 된다(Shift는 삼각 방향에 썼으므로).
     - R / Shift+R: 시계 / 반시계 돌리기. C: 중심 꼭짓점.
     - Enter: 놓기. Backspace: 마지막 타일 빼기. G: 빈틈 살펴보기.
5. **정오각형 (좁힘: 한 꼭짓점 둘레 시험만):**
   - 정오각형은 유리수 좌표로 놓을 수 없다. 단원 과제도 "채울 수 있나? → 안 된다 + 빈틈 확인"뿐이다. 그래서 자유 배치는 만들지 않는다.
   - 한 꼭짓점(허브) 둘레에 정오각형을 변끼리 붙여 1~4개 놓는다. 시작은 1개다.
   - 판정은 정수 도로 한다: `angleSum = 108·hub`.
     - `hub = 3`이면 `gapDegrees = 36`이다. 빈틈 쐐기를 빨강 + 점 무늬 `[data-gap-cell]`로 바로 그린다.
     - `hub = 4`면 `overlapDegrees = 72`다. 겹친 쐐기를 빨강 + 빗금 `[data-overlap-cell]`로 그린다.
   - 그림 좌표(코사인 등)는 화면에서만 계산한다.
   - 키보드: Enter = `hub-add`, Backspace = `hub-remove`
6. **변 깎아 반대 변에 붙이기 (`customize: 'edge-translate'`):**
   - `customCells` 처음 값은 6×6 칸 전부다.
   - 고칠 수 있는 칸:
     - 왼쪽 띠 `x ∈ {0,1}, y ∈ {2..5}`: 그 칸을 빼면 `(x+6, y)`를 더한다.
     - 위쪽 띠 `y ∈ {0,1}, x ∈ {2..5}`: 그 칸을 빼면 `(x, y+6)`을 더한다.
     - 되돌리면 반대로 한다. 왼쪽 위 2×2는 두 띠가 겹치므로 고칠 수 없다.
   - 깊이 규칙: `x = 1`(또는 `y = 1`) 칸은 바깥 칸이 이미 빠졌을 때만 뺄 수 있다. 바깥 칸은 안쪽 칸이 남아 있을 때만 되돌릴 수 있다.
   - 결과가 변으로 이어져 있지 않으면 무시한다.
   - 이 규칙이면 넓이가 늘 36이고 `(6,0)`·`(0,6)` 밀기로 평면을 덮는다(테스트).
   - `TileEditor`(`data-testid="tile-editor"`):
     - 칸 하나가 64px 이상인 확대 편집판이다. 붙은 칸은 다른 무늬로 보인다.
     - 키보드: 방향키 커서, Enter = `toggle-notch`
7. **`congruence` 모드:**
   - **설정:**
     - `grid?`(8~14, 기본 12, 꼭짓점 `0..grid`)
     - `fixed?: ShapeRef`(기본 `'quad-a'`), `fixedAt?`(기본 `[7,2]`), `fixedOrientation?: Orientation`(기본 `'cw90'`)
     - `moving?: ShapeRef`(기본 `'quad-a'`), `movingAt?`(기본 `[1,6]`)
     - `showCorrespondence?: 'after-overlap' | 'never'`(기본 `'after-overlap'`), `pairSides?: boolean`(기본 false)
     - `ShapeRef = PolygonPresetId | { points: Pt[] }`
     - 고정 도형은 프리셋 꼭짓점에 방향 식(T104 5번)을 걸고 상자 왼쪽 위를 `fixedAt`에 맞춘다.
   - **상태:** `{ mode, fixed: Pt[], movingStart: Pt[], moves: Move[], center: number, correspondence: number[] | null, everOverlapped: boolean, sidePairs: [number, number][], settings }`
   - **Action:**
     - `slide`·`flip`·`turn`·`select-center`·`undo-move`: T104 slide-flip-turn과 같다. 꼭짓점만 있는 `SquareFigure`(`cells: []`)에 `applySquareMove`를 쓰고, 꼭짓점이 `0..grid` 밖이면 무시한다.
     - `reset-moving`: 처음 자리로 돌아간다. `correspondence`는 남긴다.
     - `pair-sides {moving, fixed}`: 변 번호는 꼭짓점 i → i+1이다. 같은 움직이는 변이나 같은 고정 변의 짝은 바꾼다.
     - `unpair {moving}`
   - **겹침:**
     - 이동 뒤 `samePolygon(지금, fixed)`이면 겹친 것이다.
     - 그때 `correspondence[i]` = 움직인 꼭짓점 i와 같은 자리의 고정 꼭짓점 번호로 저장한다. `everOverlapped = true`다.
   - **대응 표시 (`after-overlap`, `correspondence`가 있을 때):**
     - 점: 대응 꼭짓점마다 같은 색 + 같은 번호 기호(①②③④) `[data-corr="point"]`를 단다. 떨어져 있으면 점선으로 잇는다.
     - 변: 같은 색 + 같은 눈금 수(1~4줄) `[data-corr="side"]`
     - 각: 같은 색 + 같은 호 수(1~4겹) `[data-corr="angle"]`
     - 색만으로 구분하지 않는다.
   - **이름표:** 고정 도형 ㄱㄴㄷㄹ…, 움직이는 도형 ㅁㅂㅅㅇ…(`strings.movingLabels`)
   - **변 짝짓기 (`pairSides`):**
     - 패널에 선택 상자 둘("움직인 도형의 변" ㅁㅂ…, "고정된 도형의 변" ㄱㄴ…)과 "짝 짓기" 버튼을 둔다. 지은 짝 목록마다 "짝 풀기"가 있다.
     - 짝짓기 과제에는 콘텐츠가 `showCorrespondence: 'never'`를 쓴다(그렇지 않으면 대응 표시가 답을 알려 준다).
   - **키보드:** T104 slide-flip-turn과 같다. Escape는 `reset-moving`이다.
8. **`line-symmetry` 모드:**
   - **설정:**
     - `task?: 'find-axis' | 'decalcomania' | 'complete'`(기본 `'find-axis'`)
     - `shapes?: LinePresetId[]`(기본 `['rectangle', 'parallelogram', 'regular-hexagon', 'isosceles-trapezoid']`)
     - `allowDrawAxis?`(기본 true. false면 축 긋기를 끄고 보기만 한다)
     - `foldPreview?`(기본 true. 접기 애니메이션을 한다)
     - `axis?: [Pt, Pt]`, `half?: Pt[]`(complete용)
   - **find-axis:**
     - 점판은 도형마다 다르다. 정사각 도형은 정사각 점판 9×9(`0..8`), `regular-hexagon`은 삼각 점판(줄 `0..6`, 줄마다 `a0 = −floor(b/2)`, `a0..a0+8`)이다.
     - 상태: `{ mode, task, shapeIndex, pending: Pt | null, axis: [Pt, Pt] | null, folds: { shape, from, to, ok, diagonal, key }[], showing: number | null, settings }`
     - Action:
       - `select-shape {index}`
       - `pick-point {at}`: 첫째는 `pending`, 둘째는 `axis`다. 같은 점은 무시한다. `axis`가 이미 있으면 그 축과 `showing`을 지우고 새 `pending`으로 시작한다.
       - `clear-axis`
       - `fold`: `axis`가 있어야 한다. reduce가 판정해 `folds`에 넣는다.
         - `ok = polygonMirrorSymmetric(도형, from, to, metric)`
         - `diagonal` = 축 위에 서로 이웃하지 않은 꼭짓점 둘이 있다(`pointOnLine`)
         - `key = lineKey(from, to)`
       - `unfold`
     - 접은 화면:
       - `ok`이면 "딱 겹쳐요"와 함께 축을 실선 + ✓ 무늬 `[data-axis-found]`로 남긴다.
       - 아니면 접힌 그림(거울상 전체)을 점선으로 그린다. 원래 도형과의 차이를 even-odd 경로로 빨강 + 빗금 `[data-fold-gap]` 처리한다.
       - 거울상 화면 좌표는 정사각 격자는 `reflectPoint`, 삼각 격자는 화면 좌표의 반사식(number)으로 구한다.
     - 찾은 축 수를 "n개 중 m개"처럼 전체 수와 함께 쓰지 않는다.
   - **decalcomania:**
     - 9×7 점판의 가운데 세로선 x = 4가 접는 선이다.
     - 상태: `dots: { at: Pt; mark: 0 | 1 | 2 | 3 }[]`, `folded`
     - Action:
       - `add-dot {at, mark}`: x ≤ 4만 받는다.
       - `remove-dot {at}`, `fold-paper`, `unfold-paper`
     - 물감은 색과 모양(●▲■◆)을 함께 다르게 한다. 접으면 `(8 − x, y)`에 같은 표시가 찍힌다.
   - **complete:**
     - 정사각 점판 9×9다. 축 `axis`와 반쪽 꺾은선 `half`(양 끝이 축 위)를 그린다.
     - 학생은 `half`의 끝에서부터 점을 골라 잇는다(`add-vertex {at}`, `undo-vertex`). `half`의 첫 점을 고르면 닫힌다.
     - 남은 반쪽(거울상)은 어디에도 그리지 않는다.
     - 기본값은 `axis [[4,0],[4,8]]`, `half [[4,1],[2,2],[1,5],[3,7],[4,7]]`이다.
   - **키보드:** 방향키 점 커서(시작 `(0,0)`), Enter 점 고르기, F 접어 보기, U 펼치기, Escape 축 지우기, 1~9 도형 고르기. 데칼코마니는 M이 물감 표시 바꾸기, P가 접기다.
9. **`point-symmetry` 모드:**
   - **설정:**
     - `task?: 'pin' | 'complete'`(기본 `'pin'`)
     - `shapes?: PointPresetId[]`(기본 `['parallelogram', 'letter-S', 'letter-N', 'regular-pentagon']`)
     - `pinAnywhere?`(기본 true: 반 칸 단위 어디나. false면 격자점만)
     - `showArcs?`(기본 true)
     - `center?: Pt`(두 배 좌표), `half?: Pt[]`(complete용)
   - 점판은 정사각 10×10(`0..9`)이다.
   - **상태:** `{ mode, task, shapeIndex, pin: Pt | null, turned: boolean, flipped: Side | null, tries: { shape, pin, overlaps }[], centerFound: string[], flipUsed: boolean, settings }`
     - `pin`은 **두 배 좌표**다(정수). 수학 계산은 `Rational.of(x, 2)`로 `GPoint`를 만든다.
   - **Action:**
     - `select-shape {index}`
     - `place-pin {at}`: `turned`·`flipped`를 풀고, `pinAnywhere`가 false면 짝수 좌표만 받는다.
     - `turn-180`: 압정이 있어야 한다. `turned = true`이고 `tries`에 결과를 넣는다. 겹치면 `centerFound`에 도형 id를 넣는다.
     - `flip {side}`: 뒤집은 그림을 보여 주고 `flipUsed = true`다. MC-SYM-POINT-AS-LINE 감지용으로 일부러 둔다.
     - `reset-turn`
     - complete는 line-symmetry와 같은 `add-vertex`·`undo-vertex`다.
   - **겹침:**
     - `polygonPointSymmetric(꼭짓점, pin/2)`
     - `regular-pentagon`은 변 수가 홀수라 어느 압정에서도 거짓이다(점대칭이 없다는 정리를 쓴다. 근사 계산 없음).
   - **화면:**
     - 돌리면 원래 자리에 잔상 `[data-ghost]`가 남는다. `showArcs`면 꼭짓점마다 180° 호 `[data-arc]`를 그린다(줄인 움직임이면 애니메이션 없이).
     - 겹치면 압정이 금색 + 별 무늬로 바뀌고 "대칭의 중심" 이름표가 붙는다 `[data-center-mark]`.
     - 겹치면 대응점 쌍마다 압정을 지나는 선분을 그리고, 두 반쪽에 같은 눈금(이등분 표시)을 단다 `[data-bisect]`.
     - 겹치기 전에는 중심 자리를 어떤 표시로도 그리지 않는다.
   - **키보드:** 방향키는 압정 커서(반 칸씩, 시작 두 배 좌표 `(9,9)`), Enter `place-pin`, T `turn-180`, Shift+방향키 `flip`, Escape `reset-turn`, 1~9 도형 고르기
   - 도형 고르기 버튼은 "도형 1"·"도형 2"처럼 쓴다. 도형 이름은 쓰지 않는다(고르기 과제의 답이 되므로).
