넓이를 보존하며 잘라 옮기는 E11의 기본 모드를 만든다. 4학년 각도 A2(각 모으기)와 5학년 다각형의 둘레와 넓이 A1(공식 유도)이 이것으로 열린다.

## 할 일
- [ ] 모드 `slice`: 직선으로 다각형 자르기(가위 도구), 조각 끌기·돌리기, 맞물리면 자석 스냅
- [ ] 모드 `formula-derive`: 평행사변형 → 직사각형(높이선 자르기), 삼각형 복제 + 경첩 180° 회전 → 평행사변형, 사다리꼴 복제 + 경첩 → 평행사변형, 마름모 대각선 자르기 → 직사각형. 도구 `scissors`·`hinge180`·`duplicate`, 모눈(`grid`)
- [ ] Observation: 조각 넓이 합(보존 여부, Rational), 재조립 외곽 도형 종류와 가로·세로, 사용한 도구 목록
- [ ] 재조립 뒤 단위넓이 격자 덮기는 E11 안에서 그린다(E04 import 금지). E04와 나란히 보여야 하면 실행기 두 판으로 하고 메모에 적는다
- [ ] 모드 `angle-gather`: 꼭짓점을 끌어 삼각형·사각형 모양 바꾸기(`deformable`), 꼭짓점을 잘라 한 점에 모으기, 모은 각의 합(`showSum: after-gather`), 서로 다른 모양 시도 기록(`repeatTrials`)
- [ ] Observation·predicates·이벤트·오버레이, 단위 테스트(넓이 보존, 각 합 180·360), `#/sandbox/E11` E2E
