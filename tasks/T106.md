2. **수학 값 규칙:**
   - 모든 점은 `Rational` 좌표다. 상태에는 `RPoint = readonly [string, string]`(Rational 정규 문자열, `Rational.toJSON()`)로 둔다. `rpoint.ts`에 `toG(p: RPoint): GPoint`(`Rational.parse`), `fromG(g: GPoint): RPoint`, `rp(x: number, y: number): RPoint`(정수만)를 둔다.
   - 좌표는 격자 단위(1 = 모눈 한 칸)이고 x는 오른쪽, y는 아래쪽이다. 화면 좌표(number)는 `layout.ts`만 만든다.
   - **잘린 점이 언제나 유리수인 이유:** 자르기는 조각 경계 위의 "자를 점" 두 개를 잇는 현(chord)으로만 한다(6번). 자를 점은 꼭짓점, 변의 중점, 변이 정수 격자선(x = 정수 또는 y = 정수)과 만나는 점뿐이다. 모두 유리수다.
   - **돌리기는 90°와 180°만:** 90° 회전(`rotate90About`)과 점대칭 180°(`pointReflect`, 경첩)는 유리수를 유리수로 보낸다. 자유 회전은 만들지 않는다.
   - **옮기기:** 이동량도 `RPoint`다. 놓을 때 자석 스냅(6번)이 꼭짓점끼리의 정확한 차이나 정수 이동량을 고른다.
   - 넓이·넓이 합·비율은 모두 `polygonArea`의 Rational이다. number 넓이는 만들지 않는다.
3. **core 기하 도우미 추가 (`geometry.ts`, 모두 Rational·정확 계산):**
   - `midpoint(a: GPoint, b: GPoint): GPoint`
   - `rotate90About(p: GPoint, center: GPoint, turns: number): GPoint`: `turns`를 4로 나눈 나머지만큼 돌린다. 한 번은 `(dx, dy) → (−dy, dx)`다.
   - `pointReflect(p: GPoint, center: GPoint): GPoint`: `2·center − p`.
   - `locatePoint(p: GPoint, polygon: readonly GPoint[]): 'inside' | 'boundary' | 'outside'`: 변 위(꼭짓점 포함)는 `boundary`. 반직선 교차 수로 정확히 판정한다.
   - `isConvexPolygon(points: readonly GPoint[]): boolean`: `simplifyPolygon` 뒤 단순 다각형이고 모든 꺾임 부호가 같다.
   - `convexHull(points: readonly GPoint[]): GPoint[]`: 일직선 위 점은 뺀다. 넓이가 0이면 점 3개 미만을 돌려준다.
   - `clipConvexPolygon(subject: readonly GPoint[], clip: readonly GPoint[]): GPoint[]`: 볼록 다각형 두 개의 교집합(Sutherland–Hodgman). 넓이가 0이면 `[]`.
   - `splitPolygonByChord(points: readonly GPoint[], a: GPoint, b: GPoint): [GPoint[], GPoint[]] | null`
     - a·b가 경계 위의 서로 다른 점이고, 같은 변 위에 함께 있지 않고, 중점이 `inside`이고, 선분 ab가 a·b 말고는 경계와 만나지 않을 때만 자른다. 아니면 `null`.
     - 첫 조각은 a에서 꼭짓점 순서대로 b까지, 둘째 조각은 b에서 a까지다. 둘 다 `simplifyPolygon`한다.

6. **slice·formula-derive 모드 (`pieces/`):**
   - **상태 (`PiecesState`):**
     - `mode: 'slice' | 'formula-derive'`
     - `pieces: { id: string; vertices: RPoint[]; copy: boolean }[]`
     - `nextId`, `cuts: number`, `copies: number`
     - `used: PieceTool[]`: 실제로 적용된 도구(정렬, 중복 없음). `PieceTool = 'move' | 'scissors' | 'rotate90' | 'hinge180' | 'duplicate'`.
     - `lastHinge: { piece: string; at: RPoint } | null`
     - `settings: { tools, grid, maxCopies, unitCover, shapeType: FormulaShapeType | 'polygon', initial: RPoint[][] }`
   - **Action:**
     - `cut { piece, from: RPoint, to: RPoint }`: `splitPolygonByChord`가 null이면 무시. 두 조각은 꼭짓점 평균의 (x, y) 사전순으로 놓고 id를 새로 준다. 원래 조각 자리에 끼운다.
     - `move-piece { piece, by: RPoint }`
     - `rotate-piece { piece, turns: 1 | -1 }`: 꼭짓점 평균(유리수)을 중심으로 90°. `rotate90` 도구가 없으면 무시.
     - `hinge { piece, at: RPoint }`: `at`은 그 조각의 꼭짓점이나 변의 중점이어야 한다. `pointReflect`로 180°.
     - `duplicate { piece }`: `copies < maxCopies`일 때만. 사본은 오른쪽으로 (외곽 상자 너비 + 2, 0) 옮겨 놓고, 판을 넘으면 아래로 (0, 높이 + 2) 옮긴다. 그래도 넘으면 무시. `copy: true`.
     - 도구가 `tools`에 없으면 그 Action은 무시한다. 조각은 16개까지다.
   - **자를 점 (`candidates.ts`의 `cutCandidates(piece): RPoint[]`):** 꼭짓점 0에서 시작해 꼭짓점 순서대로 돈다. 각 변에서는 시작 꼭짓점, 그다음 그 변 안쪽 후보(격자선 교점과 중점)를 시작점에서 가까운 순으로 넣는다. 같은 점은 한 번만 넣는다.
   - **경첩 점 (`hingeCandidates(piece)`):** `[v0, m01, v1, m12, …]`처럼 꼭짓점과 변의 중점을 번갈아 넣는다.
   - **자석 스냅 (`snap.ts`의 `snapTranslation(state, piece, raw: { x: number; y: number }, tolerance: number): RPoint`):**
     - `raw`는 끈 거리(격자 단위, number)다.
     - 옮긴 조각 꼭짓점과 다른 조각 꼭짓점의 정확한 차이 중, raw와의 거리가 `tolerance`(기본 0.4칸) 안에서 가장 가까운 것을 고른다.
     - 없으면 raw를 정수로 반올림한다. 결과는 언제나 정확한 `RPoint`다.
   - **조작(포인터):**
     - 도구 단추 줄(`옮기기`·`가위`·`돌리기`·`경첩`·`복제`, `aria-pressed`)은 `tools`에 있는 것만 보인다. 고른 도구는 View 로컬 상태다.
     - 옮기기: 조각을 끌어 놓으면 `snapTranslation` 뒤 `move-piece`.
     - 가위: 자를 점에서 눌러 다른 자를 점에서 떼면 `cut`. 끄는 동안 점선 미리보기만 그린다. 두 번 탭해도 된다.
     - 경첩: 조각을 탭해 고르면 그 조각의 경첩 점이 보인다. 하나를 탭하면 `hinge`.
     - 돌리기·복제: 조각을 탭하면 `rotate-piece {turns: 1}` / `duplicate`.
   - **키보드:**
     - 각 조각은 `<g role="button" tabIndex={0} aria-label="조각 n">`이다. Tab으로 옮긴다.
     - 방향키: 1칸 + 스냅으로 `move-piece`.
     - `R`/`Shift+R`: 돌리기, `D`: 복제.
     - `C`: 자르기 커서. ←/→로 자를 점을 고르고 Enter로 시작점, 다시 ←/→·Enter로 끝점을 정하면 `cut`. Esc는 취소.
     - `H`: 경첩 커서. ←/→·Enter로 `hinge`.
     - 현재 커서 점은 캔버스 svg의 `data-cut-cursor`·`data-hinge-cursor`(값 `"x,y"`)에 둔다(E2E용, 화면에 글자로 쓰지 않는다).
   - **그리기:** C는 조각마다 색과 무늬(빗금·점·민무늬)를 함께 다르게 한다. P는 흰 바탕과 검은 테두리, 조각 번호. 복제 조각은 점선 테두리를 더한다.
7. **angle-gather 모드 (`angle-gather/`):**
   - **상태 (`AngleGatherState`):**
     - `mode: 'angle-gather'`, `vertices: [number, number][]`(정수 격자, 계산할 때 `gp`)
     - `phase: 'shape' | 'cut'`
     - `corners: { index: number; gathered: boolean; turned: boolean }[]`: `phase === 'cut'`일 때만 채운다.
     - `recorded: boolean`: 이번 자르기에서 시도를 기록했는지.
     - `trials: { vertices: [number, number][]; sum: 180 | 360 }[]`(최대 10개)
     - `settings`
   - **각 조각:** 꼭짓점 V와 이웃 꼭짓점 P·N에 대해 V, V+(P−V)/4, V+(N−V)/4 삼각형(`CORNER_FRACTION = 1/4`, Rational)이다.
   - **Action:**
     - `move-vertex { index, to: [number, number] }`: `phase === 'shape'`이고 `deformable`일 때만. 판 밖, 겹치는 꼭짓점, 일직선(넓이 0), 볼록이 아닌 사각형이 되면 무시한다. View는 "모양이 찌그러져요" 상태 문구를 띄운다.
     - `cut-corners`: `phase`를 `cut`으로, 모든 각 조각을 `gathered: false`, `turned: false`로 만든다.
     - `gather-corner { index, turned: boolean }`, `ungather-corner { index }`, `turn-corner { index }`(turned 뒤집기)
     - `new-trial`: `phase`를 `shape`로 돌리고 `corners`를 비운다.
   - **모은 각 판정 (`fan.ts`, 정확 계산):**
     - 각 조각의 부채꼴은 두 반직선 방향 s = P−V, e = N−V이다. `cross(s, e) > 0`이 되게 순서를 맞춘다. `turned`면 둘 다 부호를 바꾼다(점대칭 180°).
     - 방향이 같다 = 외적 0, 내적 > 0. 반대다 = 외적 0, 내적 < 0.
     - 두 부채꼴이 겹치는지(`sectorsOverlap`): 한쪽의 s나 e가 다른 쪽 안쪽에 엄격히 들어가거나(`cross(s,d) > 0 && cross(d,e) > 0`), 시작끼리 또는 끝끼리 방향이 같으면 겹친다.
     - `fanState(state): 'none' | 'partial' | 'gap' | 'overlap' | 'straight' | 'full'`
       - 모은 조각이 없으면 `none`. 둘이라도 겹치면 `overlap`.
       - 모은 조각을 "앞 조각의 e = 다음 조각의 s"로 한 줄로 이을 수 있으면 사슬이다(4개 이하라 순열로 찾아도 된다). 사슬이 안 되면 `gap`.
       - 사슬인데 모은 수가 꼭짓점 수보다 적으면 `partial`.
       - 다 모았고 첫 s와 끝 e가 반대면 `straight`. 사슬이 고리로 닫히면(끝 e = 첫 s) `full`.
       - 겹침이 없으면 모은 각의 합은 360°를 넘지 않는다. 그래서 `straight` = 180°, `full` = 360°가 정확하다. 각의 도 값은 계산하지 않는다.
     - `bestTurn(state, index): boolean`: 이미 모은 조각과 겹치지 않고 반직선 하나를 나누는 turned 값을 고른다. 지금 값이 되면 지금 값, 아니면 반대 값, 둘 다 안 되면 지금 값이다.
     - `gather-corner` 뒤 `straight`/`full`이 되고 `recorded`가 false면 시도를 `trials`에 넣고 `recorded = true`로 한다.
   - **조작:**

1. **카드 17번의 "삼각형 세 조각을 모두 `turned:false`로 모으면 `overlap`"은 수학적으로 성립하지 않는다.** 기본 삼각형의 세 부채꼴은 서로 겹치지 않아 `none`/`gap` 쪽이 된다. `overlap` 판정은 기본 사각형(네 부채꼴)으로 검사하도록 테스트를 바꿨다. `fan.ts`의 `sectorsOverlap` 자체는 카드 7번 정의 그대로다.
2. **`cutCandidates` 버그 수정:** 변이 왼쪽/아래로 향할 때 격자선 교점이 `integerLinesBetween`에서 누락됐다. 시작·끝 x/y를 정렬해 넘기도록 고쳤다. 이 수정 전에는 기본 평행사변형에서 `(4,6)`에 닿을 수 없어 카드 E2E의 자르기가 불가능했다.
3. **자른 뒤 조각 배열 순서는 id 순서가 아니다.** 카드 6번대로 꼭짓점 평균의 (x, y) 사전순으로 끼워 넣기 때문에, 기본 평행사변형을 `(4,2)-(4,6)`으로 자르면 배열 0번이 삼각형(id `p3`), 1번이 사각형(id `p2`)이다. 테스트·E2E는 id가 아니라 인덱스/모양으로 조각을 고른다.
4. **E2E 자르기 커서는 시작 위치를 가정하지 않는다.** 조각마다 `data-cut-cursor` 초기값이 다르므로, 목표 좌표가 될 때까지 화살표를 누른 뒤 Enter를 누른다(카드 문구의 "→ n번"을 고정 횟수로 쓰지 않음).
5. **자르기 뒤 View가 캔버스로 포커스를 되돌린다.** 그래야 E2E에서 `Tab` 한 번으로 첫 조각에 닿는다(키보드만으로 끝까지 조작 요건).
6. **`bestTurn`은 지금 값을 먼저 시도하고, 안 되면 반대 값, 둘 다 안 되면 지금 값이다.** 삼각형 `straight`는 조각마다 turned가 달라야 해서 이 규칙이 필요했다. `turned` 하나만 뒤집는 것으로는 사슬이 안 되는 경우가 있다.
7. **`areaConserved`는 카드 9번 식 `totalArea = originalArea × (1 + copies)` 그대로다.** 복제 1회면 `areaRatio = '2'`이고 `areaConserved`는 true다.
8. **경첩 애니메이션 시작을 `setTimeout(0)`으로 미뤘다.** `react-hooks/set-state-in-effect` lint 규칙 때문에 effect 안에서 곧바로 state를 바꿀 수 없었다. `prefers-reduced-motion`이면 타이머도 `data-animating`도 쓰지 않고, view 테스트는 `waitFor`로 확인한다.
9. **샌드박스 E2E는 `?config=`의 `mode`만으로 모드가 바뀌지 않는다.** `Sandbox.tsx`가 로컬 모드 state로 덮어쓰므로, E2E는 `모드` select를 직접 고른 뒤 설정만 `?config=`로 준다.
10. **`npm test` 기본 5초 제한에서 환경성 시간 초과 1건.** `src/core/runner/__tests__/share-runner.test.tsx`의 "응답 입력을 되돌린 기록은 공유 코드에서 빠져…"가 약 5035ms로 걸린다(다른 1395개는 통과). `npx vitest run --testTimeout=20000`에서는 전부 통과하고, 그 테스트만 단독 실행해도 통과한다. T106 코드와 무관한 머신 부하 문제로 판단해 기본 제한은 건드리지 않았다.
