- 학생이 직육면체(정육면체)를 끌어 돌려 본다.

### 3. 상자와 요소 이름 `xray/geometry.ts`
- **좌표:** 상자는 `[0,w]×[0,d]×[0,h]`이다. x는 오른쪽, y는 뒤쪽(안쪽), z는 위쪽이다.
- **면 6개 `XrayFaceId`:**
  - `front`(y=0)와 `back`(y=d)
  - `left`(x=0)와 `right`(x=w)
  - `bottom`(z=0)와 `top`(z=h)
  - 마주 보는 쌍(평행)은 front↔back, left↔right, bottom↔top이다. 나머지 4면은 수직이다.
  - 바깥 법선: front `(0,−1,0)`, back `(0,1,0)`, left `(−1,0,0)`, right `(1,0,0)`, bottom `(0,0,−1)`, top `(0,0,1)`
- **꼭짓점 8개:** `v{i}{j}{k}`. i·j·k는 0 또는 1이고 점은 `(i·w, j·d, k·h)`다. 예: `v010` = 왼쪽·뒤·아래.
- **모서리 12개:** 바뀌는 축 이름과 나머지 두 자리로 쓴다.
  - x 방향: `x{j}{k}`
  - y 방향: `y{i}{k}`
  - z 방향: `z{i}{j}`
  - 예: `z01` = x=0, y=d인 세로 모서리.
  - 모서리마다 붙은 두 면을 함수로 돌려준다(`edgeFaces`).
- 요소 목록과 이름 순서는 고정한다. 키보드 Tab 순서와 테스트가 이 순서를 쓴다.

### 4. 돌려 보기 투영(정사영)
- 시점은 `{ yaw, pitch }`(도 단위 정수)다.
  - `yaw`: 15의 배수, −165~180으로 정규화한다.
  - `pitch`: 15의 배수, −75~75로 자른다.
  - 기본 `{ yaw: 30, pitch: 30 }`이면 앞·오른쪽·위가 보인다.
- 눈 방향 `e = (sinφ·cosθ, −cosφ·cosθ, sinθ)`, 오른쪽 `r = (cosφ, sinφ, 0)`, 위 `u = (−sinφ·sinθ, cosφ·sinθ, cosθ)`(φ=yaw, θ=pitch)
  - 점 p(상자 중심 기준)의 화면 좌표는 `sx = p·r`, `sy = −(p·u)`(SVG는 아래가 +)
  - 깊이는 `p·e`이고, 클수록 앞이다.
- **보이는 면:** `n·e > 1e-9`인 면이다. 판정 함수 `visibleFaces(view)`의 결과는 yaw·pitch만으로 정해진다.
  - 단위 테스트 기대값:
    - 기본 시점 → `front,right,top`
    - `{yaw:-30, pitch:30}` → `front,left,top`
    - `{yaw:30, pitch:-30}` → `front,right,bottom`
    - `{yaw:180, pitch:30}` → `back,top`(옆면은 모서리로만 보임)
- **숨은 모서리:** 붙은 두 면이 모두 보이지 않는 모서리다. 숨은 꼭짓점은 붙은 세 면이 모두 보이지 않는 꼭짓점이다.
  - 기본 시점에서 숨은 모서리는 `x10`, `y00`, `z01`(꼭짓점 `v010`에 모인 3개)이다. 테스트로 확인한다.
- **배율:** 무대 짧은 변의 84%를 상자 대각선 길이로 나눈 값이다. 돌려도 크기가 바뀌지 않게 한다. 상자 중심은 무대 가운데다.

### 5. 겨냥도 투영과 채점(사투상, 정수)
- **격자를 바꾼 이유:** 명세의 "등각 격자"를 그대로 쓰면, 정육면체는 숨은 꼭짓점이 앞 꼭짓점과 같은 점에 겹친다. 그래서 교과서 겨냥도처럼 앞면을 그대로 그리고 뒤로 가는 모서리를 오른쪽 위 대각선으로 그리는 사투상 점 격자를 쓴다.
  - 설정 키 `sketchGrid`는 받기만 하고 무시한다.
  - docs 수정은 운영자가 따로 정한다.
- **겨냥도 점 좌표:** 3D 점 `(x,y,z)` → 격자 점 `(X, Y) = (2x + y, 2z + y)`, 정수, Y는 위가 +
  - 보이는 면은 늘 `front,right,top`이다.
  - 숨은 모서리는 늘 `v010`에 모인 3개다(4번 기본 시점과 같다).
- **그릴 수 있는 크기 검사 `sketchProjectionOk(w,d,h)`:** 아래 둘 중 하나라도 있으면 false다.
  - 꼭짓점 8개의 격자 점 가운데 같은 점이 있다(`w = h = d/2`일 때).
  - 두 모서리의 투영이 같은 직선 위에서 길이가 양수만큼 겹친다(예: `d = 2h`).
  - 테스트 기대값:
    - true: `4×3×2`(w×d×h), 정육면체 1·2·3
    - false: `1×2×1`(꼭짓점 겹침), `4×4×2`(뒤 아래 모서리와 앞 위 모서리 겹침)
- **선분 표기:** `{ a:[X,Y], b:[X,Y], style:'solid'|'dashed', locked }`. `a`가 `b`보다 사전순으로 앞이 되게 정규화한다.
- **채점 `gradeSketch(segments, w,d,h)`:**
  - 모서리 12개의 투영 선분과 끝점이 정확히 같은 선분만 그 모서리로 본다.
  - 결과:
    - `visibleMissing`: 실선으로 그려지지 않은 보이는 모서리 수(점선으로 그린 것 포함)
    - `hiddenMissing`: 점선으로 그려지지 않은 숨은 모서리 수(실선으로 그린 것 포함)
    - `hiddenSolid`: 실선으로 그린 숨은 모서리 수
    - `visibleDashed`: 점선으로 그린 보이는 모서리 수
    - `extra`: 어느 모서리와도 맞지 않는 선분 수
    - `complete`: `visibleMissing = hiddenMissing = extra = 0`
  - 한 모서리를 두 토막으로 그린 것은 `extra` 2개다. 모서리를 끝점에서 끝점까지 한 번에 그어야 한다.

### 6. 설정 `XrayConfig`
| 키 | 형 | 기본 | 뜻 |
| --- | --- | --- | --- |
| `mode` | `'xray'` | — | 필수 |
| `solid` | `{ type:'cuboid'\|'cube', w, d, h }` | `{type:'cuboid', w:4, d:3, h:2}` | 정수 1~6. `cube`면 `w`를 세 모서리에 모두 쓴다 |
| `display` | `'solid' \| 'sketch'` | `'solid'` | `'sketch'`면 돌리는 무대 대신 고정 겨냥도 그림(5번 투영, 숨은 모서리 점선)을 보인다(CPA A) |
| `rotate` | boolean | true | false면 돌리기 단추·끌기·키를 막는다. `display:'sketch'`면 늘 false |
| `view` | `{yaw, pitch}` | `{30, 30}` | 처음 시점(4번 규칙으로 정규화) |
| `xray` | boolean | false | 처음 엑스레이 상태 |
| `xrayToggle` | boolean | true | false면 "엑스레이" 단추를 숨기고 `toggle-xray` 무시 |
| `tools` | `('face'\|'edge'\|'vertex')[]` | `['face','edge','vertex']` | 표시 도구. `[]`이면 표시 막대를 숨긴다 |
| `faceQuery` | boolean | false | true면 "면 관계 보기" 도구를 더한다(7번) |
| `highlightFace` | `XrayFaceId \| null` | null | 이 면을 노랑+빗금으로 칠하고 범례 "색칠된 면"을 보인다 |
| `sketch` | `false \| { prefill: 'visible' \| 'none' }` | false | 겨냥도 그리기 판(8번) |

- 받기만 하고 무시하는 키: `stage`, `fallback`, `variant`, `sketchGrid`
- 범위 밖 수는 자르고 `console.warn`한다.
- `sketch`나 `display:'sketch'`인데 `sketchProjectionOk`가 false면 `sketch=false`, `display='solid'`로 바꾸고 `console.warn`한다(테스트).

### 7. 상태·Action
`XrayState`:
```ts
{
  mode: 'xray';
  settings: XraySettings;            // 6번을 정규화한 값
  view: { yaw: number; pitch: number };
  xray: boolean;
  xrayUsed: boolean;                 // toggle-xray로 한 번이라도 켰으면 true(처음 설정값은 세지 않음)
  tool: 'face' | 'edge' | 'vertex' | 'query' | null;   // tools 첫 항목, 없으면 null
  marked: { faces: XrayFaceId[]; edges: string[]; vertices: string[] };  // 3번 고정 순서로 정렬
  queryFace: XrayFaceId | null;
  segments: SketchSegment[];         // 정규화·정렬(a, b 순)
  lineStyle: 'solid' | 'dashed';     // 기본 'solid'
}
```
`XrayAction`:
| Action | 동작 |
| --- | --- |
| `{type:'set-view', yaw, pitch}` | `rotate`일 때만 4번 규칙으로 정규화해 바꾼다 |
| `{type:'rotate-view', dYaw, dPitch}` | `set-view`와 같은 규칙으로 더한다 |
| `{type:'toggle-xray'}` | `xrayToggle`일 때만 뒤집는다. 켤 때 `xrayUsed=true` |
| `{type:'set-tool', tool}` | 허용된 도구일 때만(`query`는 `faceQuery`일 때만) |
| `{type:'toggle-mark', kind, id}` | `kind`가 `tools`에 있고 id가 맞을 때 표시를 켜고 끈다. 지금 시점에서 보이는지는 reduce가 따지지 않는다(화면이 막는다) |
| `{type:'query-face', face}` | `faceQuery`일 때만. 같은 면을 다시 누르면 `null` |
| `{type:'clear-marks'}` | 표시를 모두 지우고 `queryFace=null` |
| `{type:'set-line-style', style}` | `sketch`일 때만 |
| `{type:'add-segment', a, b, style}` | `sketch`일 때만. 두 점이 격자 안이고 서로 달라야 한다. 같은 끝점 선분이 이미 있으면 잠기지 않은 경우에만 style을 바꾼다 |
| `{type:'remove-segment', a, b}` | 잠기지 않은 선분만 뺀다 |
| `{type:'clear-sketch'}` | 잠기지 않은 선분을 모두 뺀다 |

- **겨냥도 격자 범위:** `X ∈ [−1, 2w+d+1]`, `Y ∈ [−1, 2h+d+1]`
- **`prefill:'visible'`:** 보이는 모서리 9개를 잠긴 실선으로 미리 넣는다. 학생은 숨은 모서리 3개를 점선으로 더한다(A1 과제 4).
- 상태는 JSON 직렬화가 되어야 한다. 끄는 중인 시점·첫 점 같은 화면 지역 상태는 reduce 상태에 넣지 않는다.

### 8. 화면 `XrayView`
- **배치:** T138과 같은 `.stageRow`/`.sideStack` 규칙을 쓰고 판에 `data-mode="xray"`를 단다.
  - `sketch`가 없으면: 왼쪽(넓은 칸) `XrayStage`, 오른쪽 도구 막대·범례
  - `sketch`가 있으면: 왼쪽 `SketchGrid`, 오른쪽 `XrayStage`(작게)·도구 막대. sideStack 폭은 net-fold 규칙(`min(42%, 320px)`, `min-width 220px`)을 쓴다.
- **`XrayStage`(SVG, Three.js 쓰지 않음):**
  - 면을 깊이순(화가 알고리즘)으로 그린다.
    - 엑스레이 꺼짐: 보이는 면만 불투명(흰 바탕+옅은 음영)으로 그리고, 숨은 모서리·꼭짓점은 그리지 않는다.
    - 엑스레이 켜짐: 면 불투명도 0.35. 숨은 모서리는 회색 점선, 숨은 꼭짓점은 속이 빈 원으로 그린다.
    - `display:'sketch'`면 5번 사투상 그림을 고정으로 그린다. 숨은 모서리는 늘 점선이고 엑스레이 단추는 숨긴다.
  - **끌어 돌리기(`rotate`일 때):**
    - 8px 넘게 움직이면 끌기로 본다. 가로 1px = yaw 0.5°, 세로 1px = pitch 0.5°이고, 끄는 동안은 지역 상태로 그린다.
    - 떼면 15° 단위로 맞춘 `set-view`를 한 번 보낸다(바뀌었을 때만).
    - 8px 안에서 떼면 탭이다(표시·관계 보기).
    - `usePressGesture`의 이동 기준과 같은 값을 쓴다.
  - **단추:** ↺·↻(yaw ∓45°), ⤒·⤓(pitch +30°/−30°, `rotate-view`), "엑스레이"(aria-pressed, `xrayToggle`일 때). 모두 48px 이상이다.
  - **표시 도구 막대:** "면"·"모서리"·"꼭짓점"·("면 관계 보기")과 "표시 지우기"
    - 도구에 맞는 요소만 누를 수 있다.
    - 면은 보이는 면만 누를 수 있다.
    - 모서리·꼭짓점은 화면에 그려진 것(보이는 것 + 엑스레이로 비친 것)만 누를 수 있다.
    - 누르는 범위: 모서리는 투명한 28px 굵기 선, 꼭짓점은 반지름 24px 원
    - 꼭짓점 도구일 때 표시 안 된 꼭짓점은 작은 회색 점(반지름 5px)으로 보인다.
  - **표시 모양**(색만으로 알리지 않는다):
    - 표시한 면: 파란 테두리+가운데 ✓
    - 표시한 모서리: 굵은 파란 선+가운데 ✓ 원
    - 표시한 꼭짓점: 파란 원+✓
    - 숨은 요소에 한 표시는 숨어 있는 동안 그리지 않는다. 엑스레이를 켜거나 돌려서 보이면 다시 그린다.
  - **면 관계 보기(`query`):**
    - 누른 면: 파랑+"고른 면" 무늬(굵은 테두리)
    - 평행한 면: 같은 파랑+점 무늬
    - 수직인 면: 주황 줄무늬
    - 무대 아래 범례: "고른 면 · 평행한 면(점) · 수직인 면(줄무늬)". 숨은 면은 엑스레이가 켜졌을 때만 무늬가 보인다.
  - **개수를 쓰지 않는다.** 표시한 개수, "다 찾았어요" 같은 문구를 보이지 않는다. 판정은 GoalSpec과 응답 칸 몫이다.
- **`SketchGrid`(SVG):**
  - 점 간격은 `clamp(32px, 들어갈 수 있는 크기, 48px)`이다. 점은 지름 6px, 누르는 범위는 가장 가까운 점이다.
  - **선 긋기:**
    - 점을 누르면 첫 점(파란 고리)이 된다. 다른 점을 누르면 지금 `lineStyle`로 `add-segment`를 보낸다.
    - 점에서 눌러 다른 점에서 떼도 된다(Pointer Events).
    - 첫 점을 다시 누르면 첫 점을 취소한다.
  - **선 빼기:** 누른 위치가 가장 가까운 점에서 간격의 35%보다 멀고 잠기지 않은 선분에서 12px 안이면 그 선분을 뺀다. 점 누르기가 우선이다.
  - 잠긴 선은 진회색 실선, 학생 선은 파랑(실선 또는 점선 `6 5`)으로 그린다.
  - 단추: "실선"·"점선"(aria-pressed, 선 모양 그림 포함), "선 모두 지우기". 48px 이상이다.
  - 채점 결과(맞다·틀리다)는 화면에 쓰지 않는다.
- **키보드:**
  - 무대: Q/E는 yaw ±15°, W/S는 pitch ±15°, X는 엑스레이
  - 요소: 도구에 맞는 요소에 Tab으로 가서(3번 순서, 지금 누를 수 있는 것만) Enter·Space로 표시한다. aria-label은 "면 1"…, "모서리 1"…, "꼭짓점 1"…(번호는 3번 순서)이다.
  - 겨냥도: 방향키로 점 커서를 옮기고, Enter는 점 누르기, L은 실선·점선 바꾸기, Backspace는 커서 점에 붙은 마지막 학생 선분 빼기
- **test id:**
  - `xray-stage`, `xray-face-{id}`, `xray-edge-{id}`, `xray-vertex-{id}`. 요소에는 `data-hidden`, `data-marked`를 단다.
  - `xray-tool-{face|edge|vertex|query}`, `xray-toggle`, `xray-turn-left`/`right`, `xray-tilt-up`/`down`, `xray-clear-marks`
  - `xray-sketch`, `xray-dot-{X}-{Y}`, `xray-seg-{X1}-{Y1}-{X2}-{Y2}`, `xray-style-solid`/`dashed`, `xray-sketch-clear`
- **문구:** 모두 `strings.ko.ts`(`solid3dStrings.xray`)에 둔다.

### 9. Observation(`xray`)
```
mode:'xray', solid:{w,d,h}, display, view:{yaw,pitch}, xray, xrayUsed,
visibleFaces:[...],                      // 지금 시점(3번 순서)
marked:{faces:[...], edges:[...], vertices:[...]},
markedCount:{face, edge, vertex},
queryFace,
segments:["X1,Y1-X2,Y2:s|d", ...],       // 정렬
sketch: { visibleMissing, hiddenMissing, hiddenSolid, visibleDashed, extra, complete } | null
```
- cubes·net 전용 키는 넣지 않는다. 그래서 cubes·net predicate는 xray 관찰에서 false가 되고, xray predicate도 다른 모드 관찰에서 false가 된다(테스트).

### 10. predicate(잘못된 인자는 false)
| 이름 | 인자 | 참 조건 |
| --- | --- | --- |
| `markedCountIs` | `{kind, n}` | 그 종류의 표시 개수가 n |
| `allMarked` | `{kind}` | 그 종류를 모두 표시(6·12·8) |
| `markedFacesParallelTo` | `{face}` | 표시한 면이 정확히 `face`의 맞은편 하나 |
| `markedFacesPerpendicularTo` | `{face}` | 표시한 면이 정확히 `face`와 수직인 4면 |
| `xrayUsedIs` | `{value}` | `xrayUsed === value` |
| `sketchComplete` | — | `sketch.complete` |
| `sketchHiddenDrawnSolid` | — | `sketch.hiddenSolid > 0` (숨은 모서리를 실선으로 그림) |

- MC-3D-HIDDEN-UNCOUNTED 감지(모서리 9개 등)는 콘텐츠 카드의 응답 칸 판정이 맡는다. 엔진 쪽에서는 `markedCountIs {kind:'edge', n:9}`로도 감지할 수 있게 해 둔다.

### 11. 이벤트
`view-changed {yaw,pitch}`, `xray-toggled {on}`, `mark-toggled {kind,id,marked}`, `face-queried {face}`, `segment-added {style}`, `segment-removed {}`. `EVENT_NAMES`에 더한다.

### 12. 힌트 ② 오버레이 `xray-peek` (MC-3D-HIDDEN-UNCOUNTED)
- `NetHelperBox`와 같은 상자에 지금 시점의 상자를 엑스레이 켠 모습으로 작게 그린다. 면은 반투명, 숨은 모서리는 굵은 주황 점선, 숨은 꼭짓점은 속이 빈 원이다.
- 문구: "뒤쪽에 숨은 모서리와 꼭짓점도 있을까요?"
- 개수나 번호는 쓰지 않는다.
- `display:'sketch'`면 그리지 않는다(이미 점선이 보인다).
- `index.ts`의 `overlays`에 등록하고 단위 테스트(그림/안 그림)를 둔다.
