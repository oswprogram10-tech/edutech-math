4. **감지 함수 공통 규칙(W2와 같음):**
   - 입력은 `{ value, raw, args }`이다. args 값은 모두 **문자열**이거나 문자열 배열이다.
   - 수 계산은 `Rational`로만 한다(number 연산 금지).
   - "v ≠ 정답"이 모든 조건에 붙는다. args가 없거나 읽을 수 없으면 false를 돌려주고 예외를 던지지 않는다.
   - **고르기 응답:** `value`는 고른 선택지 id 문자열이다. 콘텐츠가 `path: "response.<id>.selected.0"`으로 넘긴다(한 개 고르기만, 여러 개 고르기는 감지하지 않는다).
5. **수 감지(9개).** v = 학생 값(Rational).

   | 코드 | args | 조건 |
   | --- | --- | --- |
   | MC-ANGLE-WRONG-SCALE | actual(실제 각, 도) | v = 180 − actual, actual ≠ 90 |
   | MC-AREA-SLANT-SIDE | base, height, slant | v = base × slant, slant ≠ height |
   | MC-AREA-TRIANGLE-NO-HALF | base, height | v = base × height (정답은 그 절반) |
   | MC-CIRCLE-AREA-AS-CIRCUMFERENCE | radius, pi | v = 2 × radius × pi, 그리고 v ≠ radius² × pi |
   | MC-CIRCLE-AREA-RECT-WIDTH | expected | v = 2 × expected (예: 원주의 1/2 칸에 1) |
   | MC-CLOCK-HOUR-BETWEEN | hour(1~12) | v = hour + 1 (12이면 1) |
   | MC-GEO-DIAGONAL-COUNT-DOUBLE | expected | expected > 0 이고 v = 2 × expected |
   | MC-GEO-RADIUS-DIAMETER | expected, given(선택) | 아래 참고 |
   | MC-SHAPE-VERTEX-COUNT | expected | v가 정수이고 v > expected |

   - **MC-GEO-RADIUS-DIAMETER:**
     - given이 있으면(반지름 ↔ 지름 바꾸기) v = given이거나, v = 반대 연산 값이다. 반대 연산 값은 expected = given × 2이면 given ÷ 2, expected = given ÷ 2이면 given × 2다.
     - given이 없으면(넓이·원주 계산) v = expected ÷ 2 또는 v = expected × 4다.

9. **테스트:**
   - **레지스트리:**
     - W3 단원 명세의 코드가 모두 있다.
     - `units`가 docs/05 표와 같다.
     - backtrack이 concepts.json·units.json에 있다.
     - `detect: 'diagnose'` 코드는 모두 감지 함수가 있고, `observation` 코드는 없다.
   - **감지 함수(`diagnose-w3.test.ts`):** 코드마다 아래 세 가지를 확인한다.
     - 오개념 값 → true
     - 정답 값 → false
     - args 없음·읽을 수 없음 → false
   - **경계값:**
     - WRONG-SCALE에서 actual = 90이면 false
     - RADIUS-DIAMETER: given이 있는 두 방향, given이 없는 경우
     - CLOCK-HOUR-BETWEEN에서 hour = 12 → v = 1이면 true
     - trap이 배열일 때
     - VERTEX-COUNT에서 v가 정수가 아니면 false
