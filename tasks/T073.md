3. **정답 노출 금지:** 발문·힌트·선택지 이름·라벨에 그 과제의 정답 값을 쓰지 않는다(명세가 정한 고르기 선택지 자체는 예외). 발문에 풀이 규칙("소수 자리 수를 더해요", "두 수에 같은 수를 곱해요", "0을 붙여요")을 쓰지 않는다 — 학생이 조작으로 찾을 규칙이다. 힌트 문구는 `{a}`·`{b}`(hintVars)·`{student}`만 템플릿으로 쓴다.
4. **힌트:** 과제마다 ①(발문 `say`)·②(`show` 오버레이, 없으면 `say`만)·③(`backtrack`, 명세 ③ 열). 오개념 규칙을 일반 규칙(`{"kind":"equals","path":"mode","value":"<모드>"}`)보다 앞에 둔다. 오버레이는 **이미 있는 것만** 쓴다: E07 `point-estimate`·`align-compare`·`quotient-gap`·`extend-zero`·`scale-tiles`·`remainder-place`·`quotient-check-line`, E04 `overlap-count`, E01 `empty-plate`·`break-preview`·`plate-levels`.
5. **오개념 규칙 거는 법(중요):**
   - `detect: 'observation'` 코드(MC-DEC-MULT-ALIGN-POINT, MC-DIV-NO-EXTEND-ZERO, MC-DEC-DIV-SCALE-ONE-SIDE, MC-MULT-ALWAYS-BIGGER, MC-DIV-ALWAYS-SMALLER)는 `when: {misconception}`로 **걸리지 않는다**. E07 코드는 `{"kind":"predicate","name":"hasMisconception","args":{"code":"…"}}`(g4s2u3.json 288행처럼), 응답 위젯으로 보는 코드는 `{"kind":"equals","path":"response.<id>.symbol"|"response.<id>.selected", "value": …}`로 건다.
   - `detect: 'diagnose'` 코드(MC-DEC-POINT-PLACEMENT, MC-DEC-SHIFT-POINT-MOVES, MC-DIV-QUOTIENT-ZERO, MC-DIV-REMAINDER-SCALED)는 응답 위젯 값에 `diagnose`(+`path`)를 달고 `when: {misconception}`으로 건다. `args` 값은 **문자열**(`{"expected":"0.18"}`). 감지 함수 args: POINT-PLACEMENT `{expected}`, SHIFT-POINT-MOVES `{original, expected}`, QUOTIENT-ZERO `{expected}`, REMAINDER-SCALED `{remainder, scale}`(`src/core/math/diagnose-w2.ts`). E07 격자에서 생기는 POINT-PLACEMENT·QUOTIENT-ZERO는 `hasMisconception` predicate로 건다(엔진 Observation `misconceptions`에 들어간다).
6. **E07 판정 값:** `quotientIs`·`remainderIs`·`resultIs`·`remainderGridIs`는 Rational 비교라 `"2.08"`이나 `"52/25"` 둘 다 된다(가독성을 위해 소수 문자열로 쓴다). 몫 칸 하나는 `quotientCellIs {column, digit}`(열은 자릿값 지수: 일 0, 소수 첫째 −1), 몫 점은 `{"kind":"equals","path":"quotientPoint","value":0}`, 붙인 0 개수는 `path: "extendedZeros"`.
7. **엔진·core 수정 금지:** 과제별 결정은 지금 엔진·실행기 기능만으로 만들 수 있게 정했다. 그래도 안 되는 곳(예: 어떤 Action이 생각대로 동작하지 않음)이 있으면 **엔진을 고치지 말고 멈춰서 묻는다.**

**과제별(g6s1u3)**
10. **A1 십진 모형 나누기(E01 `divide`, `interpretation:"decimal"`, `plates` = 나누는 수):** 판 = 1, 막대 = 0.1, 낱개 = 0.01. 판정은 `platesEqual` + `plateValueIs {value}`(접시마다 그 값) + `pileValueIs {value:"0"}`(무더기에 남은 것 없음) + `brokeAtLeast {from, count}`(`from`은 블록 모양 값: 판 100, 막대 10). 화면에 접시 값·몫을 쓰지 않으므로 응답 칸은 두지 않는다.
    - T1(C) `dividend:"6.24"`, `divisor:3` "6.24를 세 접시에 똑같이 나누어 보세요" → `plateValueIs "2.08"` + `brokeAtLeast {from:10, count:1}` + 공통 조건. ① "막대 2개를 3접시에 나누면 한 접시에 막대가 몇 개씩 가지?" ② `empty-plate` ③ `g6s1u3.decimal-div-whole-blocks`.
    - T2(C) `dividend:"4.2"`, `divisor:5` → `plateValueIs "0.84"` + `brokeAtLeast {from:100, count:1}`. ① "판 4개를 5접시에 똑같이 놓을 수 있을까? 놓을 수 없으면 어떻게 할까?" ② `break-preview` ③ `g6s1u3.decimal-div-whole-blocks`.
    - T3(P) `dividend:"3"`, `divisor:4` → `plateValueIs "0.75"` + `brokeAtLeast {from:100, count:1}` + `brokeAtLeast {from:10, count:1}`. ① "남은 것을 더 작은 단위로 풀어서 나눌 수 있을까?" ② `break-preview` ③ `g6s1u3.extend-with-zero`.
11. **A2 소수 나눗셈 세로셈(E07 `mode:"div"`, `decimal:true`, `flagSkippedZero:true`):** 목표는 기본으로 `quotientIs {value}` + `remainderIs {value:"0"}`(끝까지 나눔)를 쓴다. 공통 규칙(과제마다 이 순서로): `hasMisconception` MC-DIV-QUOTIENT-ZERO → ① "그 자리에서는 한 접시에 몇 개씩 갈까?"(과제 수에 맞게 써도 됨, 값은 쓰지 않음) ② `quotient-gap` ③ `g6s1u3.decimal-div-whole-blocks` / `hasMisconception` MC-DIV-NO-EXTEND-ZERO → ① "남은 수를 더 작은 단위로 풀어서 나눌 수 있을까?" ② `extend-zero` ③ `g6s1u3.extend-with-zero` / `hasMisconception` MC-DEC-POINT-PLACEMENT → ① 과제 수로 쓴 어림 발문(예 "8쯤을 4로 나누면 대략 얼마?") ② `quotient-check-line` ③ `g5s2u4.decimal-point-by-estimate` / 일반.
    - T1(P) `dividend:"8.16"`, `divisor:4` → `quotientIs "2.04"` + `remainderIs "0"` + `quotientCellIs {column:-1, digit:"0"}`.
    - T2(P) `dividend:"9.3"`, `divisor:6`, `extendZeros:2` → `quotientIs "1.55"` + `remainderIs "0"` + `extendedZeros`가 1 또는 2(`any`).
    - T3(A) `dividend:"0.45"`, `divisor:5` → `quotientIs "0.09"` + `remainderIs "0"` + `quotientCellIs {column:0, digit:"0"}` + `quotientPoint` 0.
    - T4(P) `dividend:"6.24"`, `divisor:3`, `debugSample:{quotientRaw:"2. 8"}` "친구는 6.24 ÷ 3 = 2.8이라고 풀었어요. 틀린 칸을 표시하고 바른 몫을 써 보세요" → `flaggedCell {row:"quotient", column:-1}` + 소수 응답 `ans "2.08"`. `diagnose` QUOTIENT-ZERO `{expected:"2.08"}`(2.8을 쓰면 걸림), POINT-PLACEMENT `{expected:"2.08"}`. **빈 몫 칸(열 −1)을 `flag-cell`로 표시할 수 없으면 멈추고 묻는다**(엔진을 고치지 않는다).
    - T5(A) `dividend:"19.5"`, `divisor:6`, `extendZeros:2` "먼저 어림해 보세요. 19.5 ÷ 6은 어느 쪽에 가까울까요? 고른 다음 세로셈으로 몫을 구해 보세요" + `choice`(단일) `est`: `three` "3쯤", `thirty` "30쯤" → `est ["three"]` + `quotientIs "3.25"` + `remainderIs "0"`. 규칙: `est ["thirty"]` → ① "18쯤을 6으로 나누면 대략 얼마?" ② `say`만 ③ `g5s2u4.decimal-point-by-estimate`.
12. **이번에 하지 않는 것(메모):** A2의 E01 모형 창 동기화(`linkedBlocks`), MC-DIV-ALWAYS-SMALLER(명세 '예고 감시' — g6s2u2 A1 T5에서 다룸), 완료 기준의 '0이 들어가는 문제 2개 연속' 판정.
