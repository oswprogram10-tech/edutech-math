## 구현 결정 (2026-11-02 Claude 추가 — 여기 적힌 대로 하고, 바꿔야 하면 메모에 이유를 적고 질문한다)
1. **파일:** 모두 `src/core/storage/`(공개 API는 `index.ts`), 테스트는 `src/core/storage/__tests__/`. `LearningEvent`(docs/02 §3)는 `src/core/storage/types.ts`에 정의한다. `JsonValue`·`UnitId`·`EngineId`는 T003의 `src/core/engine-sdk`에서 가져다 쓰되 고치지 않는다(고칠 게 있으면 메모에 요청).
2. **의존성:** `dexie`, `lz-string`, `qrcode-generator`(작고 의존성 없음)를 dependency로, 테스트용 `fake-indexeddb`를 devDependency로 추가해도 된다. 모두 번들에 포함(CDN 금지).
3. **학습자 키:** 1단계 학습자 ID는 학급 번호 문자열(`"1"`~`"30"`). 이름 입력란 없음. 관심사는 `docs/05` 문장제 스킨 키(`space`, `baseball` 등)의 배열.
4. **이벤트:** `logEvent()`가 `id`(`crypto.randomUUID()`)와 `t`를 붙여 저장한다. `data`의 타입은 JSON 값만 허용하고, **화면 좌표·궤적 키**(`clientX`, `clientY`, `pageX`, `pageY`, `screenX`, `screenY`, `offsetX`, `offsetY`, `movementX`, `movementY`, `trail`, `trajectory`, `pointerPath`)는 타입으로 막고 런타임에도 거부(오류)한다. 중첩 객체 안의 키도 검사한다. **엔진 Action의 논리 좌표 `x`·`y`는 허용한다**(예: E00 `{type:'move', id, x, y}` — T003에서 엔진 상태는 픽셀이 아닌 논리 좌표로 정했다). 테스트에 E00 Action을 그대로 기록하는 경우를 넣는다.
5. **기기 ID:** 처음 실행 때 `deviceId`(UUID)를 만들어 settings에 저장한다. 내보내기 파일에 들어간다.
6. **내보내기 파일 형식:** `{ format: 'mathexplorer-export', version: 1, deviceId, exportedAt, learners, events, mastery, taskProgress }`(settings·교사 PIN은 넣지 않는다). 파일 이름 `mathexplorer-<번호들>-<날짜>.json`.
7. **QR:** 내보내기 JSON을 lz-string(`compressToEncodedURIComponent`)으로 압축해 **2,000자 이하일 때만** QR로 보여 준다. 넘으면 "파일로 내보내기를 써 주세요" 안내(문구는 `src/core/storage/strings.ko.ts`). QR 읽기(카메라)는 이 카드 범위 밖이다.
8. **가져오기:** 교사 기기에서 파일 여러 개 선택 → 합치기. 이벤트는 `id`로 중복 제거, 학습자는 번호로 합침, mastery·taskProgress는 `updatedAt`이 최신인 값이 이긴다. 형식·버전이 다르면 그 파일만 건너뛰고 결과 요약(합친 파일 수, 건너뛴 파일과 이유)을 돌려준다.
9. **공유 코드:** `encodeShareCode(json)`/`decodeShareCode(code)`, URL 해시 `#s=<코드>`. 코드 4,000자 초과면 `TOO_LONG` 결과를 돌려준다(던지지 않음). 깨진 코드는 `INVALID`.
10. **교사 PIN:** `crypto.subtle` SHA-256(salt 포함) 해시만 저장. 4~6자리 숫자. 보안 장치가 아니라 학생이 실수로 교사 화면에 들어가는 것을 막는 문 정도라고 주석에 적는다.
11. **저장소 지속성:** 시작할 때 `navigator.storage.persist()`를 요청한다(지원할 때만). **아이패드 Safari는 홈 화면에 추가하지 않은 사이트의 저장 데이터를 7일 동안 안 쓰면 지울 수 있다** — `getStorageStatus()`가 `{ backend: 'indexeddb'|'memory', persisted: boolean }`를 돌려주고, 화면 안내는 T006에서 한다. 이 내용을 메모에 남긴다.
12. **메모리 대체:** IndexedDB 열기가 실패하면 같은 API의 메모리 저장소로 바꾸고 `backend: 'memory'`로 알린다. 두 구현이 같은 테스트를 통과하게 한다.
13. **E2E:** 앱 화면이 아직 없으므로 Playwright에서 `page.evaluate(() => import('/src/core/storage/index.ts'))`로 dev 서버의 모듈을 불러 저장 → `page.reload()` → 유지를 3개 뷰포트에서 확인한다.
