## 구현 결정 (2026-11-02 Claude 추가 — 여기 적힌 대로 하고, 바꿔야 하면 메모에 이유를 적고 질문한다)
1. **해시 라우팅:** GitHub Pages는 `/map` 같은 경로를 새로고침하면 404가 나므로 모든 화면을 해시 주소로 한다. `#/`(S1), `#/map`(S2 자리 — "준비 중" 화면과 활동 목록), `#/activity/<활동ID>`(예: `#/activity/demo.A1`), `#/teacher`. 기존 `#/sandbox/<엔진>`·`#/run/<단원>`은 개발·점검용으로 그대로 둔다. 라우터 라이브러리 없이 `src/app/router.ts`의 작은 해시 라우터로 만들고 테스트를 붙인다. 각 화면은 `React.lazy`로 지연 로딩해 첫 화면 JS(gzip) 70KB 이하를 유지한다.
2. **현재 학생:** S1에서 고른 번호를 settings의 `currentLearner`에 저장해 새로고침해도 유지한다. 번호를 고르지 않은 채 `#/activity/...`로 들어오면 S1로 보낸다. 학생 전환은 ⋯ 메뉴의 "다른 친구로 바꾸기" → S1. 학생 프로필은 T004 `learners`(번호 + 관심사)를 쓴다. 이름 입력란은 없다.
3. **관심사:** T004의 `INTERESTS` 6개(`baseball`, `cooking`, `space`, `game`, `animals`, `music`)를 아이콘 + 한국어 이름 타일로 보여 주고 여러 개 고르거나 건너뛸 수 있다. 아이콘은 SVG로 번들에 넣는다(이모지만으로 정보를 전달하지 않게 글자도 함께).
4. **활동 화면(S3):** `#/activity/<활동ID>`는 단원 ID(앞부분)로 콘텐츠를 불러 그 활동의 과제만 실행한다. `src/core/runner`의 `ActivityRunner`에 `activityId?`·`targetSize?`·`onTaskChange?(task)` prop을 추가해도 된다(러너에서 고칠 것은 이것뿐). 상단 바는 뒤로·제목·🔊·⋯만 둔다. **도움(힌트) 버튼은 T012 전까지 숨긴다**(눌러도 아무 일 없는 버튼을 두지 않는다). 교구 영역이 화면 높이의 75% 이상.
5. **TTS:** `speechSynthesis`에서 `lang`이 `ko`로 시작하는 음성을 고른다. 음성 목록은 `voiceschanged` 이후에 채워질 수 있으므로 기다렸다가 다시 찾는다. 한국어 음성이 없거나 API가 없으면 🔊 버튼을 숨긴다. **아이패드 Safari는 사용자 동작 없이 시작한 음성을 막으므로**, 자동 읽기는 그 화면에서 학생이 처음 한 번 터치한 뒤부터 동작하게 한다. 과제가 바뀌면 읽던 것을 멈춘다(`cancel`). 자동 읽기 켜기/끄기는 ⋯ 메뉴, settings에 저장.
6. **저학년 모드:** 단원 ID가 `g1`·`g2`로 시작하면 자동으로 켠다(`targetSize: 64`, 자동 읽기 기본 켬). ⋯ 메뉴에서 바꿀 수 있다. **학생 화면 어디에도 학년을 표시하지 않는다**(AGENTS 규칙 10) — 메뉴 문구도 "큰 버튼" 같은 말을 쓴다.
7. **교사 PIN(`#/teacher`):** 처음이면 4자리 PIN 만들기(두 번 입력), 다음부터 PIN 입력. T004 `hashPin`/`verifyPin`을 쓴다. `PinUnavailableError`면 "이 주소(http)에서는 선생님 PIN을 쓸 수 없어요. https 주소로 열어 주세요." 안내를 보여 준다. PIN을 통과하면 교사 첫 화면(엔진 샌드박스 목록 링크 + 저장소 상태 + "S4·S5는 다음 카드에서" 자리). PIN 분실 복구는 1단계에서 만들지 않는다(메모에 적는다).
8. **저장소 안내:** `getStorageStatus()`가 `backend: 'memory'`면 S1과 교사 화면에 "이 기기에서는 기록이 저장되지 않아요(사생활 보호 모드 등)" 띠를 보여 준다. `persisted: false`면 **교사 화면에만** "아이패드는 홈 화면에 추가해야 기록이 오래 남아요" 안내를 보여 준다(학생 화면에는 띄우지 않는다).
9. **글꼴:** `pretendard` npm 패키지(OFL)를 devDependency로 설치하고, 그 안의 **한글 2350자 서브셋 woff2(굵기 400·700 두 개)**만 `public/fonts/`에 복사해 `@font-face`로 쓴다. 라이선스 파일(`public/fonts/LICENSE-Pretendard.txt`)을 함께 넣는다. 다른 굵기·전체 글꼴은 넣지 않는다. CDN 금지.
10. **스크린샷 테스트:** Playwright `toHaveScreenshot`으로 S1·S3(`#/activity/demo.A1`)·교사 PIN 화면을 3개 뷰포트에서 찍는다. 기준 이미지는 저장소에 넣고 `maxDiffPixelRatio: 0.02`. CI는 E2E를 돌리지 않으므로 로컬 기준이다(메모에 적는다).
11. **문구:** 학생 화면 문구는 `src/app/strings.ko.ts`에. 실패·오류 문구는 "다시 볼까요?" 계열(docs/09 §4). 점수·별점·축하 애니메이션 보상은 넣지 않는다(AGENTS 규칙 11).
12. **범위 밖:** S2 별자리(T008), 힌트(T012), 교사 시연 도구(T007), '보여 주기' 공유 코드 버튼(T007), S5 관리(별도 카드).
