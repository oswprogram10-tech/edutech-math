## 목표
새 엔진 `src/engines/E06-balance/`를 만들고 `equation` 모드를 구현한다.
- 수 막대와 □ 상자를 양쪽 접시에 놓는다.
- □에 수를 넣어 보면 저울이 기운다(결정적 애니메이션).
- 양쪽에 같은 수를 더하거나 빼서 □만 남길 수 있다.
- 이 카드는 g2s1u3.A2(다음 카드)에 쓴다.
- `compare`는 g1s1u4(E13 이후) 때 따로 카드를 만든다. `proportion`은 g6s2u4 때 만든다. 이 카드에서는 모드 목록에도 넣지 않는다.

## 구현 결정 (2026-11-20 Claude 작성 — 여기 적힌 대로 하고, 바꿔야 하면 메모에 이유를 적고 멈춰서 묻는다)

### 1. 설정 (`types.ts`)
```ts
type BalanceTerm = { num: string | number; neg?: boolean } | { box: true };
interface BalanceConfig {
  mode?: 'equation';                  // 기본 'equation'
  left: BalanceTerm[];
  right: BalanceTerm[];
  allowTryValue?: boolean;            // 기본 true: □에 수 넣어 보기
  allowBothSides?: boolean;           // 기본 true: 양쪽에 같은 수 더하기·빼기
  allowOneSide?: boolean;             // 기본 false: 한쪽만 더하기·빼기(기울어짐을 보여 주는 실험)
  predict?: boolean;                  // 기본 false: 조작 전에 "수평일까?" 예/아니요 잠금
  look?: 'scale' | 'bars' | 'symbols';// 기본 'scale' (C 저울 / P 막대 두 줄 / A 식만)
  showTotals?: boolean;               // 기본 true: 접시별 합(□를 넣어 봤을 때만 그 값 포함)
  tiltAnimation?: 'deterministic';    // 받기만 하고 무시해도 됨(명세 호환)
}
```
- **수는 `Rational`로 다룬다**(문자열 저장). 이 카드는 0 이상의 정수만 허용한다. 소수·분수·음수 `num`은 설정 오류로 둔다(`neg`는 "□ − 16"의 빼는 항 표시용이고 `num` 자체는 양수).
- □는 전체에 **0개 또는 1개**다. 2개 이상이면 설정 오류. 0개인 설정(예: 20 + 15 = 35)도 된다(예측 실험용).
- **설정에 □의 정답을 두지 않는다.** 기울기는 학생이 넣은 값으로만 계산한다.
- 설정 오류는 다른 엔진처럼 화면에 오류 문구로 보여 준다(기존 방식 따르기).

### 2. 상태와 Action (`reduce.ts`, 순수, JSON 직렬화)
- **상태**
  - `left`·`right`: `{ const: string; hasBox: boolean }` — 항들을 합친 수(빼는 항은 음수로 합침, 그래서 const는 음수일 수 있다)
  - `initial`: 설정에서 만든 처음 상태(되돌리기용)
  - `tryValue: string | null`, `tries: string[]`
  - `ops: { kind: 'both-add' | 'both-remove' | 'one-add' | 'one-remove'; n: string; side?: 'left' | 'right' }[]`
  - `prediction: 'yes' | 'no' | null`
- **Action**
  - `try {value}`: □에 넣어 보기(□가 있을 때만, `allowTryValue`)
  - `both {op:'add'|'remove', n}`
  - `one {op, side, n}`(`allowOneSide`일 때만)
  - `predict {value}`(잠그기 전 한 번만)
  - `reset`: 처음 상태로. `tries`·`ops`·`prediction`은 지우지 않는다(기록).
- **빼기 규칙:** 한 접시의 const가 n보다 작으면 그 빼기는 거절한다(상태 그대로). 화면은 "그만큼 뺄 수 있는 막대가 없어요" 같은 안내를 보인다. 더하기 n은 1~999.
- **예측 잠금:** `predict:true`이면 예측 전에는 `both`·`one`·`try`를 거절한다. 화면에도 예/아니요를 먼저 보이고 조작 칸을 막는다(gears와 같은 방식).

### 3. Observation (`observe.ts`)
```ts
{
  mode: 'equation';
  leftValue: string | null;   // □가 그쪽에 있고 아직 안 넣어 봤으면 null
  rightValue: string | null;
  balanced: boolean;          // 두 값이 모두 있고 같을 때만 true
  tilt: 'left' | 'right' | 'level' | 'unknown';  // 무거운 쪽
  tryValue: string | null;
  tries: string[];
  boxIsolated: boolean;       // □가 있는 쪽 const가 0이고 다른 쪽에 □가 없다
  boxValue: string | null;    // balanced면 tryValue, 아니면 boxIsolated일 때 반대쪽 const, 아니면 null
  bothSidesOps: number;
  oneSideOps: number;
  ops: ...;                   // 상태 그대로
  prediction: 'yes' | 'no' | null;
  predictionLocked: boolean;
  misconceptions: string[];
}
```
- **MC-EQUAL-ANSWER:** 넣어 본 값 중 하나라도 처음 설정의 모든 수(빼는 항 포함, 절댓값)의 합과 같으면 기록한다. 예를 들어 60 = □ + 37에 97을 넣거나, 25 + □ = 43에 68을 넣는 경우다. 수가 하나뿐이면 감지하지 않는다.

### 4. Predicates (`events.ts`)
`balanced`, `boxValueIs {value}`, `boxIsolated`, `bothSidesOpsAtLeast {n}`, `oneSideOpsAtLeast {n}`, `predictionIs {value:'yes'|'no'}`, `predictionLocked`, `triesAtMost {n}`, `hasMisconception {code}`
- `boxValueIs`는 Rational 비교(문자열 "18"과 "18/1" 같은 표기 차이 무시).
- 이벤트: `balance-changed {balanced, tilt}`를 상태가 바뀔 때 낸다(다른 엔진 `emit` 방식 따르기). 연동은 이번 카드에서 쓰지 않는다.

### 5. 화면 (`View.tsx`, 논리 1000×600 SVG)
- **look `scale`(C)**
  - 받침대, 가로대, 양쪽 접시가 있다. 접시 위에 수 막대를 쌓는다.
  - 막대 길이는 값에 비례한다. 같은 판 안에서 가장 큰 값이 접시 폭이 되게 맞춘다.
  - 막대마다 수 글자를 단다.
  - 빼는 항은 빗금 + "−16" 글자 + 다른 모양(점선 테두리)으로 그린다. 색만으로 구분하지 않는다.
  - □ 상자
    - 넣어 보기 전에는 "□" 글자와 고정 폭으로 그린다.
    - 넣어 본 뒤에는 그 값에 비례한 폭과 "□ = 넣은 값" 글자로 그린다.
- **look `bars`(P):** 저울 없이 왼쪽 줄과 오른쪽 줄의 막대(같은 축척)를 위아래로 놓는다. 가운데에 `=`/`≠` 기호와 글로 결과를 보인다.
- **look `symbols`(A):** 식 한 줄(예: `25 + □ = 43`, □를 넣었으면 그 값을 넣은 식)과 `=`/`≠` 표시만 둔다.
- **기울기**
  - 각도는 `level`이면 0°다. 아니면 무거운 쪽으로 `4° + 8° × min(1, |L−R| / max(L, R, 1))`이고, 최대는 12°다.
  - 값을 모르면(unknown) 수평으로 두고 □에 물음표를 단다.
  - CSS transition 400ms를 쓰고, `prefers-reduced-motion`이면 바로 바꾼다.
  - `data-tilt`를 단다.
- **결과 글(색만으로 전달 금지)**
  - "왼쪽이 더 무거워요", "오른쪽이 더 무거워요", "수평이에요", "□에 수를 넣어 보세요"
  - `showTotals`면 접시 아래에 합을 쓴다. □가 있는 쪽은 넣어 본 값이 있을 때만 쓴다.
  - 문구는 모두 `strings.ko.ts`에 둔다.
- **조작 칸**(SVG 밖, 판 옆이나 아래)
  - □ 넣어 보기: 숫자 키패드(0–9, ⌫)와 [넣어 보기] 단추
  - 양쪽: 수 칸 + [양쪽에 더하기]·[양쪽에서 빼기] 단추
  - 한쪽(`allowOneSide`): [왼쪽에만 더하기] 등 4개 단추
  - [처음으로] 단추
  - 예측 단추(예/아니요): `predict`일 때만
  - 단추는 48px 이상이다. 저학년 모드에서는 64px 이상이다(다른 엔진의 저학년 모드 처리 방식을 따른다).
- **키보드**
  - 숫자 키는 지금 고른 수 칸에 쓴다.
  - Enter는 [넣어 보기]다.
  - Tab으로 모든 단추에 닿는다.
- **판 맞춤:** `layout:'fit'`로 둔다. 판이 좁으면 최소 배율 0.6 아래로 줄이지 않고 스크롤한다. 조작 칸은 스크롤 상자 밖에 둔다.
- **정답 노출 금지**
  - 화면·DOM·aria에 □의 정답이 나오지 않는다(엔진은 정답을 모른다).
  - 양쪽 연산 후 반대쪽 막대 값(예: 18)은 학생이 만든 결과라 보여도 된다.

### 6. 오버레이 (`overlays/`, 힌트 ②, `CanvasAlignedOverlay`로 SVG에 맞춤)
- **`big-tilt`**(MC-EQUAL-ANSWER ②): 학생이 마지막으로 넣은 값으로 저울을 크게(12°) 기울인 반투명 그림자 저울을 그린다. 그 위에 두 쪽 합을 큰 글자로 쓰고 사이에 `≠`를 둔다. 넣은 값이 없으면 아무것도 그리지 않는다.
- **`match-bars`**(일반 ②)
  - □가 없는 쪽 막대 아래에, □가 있는 쪽 수 막대와 같은 길이의 점선 구간을 맞춰 그린다.
  - 남는 구간에는 "?"만 쓴다(값을 쓰지 않는다).
  - □가 없거나 □가 있는 쪽 const가 0 이하이면 그리지 않는다.
- look `symbols`에서는 두 오버레이 모두 그리지 않는다.

## 메모

### 구현 메모 (Sonnet, T187)
- 상태 `left`/`right`는 카드대로 `{const, hasBox}`로 합쳤다. 그래서 `20 + 15`는 접시에 막대 하나(35)로 그려진다(항별 막대는 상태에 없다). 수 막대 → □ 순서로 고정(`□ − 16`의 순서도 저울에서는 수 막대가 아래).
- `predictionLocked` 관찰값·predicate는 E15 gears와 같은 뜻으로 "예측을 잠갔는가(prediction !== null)"로 했다. 예측 전 조작 막힘은 reduce 안의 `isLocked`(관찰값에는 안 둠). 카드가 "잠겨 있는가"를 뜻했다면 반대이니 T188 때 확인 필요.
- 막대 최소 폭 36px(논리), 막대 길이 비례에서 아주 작은 값만 이 값으로 올려 쓴다.
- 설정 한쪽(`left`만 또는 `right`만)만 주면 설정 오류. 둘 다 없으면 샌드박스 기본 `25 + □ = 43`.
- `try` 값은 0~999, 더하기·빼기 n은 1~999. `predict:false`인데 `predict` Action이 오면 거절.
- 빼기 안내("그만큼 뺄 수 있는 막대가 없어요")는 View(지역 상태)가 reduce 규칙(`canRemove`)을 미리 검사해 띄운다. reduce도 같은 규칙으로 거절한다.
- big-tilt·match-bars는 look `scale`·`bars`에서 그리고 `symbols`에서는 안 그린다. big-tilt는 `bars`에서도 그림자 저울을 겹친다(카드가 symbols만 제외).
- 추가 문구: 값을 못 구하는데 `allowTryValue:false`이면 "□ 때문에 아직 알 수 없어요"(카드 4문구 밖).
- 스냅샷: `tests/e2e/balance.spec.ts-snapshots/` (scale·bars·symbols 첫 화면, scale 17 기울임, 크롬북·아이패드).
