## 할 일
- [ ] 도형 카드 데크(삼각형 12장 자동 생성, 사각형 16장 — 회전·크기 다양). 카드 성질(변·각)은 정확 계산으로 정한다. P 단계 카드에는 변·각 표시, A 단계는 표시 없음
- [ ] 모드 `venn`(`layout: grid`): 행·열 조건 3×3 표에 카드 끌어 넣기, 칸 조건과 맞는지 칸 상태 표시(색 + 무늬·글자), 불가능한 칸 고르기
- [ ] 모드 `secret-rule`의 `twenty-questions`: 컴퓨터가 seed로 비밀 카드 고르기, 질문 카드로 묻기, 학생이 직접 카드 지우기(자동 지우기 아님), 질문 수 기록. 역할 바꾸기(`roleSwap`): 컴퓨터 질문에 학생이 답하고, 틀리면 근거 문장 제시
- [ ] 모드 `hierarchy`: 사각형 조건 토글(`constraintToggles`)로 모양이 바뀌는 사각형과 포함 관계 트리, 트리 빈칸에 이름 카드 넣기, `trapezoidDefinition`(`inclusive`/`exclusive`) 설정
- [ ] 엔진끼리 import 금지: E09 점판·드래깅 테스트와 함께 써야 하면 실행기 두 판으로 하고, E17 안에서는 자기 사각형만 그린다
- [ ] Observation·predicates·이벤트·오버레이, 단위 테스트(seed 결정성, 지운 카드 모순 판정), `#/sandbox/E17` E2E
