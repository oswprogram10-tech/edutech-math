## g2s2u1 네 자리 수
| 항목 | 내용 |
| --- | --- |
| 영역 | 수와 연산 |
| 엔진 | E01 수 모형, E03 수직선 |
| 선수 단원 | g2s1u1 세 자리 수 |
| 차시 규모(참고) | 약 8~9차시 중 앱 활용 3차시 (교과서 확인) |

**핵심 아이디어:** 100이 10개면 1000. 1000 모형은 100 판 10장을 쌓은 큐브다. 네 자리 수는 천·백·십·일의 개수로 나타내고, 수직선에서 보면 1000은 10보다 훨씬 멀리 있다.

| ID | 개념 | 선수 개념 |

| g2s2u1.thousand-unit | 100이 10개 = 1000 | g2s1u1.hundred-unit |
| g2s2u1.four-digit | 네 자리 수 읽고 쓰기, 자릿값 | g2s2u1.thousand-unit, g2s1u1.digit-value |
| g2s2u1.magnitude | 10·100·1000·10000의 상대적 크기, 뛰어 세기, 크기 비교 | g2s2u1.four-digit |

### 활동
#### g2s2u1.A1 1000 큐브 적층 스튜디오 — E01 `count`, `regroup` · C→P→A
- **원 계획서:** 1,000모형 3D 큐브 적층 스튜디오
- **화면과 조작:** 100 판을 끌어 쌓기 틀에 한 장씩 올리면 등각(2.5D) 큐브가 자란다. 10장이 되면 1000 큐브로 합체. 큐브를 망치로 두드리면 판 10장으로 풀린다. 자릿값 표 4칸(천·백·십·일) 동기화.
- **설정 예시:**
  ```json
  { "mode": "regroup", "allowedBlocks": [1, 10, 100, 1000], "stackFrame": true, "render": "isometric", "chart": ["thousands", "hundreds", "tens", "ones"] }
  ```
- **과제:**
  1. 판 10장 쌓아 1000 만들기 / 판정: `thousands == 1`
  2. 2천 4백 3십 6 만들기 / 판정: 값 2436, 정규형
  3. 판 13장 + 막대 5개 → 수 쓰기 / 판정: 정규형 1350, 입력 1350
  4. 3058 블록으로 / 판정: 값 3058(십 칸 0)
  5. 큐브 1개를 풀고도 값이 같음 확인 / 판정: 값 불변, 판 10장 증가
- **CPA 페이딩:** C: 등각 큐브 / P: 평면 기호(□ 판, ▮ 막대) / A: 자릿값 표

#### g2s2u1.A2 핀치 줌아웃 수직선 — E03 `log-zoom` · P→A
- **원 계획서:** 로그 스케일 핀치 줌아웃(10 → 10000) 수직선
- **화면과 조작:** 0~10 수직선에서 시작. 두 손가락 오므리기(또는 − 버튼)로 줌아웃하면 0~100, 0~1000, 0~10000으로 눈금이 바뀌고 이전 구간이 작은 조각으로 줄어 보인다. 수 카드를 알맞은 자리에 놓기.
- **설정 예시:**
  ```json
  { "mode": "log-zoom", "levels": [10, 100, 1000, 10000], "controls": ["pinch", "wheel", "buttons"], "placeCards": [500, 1000, 2500, 9000] }
  ```
- **과제:**
  1. 0~1000에서 500 놓기 / 판정: 위치 오차 ≤ 1눈금(100)
  2. 0~10000에서 1000, 2500 놓기 / 판정: 오차 ≤ 1눈금(500 또는 1000 눈금 설정에 따름)
  3. "1000씩 뛰어 세기 3200부터 3번" / 판정: 4200, 5200, 6200
  4. 4개 수(2987, 3010, 2899, 3100) 작은 것부터 / 판정: 순서 일치
- **CPA 페이딩:** P: 줌 연출 / A: 수 카드만 정렬

## g2s2u2 곱셈구구
| 항목 | 내용 |
| --- | --- |
| 영역 | 수와 연산 |
| 엔진 | E04 배열·넓이 모델 |
| 선수 단원 | g2s1u6 곱셈 |
| 차시 규모(참고) | 약 10~12차시 중 앱 활용 4~5차시 (교과서 확인) |

**핵심 아이디어:** 모르는 곱셈은 아는 곱셈으로 쪼개서 만든다(7×8 = 7×5 + 7×3). 단이 하나 커지면 곱이 그 수만큼 커진다. 곱셈표는 대각선을 기준으로 대칭이다(교환법칙). 1과 0의 곱에는 규칙이 있다.

### 개념 노드
| ID | 개념 | 선수 개념 |
| --- | --- | --- |
| g2s2u2.facts-by-table | 2~9단 곱셈구구 | g2s1u6.mult-sentence |
| g2s2u2.split-strategy | 아는 곱셈으로 쪼개기(분배) | g2s2u2.facts-by-table, g2s1u6.array |
| g2s2u2.table-step | 단의 곱이 그 수만큼 커지는 규칙 | g2s2u2.facts-by-table |
| g2s2u2.one-zero | 1의 곱, 0의 곱 | g2s1u6.equal-groups |
| g2s2u2.table-symmetry | 곱셈표 대칭(교환법칙) | g2s1u6.array |

### 활동
#### g2s2u2.A1 무연필 배열판 분할 전략가 — E04 `split` · C→P→A
- **원 계획서:** 무연필 격자 배열판 분할(예: 7×8 = 7×5 + 7×3) 전략가
- **화면과 조작:** 7×8 점 배열. 세로(또는 가로) 분할선을 끌어 배열을 두 부분으로 나누면 각 부분의 곱이 색별로 표시되고 식이 생긴다(`7×5 + 7×3`). 학생은 아는 곱이 되도록 분할 위치를 고른다. 5단 분할선에는 약한 자석.
- **설정 예시:**
  ```json
  { "mode": "split", "rows": 7, "cols": 8, "maxSplits": 1, "orientation": "either", "snapHints": [5], "showPartials": "color" }
  ```
- **과제:**
  1. 6×7을 5와 2로 나눠 구하기 / 판정: 분할 후 부분곱 30, 12, 결과 42
  2. 7×8을 내 방법으로 / 판정: 결과 56, 부분곱 합 == 56
  3. 8×9를 두 가지 다른 분할로 / 판정: 서로 다른 분할 2개, 결과 모두 72
  4. 9×6 = 10×6 − 1×6 (빼기 분할: 10줄에서 1줄 지우기) / 판정: 54
- **CPA 페이딩:** C: 사탕 배열 / P: 점 배열 / A: 분할 식만

#### g2s2u2.A2 곱셈표 대칭 색칠 보드 — E04 `times-table` · P→A
- **원 계획서:** 곱셈표 대칭 색칠 보드
- **화면과 조작:** 빈 곱셈표(1~9 × 1~9). 아는 칸부터 채우면 같은 값의 대칭 칸이 반짝인다(대각선 접기 애니메이션). 같은 수가 나오는 칸을 같은 색으로 칠하기, 한 줄의 규칙(+단씩) 화살표 그리기.
- **설정 예시:**
  ```json
  { "mode": "times-table", "size": [9, 9], "prefill": "rows-2-5", "symmetryReveal": true, "colorSameValue": true }
  ```
- **과제:**
  1. 4단 줄 채우기 / 판정: 4, 8, …, 36
  2. "4×7과 같은 값의 칸을 찾아요." / 판정: 7×4 칸 선택
  3. 대각선으로 접으면 겹치는 칸 값이 같을까 예측 → 접기 / 판정: 예측 == 예
  4. 1단·0의 곱(0×5, 5×0) 칸 / 판정: 5, 0, 0
  5. 곱이 24인 칸 모두 / 판정: {3×8, 4×6, 6×4, 8×3}
- **CPA 페이딩:** P: 칸에 점 배열 미니 그림 / A: 숫자만

## g2s2u3 길이 재기
| 항목 | 내용 |
| --- | --- |
| 영역 | 도형과 측정 |
| 엔진 | E13 측정 실험실 |
| 선수 단원 | g2s1u4 길이 재기 |
| 차시 규모(참고) | 약 7~8차시 중 앱 활용 3차시 (교과서 확인) |

**핵심 아이디어:** 긴 길이를 cm로 재면 수가 너무 커진다 → 100cm = 1m라는 더 큰 단위. 1m 20cm = 120cm. 길이도 m는 m끼리, cm는 cm끼리 더하고 뺀다.

### 개념 노드

| g2s2u3.length-add-sub | 길이의 덧셈·뺄셈(받아올림·받아내림 포함) | g2s2u3.m-cm-convert, g2s1u3 |
| g2s2u3.estimate-m | 1m 어림, 몸의 길이로 어림 | g2s2u3.meter-unit |

### 활동
#### g2s2u3.A1 100cm → 1m 줄자 합체 — E13 `length` · C→P
- **원 계획서:** 100cm → 1m 줄자 합체
- **화면과 조작:** 10cm 막대(10칸)를 끌어 이어 붙이면 길이 띠가 자란다. 10개(100cm)가 되면 띠가 말리며 '1m 줄자' 한 개로 합체. 교실 물건(칠판, 문, 사물함) 길이를 1m 줄자와 10cm 막대로 재기.
- **설정 예시:**
  ```json
  { "mode": "length", "units": ["cm-10-rod", "m-tape"], "mergeRule": { "from": "cm-10-rod", "count": 10, "to": "m-tape" }, "object": { "name": "blackboard", "lengthCm": 320 } }
  ```
- **과제:**
  1. 10cm 막대 10개 이어 1m 만들기 / 판정: 합체 이벤트 발생
  2. 칠판 길이 재기 / 판정: 3m 20cm 입력 + `320cm` 입력 둘 다
  3. 135cm를 m와 cm로 / 판정: 1m 35cm
  4. 2m 5cm를 cm로 / 판정: 205
- **CPA 페이딩:** C: 띠와 막대 / P: 길이 막대 도식 / A: 단위 변환 식

#### g2s2u3.A2 길이 블록 기차 단위 승격기 — E13 `length` · P→A
- **원 계획서:** 길이 블록 기차 단위 승격기
- **화면과 조작:** 기차 칸 두 줄(m 칸, cm 칸). 두 길이를 더하면 cm 칸 블록이 100을 넘을 때 '승격' 버튼으로 1m 칸 하나로 바꾼다(E01 받아올림과 같은 논리). 뺄셈은 1m 칸을 100cm로 풀기.
- **설정 예시:**
  ```json
  { "mode": "length", "variant": "unit-train", "op": "add", "a": "1m 70cm", "b": "2m 50cm", "promote": { "cm": 100, "m": 1 } }
  ```
- **과제:**
  1. 1m 30cm + 2m 40cm / 판정: 3m 70cm
  2. 1m 70cm + 2m 50cm (승격) / 판정: 4m 20cm, 승격 Action 1회
  3. 5m 20cm − 2m 60cm (풀기) / 판정: 2m 60cm
  4. 기차 없이 식만 / 판정: 결과 동치
- **CPA 페이딩:** P: 기차 블록 / A: 세로 정렬된 'm | cm' 칸 계산
