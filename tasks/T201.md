## 목표
새 엔진 `src/engines/E14-clock-time/`를 만든다. 이 카드에서 만드는 것은 두 가지다.
- `clock` 모드: 긴바늘을 돌리면 짧은바늘이 톱니처럼 따라 돈다.

### 1. 공통
- **시각 표현**
  - 상태는 12시간 시계의 분 `minutes: number`(0~719 정수)로 둔다. 0은 12:00이다.
  - 시는 `floor(minutes/60)`인데 0이면 12다. 분은 `minutes % 60`이다.
  - 짧은바늘 각도는 `minutes × 0.5°`, 긴바늘은 `(minutes % 60) × 6°`다.
  - 시각 문자열은 `"H:MM"`(예: `"8:30"`, `"12:05"`)이다. 설정·Observation·predicate가 모두 이 형식을 쓴다.
- **판 맞춤**
  - 논리 크기는 1000×600 SVG다. 시계는 왼쪽 원(지름 약 480)에 그리고, 펼친 띠는 아래에 둔다.
  - `layout:'fit'`, 최소 배율 0.6, 그 아래는 스크롤한다.
  - 조작 칸은 T199 원칙(세로 배치에서 `flex: 0 0 auto`, 바깥 상자 세로 스크롤)을 처음부터 따른다.
- **입력·접근성**
  - 단추는 48px다. 1·2학년 단원은 실행기가 64px로 키우므로 `--touch-target` 변수를 따른다.
  - 끌기는 Pointer Events로 한다.
  - 색만으로 바늘을 구분하지 않는다. 긴바늘은 길고 가늘다. 짧은바늘은 짧고 굵으며 끝 모양이 다르다.
- **정답 노출 금지**
  - 판 안에 시각 숫자(디지털 표시)는 `digitalReadout:'always'`일 때만 쓴다.
  - 기본은 `'never'`다. 읽기 과제에서 시각 글이 DOM·aria에 나오지 않게 한다.
  - 바늘 aria는 "긴바늘", "짧은바늘"과 가리키는 방향만 말한다(예: "긴바늘이 6을 가리켜요").
  - 짧은바늘이 두 수 사이일 때 aria는 "짧은바늘이 8과 9 사이에 있어요"로 말하고, 시를 계산해 말하지 않는다.
- 문구는 `strings.ko.ts`에 둔다. 학년 표시·점수는 두지 않는다.

### 2. `clock` 설정
```
{ mode:'clock',
  start?: "H:MM",                 // 처음 시각, 기본 "12:00"
  granularity?: 'hour'|'half-hour'|'five-minute'|'minute',   // 기본 'minute'
  snapMinuteTo?: number[] | '5-weak',
  showGears?: boolean,            // 기본 false
  hideMinuteHand?: boolean,       // 읽기 과제용: 긴바늘 숨김
  readOnly?: boolean,             // 바늘을 못 움직임(읽기 과제)
  digitalReadout?: 'never'|'always',   // 기본 'never'
  unroll?: boolean }              // 펼치기 단추를 보임, 기본 false
```
- **허용 분.** `granularity`가 허용 분 간격을 정한다(60·30·5·1).
  - `snapMinuteTo`가 배열(예: `[0,30]`)이면 그 분들만 허용하고 `granularity`보다 우선한다.
  - `'5-weak'`이면 1분 단위로 움직이되, 끌다가 손을 뗄 때 5의 배수에서 ±1분 안이면 5의 배수에 붙는다. 키보드는 1분씩 움직인다.
  - `start`가 허용 분이 아니면 설정 오류다.
- `docs/04-units`의 `digitalReadout:"after-submit"`은 실행기에 제출 결과를 엔진에 알리는 계약이 없어 지원하지 않는다. 설정에 오면 `'never'`로 읽고 메모에 남긴다.

### 3. `clock` 조작
- **긴바늘 끌기.**
  - 포인터 각도의 변화를 누적해 분을 바꾼다(되감기). 12를 시계 방향으로 지나면 다음 시가 되고, 반대 방향이면 이전 시가 된다. 0과 719 사이는 감아 돈다.
  - 끄는 동안에는 지역 미리보기로 두 바늘을 함께 움직인다. 손을 뗄 때 허용 분에 맞춘 `set-time` Action을 한 번 보낸다.
- **짧은바늘 끌기도 허용한다.** 짧은바늘 각도로 분을 정하고(긴바늘이 그만큼 빨리 돈다) 같은 규칙으로 맞춘다. 1학년이 짧은바늘만 돌려 보는 탐색도 막지 않는다.
- **키보드.**
  - 시계 판은 `role="slider"`다. ←→는 허용 간격 한 칸씩 움직이고, Shift+←→는 1시간씩 움직인다.
  - aria-valuetext는 1번의 바늘 방향 문장이다.
  - 같은 조작을 하는 단추 [◀ 거꾸로]와 [앞으로 ▶]를 조작 칸에 둔다.
- **Action:**
  - `set-time {minutes}`: 허용 분이 아니면 거절한다. 같은 값도 거절한다.
  - `step {delta}`: 허용 간격의 배수다.
  - `toggle-unroll`
  - `reset`
  - `readOnly`이면 `set-time`과 `step`을 거절한다.
- **톱니(`showGears`).**
  - 시계 판을 반투명하게 하고 뒤에 맞물린 톱니 둘을 그린다. 큰 톱니는 긴바늘 축에, 작은 톱니는 짧은바늘 축에 붙인다.
  - 큰 톱니는 긴바늘과 같이 돌고, 작은 톱니는 짧은바늘과 같이 돈다(그림만).
  - 이름표 "긴바늘이 한 바퀴 돌면 짧은바늘은 한 칸"을 단다.

### 4. 펼치기(`unroll:true`)
- 조작 칸에 [펼치기]/[다시 감기] 단추를 둔다. 누르면 `toggle-unroll` Action을 보낸다.
- **펼친 상태.**
  - 시계 아래(또는 옆)에 0~60분 가로 띠를 그린다. 시계 판은 그대로 둔다.
  - 띠 위에는 1~12 숫자를 5분 칸마다 쓰고, 띠 아래에는 0, 5, 10, …, 60을 쓴다. 1분 작은 눈금도 그린다.
  - 긴바늘의 현재 분 자리에 띠 위 표시(▲ + 세로선)를 둔다. 긴바늘을 돌리면 같이 움직인다.
  - 띠 아래 분 숫자는 시계 원래 눈금을 펴 놓은 것이다. 학생 바늘 자리의 분 값을 따로 글로 쓰지 않는다. 읽기 과제(`readOnly`)에서 띠는 분을 세는 도구이고, 띠 위 표시가 곧 답 자리라서 `readOnly`이면 표시를 그리지 않는다.
- **전환 연출.** 둘레가 풀리는 모핑은 300ms 안의 단순 보간이다. `prefers-reduced-motion`이면 바로 바꾼다. 상태에는 `unrolled: boolean`만 둔다.

### 5. Observation과 predicates
- **Observation:** `mode`, `time: "H:MM"`, `hour`, `minute`, `minutes`, `moves`(받아들인 set-time·step 수), `unrolled`, `misconceptions: []`
- **Predicates:**
  - `timeIs {time}`
  - `hourIs {hour}`
  - `minuteIs {minute}`
  - `moved`(moves ≥ 1)
  - `unrolled`
- 엔진은 오개념을 스스로 기록하지 않는다. 콘텐츠가 `minuteIs` 같은 predicate로 힌트 규칙을 건다. 예: 3시 과제에서 분이 15이면 MC-CLOCK-HANDS.

### 6. 오버레이 (`CanvasAlignedOverlay`)
- **`hour-hand-focus`** (MC-CLOCK-HANDS ②): 긴바늘을 흐리게(점선 윤곽) 다시 그리고, 짧은바늘을 굵은 윤곽으로 강조한다. "몇 시는 짧은바늘이 알려 줘요" 이름표를 단다.
- **`rewind-to-hour`** (MC-CLOCK-HOUR-BETWEEN ②)
  - 지금 시각에서 정시(`floor`)로 되감은 유령 바늘 둘을 점선으로 그린다.
  - 긴바늘 끝에서 12까지 거꾸로 도는 호 화살표를 그린다.
  - 유령 짧은바늘이 가리키는 숫자를 원으로 둘러싼다. 숫자 글을 새로 쓰지는 않는다.
  - 분이 0이면 그리지 않는다.
- **`numeral-minutes {numeral}`** (MC-CLOCK-MINUTE-NUMERAL ②)
  - 시계 숫자 numeral(1~11) 바깥에 "numeral×5분" 값(예: 5 → "25분")을 이름표로 단다.
  - 펼친 상태면 띠의 그 자리에도 같은 이름표를 둔다.
  - 콘텐츠가 과제 답과 다른 numeral을 넘긴다.
  - numeral이 없거나 범위 밖이면 그리지 않는다.

### 구현 메모 (Sonnet, 2026-11-20)
- **등록**: 엔진 목록은 `import.meta.glob` 자동 등록이라 `src/core/`를 건드리지 않았다. fit-canvas `ENGINES`에 E14를 더하고 `outerScrollY` 목록에도 E14를 넣었다(T199 원칙 CSS).
- **샌드박스 기본**: 설정이 `mode`뿐이면(`Object.keys`가 `mode`만) `start:"3:00"`, `showGears`, `unroll`을 켠다. 콘텐츠는 `start` 등 하나라도 쓰면 일반 기본(12:00·톱니 꺼짐·펼치기 꺼짐)이다.
- **허용 분**: `step`은 허용 분 전체(0~719) 목록 위를 한 칸씩 움직인다(정시만이면 한 칸=1시간, `[0,30]`이면 30분). 끌어 놓기는 `snapMinutes`가 가장 가까운 허용 분(같으면 앞쪽)에 붙이고, `5-weak`는 5의 배수 ±1분일 때만 붙인다(4:59→5:00 포함). Shift+←→와 [한 시간]은 `set-time`으로 ±60분이다.
- **끌기**: 긴바늘·짧은바늘 모두 `useDrag`로 누르는 순간의 각도 기준 변화량을 누적한다(긴바늘 6°=1분, 짧은바늘 1°=2분). 긴바늘 끌기 칸은 반지름 70 바깥, 짧은바늘 칸은 중심~118이라 두 바늘이 겹쳐도 둘 다 집을 수 있다.
- **구현 결정과 다르게 한 것(2개)**
  - `hideMinuteHand`이면 펼친 띠 위 표시도 그리지 않는다(표시가 곧 긴바늘 분이라 숨긴 뜻이 사라진다). 결정서에는 `readOnly`만 적혀 있다.
  - 톱니는 맞물린 모양이 아니라 같은 축에 겹쳐 그렸다(큰 톱니는 긴바늘과, 작은 톱니는 짧은바늘과 같이 돈다). 맞물림은 그림만이고 두 축이 시계 중심 하나라서 바늘 축과 톱니 축을 일치시켰다.
- **정답 노출**: `digitalReadout:'never'`에서 DOM·aria에 시각 글이 없음을 단위 테스트로 확인(`8:30|8시|30분`). 슬라이더에는 `aria-valuenow`를 두지 않고 `aria-valuetext`만 둔다(값을 숫자로 내면 시각이 새므로). `"after-submit"`은 `'never'`로 읽는다.
- **E2E 도우미**: 판이 칸에 맞춰 크기를 정하기 전에 좌표를 재면 끌기가 어긋나 `open()`에서 캔버스 상자가 안정될 때까지 기다린다. 오버레이 정렬은 WebKit이 `<text>` 상자를 엉뚱하게 돌려줘서(0,0 근처) 글 요소 대신 계산한 좌표와 비교한다. 펼치기 보간(300ms) 중에는 상자가 줄어 있으므로 잰 뒤에 기다린다.
- **기준 이미지(신규 4장)**: `clock-gears`, `clock-unrolled` × 크롬북·아이패드. 직접 열어 보니 시계·톱니·띠 숫자·표시가 잘리지 않고 조작 칸이 눌리지 않았다. 크롬북은 판 높이가 낮아 시계가 작게 보이나 최소 배율 0.6보다 크다.
- 범위 밖 요청: 없음.
