## 목표
E12에 두 번째 필수 모드 `net-fold`를 더한다.
- 학생이 모눈에 면을 놓아 정육면체·직육면체 전개도를 그리고 "접기"를 누른다.
- 접는 모습이 움직이며 보이고, 겹친 면은 빨간 빗금, 빈 면은 점선 구멍으로 나타난다.
- 엔진이 전개도가 맞는지 정확히 판정한다(정수 계산).
- 서로 다른 전개도 기록, ★면과 마주 보는 면 예측, 읽기 전용 전개도 카드를 제공한다.

이 카드가 끝나면 g5s2u5.A2 과제 1~5의 콘텐츠 카드를 쓸 수 있다. 각기둥(g6s1u2)·원기둥(g6s2u6) 전개도와 겉넓이 칠하기(g6s1u6)는 뒤 카드가 맡는다.

### 1. 모드 유니온
- `types.ts`:
  - `SolidMode = 'cubes' | 'net-fold'`
  - `SolidConfig = CubesConfig | NetFoldConfig`
  - `SolidState = CubesState | NetFoldState`
  - `SolidAction = CubesAction | NetFoldAction`
- `createInitialState(config)`: `config.mode === 'net-fold'`이면 net 상태를 만들고, 그 밖에는 지금과 같다.
- `reduce`·`observe`·`emit`·`SolidView`는 `state.mode`로 나눈다.
  - net 쪽 코드: `net/` 폴더(아래 2번)와 `views/NetFoldView.tsx`
  - cubes 쪽 코드는 동작을 바꾸지 않는다. 타입 좁히기(`state.mode === 'cubes'`)만 더한다.
- 같은 이름의 Action(`move-cursor`, `turn`, `clear`)은 두 모드가 같은 모양을 쓴다.
- 상대 모드 전용 Action은 상태를 그대로 돌려준다.
- `index.ts`: `modes: ['cubes', 'net-fold']`

### 3. 설정 `NetFoldConfig`
| 키 | 형 | 기본 | 뜻 |
| --- | --- | --- | --- |
| `mode` | `'net-fold'` | — | 필수 |
| `target` | `'cube' \| 'cuboid'` | `'cube'` | 다른 값이면 `'cube'`로 보고 `console.warn` |
| `faceSize` | 정수 1~3 | 1 | 정육면체 한 모서리 칸 수 |
| `dims` | `[a,b,c]` 정수 1~4 | `[faceSize ×3]` | 직육면체 세 모서리. `target:'cube'`면 무시 |
| `grid` | `[cols, rows]` 정수 3~10 | `[6,6]` | 범위 밖은 자른다 |
| `maxFaces` | 정수 6~10 | 8 | 놓을 수 있는 최대 면 수 |
| `given` | `NetFaceConfig[]` | `[]` | 처음 놓인 면 |
| `editable` | boolean | true | false면 면 놓기·빼기·모양 고르기·지우기 무시 |
| `foldable` | boolean | true | false면 "접기" 단추를 숨기고 `fold` 무시(CPA A 단계) |
| `animate` | boolean | true | false면 접기 결과만 바로 보인다(움직임 없음) |
| `collisionHighlight` | boolean | true | 접었을 때 겹친 면·찢어지는 선·빈 면 표시 |
| `pairColors` | boolean | true | 바르게 접혔을 때 마주 보는 면 쌍을 같은 색+같은 무늬로 칠함 |
| `predict` | `{ of: string }` 또는 없음 | 없음 | 마주 보는 면 예측 모드(아래 7번) |
| `netLog` | boolean | false | 바르게 접힌 서로 다른 전개도를 기록(아래 8번) |
| `netCards` | `NetCardConfig[]` | `[]` | 읽기 전용 전개도 카드(아래 9번) |

- `NetFaceConfig = { at: [x, y], w, h, label?: string, locked?: boolean }`
  - `w`, `h`는 칸 수다.
  - `label`은 한 글자 이하로 자른다(예: `★`, `ㄱ`).
- `NetCardConfig = { id, label, faces: {at, w, h, label?}[] }`
- **면 크기 규칙:** 모든 면의 `{w,h}`는 target 크기에 맞아야 한다.
  - 정육면체: `faceSize×faceSize`
  - 직육면체: `dims`에서 서로 다른 두 모서리를 고른 쌍. 가로·세로를 바꾼 것도 된다.
  - 맞지 않는 `given` 면, 모눈 밖 면, 서로 겹치는 면은 `createInitialState`에서 빼고 `console.warn`한다.
  - 테스트로 확인한다.
- 받기만 하고 무시하는 키: `stage`, `fallback`, `variant`(cubes와 같은 방식). 각기둥·원기둥용 키(`baseSides`, `pieces` 등)는 이 카드에서 받지 않는다.

### 4. 상태·Action
`NetFoldState`:
```ts
{
  mode: 'net-fold';
  settings: NetFoldSettings;   // 3번을 정규화한 값
  faces: NetFace[];            // {x,y,w,h,label:string|null,locked}. 늘 (y,x) 순 정렬
  shape: readonly [number, number];   // 다음에 놓을 면 [w,h]
  cursor: GridCoord;
  folded: boolean;
  viewTurn: ViewTurn;
  prediction: string | null;   // 고른 면 label
  predictedBeforeFold: boolean;
  foundNets: string[];         // 정규형 키, 오름차순·중복 없음
}
```
`NetFoldAction`:
| Action | 동작 |
| --- | --- |
| `{type:'place-face', x, y}` | `(x,y)`를 왼쪽 위로 `shape` 면을 놓는다. 모눈 밖, 다른 면과 칸이 겹침, `maxFaces` 도달, `folded`, `!editable`이면 무시 |
| `{type:'remove-face', x, y}` | `(x,y)` 칸을 덮은 면을 뺀다. `locked`·`folded`·`!editable`이면 무시 |
| `{type:'select-shape', w, h}` | 허용된 면 크기일 때만 `shape`를 바꾼다 |
| `{type:'rotate-shape'}` | `shape`의 가로·세로를 바꾼다(허용될 때만) |
| `{type:'move-cursor', to}` | 모눈 안으로 자른다 |
| `{type:'fold'}` | `foldable`일 때 `folded=true`. `netLog`이고 결과가 바르면 정규형 키를 `foundNets`에 더한다 |
| `{type:'unfold'}` | `folded=false` |
| `{type:'turn', dir}` | 접힌 그림 회전(`viewTurn` ±1 mod 4) |
| `{type:'predict', label}` | `predict`가 켜졌고 `folded=false`이며 그 label의 면이 있고 `label !== predict.of`일 때만 설정. 처음 설정될 때 `predictedBeforeFold=true` |
| `{type:'clear'}` | 잠기지 않은 면을 모두 빼고 `folded=false`, `prediction=null`. `foundNets`는 남긴다 |

- 학생이 놓은 면의 `label`은 `null`이다.
- 상태는 JSON 직렬화가 되어야 한다(되감기·미러링).

### 5. 접기 판정 `net/geometry.ts` (정수, 순수 함수)
아래 알고리즘은 시험 구현(Python)으로 검산했다. 정육면체 6칸 도형 35가지 중 정확히 11가지가 바르다(찢어짐 8, 겹침 16).

**① 이웃.** 두 면이 길이가 양수인 변을 함께 가지면 이웃이다. 꼭짓점만 닿으면 이웃이 아니다. 공유 구간은 두 변의 겹친 부분이다.

**② 바닥 면(뿌리).** 넓이가 가장 큰 면을 바닥으로 한다. 같으면 `(y, x)`가 가장 작은 면.

**③ 접기 트리.**
- 뿌리에서 너비 우선 탐색을 한다. 이웃은 면 정렬 순서로 본다.
- 처음 닿은 변이 경첩이 된다.
- 뿌리와 이어지지 않은 면은 펼친 채로 두고 `connected=false`다.

**④ 90° 접은 위치.** 각 면에 3D 정수 사상 `M(p) = O + AX·px + AY·py`(`p`는 모눈 좌표)와 법선 `N`을 둔다.
- 뿌리: `O=(0,0,0)`, `AX=(1,0,0)`, `AY=(0,1,0)`, `N=(0,0,1)`. 모든 면이 `+N` 쪽(위)으로 접힌다.
- 부모 `(O,AX,AY,N)` → 자식. 경첩이 세로선 `x=e`이고 자식이 오른쪽(`s=+1`) 또는 왼쪽(`s=−1`)에 있을 때:
  - `AX' = s·N`, `AY' = AY`, `N' = −s·AX`, `O' = (O + e·AX) − e·AX'`
- 가로선 `y=e`이면 x·y 역할을 바꾼다:
  - `AY' = s·N`, `AX' = AX`, `N' = −s·AY`, `O' = (O + e·AY) − e·AY'`
- 각 면의 네 꼭짓점을 사상해 축에 나란한 3D 직사각형(한 축 두께 0)을 얻는다.

**⑤ 상자 칸(슬롯) 6개.**
- 바닥 면이 모눈 `(x0,y0,w,h)`이면 상자는 `[x0,x0+w]×[y0,y0+h]×[0,H]`이다.
- `H`는 정육면체면 `faceSize`, 직육면체면 `dims`에서 바닥의 두 모서리를 하나씩 뺀 나머지다.
- 상자의 여섯 면이 슬롯이다. 슬롯 번호는 `0,1`=z 아래·위, `2,3`=x 작은·큰 쪽, `4,5`=y 작은·큰 쪽이다. `(2k, 2k+1)`이 마주 보는 쌍이다.

**⑥ 판정**(뿌리와 이어진 면만):
- `overlapPairs`: 같은 평면에서 넓이가 양수만큼 겹치는 면 쌍의 수
- `tornEdges`: 트리 경첩이 아닌 공유 변 중, 두 면에서 사상한 끝점 쌍이 다른 것의 수. 종이를 잘라야 접힌다는 뜻이다.
- `outsideFaces`: 어느 슬롯과도 정확히 같지 않은 면의 수
- `missingSlots`: 아무 면도 덮지 않은 슬롯 번호 목록
- `valid`는 아래가 모두 참일 때다:
  - 면이 정확히 6개
  - `connected`
  - `overlapPairs = tornEdges = outsideFaces = 0`
  - `missingSlots`가 빈 목록
- 각 면의 슬롯 번호(`slotOf`)도 돌려준다. 맞는 슬롯이 없으면 `null`이다.

**⑦ 정규형 키 `canonicalNetKey(faces)`.**
- 면 사각형 집합에 8가지 대칭(90° 회전 4 × 뒤집기 2)을 적용한다. 회전하면 면의 w·h가 바뀐다.
- 각각을 최소 x·y가 0이 되게 옮기고, `"x,y,w,h"`를 정렬해 `;`로 잇는다.
- 그중 사전순 최소 문자열이 키다. label은 키에 넣지 않는다.

**⑧ 검산 예(단위 테스트에 그대로 넣는다; 정육면체 `faceSize 1`, 칸 `[x,y]`)**
| 전개도 | 결과 |
| --- | --- |
| 1-4-1 십자 `(1,0)(0,1)(1,1)(2,1)(3,1)(1,2)` | valid |
| 일렬 6 `(0,0)…(5,0)` | overlapPairs 2, missing 2, torn 0 |
| 2×3 직사각형 | overlapPairs 3, torn 2, missing 2 |
| 십자에서 `(1,2)` 뺀 5면 | missing 1, overlap 0 |
| 십자 + `(2,2)` 7면 | overlap 1, torn 1, missing 0 |
| 십자 + `(5,5)` 떨어진 면 | connected false, missing 1 |
| 35가지 6칸 도형 전부(테스트에서 생성) | valid 정확히 11, 서로 다른 정규형 키도 11 |

**⑨ 직육면체 4×3×2 검산 예**
- 바닥 `(2,2,4,3)`, 뒤 `(2,0,4,2)`, 앞 `(2,5,4,2)`, 왼 `(0,2,2,3)`, 오른 `(6,2,2,3)`, 위 `(2,7,4,3)` → valid. 모눈은 `[8,10]`이 필요하다.
- 위 면을 `(6,5,4,3)`으로 옮기면 → overlap 1, torn 1, outside 1, missing 1

**⑩ 마주 보는 면(label 기준).**
- 바르게 접혔을 때 `opposites[label] = 같은 쌍 슬롯에 있는 면의 label`. label이 없는 면은 빠진다.
- 검산 예:
  - `★(0,0) ㄱ(0,1) ㄴ(1,1) ㄷ(2,1) ㄹ(3,1) ㅁ(2,2)` → ★↔ㅁ, ㄱ↔ㄷ, ㄴ↔ㄹ
  - `★(1,0) ㄱ(1,1) ㄴ(0,1) ㄷ(1,2) ㄹ(2,2) ㅁ(2,3)` → ★↔ㄷ, ㄱ↔ㅁ, ㄴ↔ㄹ

**⑪ 애니메이션용 함수** `foldTransforms(faces, angleRad)`: 각 면의 3D 꼭짓점 4개(실수)를 돌려준다.
- 트리 경첩마다 부모 기준으로 같은 각도만큼 돈다.
- `angle = π/2`에서 결과가 ④의 정수 위치와 1e-9 안에서 같아야 한다(테스트).
- `fold-path` 오버레이용으로 경첩별 각도 지정판 `foldTransformsWith(faces, root, angleOf: (faceIndex) => number)`도 만든다.

### 6. 화면 `NetFoldView`
- **배치:** cubes와 같은 `.stageRow`/`.sideStack` 규칙(T137 중간 폭 포함)을 쓴다.
  - net-fold 판(`data-mode="net-fold"`)에서만 `.sideStack`을 `flex: 0 1 min(42%, 320px)`, `min-width: 220px`로 줄여 모눈에 폭을 더 준다(2026-11-15 운영자 결정). cubes 판 배치는 바꾸지 않는다.
  - 왼쪽(넓은 칸): 모눈 `NetGrid`
  - 오른쪽: 접기 그림 `FoldStage`, 그 아래 `NetCardsPanel`·예측 안내
  - 같은 CSS 클래스를 재사용하고 cubes 배치 결과는 바꾸지 않는다.
- **`NetGrid`(SVG):**
  - **칸 크기(2026-11-15 운영자 결정 — 48px 기준은 칸이 아니라 누르는 대상인 면에 둔다):**
    - `minFaceSide` = 허용 면 크기 중 가장 짧은 변의 칸 수(정육면체 `faceSize`, 직육면체 `min(dims)`).
    - `minCell = max(32px, ceil(48px / minFaceSide))`. 예: 정육면체 `faceSize 1` → 48px, `faceSize 2` → 32px, 직육면체 4×3×2 → 32px.
    - 칸 크기 = `clamp(minCell, 들어갈 수 있는 크기, 72px)`. 가장 작은 면이 늘 48px 이상이 된다.
    - 놓기는 누름→이동→뗌 그림자로 자리를 맞추므로 칸 하나를 정확히 누를 필요가 없다. 키보드 놓기도 그대로다.
    - 모눈은 `.netGridHost` 안에서 **위쪽에 붙인다**(`align-items: flex-start` 또는 `margin-block: auto` 대신 위 정렬). 안내 문구(`instructions`)는 모눈 위 별도 줄에 두어 모눈 칸을 가리지 않게 한다(검수에서 `net-cell-2-0` 클릭이 안내 문구에 가로채인 문제).
    - 그래도 넘치면 측정값을 메모에 적고 멈춰서 묻는다.
  - **놓기:** 빈 칸을 누르면 그 칸이 왼쪽 위인 `shape` 면을 놓는다.
    - 누르는 동안 놓일 자리를 반투명 그림자로 보여 준다(Pointer Events: 누름→이동→뗌에서 놓기).
    - 놓을 수 없으면 그림자를 빨간 점선과 "놓을 수 없어요" 문구로 보이고, 떼어도 놓지 않는다.
  - **빼기:** 면을 누르면 그 면을 뺀다.
  - **면 표시:** label을 면 가운데 크게 쓴다. 잠긴 면은 자물쇠 아이콘을 단다.
  - **접은 뒤 모눈:**
    - `pairColors`이고 valid면 각 면에 쌍 색+쌍 무늬(●▲■)를 칠한다.
    - `collisionHighlight`이면 겹친 면에 빨간 빗금과 "겹침" 글자, 찢어지는 변에 굵은 빨간 지그재그 선을 그린다.
  - **도구 막대:**
    - 면 모양 고르기: 직육면체일 때만 보인다. 허용 크기를 작은 그림 단추로 보여 주고, "돌리기" 단추가 있다.
    - "접기"/"펼치기"(토글)와 "모두 지우기"
    - 모든 단추는 48px 이상이다.
- **`FoldStage`(SVG, Three.js 쓰지 않음):**
  - 면 사각형 6~10개를 정사영(등각에 가까운 고정 시점, 요 각도 = 45°+90°·`viewTurn`, 내려보기 30°)으로 그린다.
  - 그리는 순서는 면 중심 깊이순(화가 알고리즘)이다. 면 채움은 불투명도 0.85.

  - **접기:** "접기"를 누르면 각도 0→90°를 1.6초 동안 바꾼다(`requestAnimationFrame`). 각도는 View 안 지역 상태이고, reduce 상태가 아니다.
    - `animate:false`나 `prefers-reduced-motion`이면 바로 90°.
    - "펼치기"는 반대로 움직인다.
  - **표시**(접힌 뒤, `collisionHighlight`일 때):

    - 빈 슬롯: 점선 사각형+"빈 곳" 글자. 깜빡임은 움직임 줄이기 설정을 따른다.

### 7. 마주 보는 면 예측(`predict: { of: '★' }`)
- 모눈 위에 "접기 전에 ★면과 마주 보는 면을 골라 보세요"를 보인다.
- 면을 누르면 `predict` Action을 보낸다. 고른 면은 굵은 테두리와 "예측" 글자로 표시한다.
- 예측 모드에서는 `place-face`·`remove-face`를 보내지 않는다(면 누르기 = 예측). 보통 `editable:false`와 함께 쓴다.
- 예측 전에는 "접기" 단추를 비활성화하고 "먼저 골라 보세요"를 보인다(CPA P 단계 "예측 필수").
- 접은 뒤에도 예측은 바꿀 수 없다. 접기 그림에서 예측한 면과 ★면을 굵은 테두리로 보인다.
- 정답 여부 문구("맞았어요" 등)는 엔진이 쓰지 않는다. 판정은 GoalSpec 몫이다.

### 8. 서로 다른 전개도 기록(`netLog: true`)
- 바르게 접힌 뒤 키가 새것이면 `foundNets`에 더한다(4번 `fold`).
- 모눈 아래에 "찾은 전개도 n가지"와 찾은 전개도 썸네일(작은 SVG, 칸 12px)을 줄지어 보인다.
- 이미 있는 키면 "이미 찾은 전개도와 같아요(돌리거나 뒤집으면 같아요)"를 보이고, 같은 썸네일을 잠깐 강조한다.

### 9. 전개도 카드(`netCards`)
- cubes `CardsPanel`과 같은 모양의 읽기 전용 카드다.
- 카드 안에 전개도를 작은 SVG로 그리고(칸 18px, label 포함) 카드 이름(가·나·다·라)을 단다.
- 고르기 응답은 실행기 응답 칸(`response.<id>.selected`)이 맡는다. 엔진은 카드 선택 상태를 갖지 않는다.
- 카드 2~4장. 3장 이상이면 T137 카드 한 줄 규칙을 따른다(`data-card-count`).

### 10. Observation(`net-fold`)
```
mode:'net-fold', target, dims:[a,b,c], faces:[[x,y,w,h,label|null]...],
faceCount, connected, folded, overlapPairs, tornEdges, outsideFaces,
missingCount, valid, netKey (valid일 때 정규형 키, 아니면 null),
foundNets:[...], foundCount, prediction, predictedBeforeFold,
opposites:{label:label} (valid일 때만, 아니면 {}), viewTurn
```
- 판정 값(overlapPairs 등)은 `folded`와 상관없이 늘 계산한다. 접기 전 판단만 하는 A 단계 과제가 있기 때문이다.
- cubes 전용 키(`count`, `cubes`, `top` 등)는 넣지 않는다. 그래서 cubes predicate는 net 관찰에서 false가 된다(테스트).

### 11. predicate(잘못된 인자는 false)
| 이름 | 인자 | 참 조건 |
| --- | --- | --- |
| `netValid` | — | `valid` |
| `netSixInvalid` | — | `faceCount === 6 && !valid` (MC-NET-ANY-SIX 감지용) |
| `netFaceCountIs` | `{n}` | `faceCount === n` |
| `foundNetsAtLeast` | `{n}` | `foundCount >= n` |
| `predictedOpposite` | `{of}` | `valid && prediction !== null && opposites[of] === prediction` |
| `predictedAdjacent` | `{of}` | `valid && prediction !== null && prediction !== of && opposites[of] !== prediction` (MC-NET-ADJACENT-AS-OPPOSITE 감지용) |
| `oppositeIs` | `{a, b}` | `opposites[a] === b` |

### 12. 이벤트
`face-placed {x,y,w,h,count}`, `face-removed {x,y,w,h,count}`, `net-folded {valid, overlapPairs, missingCount}`, `net-unfolded`, `prediction-set {label}`, `view-turned {viewTurn}`. `EVENT_NAMES`에 더한다.
