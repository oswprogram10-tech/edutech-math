## 목표
g6s1u2.A2 「각기둥 전개도」를 위해 각기둥 전개도 조립을 만든다.
- 학생은 정n각형 밑면 조각(n 3~6)과 직사각형 옆면 조각을 이미 놓인 조각의 변에 하나씩 붙여 전개도를 만든다.
- "접기"를 누르면 엔진이 각 조각이 각기둥의 어느 면 자리로 가는지 계산한다. 그 결과로 맞게 접히는지 판정하고, 접힌 각기둥을 그린다.
- 보기 카드(가·나·다)로 그림만 보고 접히지 않는 전개도를 고르는 과제(A 단계)도 지원한다.

### 0. 왜 모눈 방식이 아닌가
- 지금 `net-fold`는 모눈 칸에 축과 나란한 직사각형만 놓는다. 정삼각형이나 정오각형 밑면은 모눈에 올라가지 않는다.
- 그래서 "변에 붙이기" 방식(조각 나무)을 새로 만든다.
- 설정은 명세대로 `mode:'net-fold'`, `target:'prism'`로 받는다. 상태와 관찰의 `mode`는 따로 `'prism-net'`을 쓴다(1번).
- cube·cuboid 전개도 코드는 바꾸지 않는다.

### 1. 모드 나누기
- `createInitialState`: `mode:'net-fold'`이고 `target:'prism'`이면 `createPrismNetState`로 보낸다. 상태는 `{ mode: 'prism-net', ... }`이다.
- `SolidState`·`SolidAction`·`SolidMode`에 `'prism-net'`을 더한다. reduce·observe·emit·View는 `state.mode`로 나눈다(T139·T142와 같은 방식).
- `NetTarget` 타입에 `'prism'`을 더하지 않는다. 설정 타입에는 `PrismNetConfig`(`mode:'net-fold'`, `target:'prism'`)를 따로 두고 `SolidConfig` 유니온에 더한다.
- `index.ts`의 `modes` 목록에 `'prism-net'`은 넣지 않는다. 콘텐츠는 `net-fold`로 쓴다. 샌드박스 모드 선택에는 "각기둥 전개도"로 더한다.

### 3. 3D 면 자리와 변 (`prismnet/model.ts`, 정수만)
- 각기둥 면 자리는 `B`(아랫밑면), `T`(윗밑면), `S0..S{n-1}`(옆면)이다. 옆면 `Si`는 밑면의 변 i 위에 선다.
- 자리마다 바깥에서 본 반시계 방향 변 목록과 그 변 너머의 자리를 고정한다.
  - `B`: 변 k → `S{k}`. 밖(아래)에서 볼 때 반시계가 되게 순서를 맞춘다. 구현할 때 T와 방향이 반대가 되는 것을 테스트로 확인한다.
  - `T`: 변 k → `S{k}`
  - `Si`: [아래 → `B`, 오른쪽 → `S{i+1}`, 위 → `T`, 왼쪽 → `S{i−1}`](n으로 나머지)
- 변 길이 종류는 둘이다. 밑면 변과 옆면의 위·아래 변은 `s`, 옆면의 왼쪽·오른쪽 변은 `h`다.
  - 설정에서 `sideLen`과 `height`가 같으면 붙일 변이 모호해진다. 그래서 `height`를 하나 키우고 `console.warn`한다(테스트).
- **조각 나무:**
  - 조각은 `{ id, type:'base'|'rect', parent:number|null, parentEdge, edge, locked }`이다.
  - 뿌리 조각은 `parent:null`이다. 붙이기는 "부모 조각의 변 `parentEdge`에 새 조각의 변 `edge`를 맞댄다"는 뜻이다.
  - 새 조각의 `edge`는 엔진이 정한다.
    - `base`는 늘 변 0이다.
    - `rect`는 부모 변 길이가 `s`면 아래 변(0), `h`면 왼쪽 변(3)이다.
    - 조각 변 번호는 반시계다. 직사각형은 [0 아래(s), 1 오른쪽(h), 2 위(s), 3 왼쪽(h)], 밑면은 0..n−1(모두 s)이다.
- **자리 계산 `assignSlots(pieces, n)`:**
  - 뿌리가 `base`면 `B`, `rect`면 `S0`이다. 뿌리의 변 k는 그 자리의 변 k와 같다.
  - 부모가 자리 P에 있고 부모 변 e가 P의 변 e′이면, 자식 자리 F는 P의 변 e′ 너머 자리다.
  - 자식의 맞댄 변은 F에서 P를 보는 변이다. 나머지 변 번호는 반시계 순서로 이어 맞춘다.
  - **종류가 다르면 불일치다.** `base`가 S 자리에 가거나 `rect`가 B·T 자리에 가면 `mismatch`다. 그 아래 자손은 자리를 `null`로 둔다.
- **판정 `evaluatePrismNet`:**
  - `slotOf[]`: 조각마다 자리 이름 또는 null
  - `duplicates`: 같은 자리에 둘 이상 간 조각 번호
  - `missing`: 비어 있는 자리 수
  - `mismatch`: 불일치 조각 번호
  - `paperOverlap`: 4번에서 계산한 겹치는 조각 쌍
  - `valid`: 자리 n+2개를 한 번씩 채우고, `duplicates`·`mismatch`·`paperOverlap`이 모두 비어 있음
  - `bothBasesSameEnd`: 밑면 조각 두 개가 모두 B, 또는 모두 T 자리에 감(MC 감지용)
- 정수와 자리 이름만으로 계산한다. 이 판정에는 좌표를 쓰지 않는다(`paperOverlap` 빼고).

### 4. 2D 배치 (`prismnet/layout.ts`, 화면 좌표)
- 정n각형 한 변 `s`, 직사각형 `s×h`(칸 단위)다. 뿌리를 원점에 두고, 붙일 때마다 부모 변의 바깥쪽에 새 조각을 놓는다.
- 좌표는 화면용 `number`다(cos·sin을 쓴다).
- **종이 겹침:** 두 조각 다각형의 넓이가 겹치면 겹침이다.
  - 변이나 점이 닿는 것은 겹침이 아니다.
  - 볼록 다각형 분리축 검사를 쓰고, 허용 오차는 칸 길이 × 1e-6이다.
  - 이 값은 "종이 위에서 겹쳐 오릴 수 없다"는 화면 판정이다. AGENTS.md 절대 규칙 2번의 수학 값(분수·측정값)이 아니다. 근거를 주석에 적는다.
- 붙일 때 종이 겹침이 생기는 붙이기도 허용한다. 학생이 접어 보고 알게 한다. 판정에서만 `valid=false`가 된다.
- `layoutBounds`: 전체 배치의 경계 상자다. 화면은 이 상자가 판에 들어가게 배율을 정한다.

### 5. 설정 `PrismNetConfig`
| 키 | 형 | 기본 | 뜻 |
| --- | --- | --- | --- |
| `mode`·`target` | `'net-fold'`·`'prism'` | — | 필수 |
| `baseSides` | 3~6 | 3 | n |
| `sideLen` | 1~4 정수 | 2 | 밑면 한 변(칸) |
| `height` | 1~6 정수 | 3 | 옆면 높이(칸). `sideLen`과 같으면 +1(3번) |
| `pieces` | `{ base?: number, rect?: number }` | `{base:2, rect:n}` | 쓸 수 있는 조각 수(0~8). 명세의 배열 형식(`["triangle","triangle","rect",…]`)도 받아 개수로 바꾼다 |
| `given` | `{type, parent, parentEdge, locked?}[]` | `[]` | 처음 놓인 조각. 첫 항목이 뿌리이고, 그 수만큼 `pieces`에서 뺀다 |
| `editable` | boolean | true | |
| `foldable` | boolean | true | |
| `showLengths` | boolean | false | 조각 변에 길이 글자("2"·"3")를 쓴다(A2 과제 2) |
| `collisionHighlight` | boolean | true | 접었을 때 문제 조각에 무늬를 칠한다 |
| `netCards` | `{id, label, n?, root:'base'\|'rect', steps:{parent, parentEdge, type}[]}[]` | `[]` | 보기 카드 |
| `stage`·`fallback` | | | 받기만 하고 무시한다 |

- 잘못된 `given`(없는 부모나 변, 이미 붙은 변)은 그 항목부터 버리고 `console.warn`한다.

### 6. 상태·Action
`PrismNetState`:
```ts
{ mode:'prism-net'; settings; pieces: PrismPiece[]; selectedType: 'base'|'rect'|null; folded: boolean; foldCount: number }
```
| Action | 동작 |
| --- | --- |
| `{type:'select-piece-type', pieceType}` | 남은 수가 있을 때만 |
| `{type:'attach', parent, parentEdge}` | `editable`이고 접혀 있지 않을 때, 고른 종류가 남아 있고 그 변이 비어 있으며 길이가 맞아야 한다(`base`는 s 변만). 조각이 하나도 없으면 `parent:null`로 뿌리를 놓는다 |
| `{type:'remove-piece', id}` | 잠기지 않은 잎 조각만(자식이 없는 조각) |
| `{type:'clear'}` | 잠기지 않은 조각을 모두 빼고 펼친다 |
| `{type:'toggle-fold'}` | `foldable`이고 조각이 1개 이상일 때. 접을 때 `foldCount+1` |

- 붙이기나 빼기를 하면 `folded=false`가 된다.
- 상태는 JSON 직렬화가 되어야 한다.

### 7. 화면 `PrismNetView`
- **배치:** T138 net-fold와 같은 `.stageRow`/`.sideStack` 규칙을 쓰고 판에 `data-mode="prism-net"`을 단다.
  - 왼쪽: 조각 판 `PrismNetBoard`(SVG)
  - 오른쪽: 조각 고르기, 접기·모두 지우기, 접힌 그림, 보기 카드
- **조각 판:**
  - 놓인 조각을 그린다. 밑면은 연한 파랑, 옆면은 연한 노랑이다. 색만으로 알리지 않도록 밑면 가운데에 작은 다각형 표시를 한다.
  - 비어 있는 변 중 지금 고른 종류를 붙일 수 있는 변에는 "+" 손잡이를 단다. 크기는 48px 이상이고, 변 바깥쪽 가운데에 둔다.
  - 손잡이를 누르면 `attach`가 간다. 조각을 누르면 그 조각을 고르고, 다시 누르거나 "조각 빼기"를 누르면 뺀다(잎일 때만).
  - 조각이 없으면 판 가운데에 큰 "+" 하나를 두어 뿌리를 놓는다.
  - 배율은 `layoutBounds`가 판에 들어가게 정한다. 칸 크기는 24~56px다. 조각이 늘어 판을 넘으면 배율을 줄인다.
- **조각 고르기:** "밑면(n각형) 조각"·"옆면 조각" 단추(aria-pressed, 조각 그림 포함)를 두고, 남은 수를 "남은 조각 2"처럼 쓴다. 남은 수는 설정이 준 값이라 정답 노출이 아니다.
- **접기 결과:**
  - `valid`면 `prism/geometry.ts`(T142)의 각기둥 그림을 쓴다. 같은 n과 높이로 돌려 볼 수 있는 작은 무대를 그린다. 같은 엔진 폴더라 import해도 된다.
  - `valid`가 아니면 접힌 그림 대신 "접히지 않아요" 상태 글과, `collisionHighlight`일 때 문제 조각(중복·불일치·종이 겹침)에 빗금 무늬를 그린다.
    - 무엇이 왜 틀렸는지는 쓰지 않는다. 판정 이유는 힌트가 맡는다.
- **보기 카드:**
  - `netCards`의 각 카드를 4번 배치로 작게 그린다.
  - T141처럼 카드만 보기 조건이면 카드를 크게 보이고 판·도구를 빼는 규칙을 그대로 따른다. 조건: `editable:false`, `foldable:false`, 카드 있음, `given` 없음.
- **키보드:**
  - Tab으로 "+" 손잡이와 조각을 오가고, Enter·Space로 붙이거나 고른다.
  - Delete·Backspace는 고른 조각 빼기, B·R은 밑면·옆면 고르기, F는 접기·펼치기다.
- **test id:**
  - 판·조각: `prismnet-board`, `prismnet-piece-{id}`(`data-slot`은 넣지 않는다 — 정답 노출), `prismnet-handle-{pieceId}-{edge}`, `prismnet-root-handle`
  - 단추: `prismnet-type-base`·`prismnet-type-rect`, `prismnet-fold`, `prismnet-clear`, `prismnet-remove`
  - 결과·카드: `prismnet-folded-stage`, `prismnet-cards`, `prismnet-card-{id}`
- 문구는 `strings.ko.ts`의 `solid3dStrings.prismNet`에 둔다.

### 11. 테스트
- **`prismnet-model.test.ts`:**
  - n=3..6에서 밑면 하나에 옆면 n개를 둘러 붙이고 마지막 밑면을 옆면 하나의 위 변에 붙이면 valid다.
