# 10. 원 계획서 대비 변경점

원 계획서(「차세대 초등 수학 에듀테크 플랫폼(가칭: MathExplorer 2022) 종합 앱 개발 계획서」)의 **교육적 설계는 그대로 유지**했다. 바뀐 것은 *누가, 어떤 예산으로, 어떤 기기에서* 만드느냐에 맞춘 실행 방법이다.

## 조건
- 개발: 운영자(콘텐츠 제공자) 1명 + 코딩 에이전트(Claude, Codex, OpenCode)
- 예산: 무료 서비스만
- 제공 대상: 여러 학교·학급, 1~6학년 전체 (시범 운영은 운영자 직접) — 2026-11-02 "내 학급 수업"에서 바꿈
- 기기: 크롬북, 아이패드, 갤럭시탭, 전자칠판·교사 PC
- 학생 데이터: 단계적으로(기기 저장 → 학급 코드)

## 기술 대체표

| 원 계획서 | 바꾼 것 | 이유 |
| --- | --- | --- |
| 마이크로 프론트엔드 | 단일 Vite+React 앱, **엔진 폴더 단위 모듈** | 1인 개발에 마이크로 프론트엔드는 운영 부담만 크다. 폴더 경계 + import 금지 규칙으로 같은 병렬성 확보 |
| MyScript / Mathpix 필기 OCR | **칸 입력(E07 세로셈 격자) + 수식 키패드(E08)** | 유료. 칸 입력은 자릿값 열을 화면이 강제해 오류 원인 진단이 오히려 정확하다. 손글씨 숫자 한 칸 인식은 3단계 선택 |
| SymPy / Algebrite CAS | **자체 유리수 연산 + 초등 수식 파서** | 초등 범위는 작다. 브라우저에서 오프라인·결정론적으로 동작, 100% 테스트 가능 |
| Neo4j(CASE 표준 DAG) | **JSON 그래프 파일 + TypeScript 알고리즘** | 노드 수백 개 규모에 그래프 DB는 과하다. 서버가 필요 없다 |
| BKT | **단순화한 숙달 업데이트 규칙** → 데이터가 쌓이면 정식 BKT | 파라미터 추정에 필요한 데이터가 아직 없다 |
| LLM + Socratic Guardrail 튜터 | **규칙 기반 힌트 사다리(오개념 코드 → 발문 → 시각적 반례 → 역추적)** | 무료 조건, 개인정보, 그리고 *정답을 절대 말하지 않는* 보장은 규칙 기반이 더 확실하다. LLM은 3단계에서 문장 다듬기 보조로만 |
| LLM 관심사 문장제 리라이터 | **템플릿 스킨**(수치 구조 고정, 이야기 틀만 교체) | 무료, 수치 오류 0, 교사 검수 가능 |
| GeoGebra / 알지오매스 API | **자체 제약 기반 작도(E09)**, 어려우면 GeoGebra 임베드 검토 | 앱 전체와 같은 조작감·로그 형식 유지. GeoGebra는 비상업 무료지만 라이선스 확인 필요 |
| WebXR AR | **3D 뷰어 기본, AR은 안드로이드 한정 선택** | 아이패드 Safari가 WebXR을 지원하지 않는다 |
| MediaPipe 전신 모션 | **선택 기능**, 영상 미저장 | 저가 기기 성능, 카메라 개인정보 |
| Web Speech STT(음성 인식) | **선택 기능**, TTS(읽어 주기)는 기본 | 브라우저마다 동작이 다르고 음성이 외부 서버로 갈 수 있다 |
| Node/FastAPI + Socket.io 서버 | **1단계 서버 없음**, 2단계 Supabase Realtime(무료) | 서버 운영 부담 0. 미러링은 영상이 아니라 교구 상태 JSON |
| LRS(xAPI) | **IndexedDB 이벤트 로그(xAPI 비슷한 형태)** + 내보내기 | 서버 없이 시작. 필요하면 나중에 xAPI로 변환 가능 |
| 교구 140여 개를 단원마다 개발 | **20개 엔진 × 모드 × 단원 설정(JSON)** | 71개 단원을 혼자 완성할 수 있게 하는 핵심 결정 |

## 일정·지표
| 원 계획서 | 바꾼 것 |
| --- | --- |
| 18개월 4페이즈(전문 팀 기준) | 엔진 웨이브 W0~W7, 웨이브마다 수업에 바로 사용(`07-roadmap.md`) |
| "흥미도 +30%, 성취도 +25%" | 측정 도구를 정한 지표: 단원 사전·사후 진단, 흥미 설문, 앱 과정 지표(`01-product.md` §5) |
| "AI 연산 환각 0%" KPI | 지표가 아니라 설계상 보장(계산은 결정론적 코어만) |
| "OCR 인식 정확도 92%" | 해당 없음(칸 입력) |

## 그대로 유지한 것
- 4대 설계 원칙, 4개 영역 엔진 아이디어, 71개 단원의 교구 아이디어 전부(각 단원 명세에서 활동 또는 '후순위·선택'으로 모두 다룸)
- 무학년 역추적, 별자리 성장 맵, 교사 일시정지·익명 전략 비교, 학부모 대화 카드(3단계), 내재적 게임화 원칙

## 확인이 필요한 것
- **단원명:** 3~6학년은 검정 교과서라 출판사마다 단원명·순서가 다를 수 있다. 원 계획서 단원명을 기준으로 두고, 교과서가 정해지면 `units.json`의 `textbookAlias`로 맞춘다.
- **성취기준 코드:** 2022 개정 교육과정 원문에서 확인해 채워야 한다(작업 카드 T090).
