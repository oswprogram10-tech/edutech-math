# 09. 개인정보·안전 설계

> 법률 자문이 아니다. 실제 수업에 쓰기 전에 학교의 개인정보·정보 담당 선생님과 확인할 것.

## 1. 기본 방침: 모을 필요가 없으면 모으지 않는다

| 단계 | 저장하는 것 | 저장하지 않는 것 | 저장 위치 |
| --- | --- | --- | --- |
| 1단계 | 학급 번호, 관심사, 교구 Action 기록, 개념 숙달도 | 이름, 사진, 생년월일, 연락처, 화면 좌표 궤적, 음성 | 학생 기기의 IndexedDB |
| 2단계 | + 학급 코드, (선택) 별명 | 실명 | Supabase(학급 단위) |
| 3단계 | + 풀이 음성(Thinklet) | — | 기본은 기기. 공유할 때만 내보내기 |

- 별명 입력란에는 "진짜 이름은 쓰지 마세요" 안내와 간단한 필터(교사가 등록한 학생 이름 목록과 일치하면 경고 — 이름 목록은 교사 기기에만)를 둔다.
- 번호 ↔ 이름 대응표는 앱에 넣지 않는다. 교사가 따로 가지고 있는다.

## 2. 학교에서 쓰기 전에 확인할 것
- 학교에서 학생이 쓰는 학습 소프트웨어를 고르고 쓰는 절차(교육부·교육청 기준, 학교운영위원회 심의 등)가 이 앱에도 적용되는지.
- 2단계에서 학생 데이터가 외부 서버(Supabase, 해외 리전일 수 있음)에 저장되는 것에 대해 보호자 안내·동의가 필요한지. 만 14세 미만 아동의 개인정보는 법정대리인 동의가 원칙이므로, **식별할 수 없는 정보만 저장하는 설계**를 유지하는 것이 가장 단순하다.
- Supabase 프로젝트 리전은 가능하면 서울(ap-northeast-2)을 고른다(무료 플랜에서 고를 수 있는지 생성 시 확인).

## 3. 기술적 보호 장치
- Supabase Row Level Security: 학생은 자기 학급 채널·자기 기록만, 교사는 자기 학급만.
- 학급 코드는 학기 끝에 만료. 교사가 '학급 데이터 모두 삭제' 버튼으로 지울 수 있다.
- 교사 대시보드 URL에는 비밀 토큰이 아니라 교사 로그인(Supabase Auth 이메일 매직링크)을 쓴다.
- 카메라(MediaPipe)·마이크(STT, Thinklet) 기능은 기본 꺼짐. 켤 때 화면에 "영상은 저장되지 않아요" 표시, 영상 프레임은 기기 밖으로 보내지 않는다.
- 외부 스크립트·폰트 CDN을 쓰지 않는다(모두 번들 포함) — 오프라인과 추적 방지.
- 분석 도구(구글 애널리틱스 등) 넣지 않는다.

## 4. 아동 안전·정서
- 경쟁 랭킹, 타인과 비교하는 화면 없음. 익명 비교는 교사 화면에서만, 번호 없이.
- 실패 표현은 "틀렸어요" 대신 "다시 볼까?" 계열. 연속 실패 시 부스터 또는 '선생님께 도움 요청'으로 빠져나갈 길을 항상 준다.
- 문장제 스킨에 실존 인물·브랜드·연예인 이름을 쓰지 않는다.
