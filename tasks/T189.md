## 목표
새 엔진 `src/engines/E20-ratio-lab/`를 만든다. 필수 모드 둘을 구현한다.
- `mix`: 초코 우유 배합. 비율에 따라 진하기가 바뀌고, 진하기 띠 위에 표시가 생긴다.
- `resize`: 사진 늘리기. 더하기로 늘리면 찌그러지고, 곱하기로 늘리면 모양이 유지된다.

이 엔진은 g6s1u4(뒤 카드)에 쓴다. `rate`·`percent`·`bar-model`·`proportion-grid`는 뒤 카드에서 만든다. 이 카드에서는 모드 목록에도 넣지 않는다.

### 1. 공통
- **수:** 양은 0 이상의 정수 `number`(블록·칸 개수)로 저장한다. 비의 값·비교는 `Rational`로 계산한다. Observation의 비의 값은 기약분수 문자열(예: `"1/4"`, `"2"`)이다.
- **판 크기:** 논리 1000×600 SVG, `layout:'fit'`. 좁으면 최소 배율 0.6 아래로 줄이지 않고 스크롤한다. 조작 칸은 스크롤 상자 밖에 둔다.
- **단추:** 48px 이상(6학년)이다. 키보드로 모든 단추에 닿는다. 단추마다 단축키를 하나씩 둔다(strings에 적는다).
- **색만으로 전달 금지:** 진하기는 색과 함께 띠 위의 모양 표시(▲ 기준 컵, ● 내 컵, ■ 비교 컵 등)와 이름표로 보인다. 찌그러짐은 모양 자체로 보인다.
- **정답 노출 금지:** 목표 값(예: 시럽 2)을 화면·DOM·aria에 쓰지 않는다. 엔진은 목표 값을 설정으로 받지 않는다. 판정은 콘텐츠 goal이 Observation으로 한다.
- 문구는 모두 `strings.ko.ts`에 둔다. 학년 표시와 점수는 두지 않는다.

### 2. `mix`
```ts
interface MixConfig {
  mode: 'mix';
  reference?: { milk: number; syrup: number };              // 기준 컵(고정, 조작 불가)
  fixedCups?: { id: string; label: string; milk: number; syrup: number }[]; // 비교용 고정 컵(0~3개)
  make?: { milk?: number; syrup?: number; maxEach?: number } | null;        // 학생 컵 시작값, 기본 {milk:0,syrup:0,maxEach:30}; null이면 학생 컵 없음
  scaleFactors?: number[];   // 기본 [2, 3]: ×k 단추
  look?: 'blocks' | 'strip' | 'ratio';  // C 블록 컵 / P 띠 그림 / A "우유 4 : 시럽 1" 글만, 기본 'blocks'
  showStrip?: boolean;       // 기본 true: 진하기 띠
}
```
- **Action:** `add {ingredient:'milk'|'syrup', n:1}`, `remove {ingredient, n:1}`, `scale {k}`(두 양에 모두 k를 곱함, maxEach를 넘으면 거절), `reset`.
- **진하기:** 시럽 ÷ (우유 + 시럽)을 0~1 띠 위치로 쓴다. 색은 그 위치를 정해진 갈색 단계로 바꾼다(결정적).
  - 우유와 시럽이 모두 0이면 빈 컵이다. 띠에 표시하지 않는다.
- **화면**
  - 컵 안에 블록을 그린다. 흰 블록과 갈색 블록은 무늬(점)로도 구분한다. 블록이 많으면 블록 크기를 줄인다(컵 높이 고정).
  - 컵 위에 이름을 단다. 기준 컵·고정 컵 이름은 설정의 label, 학생 컵은 "내 컵"이다.
  - 컵 아래에 "우유 a, 시럽 b"를 쓴다. 학생이 넣은 값이라 노출이 아니다.
  - `look:'ratio'`이면 컵 대신 "우유 a : 시럽 b" 글자와 띠만 둔다.
- **Observation**
  - `mode`
  - `cup: {milk, syrup, value: string|null}` (value = 시럽/우유, 우유 0이면 null)
  - `referenceValue: string|null`, `sameAsReference: boolean`
  - `fixed: {id, milk, syrup, value}[]`, `darkestFixedId: string|null`(같으면 null)
  - `addOps`, `scaleOps`
  - `misconceptions: string[]`
- **MC-RATIO-ADDITIVE:** 기준 컵이 있다. 학생 컵이 (기준 우유 + d, 기준 시럽 + d)이고 d ≥ 1이며, 기준과 비의 값이 다르면 기록한다.
- **Predicates:** `cupIs {milk, syrup}`, `sameAsReference`, `cupValueIs {value}`(Rational 비교), `scaleUsed`, `hasMisconception {code}`
- **오버레이**
  - `side-by-side`(MC-RATIO-ADDITIVE ②): 기준 컵과 내 컵을 띠 위에 나란히 확대한다. 두 표시 사이에 차이 화살표와 "≠"를 그린다. 같으면 그리지 않는다.
  - `unit-groups`(일반 ②): 내 컵 블록을 기준 컵 한 묶음(예: 우유 4 + 시럽 1)씩 점선 고리로 묶는다. 묶음에 안 들어가는 블록은 빗금으로 둔다. 몇 묶음인지 글은 쓰지 않는다.

### 3. `resize`
```ts
interface ResizeConfig {
  mode: 'resize';
  base: { w: number; h: number };     // 예: {w:4, h:3} (칸)
  addStep?: number;                    // 기본 2: "둘 다 +n" 단추
  scaleFactors?: number[];             // 기본 [2, 3]
  max?: number;                        // 기본 24 (한 변 최대 칸)
  showVerdict?: boolean;               // 기본 true: "처음 모양과 같아요/달라요" 글
  look?: 'picture' | 'table';          // C 사진 / P 표(가로·세로 열), 기본 'picture'
}
```
- **Action:** `step {dim:'w'|'h', delta:+1|-1}`, `add-both {n}`, `scale {k}`, `save`(지금 크기를 담기, 같은 크기는 한 번만), `reset`. 1칸 미만이나 max 초과는 거절한다.
- **그림**
  - 처음 크기 비율로 만든 간단한 SVG 그림(강아지 얼굴 같은 단순 도형 조합, 외부 파일 없음)을 쓴다.
  - 이 그림을 가로 w/w0, 세로 h/h0로 늘려 그린다. 그래서 비율이 다르면 찌그러진다.
  - 뒤에 칸 격자를 깔고, 가로·세로 칸 수 글자를 단다.
- **담은 크기:** 오른쪽 목록에 작은 그림 + "가로 a, 세로 b"로 보인다. `look:'table'`이면 표로 보인다.
- **Observation**
  - `mode`
  - `size: {w, h}`, `base`, `distorted`(w:h가 base와 동치가 아님)
  - `saved: {w, h, equivalent: boolean}[]`
  - `savedEquivalentCount`: base와 크기가 다르고 동치인 담은 크기 수
  - `addOps`, `scaleOps`
  - `misconceptions`
- **MC-RATIO-ADDITIVE:** 담은 크기 중 (w0 + d, h0 + d), d ≥ 1이고 동치가 아닌 것이 있으면 기록한다.
- **Predicates:** `savedEquivalentAtLeast {n}`, `allSavedEquivalent`(담은 것이 하나 이상이고 모두 동치), `sizeIs {w, h}`, `distorted`, `hasMisconception {code}`
- **오버레이**
  - `ratio-grid`(②): 지금 크기 위에 처음 크기(w0×h0) 타일을 왼쪽 위부터 깐다. 다 덮이지 않는 부분은 빗금으로 표시한다. 늘어난 비율이 가로·세로에서 다르면 이게 보인다.
  - `growth-arrows`(MC-RATIO-ADDITIVE ②): 가로·세로 변에 "+d" 화살표와, 처음 길이에 대한 늘어난 정도 막대(가로 d/w0, 세로 d/h0 길이)를 나란히 그린다. 분수 값 글은 쓰지 않는다.
