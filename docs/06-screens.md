# 06. 화면 명세

화면 이름 뒤 괄호는 단계(1/2/3). 모든 화면은 가로·세로 방향, 768px(아이패드 세로)~1920px(전자칠판)에서 동작해야 한다.

## 공통 UI 규칙
- 상단 바: 왼쪽 '뒤로', 가운데 활동 제목(짧게), 오른쪽 🔊(발문 읽기)·도움(힌트)·⋯(설정). 그 밖의 버튼은 두지 않는다.
- 교구 영역이 화면의 75% 이상을 차지한다.
- 발문은 교구 위 말풍선 한 줄. 저학년은 그림 아이콘 + 자동 TTS(설정에서 끄기).
- 피드백은 빨강/초록 색만으로 전달하지 않는다: 아이콘(✓, ?)과 짧은 문장을 함께 쓴다.
- 애니메이션은 `prefers-reduced-motion`을 존중한다.
- 글꼴: 한글 가독성이 좋은 무료 글꼴(예: Pretendard, 나눔스퀘어라운드 — 라이선스 확인 후 `public/fonts`에 포함, 오프라인 대응).

## S1. 시작 (1)
- 처음 실행: "몇 번이에요?" 1~30 번호 버튼(큰 타일) → 관심사 고르기(아이콘 6개, 건너뛰기 가능).
- 같은 기기를 여러 학생이 쓰면 번호 타일에서 자기 번호를 누르고 들어간다. 비밀번호 없음(1단계 위협 모델: 장난 수준. 2단계에서 학급 코드).
- 오른쪽 아래 작은 '선생님' 버튼 → 교사 PIN(기기에 저장, 4자리) → 교사 모드.

## S2. 나의 수학 별자리 (1)
- 한 화면에 영역 4개(수와 연산 / 변화와 관계 / 도형과 측정 / 자료와 가능성)를 하늘의 네 구역으로 배치. 별 = 개념 노드, 선 = 선수 관계.
- 학년 표시 없음. 교사가 켠 단원의 별만 보인다(나머지는 흐린 점).
- 별 밝기 3단계: 아직(어둠) / 연습 중(희미) / 숙달(빛남). 부스터로 극복한 별에는 작은 반짝임 표시 → '빛나는 극복 노트'에 기록.
- 별을 누르면 그 개념이 있는 활동 목록.
- 성능: 별 수백 개는 SVG 한 장으로 그린다. 확대·이동 지원.

## S3. 활동 화면 (1)
- 엔진 View + 발문 말풍선 + 하단 진행 점(과제 수).
- '확인' 버튼이 필요한 과제와, 조작이 목표를 만족하는 순간 자동 통과되는 과제가 있다(과제 설정 `submit: 'button'|'auto'`).
- 힌트 버튼: 단계가 오를 때 버튼 옆에 점 표시(①②③). ③은 "잠깐 연습하고 올까?" 카드 → 부스터 창.
- 부스터 창: 전체 화면 모달, 상단에 "잠깐 연습 (2~3분)" 표시만, 학년 표시 없음. 끝나면 원래 화면 그대로 복귀(상태 보존).
- '보여 주기' 버튼(1단계): 현재 상태를 짧은 공유 코드(또는 QR)로 만들어 교사 기기에서 열 수 있게 한다. 상태 JSON을 압축해 URL 해시에 담는다 — 서버 불필요.

## S4. 교사 시연 모드 (1) — 전자칠판
- 엔진 목록(20개, 그림 카드) → 엔진·모드 선택 → 빈 교구 자유 조작. 과제·채점 없음.
- 도구 막대: 펜(3색), 지우개, 화면 2분할, 확대(1×/1.5×/2×), 되감기 슬라이더(조작 과정 재생), 초기화.
- 2분할: 왼쪽·오른쪽에 서로 다른 상태(학생 공유 코드 2개)를 띄워 전략 비교. 학생 번호는 표시하지 않는다(익명).

## S5. 교사 관리 (1)
- 단원 켜기/끄기와 표시 이름·순서 바꾸기(교과서 맞춤).
- 기기 기록 가져오기: 학생 기기의 내보내기 파일/QR을 모아 학급 요약 보기(05 §7).
- 교사 PIN 변경, 모든 기록 지우기(확인 2번).

## S6. 학급 실시간 대시보드 (2)
- 학급 만들기 → 6자리 코드. 학생 S1에서 '학급 코드 입력'.
- 썸네일 격자(최대 30): 각 학생의 현재 교구 상태를 `readOnly` 축소 렌더. 오개념 감지 학생은 테두리에 ? 표시(빨강 경보 대신 차분한 표시).
- 상단: 전체 일시정지(학생 화면에 "선생님을 봐 주세요" 오버레이), 익명 비교(썸네일 2~3개 선택 → S4 2분할로), 투표 시작(E18 class-vote).
- 수업 끝: 모둠 편성 제안(보충/유창성/심화) — 교사가 확인·수정 후 출구 과제 배포.

## S7. 도형 스무고개 대전 (2) — g4s2u4
- 두 학생 매칭(교사가 짝 지정 또는 무작위). 한 명이 사각형 하나를 비밀로 고르고, 다른 한 명은 예/아니오 질문 카드로 좁혀 간다. 1단계는 컴퓨터 상대 버전.

## S8. 풀이 영상(Thinklet) (3)
- 교구 조작 Action 재생 + 마이크 녹음을 동기화. 영상 파일이 아니라 *Action 목록 + 음성*으로 저장하므로 가볍다. 음성은 기기에만 저장, 교사에게 보낼 때만 내보내기.

## S9. 학부모 대화 카드 (3)
- 주 1회, 학생이 그 주에 쓴 전략 하나와 가정에서 할 수 있는 대화 질문 하나. 성적·백분위 없음. 카드 문구는 단원별 템플릿(교사 검수).
