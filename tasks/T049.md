## 구현 결정 (2026-11-04 Claude 작성 — 여기 적힌 대로 하고, 바꿔야 하면 메모에 이유를 적고 질문한다)
1. **폴더·모드:** `src/engines/E05-fraction-model/`만 고친다. `modes`는 기존 8개 뒤에 `multiply`, `divide-measure` 순서로 붙인다. `share`·`divide-whole`은 모드가 아니라 **partition의 `variant`**다(`variant?: 'share' | 'divide-whole'`, 없으면 지금 partition 그대로). 상태는 `mode: 'partition'`을 유지하고 `variant`로 구분하는 별도 타입(`ShareState`, `DivideWholeState`)을 `FractionModelState` 합집합에 더한다. `inferMode`: `variant`가 있으면 partition, `dividend`+`divisor`(variant 없음)면 divide-measure. View.tsx가 이미 1963줄이므로 새 화면은 `views/MultiplyView.tsx`, `views/DivideMeasureView.tsx`, `views/ShareView.tsx`, `views/DivideWholeView.tsx`로 두고 View.tsx 루트 switch는 고르기만 한다. reduce도 `reduce-multiply.ts` 등으로 나눈다. 기존 8개 모드의 동작·Observation·이벤트는 바꾸지 않는다(`events.test.ts:272`의 modes·events·overlays 목록 단언만 새 목록으로 고친다).
2. **수와 여러 전체:** 분수 값은 모두 `Rational`(`fractions.ts`의 `parseRational` 등). 화면 좌표만 number. 1보다 큰 값은 **정사각형(막대)을 여러 개** 나란히 그려 나타낸다: 필요한 전체 수 = 값의 올림(최대 4). 설정 분수는 `"2/3"`, `"1 1/2"`, `"4"` 같은 문자열과 정수 number를 받는다.
3. **multiply:** 설정 `a`(0 < a ≤ 4, 여러 전체 허용), `b`(0 < b ≤ 1), `layout`(기본 `{ a: "vertical", b: "horizontal" }` — 기존 overlay-slicer의 `orientation`과 다른 키다, 섞지 않는다), `build: "student" | "preset"`(기본 `student`), `showCounts`(기본 **false**), `maxDenominator`(기본 12). `blend` 키는 받지만 무시한다(늘 반투명 + 무늬).
   - 상태 `multiply: { aParts, aShaded, bParts, bShaded }`(정수). `a` 방향은 전체 여러 개를 가로로 잇는 세로 칸(aParts = 한 전체를 나눈 수, aShaded = 칠한 칸 수 — 여러 전체에 걸쳐 셈), `b`는 가로 칸.
   - Action `set-parts {side, parts}`, `set-shaded {side, count}`(E04 fraction-area와 같은 이름). `preset`이면 처음부터 a, b대로 놓인다(P 단계 "겹침 자동").
   - 그림: a = 노랑 + 세로 빗금, b = 파랑 + 가로 빗금, 겹침 = 초록 + 격자 무늬(색은 E04 `FractionAreaView.tsx`의 YELLOW `#b45309`, BLUE `#2f6fde`, GREEN `#215c2a`를 복사). `showCounts`가 true일 때만 "전체 칸 12 · 겹친 칸 6"을 쓴다. **곱(1/2)은 어떤 설정에서도 쓰지 않는다.**
4. **divide-measure:** 설정 `dividend`(≤ 4), `divisor`(> 0), `showRemainderFractionOfDivisor`(기본 false).
   - 위에 나뉨수 막대(전체 단위 눈금 + 그 분모 눈금), 아래에 자 막대(나누는 수 길이, 그 분모 눈금). 화면 단위 길이는 `max(dividend, divisor)`의 올림 전체가 들어가게 정한다.
   - Action `lay-ruler`(앞 자 끝에 다음 자를 놓는다. 남은 길이가 자보다 짧으면 **부분 자**를 놓고 더 놓지 않는다), `lift-ruler`(마지막 자), `clear-rulers`. 키보드 Space/Enter = 놓기, Backspace = 들기.
   - 온전한 자마다 1, 2, 3… 번호 도장(학생이 놓은 수를 세는 것이라 허용 — 명세대로). 부분 자는 자 전체 윤곽을 점선으로 그리고 채운 부분만 칠한다. `showRemainderFractionOfDivisor`가 true면 부분 자를 공통 단위(두 분모의 최소공배수) 칸으로 나눠 세어 볼 수 있게만 한다. **"자의 1/8" 같은 값 글자는 쓰지 않는다.**
   - 몫과 역수 곱셈 모핑은 그리지 않는다(g6s2u1.A2의 모핑은 E03 `double`, T048 몫).
5. **partition `share`:** 설정 `wholes`(전체 수 1~6), `people`(2~6), `shape`(`circle` 기본 / `rect` / `bar`), `plateLabel`(기본 **false**). `equalPartsCheck`는 받지만 무시하고, 기존 넓이 같음 검사를 늘 켠다.
   - 전체마다 기존 자르기 도구를 쓰고, 끌기 없는 대안으로 "똑같이 n조각" 버튼(`cut-equal {whole, parts}`, 2~12)을 둔다.
   - 나누기: 조각을 고르고(누르기·Enter) 접시를 누르거나 숫자 키 → `deal-piece {whole, piece, plate}`. 되돌리기는 `return-piece {whole, piece}`. 한 조각은 한 접시에만 놓인다.
   - 접시에는 받은 조각 그림만 놓인다. `plateLabel`이 true면 "1/4 조각 3개"처럼 조각 크기와 개수만 쓰고 합한 값(3/4)은 쓰지 않는다.
   - 상태 `share: { wholes: { cuts, pieces: { plate: number | null }[] }[] }`.
6. **partition `divide-whole`:** 설정 `fraction`(나뉨수 — 단원 명세 키를 그대로 쓴다. **variant가 있으면 `simplifyFrom`을 건너뛰어 약분 퍼즐로 바뀌지 않게 한다**), `divisor`(2~6), `morphToMultiply`(기본 **false**), `groupShortcut`(기본 true).
   - 정사각형(1보다 크면 여러 개)에 나뉨수만큼 세로 띠를 칠해 시작한다.
   - "÷ n" 카드를 누르면 가로 칸 슬라이더가 열린다(−/+ 버튼, `set-rows {rows}`, 1~divisor). rows가 바뀔 때 가로선이 생기고 `partitioned`를 올린다. `keep-row {row}`를 하면 칠한 띠 중 그 가로 줄만 진하게 남고 나머지는 흐려진다.
   - `groupShortcut`이고 분자가 divisor의 배수(6/7÷3)면 "묶어서 나누기" 버튼(`bundle`)으로 칠한 띠를 divisor 묶음으로 나누고 한 묶음을 고른다(`keep-bundle {index}`).
   - `morphToMultiply`가 true면 keep 뒤 식 띠 `4/5 ÷ 3`이 `4/5 × 1/3`으로 바뀌는 애니메이션을 보여 준다. 이 식은 g6s1u1.A2 과제 3의 답이라 기본은 false다. 콘텐츠 카드가 과제 순서를 보고 켠다(메모에 남김).
7. **Observation(새 키, 해당 없으면 null):**
   - multiply: `a`, `b`(학생이 놓은 값, Rational 문자열), `aParts`, `bParts`, `squares`, `overlapCells`, `totalCells`, `product`(관찰에만, 화면에는 없음).
   - divide-measure: `dividend`, `divisor`, `rulersLaid`(온전한 자 수), `partial`(부분 자가 자의 몇인지 Rational 문자열 또는 null), `measured`(rulersLaid + partial), `measureComplete`.
   - share: `plates: string[]`(접시별 값), `platesEqual`, `allDealt`, `piecesPerWhole: number[]`, `equal`(모든 전체가 같은 넓이로 나뉨).
   - divide-whole: `dividend`, `divisor`, `rows`, `keptRow`, `kept`(남긴 값), `bundled`.
   - 기존 `wholes` 배열은 새 모드에서도 지금 규칙대로 채운다.

### 구현 결과
- `modes`에 `multiply`, `divide-measure`를 기존 8개 뒤에 붙였다. `share`·`divide-whole`은 `partition`의 `variant`로 두고 `ShareState`·`DivideWholeState`를 합집합에 더했다(`isShareState`·`isDivideWholeState` 타입 가드).
- 새 reducer는 `reduce-multiply.ts`, `reduce-divide-measure.ts`, `reduce-share.ts`, `reduce-divide-whole.ts`로 나눴고, `reduce.ts`는 `inferMode`·`createInitialState`·`reduce`에서 고르기만 한다. 공용 계산은 `pieces.ts`(`piecesOf`), `layout.ts`(정사각형·막대 배치, `MAX_SQUARES`), `geometry.ts`(`autoPresetCuts`·`boundingBox`)로 뺐다.
- 새 화면은 `views/MultiplyView.tsx`, `views/DivideMeasureView.tsx`, `views/ShareView.tsx`, `views/DivideWholeView.tsx`에 두고 `View.tsx` 루트 switch가 분기한다. 새 화면 공용 부품은 `views/shared.tsx`, 컴포넌트가 아닌 함수는 `views/helpers.ts`에 있다.
- `observe.ts`에 카드 7번 키를 모두 넣었고(`plates`·`platesEqual`·`allDealt`·`piecesPerWhole`·`equal`, `kept`·`bundled`·`squares` 등), `events.ts`에 `area-changed`·`ruler-laid`·`dealt`·`rows-set`·`row-kept`와 `primaryValue`(multiply=곱, divide-measure=잰 길이, share=첫 접시, divide-whole=남긴 값), 판정 7개(`overlapCellsIs`·`productIs`·`factorsAre`·`measuredIs`·`platesAre`·`keptValueIs`·`rowsIs`)를 더했다.
- 오버레이 `overlap-count`·`ruler-repeat`·`remainder-beside`·`row-preview`를 추가하고 `grid-reveal`이 multiply에서도 격자 선을 그리게 했다.
- 접근성: 새 화면의 모든 조작은 −/+ 단추, 조각 고르기 → 접시 단추, 자 놓기/들기 단추와 키보드(Space·Enter·Backspace, 접시 숫자 키)로 끝낼 수 있다. 색만으로 구분하지 않고 빗금·격자·점선 무늬를 함께 쓴다. share에는 끌기 칼선(선)도 붙였고, 끌지 않고 누르기만 하면 조각 고르기로 동작한다.

### 카드와 다르게 한 점과 이유
- **`open-rows` 액션 이름**: 카드에는 "÷ n 카드를 누르면 가로 칸 슬라이더가 열린다"만 있어 액션 이름이 없었다. `open-rows`로 정하고 `rowsOpen`을 켜기만 한다(칸 수 변경은 `set-rows`).
- **share의 `equal` 의미**: "모든 전체가 같은 넓이로 나뉨"을 전체마다 조각 넓이가 같은지(기존 `piecesAreEqual`)로 읽었다. 전체끼리 조각 수가 같은지는 보지 않는다. 카드 14번의 "같지 않게 자르면 equal false"는 한 전체를 서로 다른 넓이로 자른 경우로 테스트했다.
- **share `dealt {plate, value}`의 `value`**: 조각 하나의 값이 아니라 그 접시에 지금까지 모인 합으로 정했다. 바로 뒤 `value-changed`(첫 접시)와 같은 뜻이 되게 하기 위해서다.
- **share 끌기 칼선**: 기존 partition의 직선 칼선과 같은 `cut` 액션을 전체별 좌표로 보낸다. 중심 칼선(radial) UI는 넣지 않았고, 끌기 없는 대안인 "똑같이 n조각"이 모든 과제를 끝낼 수 있게 한다.
- **divide-whole `bundled`**: "묶어서 나누기"를 누른 상태(`bundleOpen`)를 뜻한다. 실제로 한 묶음을 고르는 것은 `keep-bundle`의 두 단계다. `kept`는 `keptBundle`이 있을 때만 값이 있다.
- **divide-whole `canBundle`**: `groupShortcut`이 켜져 있고 칠한 띠 수(`dividendShaded`, 분자)가 `divisor`의 배수일 때만 참이다. 2 1/4처럼 분자가 9인 경우도 묶을 수 있다.
