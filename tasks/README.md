## W3 평면 도형
엔진 카드(T100~T108)와 오개념 레지스트리 카드(T109)를 먼저 하고, 단원 콘텐츠 카드(T110~T121)는 선행 엔진 카드와 T109가 병합된 뒤 한다. T100이 E09와 함께 core 기하 도우미(`src/core/math/geometry.ts`)를 만들므로 E10·E11·E17 카드도 T100 뒤에 한다. E17(원래 W6)은 4학년 삼각형·사각형 단원에 필요한 도형 모드만 W3에서 먼저 만든다. '구현 결정'은 카드를 맡기기 직전에 Claude가 채운다(T100~T109는 채워 둠). T100·T109는 병합했다. T101~T108도 검수 ㉔를 거쳐 병합했다(2026-11-11). T110~T121의 구현 결정을 채웠다(2026-11-11, 공통 1~9 + 과제별 + Opus 결정). 단원 카드는 모두 main에서 딴다. T113·T119만 E09 엔진을 조금 고친다(CircleView 밧줄 길이·도구 이름 / perimeter 안내 문구).
