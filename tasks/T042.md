## 구현 결정 (2026-11-04 Claude 작성 — 여기 적힌 대로 하고, 바꿔야 하면 메모에 이유를 적고 질문한다)
1. **폴더:** `src/engines/E01-base-ten/`, E05·E07과 같은 구조. 엔진 ID `E01`, 이름 "수 모형", modes 순서 `count`, `regroup`, `add-sub`, `place-chart`, `free`. 확장 모드(`big-number`, `decimal`, `divide`)는 T043 몫이므로 만들지 않는다. E07과의 연결(받아올림·받아내림 칸 표시)은 E07 쪽 `receive`가 할 일(T046)이므로 이 카드는 **이벤트를 내기만** 한다.
2. **수 표현:** 블록 값은 `1 | 10 | 100 | 1000`(number). 나타내는 수는 0~9999 정수라 number로 충분하다. T043의 `decimal`이 들어오면 그때 `Rational`로 바꿀 수 있게, 값 계산은 `value.ts` 한 곳에 모은다(`valueOf(state)`).
3. **상태:** `blocks: {id, value, x, y, zone?}[]`(x·y는 논리 좌표 정수, `zone`은 add-sub의 `a`/`b`/`sum`/`take`), `chart: (string | null)[] | null`(자릿값 표 칸에 학생이 쓴 숫자, 높은 자리부터), `log: {kind: 'group' | 'break', from: 1|10|100|1000}[]`(묶기·풀기 순서 — 판정용), `lastAttempt: {count, value, ok} | null`, `nextId`. 논리 캔버스 1000×600, 누른 위치는 SDK `pointerToLogical`.
4. **올가미 묶기:** SDK `useLasso`로 폐곡선을 그리면 안에 든 블록 id 목록으로 `lasso-group {ids}` 하나를 dispatch한다. reduce가 판정한다: 모두 같은 값이고 정확히 10개면 그 10개를 지우고 값 ×10 블록 하나를 무게중심에 만든다(`log`에 group). 아니면 블록은 그대로, `lastAttempt = {count, value, ok:false}`(값이 섞였으면 value null). View는 실패한 시도에 "○개" 개수 배지를 1.5초 보여 준다(학생이 감싼 개수 — 목표 값이 아니다). 1000 블록은 더 묶지 않는다. 설정 `lasso`(기본 true)가 false면 대체로 **"10개 묶기" 버튼**: 같은 값 블록 10개 이상이 있을 때 그 값을 골라 묶는다(크롬북·키보드·전자칠판 대체 — lasso가 true여도 버튼은 항상 있다).
5. **망치 풀기:** 블록을 두 번 톡(또는 선택 + "풀기" 버튼/Enter) → `break {id}`. 값 ÷10 블록 10개를 그 자리 근처에 부채꼴로 놓는다(`log`에 break). 1은 풀지 않는다.
6. **블록 놓기:** 설정 `allowedBlocks`(기본 `[1, 10, 100]`)의 블록 상자에서 끌어 오면 `add {value, x, y}`, 캔버스 밖·휴지통으로 끌면 `remove {id}`, 옮기기 `move {id, x, y}`. `maxValue`(기본 9999)를 넘게 만드는 add는 무시한다. 설정 `start`: `{ ones?, tens?, hundreds?, thousands?, scattered? }` — `scattered: true`면 낱개를 seed(`start.seed`, 기본 1)로 정한 위치에 흩어 놓는다(reduce에서 무작위 금지, createInitialState에서 한 번).
7. **자리 칸(snap):** 설정 `snapColumns`(boolean)면 캔버스 아래에 자릿값 칸(천·백·십·일)을 그리고, 블록을 칸 근처에 놓으면 자기 값의 칸에 붙는다(다른 값의 칸에 놓으면 붙지 않고 놓은 자리에 남는다 — 오개념이 드러나야 한다).
8. **자릿값 표(chart):** 설정 `chart`(열 이름 배열, 예 `["tens","ones"]` — 높은 자리부터), `chartFill`(`"student"` 기본 / `"auto"`). student: 학생이 칸을 눌러 숫자 0~9를 쓴다(`set-digit {column, digit}`, 키패드는 엔진 안의 작은 숫자 키패드, 키보드 숫자 지원). auto: 지금 블록 개수를 칸에 그대로 보여 준다 — **정규형이 아니면 한 칸에 10 이상이 나올 수 있다**(그대로 보여 준다). auto는 그 과제의 답을 그대로 읽게 될 수 있으므로 콘텐츠 카드가 과제별로 정한다. 1학년 용어: 열 이름 표시 문구는 설정 `chartLabels`(기본 `tens`→"십", `ones`→"일"; 1학년 콘텐츠는 `["10개씩 묶음","낱개"]`를 넘긴다).
9. **place-chart:** 설정 `columns`, `bidirectional`(기본 true), `digits`(학생이 칸에 놓을 숫자 카드, 예 `[3,7,1]`). 숫자 카드를 칸에 끌어 놓으면(`place-digit {index, column}`) 위쪽 블록이 그 숫자만큼 생긴다(정규형으로). bidirectional이면 블록을 더하거나 빼면 칸 숫자도 바뀐다(블록 개수가 10이 되면 그 칸은 "10" 그대로 — 자동으로 묶지 않는다). 주사위 굴리기·상대(컴퓨터) 대결은 만들지 않는다(무작위·경쟁 요소 — 숫자는 콘텐츠 `digits`로 준다. 메모에 남김).
10. **add-sub:** 설정 `op`(`add`/`sub`), `a`, `b`, `regroupAllowed`(기본 true), `snapColumns`(기본 true), `constraint`(`"none"` / `"no-negative-take"`). add: 위에 a·b 블록 두 무더기, 학생이 "모으기" 칸(`sum` zone)으로 끌어 모은다. sub: a 블록 무더기와 "빼기 접시"(`take` zone). 빼기 접시에 놓인 블록은 값에서 빠진다. `no-negative-take`: 빼기 접시에 같은 자리 블록을 b의 그 자리 숫자보다 많이 놓을 수 없다(넘치는 놓기는 무시하고 블록이 흔들리는 CSS 효과). 낱개가 모자라면 상위 블록을 풀어야 한다. 식 카드는 응답 위젯 몫이다.
11. **CPA 그림:** C: 2.5D 블록(1 = 작은 정육면체, 10 = 막대, 100 = 판, 1000 = 등각 큐브), 아이콘 블록 옵션 `icon`(`candy`/`star`, 1블록에만 — 1학년 "사탕 아이콘"). P: 평면 사각형·막대·점. A: 블록을 그리지 않고 자릿값 표만(표가 없으면 빈 상자). 설정 `render`(`"auto"` 기본 / `"isometric"` / `"flat"`)로 덮어쓸 수 있다. 1000 큐브가 많을 때 성능: 같은 값 블록이 20개를 넘으면 겹쳐 쌓는 묶음 그림으로 그린다(개수 배지 없이).
12. **Observation:** `mode`, `value`(지금 나타내는 수; add는 `sum` zone 값, sub는 남은 값), `counts: {thousands, hundreds, tens, ones}`, `canonical`(모든 자리 ≤ 9), `groups`(log의 group 수), `breaks`, `log`, `lastAttempt`, `chartDigits`(학생이 쓴 표), `chartValue`(표가 다 찼을 때 그 수, 아니면 null), `taken`(sub에서 빼기 접시 값), `allowHundredReveal`이면 값이 100이 된 적이 있는지(`reachedHundred`).
13. **Predicates:** `valueIs {value}`, `canonical`, `countsAre {thousands?, hundreds?, tens?, ones?}`, `groupedAtLeast {from, count}`, `brokeAtLeast {from, count}`, `brokeBefore {first, then}`(log에서 first 풀기가 then 풀기보다 먼저), `chartIs {value}`.
14. **이벤트(연결용, 모양 고정 — T046이 받는다):** `grouped {from, to, column}`, `broken {from, to, column}`(column은 E07과 같은 자릿값 지수: 일 0, 십 1, 백 2, 천 3), `value-changed {value}`.
15. **정답 노출 금지:** 기본 설정에서 나타내는 수를 화면에 숫자로 쓰지 않는다(`showValue` 설정 없음 — 수는 학생이 표나 응답 위젯으로 쓴다). chart `auto`만 개수를 보여 준다.
16. **입력·접근성:** Pointer Events, 블록 터치 타깃 ≥ `targetSize`(1 블록이 작으므로 터치 판정 반경을 SDK `minTouchRadius`로 넓힌다). 키보드: Tab으로 블록·상자·칸 이동, Space 집기/놓기, 방향키 이동(Shift 5배), Enter 풀기, `G` 또는 "10개 묶기" 버튼으로 묶기, Delete 빼기.
17. **오버레이(힌트 ②):** `ten-outline`(같은 값 블록 10개 자리를 점선 윤곽으로 보여 줌 — 몇 개가 모자라는지 빈 윤곽으로), `place-value`(칸마다 자릿값 이름과 그 칸 블록이 나타내는 수), `break-preview`(선택한 상위 블록이 풀리면 몇 개가 되는지 흐린 그림).
18. **테스트:** reduce 단위(9·10·11개 올가미, 섞인 값, 1000 더 묶지 않음, 풀기 후 값 불변, scattered seed 결정성, no-negative-take, place-chart 양방향, log 순서), observe·predicates, `assertSerializable`, View 테스트(기본 상태에서 값 숫자가 DOM에 없음), `#/sandbox/E01` E2E 3개 뷰포트: 낱개 34개를 "10개 묶기" 버튼으로 정규형 만들기 → `counts` 3·4, 올가미로 10개 묶기 1회(좌표는 `tests/e2e/canvas-point.ts`의 `logicalToScreen`), 키보드만으로 100판 하나 풀기.

## 메모
- 구현 파일: `src/engines/E01-base-ten/`(types·value·layout·reduce·observe·events·strings.ko·View·overlays 3개), `__tests__/engine.test.ts`, `__tests__/view.test.tsx`, `tests/e2e/base-ten.spec.ts`. `src/core/`·다른 엔진·`data/`·`docs/`는 건드리지 않았다. core 변경 요청 없음.
- **sub 값 해석(결정 10·12):** 빼기 접시로 옮긴 블록은 이미 `a` 구역에서 빠지므로 `value`는 `a` 구역만 세고 `taken`을 따로 읽는다(두 번 빼지 않기). 블록 상자에서 접시로 바로 놓는 `add`는 처음 수 무더기(`a`) 자리로 되돌린다.
- **입력:** 블록 옮기기·꺼내기는 SDK `useDrag`, 올가미는 `useLasso`만 쓴다. 두 drag의 move/up/cancel을 SVG에 붙여, 블록을 잡은 뒤 포인터가 블록 밖으로 나가도 놓인다. 상자 블록은 Enter/Space로도 놓는다.
- **두 번 톡 풀기:** `pointerdown`의 `event.timeStamp`로 판정한다(`Date.now`는 `react-hooks/purity` 규칙이 막아서).
- **실패 배지:** `lastAttempt` 객체가 바뀔 때마다 1.5초 보인다. 보이는 동안 같은 시도는 다시 뜨지 않는다.
- **chart auto:** 정규형이 아니면 "10"을 그대로 보여 주고 `chartValue`는 null이다(결정 8·12). `student`는 `set-digit`만 바꾸고 블록은 만들지 않는다. `place-chart`에서 카드를 다른 칸으로 옮기면 이전 칸 블록을 지우고 새 칸 블록을 만든다.
- **레이아웃:** 화면 폭이 좁으면 5:3 캔버스가 뷰포트보다 길어져 페이지가 스크롤된다(다른 엔진과 같은 셸). E2E는 캔버스를 스크롤해 아래까지 보이게 한 뒤 `logicalToScreen`으로 좌표를 잰다. 캔버스 높이를 뷰포트에 맞추는 일은 `src/app` 몫이라 손대지 않았다(필요하면 별도 카드).
- T043(`decimal`)은 `value.ts`의 `valueOf`·`countsOf`만 바꾸면 되도록 계산을 모아 두었다.
