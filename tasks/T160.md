## 목표
T159 검수에서 크롬북 그림그래프 화면 문제 두 가지가 나왔다.

1. **읽기용(given) 그림그래프가 판보다 크다.**
   - g3s2u6.A2 크롬북 두 칸 배치에서 넷째 줄(라)이 잘린다. 이름 글자도 보이지 않는다.
   - 누르는 그림이 없는데도 그림을 `targetSize` 크기로 그려서 생긴 문제다.
2. **만들기용 행 조작 단추가 판 아래에 따로 있다.**
   - g3s2u6.A1 크롬북 첫 화면에서는 '가' 줄의 "+ 작은 그림·묶기·펼치기" 단추만 보인다. 나머지 줄 단추는 스크롤해야 나온다.
   - 어느 단추가 어느 줄 것인지도 멀리 떨어져 있어 알기 어렵다.

## 구현 결정 (2026-11-18 Claude 작성 — 여기 적힌 대로 하고, 바꿔야 하면 메모에 이유를 적고 멈춰서 묻는다)
1. **읽기용 그림그래프 맞춤:**
   - `table-to-graph`의 그림그래프 보기와 `build:"given"`은 그래프 영역 안에 다 들어가도록 그림 크기를 줄인다.
     - 행 높이 = min(지금 크기, 영역 높이 ÷ 행 수)이다.
     - 그림 한 변은 행 높이에 맞춘다. 큰 그림·작은 그림 비율(1.6배)은 유지한다.
   - 하한은 작은 그림 한 변 20px(화면)이다. 하한에 걸리면 지금처럼 세로 스크롤 + T158 안내 띠를 쓴다.
   - 행 이름·범례 글자는 T158의 최소 글자 크기를 따른다.
2. **만들기용 행 조작 위치:**
   - `build:"student"`에서 행마다 "+ 작은 그림", "묶기", "펼치기" 단추를 그 행 안 오른쪽 끝에 둔다.
     - 단추는 HTML이다. 행 SVG 옆에 같은 높이로 붙인다. 행 하나 = 행 이름 + 그림 칸 + 단추 묶음.
   - 행 높이는 단추 높이(`targetSize`) 이상이다.
   - 폭이 좁아 단추 묶음이 들어가지 않으면, 단추를 그 행 바로 아래 줄로 내린다. 다른 행 단추와 섞이지 않게 한다.
   - 판 아래의 따로 떨어진 단추 줄은 없앤다. 키보드 순서는 행 순서대로 이름 → 그림 → 단추다.
   - 올가미·탭·키보드 동작, Action, Observation은 바꾸지 않는다.
3. **테스트:**
   - graph-studio E2E(3 뷰포트 + 크롬북 두 칸 폭 660×420):
     - given 그림그래프 4행(값 32·25·41·18)이 영역 안에 다 들어간다(SVG 상자 ≤ 영역 + 1px, 스크롤 없음).
     - 학생 만들기에서 각 행의 "+ 작은 그림" 단추의 세로 가운데가 그 행 상자 안에 있다(줄이 내려간 경우는 행 바로 아래).
   - g3s2u6.spec.ts: A2.T1 크롬북에서 라 줄 이름이 첫 화면에 보이는지 단언한다. 첫 화면 기준표를 실제에 맞게 고치고 메모에 적는다.
   - 바뀐 스냅샷(graph-studio pictograph, g3s2u6)은 다시 찍고 직접 연다. E18 밖 스냅샷이 바뀌면 멈춘다.
4. **멈춤 조건:** 크롬북 두 칸 배치에서 given 그림그래프의 작은 그림이 20px 미만이 되거나, 만들기 화면에서 단추가 `targetSize`보다 작아지면 측정값과 함께 멈춘다.
