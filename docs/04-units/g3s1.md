### 활동
#### g3s1u1.A1 백·십·일 연속 풀기 캔버스 — E01 `add-sub` + E07 `sub` · C→P→A
- **원 계획서:** 백·십·일 2단계 연속 파쇄(받아내림) 제약 캔버스
- **화면과 조작:** 위쪽에 자릿값 판(백·십·일 칸)과 블록, 아래쪽에 세로셈 격자가 함께 있다. 빼는 수만큼 블록을 "빼기 접시"로 끌어 가야 하는데, 일의 자리 블록이 모자라면 끌 수 없고 흔들린다(제약). 십 블록을 망치로 두드려 10개로 풀어야 한다. 십의 자리가 0이면 먼저 백 블록을 풀어야 한다. 블록을 풀 때마다 세로셈의 해당 자리 위에 작은 받아내림 숫자가 자동으로 연하게 표시되고(C), P 단계부터는 학생이 직접 그 칸을 입력한다.
- **설정 예시:**
  ```json
  { "mode": "add-sub", "op": "sub", "a": 403, "b": 158, "constraint": "no-negative-take", "linkColumnCalc": true }
  ```
- **과제(쉬운 것 → 어려운 것):**
  1. 352 − 127 (한 번 받아내림) / 판정: `observe().value == 225` 이고 `broken` 이벤트가 십의 자리에서 1회 이상
  2. 524 − 268 (두 번 받아내림) / 판정: 결과 256 + 십·백 자리에서 각각 풀기 발생
  3. 403 − 158 (0을 건너는 받아내림) / 판정: 결과 245 + 백 블록 풀기가 십 블록 풀기보다 먼저 발생
  4. 478 + 365 (두 번 받아올림) / 판정: 결과 843 + `grouped` 2회(일→십, 십→백)
  5. (A 단계) 세로셈 격자만으로 602 − 357 / 판정: 모든 칸이 기대값과 일치
- **CPA 페이딩:** C: 입체 블록, 받아내림 칸 자동 표시 / P: 평면 막대·점 블록, 받아내림 칸은 학생 입력 / A: 블록 숨김, 세로셈만(막히면 힌트 ②에서 블록 잠깐 보이기)

#### g3s1u1.A2 어림 신호등 — E03 `rounding` + E07 `estimate` · P→A
- **원 계획서:** 어림값 신호등 검증기
- **화면과 조작:** 계산 전에 먼저 수직선에서 두 수를 가장 가까운 몇백(또는 몇백 몇십)으로 끌어 어림값을 만든다. 그다음 세로셈으로 계산하면, 실제 결과와 어림값의 차이에 따라 신호등이 초록(가깝다)·노랑·빨강(어림과 너무 다름 → 다시 확인)으로 켜진다.
- **설정 예시:**
  ```json
  { "mode": "estimate", "op": "add", "a": 389, "b": 412, "roundTo": 100, "tolerance": { "green": 100, "yellow": 200 } }
  ```
- **과제:**
  1. 389 + 412를 몇백으로 어림하기 / 판정: E03 점 위치 400, 400 + 합 800
  2. 계산 후 신호등 확인 / 판정: E07 결과 801, 신호 초록
  3. 일부러 틀린 풀이 "512 − 287 = 375"를 보고 신호등으로 의심하기 / 판정: 학생이 "다시 확인" 버튼 선택 + 어림 500 − 300 = 200 입력
  4. 어림 결과만으로 "두 수의 합이 900보다 클까?" 판단 / 판정: 예·아니요 선택 정오
- **CPA 페이딩:** P: 수직선 위 끌기 / A: 어림값을 숫자로 바로 입력

### 활동
#### g3s1u2.A1 선 레이저 발사기 — E09 `construct` · C→P
- **원 계획서:** 선분·반직선·직선 레이저 발사기
- **화면과 조작:** 점판 위 두 점을 고르고 "선분/반직선/직선" 도구 중 하나로 잇는다. 반직선과 직선을 고르면 끝없는 쪽으로 레이저 빛이 화면 끝까지 뻗어 나간다(연장 미리보기). 화면 곳곳의 별을 레이저로 맞히는 퍼즐로 "어느 쪽으로 끝이 없는가"를 체험한다. 반직선은 시작점을 바꾸면 다른 반직선이 됨을 보여 준다(ㄱㄴ과 ㄴㄱ).
- **설정 예시:**
  ```json
  { "mode": "construct", "tools": ["segment", "ray", "line"], "grid": 9, "targets": [[1,1],[7,4],[3,8]], "showExtension": true }
  ```
- **과제:**
  1. 점 ㄱ, ㄴ을 잇는 선분 긋기 / 판정: 객체 타입 segment, 끝점 = {ㄱ, ㄴ}
  2. 별 2개를 한 번에 맞히는 반직선 / 판정: ray, 두 별이 반직선 위
  3. 반직선 ㄱㄴ과 반직선 ㄴㄱ 각각 긋기 / 판정: 시작점이 서로 다른 ray 2개
  4. 이름 맞히기: 화면의 세 선을 선분·반직선·직선 상자로 분류 / 판정: 분류 정오
- **CPA 페이딩:** C: 레이저 애니메이션 / P: 끝점 표시(점·화살표)만 / A: 기호 이름(선분 ㄱㄴ, 반직선 ㄱㄴ)으로 답하기

#### g3s1u2.A2 직각 찾기와 직각 도형 만들기 — E09 `construct` + `classify` · C→P→A
- **원 계획서:** 디지털 종이접기 직각 생성 + 직각삼각자 스냅 스캐너
- **화면과 조작:** 가상 직각삼각자를 끌어 도형의 각에 대면, 직각이면 "딸깍" 스냅되며 초록 표시, 아니면 틈이 보인다. 기울어진 직각도 직각임을 확인한다. 이어서 점판에서 직각삼각형·직사각형·정사각형을 만들면 `classify`가 직각 개수와 같은 변 길이를 자동으로 표시한다.
- **설정 예시:**
  ```json
  { "mode": "classify", "tools": ["set-square", "geoboard-band"], "showProperties": ["rightAngles", "equalSides"], "rotatedShapes": true }
  ```
- **과제:**
  1. 여러 각 중 직각을 모두 찾아 표시(기울어진 직각 2개 포함) / 판정: 표시 집합 = 직각 집합
  2. 직각이 1개인 삼각형 만들기 / 판정: `rightAngles == 1`, 변 3개
  3. 네 각이 모두 직각인 사각형 2가지(정사각형 아닌 것, 정사각형) / 판정: `rightAngles == 4` 두 개, 그중 하나만 `equalSides == 4`
  4. "정사각형은 직사각형일까?" 예/아니요와 이유 카드 선택 / 판정: 예 + "네 각이 모두 직각" 카드
- **CPA 페이딩:** C: 삼각자 스냅 / P: 각 표시 기호(ㄴ자 표시) / A: 성질 목록만 보고 도형 이름 쓰기

### 활동
#### g3s1u3.A1 접시 나누기 vs 묶어 덜기 동시 실험실 — E02 `share` + `measure-out` · C→P→A
- **원 계획서:** 등분제(접시 배분) vs 포함제(묶어 덜기) 동시 비교 실험실
- **화면과 조작:** 화면 왼쪽(`share`): 사탕 12개와 접시 3개 — 사탕을 하나씩 접시에 끌어 놓거나 "한 바퀴씩 나누기" 버튼. 오른쪽(`measure-out`): 사탕 12개를 4개씩 봉지에 담기 — 올가미로 4개를 묶으면 봉지가 된다. 두 실험이 끝나면 "12 ÷ 3 = 4"와 "12 ÷ 4 = 3"이 같은 수들로 이루어졌음을 나란히 보여 준다.
- **설정 예시:**
  ```json
  { "left": { "mode": "share", "total": 12, "groups": 3 }, "right": { "mode": "measure-out", "total": 12, "groupSize": 4 }, "showEquation": "after-both" }
  ```
- **과제:**
  1. 사탕 12개를 접시 3개에 똑같이 / 판정: 접시별 개수 동일(4,4,4) + 남은 사탕 0
  2. 사탕 12개를 4개씩 봉지에 / 판정: 봉지 수 3, 남은 사탕 0
  3. 문장제 카드 4장을 "나누어 주기/덜어 내기"로 분류 / 판정: 분류 정오
  4. 15 ÷ 5를 두 방법 중 하나로 나타내고 식 쓰기 / 판정: 모델 결과 3 + 식 입력 `15÷5=3`
- **CPA 페이딩:** C: 사탕 그림·끌기 / P: 점과 동그라미 묶음 / A: 식만, 확인용 그림 버튼

#### g3s1u3.A2 곱셈·나눗셈 가족 배열 — E04 `dot-array` · P→A
- **원 계획서:** 곱셈·나눗셈 역연산 삼각형 카드
- **화면과 조작:** 점 배열 3줄 × 5개를 보여 주고 "이 배열로 만들 수 있는 식 모두"를 고르게 한다(3×5=15, 5×3=15, 15÷3=5, 15÷5=3). 배열을 가로로 자르는 선을 끌면 등분제, 세로 묶음을 표시하면 포함제 해석이 강조된다. 삼각형 카드(꼭짓점: 15, 3, 5) 하나를 가리면 가려진 수를 구하는 식을 고른다.
- **설정 예시:**
  ```json
  { "mode": "dot-array", "rows": 3, "cols": 5, "showSplitLines": true, "factFamily": true }
  ```
- **과제:**
  1. 배열을 보고 곱셈식 2개, 나눗셈식 2개 고르기 / 판정: 선택 집합 일치
  2. 24 ÷ 6의 몫을 배열을 만들어 구하기 / 판정: 행 6 또는 열 6으로 24개 배열 + 몫 4
  3. 삼각형 카드(?, 7, 56) — 몫 찾는 곱셈구구 고르기 / 판정: 7 × 8 선택
  4. A 단계: 36 ÷ 9 = □ 을 곱셈구구로 / 판정: 4
- **CPA 페이딩:** P: 점 배열 / A: 삼각형 카드와 식만

#### g3s1u4.A1 넓이 모델과 세로셈 색 연동 — E04 `area-model` + E07 `mul` · C→P→A
- **원 계획서:** 2분할 직사각형 넓이 모델(Area Model)과 세로셈 부분곱 색상 코드 동기화기
- **화면과 조작:** 23 × 4 직사각형(가로 23칸, 세로 4칸)이 보인다. 학생이 분할선을 20과 3 사이로 끌어 두 조각으로 나누면 조각마다 넓이가 파랑(20×4=80), 주황(3×4=12)으로 표시된다. 오른쪽 세로셈 격자의 부분곱 줄이 같은 색으로 강조되고, A 단계에서는 받아올림 방식(한 줄 세로셈)과 부분곱의 대응을 색으로 보여 준다.
- **설정 예시:**

- **과제:**
  1. 23 × 4를 쪼개서 구하기 / 판정: 분할 위치 20|3, 부분곱 80·12, 합 92
  2. 34 × 3, 학생이 다른 쪼개기(예: 30|4 또는 17|17) 시도 / 판정: 어떤 분할이든 부분곱 합 102
  3. 세로셈(부분곱 방식)으로 46 × 5 / 판정: 칸 값 일치(30, 200, 230)
  4. 세로셈(받아올림 방식)으로 213 × 4 / 판정: 852, 받아올림 칸 일치
  5. 312 × 3을 넓이 모델 3분할로 / 판정: 300|10|2 분할 + 합 936
- **CPA 페이딩:** C: 모눈 칸이 보이는 직사각형 / P: 칸 없이 가로·세로 길이만 적힌 직사각형 / A: 세로셈만

- **화면과 조작:** ① 개미·연필심 등 짧은 물체를 cm 자로 재면 눈금 사이에 끝이 걸린다. 확대 버튼(핀치 줌)을 누르면 1cm가 10칸으로 나뉜 mm 눈금이 나타난다. ② 가상 동네 지도(학교·도서관·공원)에서 길 구간을 차례로 눌러 경로를 만들면 구간 길이(m)가 더해지고, 1000m가 되면 "1km" 막대가 채워진다.

## g3s1u6 분수와 소수
| 항목 | 내용 |
| --- | --- |
| 영역 | 수와 연산 |
| 엔진 | E05 분수 모델, E03 수직선 |
| 선수 단원 | g3s1u3 나눗셈 |
| 차시 규모(참고) | 교과서 약 10~11차시 중 앱 활용 5~6차시 (교과서 확인) |
| 우선순위 | **MVP 핵심 단원** |

**핵심 아이디어:** 분수는 "전체를 **똑같이** 나눈 것 중의 몇"이다. 조각 수가 같아도 크기가 다르면 똑같이 나눈 것이 아니다. 단위분수는 나누는 수가 클수록 한 조각이 작다. 1을 10등분한 하나가 1/10 = 0.1이고, 소수는 분수의 또 다른 이름이다.

| g3s1u6.tenths-decimal | 0.1 단위 소수와 분수 10분의 몇의 관계 | g3s1u6.part-of-whole |

### 활동
#### g3s1u6.A1 등분 레이저 커터 — E05 `partition` + `shade` · C→P→A
- **원 계획서:** 면적 적분 검증 등분할 레이저 커터
- **화면과 조작:** 직사각형·원·삼각형·불규칙 도형 케이크가 있다. 학생이 레이저 커터 선을 끌어 자르면 조각마다 넓이가 계산되어 막대 높이로 아래에 나란히 표시된다. 모든 조각의 넓이가 같으면 "똑같이 나눴다" 도장이 찍히고, 다르면 막대 높이 차이가 보인다(정답 판정은 넓이 비교, 조각 수 아님). 이어서 조각을 눌러 색칠하면 분수가 만들어진다.
- **설정 예시:**
  ```json
  { "mode": "partition", "shape": "rect", "targetParts": 4, "cutTool": "free-line", "equalityCheck": "area", "areaTolerance": 0.02, "then": { "mode": "shade", "target": "3/4" } }
  ```
- **과제(쉬운 것 → 어려운 것):**
  1. 직사각형 케이크를 똑같이 4조각 / 판정: 조각 4개 + 넓이 모두 같음(허용 오차 2%)
  2. 같은 직사각형을 *다른 방법*으로 똑같이 4조각(대각선 등) / 판정: 1번과 다른 절단 + 등분 성립
  3. 화면의 나뉜 도형 6개 중 "4등분이 아닌 것" 모두 고르기(조각 수는 4지만 크기 다른 것 포함) / 판정: 선택 집합 = 비등분 도형 집합
  4. 원 케이크를 똑같이 3조각 나눈 뒤 2/3 색칠 / 판정: 등분 + 색칠 2칸 + 분수 표기 2/3
  5. 색칠된 그림을 보고 분수 쓰기(부분 5/8) / 판정: 입력 5/8 (색칠 안 된 부분 3/8과 구별)
- **CPA 페이딩:** C: 케이크 그림과 자르기 / P: 단순 도형과 등분선 / A: "전체의 3/4을 색칠한 그림은?" 고르기, 분수만 쓰기

#### g3s1u6.A2 단위분수 크기 비교 — E05 `compare` + E03 `fraction` · C→P→A
- **원 계획서:** (등분할 레이저 커터 + 분수-소수 줌인 수직선의 비교 단계로 구성)
- **화면과 조작:** 같은 크기 막대 2개를 위아래로 두고 각각 2·3·4…등분한다. 한 조각씩 색칠한 뒤 두 조각의 길이를 나란히 정렬해 비교한다. 이어서 0~1 수직선에 1/2, 1/3, 1/4 … 위치에 점을 끌어 놓는다(눈금 스냅). 분모가 같은 분수(2/5, 4/5)도 막대와 수직선으로 비교한다.
- **설정 예시:**
  ```json
  { "mode": "compare", "bars": [{ "parts": 3, "shaded": [0] }, { "parts": 5, "shaded": [0] }], "align": "left", "numberLine": { "mode": "fraction", "min": 0, "max": 1, "subdivisions": [3, 5] } }
  ```
- **과제:**
  1. 1/3과 1/5 중 큰 것 / 판정: 1/3 선택 + 막대 정렬 동작 기록
  2. 1/2, 1/4, 1/8을 큰 순서로 / 판정: 순서 일치
  3. 수직선에 1/4 위치 점 찍기 / 판정: 점 값 = 1/4
  4. 2/5와 4/5 비교, 3/7과 5/7 비교 / 판정: 둘 다 정답
  5. "□/6이 1/6보다 크고 5/6보다 작은 □는?" 모두 고르기 / 판정: {2,3,4}
- **CPA 페이딩:** C: 같은 크기 막대 직접 등분 / P: 수직선과 막대 겹쳐 보기 / A: 분수 기호만으로 비교(> < 입력)

#### g3s1u6.A3 1/10 확대경 — 분수에서 소수로 — E05 `partition` + E03 `decimal` · C→P→A
- **원 계획서:** 분수-소수 10배 줌인 수직선 (+ 토키 음성 발표는 후순위)
- **화면과 조작:** 1m 리본(막대)을 10등분하면 한 칸이 1/10 = 0.1임을 이름표로 보여 준다. 수직선 0~1 구간을 핀치 줌(또는 + 버튼)하면 0.1 눈금이 10개 나타난다. 수직선은 0~3까지 확장되어 1.3, 2.7 같은 소수도 놓는다. 막대 색칠 칸 수와 수직선 점, "10분의 □", "0.□" 표기가 동시에 바뀐다(양방향 연동).
- **설정 예시:**
  ```json
  { "bar": { "mode": "partition", "shape": "bar", "fixedParts": 10, "label": "1m" }, "numberLine": { "mode": "decimal", "min": 0, "max": 3, "unit": "1", "zoom": { "from": "1", "to": "1/10" } }, "linkRepresentations": ["fraction", "decimal"] }
  ```
- **과제:**
  1. 10등분한 리본 4칸 색칠 → 분수와 소수로 / 판정: 4/10, 0.4
  2. 수직선에 0.7 점 찍기 / 판정: 점 값 = 7/10
  3. 1.3을 수직선에 / 판정: 점 값 = 13/10, 1과 2 사이
  4. 0.6과 0.9 비교, 1.2와 0.8 비교 / 판정: 부등호 정답
  5. "0.1이 23개인 수" 쓰기 / 판정: 2.3
- **CPA 페이딩:** C: 리본 자르기 / P: 수직선 줌 / A: 소수·분수 표기만, 막히면 줌 수직선 힌트
