### 활동
#### g1s1u1.A1 손가락 수 소환 선반 — E02 `summon` · C→P
- **원 계획서:** 멀티터치 수 소환 선반
- **화면과 조작:** 빈 선반 위 화면을 손가락 여러 개로 동시에 누르면 그 수만큼 셈돌이 떨어져 선반에 줄 선다. 크롬북·전자칠판은 "톡 누를 때마다 1개" 대체 입력과 숫자 버튼(1~9). 셈돌을 끌어 빼거나 휴지통에 넣을 수 있다. 선반 옆에 수 카드가 실시간으로 바뀐다.
- **설정 예시:**
  ```json
  { "mode": "summon", "max": 9, "shelf": true, "showNumeral": "after-submit", "input": ["multitouch", "tap", "buttons"] }
  ```
- **과제:**
  1. "🍎 사과 4개를 만들어요." / 판정: `total == 4`
  2. "손가락 3개로 눌러요. 몇 개 생겼나요?" → 수 버튼 입력 / 판정: 입력값 == `total`
  3. "7개를 만들어요." / 판정: `total == 7`
  4. "그림 카드(🐟 6마리)와 같은 수만큼 놓아요." / 판정: `total == 6`
  5. "하나도 없게 만들어요." / 판정: `total == 0` (0 도입)
- **CPA 페이딩:** C: 과일·동물 모양 셈돌 + 낙하 연출 / P: 단색 동그라미, 수 카드 표시 / A: 셈돌 없이 수 카드 고르기 과제 1개

#### g1s1u1.A2 번쩍! 한눈에 세기 — E02 `flash`, `ten-frame` · P
- **원 계획서:** 서비타이징(한눈에 묶어 세기) 다중 표상 연동기
- **화면과 조작:** 주사위 눈·텐프레임·손가락 그림 중 하나가 1~1.5초 보였다가 가려진다. 학생은 수 버튼을 누른다. 정답 후 같은 수를 다른 표상 3개(주사위, 텐프레임, 손가락)로 나란히 보여 준다.
- **설정 예시:**
  ```json
  { "mode": "flash", "range": [1, 9], "displayMs": 1500, "layouts": ["dice", "ten-frame", "fingers", "random"], "afterReveal": "multi-representation" }
  ```
- **과제:**
  1. 주사위 배열 1~5 (5문항) / 판정: 입력 == 표시 수
  2. 텐프레임 6~9 "5와 몇?" / 판정: 입력 == 표시 수
  3. 무작위 배열 3~5 / 판정: 입력 == 표시 수, 응답시간 기록
  4. "텐프레임에 6을 채워요." (`ten-frame` 단일) / 판정: `frameFill == 6`
- **CPA 페이딩:** C 없음(A1에서 다룸) / P: 배열 그림 / A: 표상이 숫자로 바뀌어 "같은 수 찾기"

#### g1s1u1.A3 수 징검다리 — E03 `integer` · P→A
- **원 계획서:** (원 계획서에는 수직선 별도 항목 없음 — units.json E03 배정에 따라 수의 순서 활동 추가)
- **화면과 조작:** 0~9 징검다리(눈금) 위 개구리. 수 카드를 알맞은 돌에 끌어 놓기, "1 큰 수"로 한 칸 점프.
- **설정 예시:**
  ```json
  { "mode": "integer", "min": 0, "max": 9, "unit": "1", "labels": "partial", "character": "frog" }
  ```
- **과제:**
  1. 빈 돌에 3, 6, 8 카드 놓기 / 판정: 각 점 값 == 카드 값
  2. "5보다 1 큰 수로 뛰어요." / 판정: 마지막 점프 `to == 6`
  3. "7보다 1 작은 수는?" / 판정: 점 값 == 6
  4. "아무것도 없는 수는 어디?" / 판정: 점 값 == 0
- **CPA 페이딩:** P: 돌 위 셈돌 개수 함께 표시 / A: 숫자 눈금만

### 활동
#### g1s1u3.A1 구슬 모으기·가르기 — E02 `part-whole` · C→P→A
- **원 계획서:** 구슬 군집 핀치(Pinch) 합치기·가르기
- **화면과 조작:** 두 접시의 구슬을 두 손가락으로 모으는(핀치 인) 동작 또는 한 접시를 끌어 다른 접시로 합치기. 한 무더기를 손가락으로 쓸어 둘로 가르기(대체: 구슬 하나씩 끌기, 칸막이 버튼). 위에는 가르기 나무(전체 ○ 아래 두 ○)가 동기화.
- **설정 예시:**
  ```json
  { "mode": "part-whole", "total": 6, "parts": 2, "gesture": ["pinch", "drag", "divider-button"], "showBond": true }
  ```
- **과제:**
  1. 3과 2를 모아요 → 몇? / 판정: 합친 개수 == 5, 입력 == 5
  2. 6을 두 접시로 갈라요(아무렇게나) / 판정: 두 접시 합 == 6, 둘 다 1 이상
  3. "6을 다르게 가르는 방법을 3가지 찾아요." / 판정: 서로 다른 (a,b) 순서쌍 3개(순서 무관)
  4. 8 = 5와 □ / 판정: 입력 == 3
  5. 가르기 나무 숫자만 보고 빈칸(9 = 4와 □) / 판정: 입력 == 5
- **CPA 페이딩:** C: 구슬 / P: 점과 가르기 나무 / A: 나무 숫자만 → 덧셈식·뺄셈식 카드 연결

#### g1s1u3.A2 그림 이야기 극장 — E02 `part-whole` · C→A
- **원 계획서:** 음성 인식(STT) 덧뺄셈 이야기 극장 (STT는 선택 기능)
- **화면과 조작:** 짧은 그림 장면(새 3마리 + 2마리 날아옴 / 풍선 7개 중 2개 터짐 / 사탕 5개와 3개 비교)을 보고, 셈돌로 장면을 재현한 뒤 식 카드(`□ + □ = □`, `□ − □ = □`)를 숫자 버튼으로 완성. 자기가 만든 이야기는 🎤 녹음(선택)·TTS 재생.
- **설정 예시:**
  ```json
  { "mode": "part-whole", "story": "birds-join", "operation": "add", "numbers": [3, 2], "equationCard": true, "voice": { "tts": true, "stt": false, "recordLocalOnly": true } }
  ```
- **과제:**
  1. 새 이야기(첨가) → 셈돌 재현 + 식 / 판정: 셈돌 합 == 5, 식 `3+2=5`과 동치
  2. 풍선 이야기(제거) / 판정: 남은 수 == 5, 식 `7-2=5`
  3. 비교(사탕 5개 vs 3개, "몇 개 더 많아?") / 판정: 일대일 짝 Action 후 입력 == 2
  4. "4 + 0 은?" 그림(빈 접시) / 판정: 4
  5. 식 `5 − 3 = 2`를 보고 맞는 그림 고르기 / 판정: 선택 장면 일치
- **CPA 페이딩:** C: 장면 그림과 셈돌 / P: 점 / A: 식만 보고 그림 고르기(역방향)

### 활동
#### g1s1u4.A1 밧줄 펴기·겹치기·옮겨 담기 — E13 `compare-direct` · C→P
- **원 계획서:** 베지에 곡선 밧줄 펴서 길이 비교 + 유체 수조 들이 비교
- **화면과 조작:** (길이) 구불구불한 밧줄 2개 — 끝을 잡아 당기면 곧게 펴지고, 왼쪽 출발선에 자석 스냅. (넓이) 손수건·책을 끌어 겹치기. (들이) 컵의 물을 같은 투명 수조로 붓기 버튼(물 높이 애니메이션).
- **설정 예시:**
  ```json
  { "mode": "compare-direct", "attribute": "length", "items": [{"id":"rope-a","shape":"curvy","length":7},{"id":"rope-b","shape":"straight","length":6}], "baseline": true, "straighten": true }
  ```
- **과제:**
  1. 구불구불한 밧줄 vs 곧은 밧줄 "더 긴 것?" / 판정: 펴기 Action 후 정답 선택(펴지 않고 고르면 정답이라도 힌트 ① 표시)
  2. 연필 3자루 길이 순서 / 판정: 순서 배열 일치 + 출발선 맞춤
  3. 손수건 vs 책 넓이 / 판정: 겹치기 Action + 선택 일치
  4. 키 큰 컵 vs 넓은 컵 "물이 더 많이 들어가는 것?" / 판정: 붓기 Action + 선택 일치
- **CPA 페이딩:** C: 사물 그림 / P: 막대·사각형 도식 / A: 해당 없음

#### g1s1u4.A2 양팔저울 무게 비교 — E06 `compare` · C
- **원 계획서:** 양팔저울 무게 비교
- **화면과 조작:** 사물(사과, 풍선, 돌, 깃털, 큰 스펀지, 작은 쇠공)을 양쪽 접시에 끌어 놓으면 저울이 기운다(결정적 애니메이션). 비교 결과를 "무겁다/가볍다" 카드로 붙인다.
- **설정 예시:**
  ```json
  { "mode": "compare", "items": [{"id":"sponge","weight":2,"visualSize":"large"},{"id":"iron-ball","weight":9,"visualSize":"small"}], "showValues": false }
  ```
- **과제:**
  1. 사과 vs 깃털 / 판정: 두 물건 올림 + "무거운 것" 선택 일치
  2. 큰 스펀지 vs 작은 쇠공(크기와 무게 반대) / 판정: 선택 == iron-ball
  3. 세 물건 무게 순서(저울을 두 번 이상 사용) / 판정: 순서 일치, 비교 Action ≥ 2
  4. "저울이 수평이 되게 해요." / 판정: `balanced == true`
- **CPA 페이딩:** C 위주, P: 저울 대신 화살표 도식으로 결과 기록

## g1s1u5 50까지의 수

| 차시 규모(참고) | 약 9~10차시 중 앱 활용 3~4차시 (교과서 확인) |

**핵심 아이디어:** 낱개 10개를 묶으면 '10개씩 묶음 1개'. 몇십 몇은 10개씩 묶음 수와 낱개 수로 나타낸다. 묶어서 세면 빠르고 정확하다.

| g1s1u5.order-to-50 | 50까지 수의 순서, 크기 비교 | g1s1u5.tens-and-ones |

### 활동
#### g1s1u5.A1 10개씩 올가미 묶기 — E01 `count`, `regroup` · C→P→A
- **원 계획서:** 10개씩 올가미(Lasso) 묶어 세기
- **화면과 조작:** 흩어진 낱개(별·사탕 아이콘의 1블록) 23~47개. 손가락으로 10개를 감싸면 한 줄(10막대)로 합체(따닥 소리). 9개·11개 감싸면 합체 안 되고 개수 배지가 뜬다. 오른쪽 '10개씩 묶음 / 낱개' 표가 자동으로 채워진다.
- **설정 예시:**
  ```json
  { "mode": "regroup", "start": { "ones": 34, "scattered": true }, "allowedBlocks": [1, 10], "lasso": true, "chart": ["tens", "ones"], "chartEditable": false }
  ```
- **과제:**
  1. 낱개 20개 묶기 → "몇?" / 판정: `tens == 2 && ones == 0`, 입력 20
  2. 낱개 34개 묶어 세기 / 판정: 정규형(`ones ≤ 9`), 입력 34
  3. "10개씩 묶음 4개와 낱개 7개를 만들어요." / 판정: 나타내는 수 == 47
  4. 수 카드 29 보고 블록 놓기 / 판정: 값 == 29, 정규형
  5. 묶음 2개 + 낱개 15개 상태에서 "더 묶을 수 있어?" / 판정: 최종 정규형 3묶음 5낱개
- **CPA 페이딩:** C: 사탕 아이콘 블록 / P: 막대와 점 / A: 자릿값 표 숫자만(묶음·낱개 칸)

#### g1s1u5.A2 구슬셈판 뛰어 세기 징검다리 — E02 `rekenrek` · P→A

- **화면과 조작:** 5줄 × 10개 구슬셈판(5개씩 색 바뀜). 구슬을 왼쪽으로 밀면 개수 표시. "10씩 뛰어 세기" 모드에서는 한 줄을 통째로 밀기.
- **설정 예시:**
  ```json

  ```
- **과제:**
  1. 32 만들기(구슬 최소 동작) / 판정: 왼쪽 구슬 합 == 32, 줄 단위 밀기 사용 여부 기록
  2. 10, 20, 30, … 뛰어 세며 50까지 / 판정: 각 단계 값이 10의 배수 순서
  3. 2씩 뛰어 세기 2~20 / 판정: 값 순서 일치
  4. 27과 31 중 큰 수 / 판정: 선택 == 31, 두 수를 셈판에 나타낸 Action 존재
  5. "29 다음 수는?" / 판정: 30
