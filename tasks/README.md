# 작업 카드

에이전트에게 카드 하나씩 맡긴다(`docs/08-agent-workflow.md`). 카드 상태는 카드 안의 '상태' 칸을 고친다.
W0~W1 카드는 미리 만들어 두었다. 다음 웨이브 카드는 W1이 끝날 때 에이전트에게 `docs/07-roadmap.md`의 다음 웨이브를 `tasks/_TEMPLATE.md` 형식으로 만들어 달라고 요청한다.
