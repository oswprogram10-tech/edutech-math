## 목표
E19(T193)에 g5s2u6.A2에서 쓸 가능성 모드 셋을 더한다.
- `words`: 말 카드·상황 카드를 0~1 수직선 칸에 놓는다.
- `spinner`: 회전판이나 주머니를 만들고 한 번씩 돌린다.
- `simulate`: 10회·1,000회·10,000회 결과의 상대도수를 나란히 비교한다.

## 구현 결정 (2026-11-20 Claude 작성 — 여기 적힌 대로 하고, 바꿔야 하면 메모에 이유를 적고 멈춰서 묻는다)

### 1. 공통
- T193의 공통 결정(Rational, 판 맞춤 최소 0.6 + 스크롤, 48px, 키보드, 색만으로 전달 금지, 문구 위치)을 그대로 따른다.
- **난수와 순수 reduce**
  - 시행 결과는 Action에 실린 `seed`로 정한다. 시드를 쓰는 작은 PRNG(mulberry32 등)를 엔진 안에 두고, reduce 안에서 계산한다.
  - View는 `crypto.getRandomValues`로 seed를 만들어 Action에 넣는다. 테스트는 고정 seed를 쓴다.
  - 같은 Action 목록이면 결과가 같다. 그래서 되감기·미러링이 된다.
  - 10,000회는 reduce 안에서 바로 센다. Web Worker는 쓰지 않는다(정수 세기뿐이라 충분히 빠름). 1회 reduce가 크롬북에서 50ms를 넘으면 메모에 적는다.
- **결과 색**
  - 4가지(빨강·파랑·노랑·초록)를 쓰고, 각각 무늬(민·빗금·점·격자)와 이름 글을 함께 둔다.
  - id는 `red`·`blue`·`yellow`·`green`이다.

### 2. `words`
```ts
{ mode:'words'; cards: { id: string; text: string }[];   // 1~6장, 말 카드 또는 상황 카드
  slots?: 'five' | 'three';                               // 기본 'five': 0, 1/4, 1/2, 3/4, 1
  slotLabels?: 'words' | 'numbers' | 'both' }             // 기본 'both'
```
- 칸 이름: 불가능하다(0)·~아닐 것 같다(1/4)·반반이다(1/2)·~일 것 같다(3/4)·확실하다(1). `three`는 0·1/2·1이다.
- **Action:** `place {cardId, slot}`(slot은 Rational 문자열), `unplace {cardId}`, `reset`
- **조작**
  - 카드를 끌어 칸에 놓는다. 한 칸에 여러 장을 놓을 수 있고 위로 쌓는다.
  - 키보드: Tab으로 카드 → ←→로 칸 고르기 → Enter
- **Observation:** `placements: Record<cardId, string|null>`, `allPlaced`
- **Predicates:** `placementIs {card, value}`, `allPlaced`

### 3. 장치(`spinner`·`simulate` 공통)
```ts
type Device =
  | { type: 'spinner'; sectors: { color: Outcome; size: number }[] }   // 1~8칸, size 1~4
  | { type: 'bag'; marbles: { color: Outcome; count: number }[] };      // 0~10개씩, 합 1~20
```
- 설정 `device`가 처음 장치다. `editable?: boolean`(기본 true)이면 학생이 바꿀 수 있다.
  - 회전판: 칸 더하기·빼기, 칸 색 바꾸기, 칸 크기 바꾸기
  - 주머니: 색별 +/−
- **가능성:** 색별 비율 = 그 색 size 합 / 전체(주머니는 개수). Rational이다.
- 장치를 바꾸면 그때까지의 시행 결과를 지운다(다른 공장이 되므로). `edits` 수는 남긴다.

### 4. `spinner`
- **설정:** `{ mode:'spinner', device, editable? }`
- **Action:** 장치 편집 Action들, `spin {seed}`(1회), `reset`
- **화면**
  - 회전판은 원형 칸과 화살표로, 주머니는 구슬 그림으로 그린다.
  - 돌리기 연출은 600ms이고, `prefers-reduced-motion`이면 바로 결과를 보인다.
  - 최근 결과 10개를 줄로 보이고, 색별 횟수 표를 둔다.
- **Observation:** `device`, `probabilities: Record<Outcome,string>`, `trials: number`, `counts: Record<Outcome,number>`, `last: Outcome[]`(최근 10개), `edits`
- **Predicates:** `probabilityIs {outcome, value}`, `trialsAtLeast {n}`, `deviceHas {outcome, count}`(주머니 개수 또는 회전판 칸 size 합)

### 5. `simulate`
- **설정:** `{ mode:'simulate', device, editable?, batches?: number[] /* 기본 [10,1000,10000] */, showExpected?: boolean /* 기본 true */ }`
- **Action:** 장치 편집, `run {batch, seed}`(batches 중 하나), `clear`
- **화면**
  - batches 수만큼 비교 칸을 나란히 둔다. 칸마다 [n회 돌리기] 단추와 색별 상대도수 막대(같은 축척 0~1)가 있다.
  - 막대 끝에 "n번 중 k번"을 쓴다. 같은 칸을 다시 돌리면 그 칸만 새로 한다.
  - `showExpected`이면 장치 가능성 위치에 가로 점선과 "가능성" 이름표를 둔다. 학생이 만든 장치라 노출이 아니다.
- **Observation**
  - `device`, `probabilities`
  - `results: { batch: number; counts: Record<Outcome,number>; rel: Record<Outcome,string> }[]`(돌린 칸만)
  - `runs`
- **Predicates:** `batchRun {batch}`, `allBatchesRun`, `probabilityIs`

### 6. 오버레이
- **`small-batches`**(MC-CHANCE-SMALL-SAMPLE ②)
  - 지금 장치로 10회 묶음 5개(고정 seed 5개, 오버레이 안에서 순수 계산)의 결과 막대를 나란히 그린다. 들쭉날쭉함이 보인다.
  - simulate·spinner에서 쓴다.
- **`after-streak`**(MC-CHANCE-GAMBLER ②)
  - 지금 장치로 10,000회(고정 seed)를 돌린다. "빨강이 5번 이어진 바로 다음" 결과만 모아 상대도수 막대로 그린다. 옆에 전체 상대도수 막대를 둔다.
  - 장치에 빨강이 없으면 그리지 않는다.

### 7. 등록과 테스트
- `modes`에 셋을 더한다. fit-canvas ENGINES에 더한다.
- 기존 평균 모드 기준 이미지가 샌드박스 모드 상자 너비 때문에 도구 줄만 밀리면, 그 이미지만 다시 찍고 메모에 적는다(Opus 허락). 엔진 그림이 달라졌으면 멈추고 묻는다.
- 샌드박스 기본
  - words: 말 카드 5장
  - spinner: 빨강1·파랑1 회전판
  - simulate: 같은 장치, [10,1000,10000]
- **단위**
  - PRNG 결정성(같은 seed → 같은 결과)
  - 10,000회 빨강 1/2 장치의 상대도수가 0.45~0.55
  - 장치 편집 범위 거절, 편집 시 결과 지움
  - probabilities: 주머니 빨강 0개 → "0", 모두 빨강 → "1"
  - words place·unplace
  - JSON 왕복, predicates
  - 오버레이 계산 함수 순수성
- **E2E**(`tests/e2e/chance-lab.spec.ts`에 추가, 3 뷰포트)
  - words 끌어 놓기·키보드
  - spinner 편집 → 돌리기(reduced-motion)
  - simulate 세 칸 돌리기, 크롬북에서 10,000회 단추 → 막대가 1초 안에 나옴
  - 오버레이 둘 1px 정렬
  - 모드별 첫 화면 스냅샷
- **E2E 범위:** `npx playwright test chance-lab fit-canvas overlay-alignment --workers=3 --reporter=line`
