2. **`diagonal` 모드 — 설정 `DiagonalConfig`:**
   - `mode: 'diagonal'`(필수), `polygons?: number[]`(각 3~10 정수, 중복 제거, 기본 `[3, 4, 5, 6]`), `rejectAdjacent?: boolean`(기본 true), `countTable?: boolean`(기본 false), `polygonCards?`(받기만 하고 무시 — 아래 6번).
   - **그림:** 정n각형. 중심 (500, 520), 외접원 반지름 340(논리 좌표), 0번 꼭짓점이 맨 위, 시계 방향. 꼭짓점 좌표는 화면 계산(`Math.cos`/`Math.sin`)만이고 수학 값은 꼭짓점 번호다. 꼭짓점 이름표 ㄱ, ㄴ, ㄷ …(`strings.ko.ts`의 `vertexLabels`). 꼭짓점 터치 반경은 `minTouchRadius(targetSize)` 이상.
   - **상태 `DiagonalState`:** `mode: 'diagonal'`, `current`(polygons 인덱스), `pending: number | null`(고른 첫 꼭짓점), `drawn: Record<string, [number, number][]>`(키 = n, 쌍은 `[작은 번호, 큰 번호]`로 정규화, 그은 순서), `sides: Record<string, [number, number][]>`(`rejectAdjacent: false`일 때 그은 변), `adjacentAttempts: number`, `duplicateAttempts: number`, `lastRejected: { n, pair: [number, number], reason: 'adjacent' | 'duplicate' } | null`, `settings`.
   - **Action:** `select-polygon {index}`, `pick-vertex {vertex}`(첫 번째는 `pending`, 두 번째는 긋기, 같은 꼭짓점이면 `pending` 취소), `undo-diagonal`(현재 다각형의 마지막 대각선), `clear-diagonals`(현재 다각형).
   - **판정(정수):** `d = |i − j|`, 이웃 = `d === 1 || d === n − 1`. 
     - 이웃이고 `rejectAdjacent`면: 긋지 않고 `adjacentAttempts += 1`, `lastRejected` 기록. 화면은 빔이 그 변을 따라 빛나며 튕기는 연출과 "이건 변이에요" 글자(`prefers-reduced-motion`이면 연출 없이 글자와 굵은 변만).
     - 이웃이고 `rejectAdjacent: false`면: `sides`에 넣고 변 위에 겹쳐 그린다(대각선 수에 넣지 않는다).
     - 이미 그은 쌍(순서 무관)이면: 긋지 않고 `duplicateAttempts += 1`, 그 대각선이 한 번 깜빡이고 "이미 그은 선이에요" 글자.
     - 아니면 `drawn`에 더한다. 레이저 빔 연출(C 단계), P 단계는 검은 선.
   - **개수 표(`countTable`):** `data-testid="diagonal-table"`. 행 = 설정의 다각형 순서, 열 = "꼭짓점 수"(n — 문제 조건이라 보여도 된다), "그은 대각선"(학생이 그은 수, 0이면 빈칸). **전체 개수·완성 여부·규칙은 쓰지 않는다.** 기본 false면 표가 없다. 다각형 이름(오각형 등)도 쓰지 않는다 — 이름 맞히기가 과제일 수 있어서 "꼭짓점 n개"로만.
   - **키보드:** 캔버스 포커스에서 ←/→가 꼭짓점 커서를 돌리고 Enter가 `pick-vertex`, Escape는 `pending` 취소, Backspace는 `undo-diagonal`. 다각형 고르기는 Tab으로 가는 단추 "꼭짓점 n개".
3. **diagonal Observation·Predicates·이벤트:**
   - Observation: `mode`, `current: n`, `polygons: { n, drawn: number, complete: boolean }[]`(`complete`는 `drawn === n(n−3)/2`, Observation에만), `pairs: Record<string, [number, number][]>`, `adjacentAttempts`, `duplicateAttempts`, `sidesDrawn: number`.
   - Predicates: `diagonalsComplete {n}`(g4s2u6.A1-2 "오각형 5개, 중복 없음" — 중복은 구조상 없다), `diagonalCount {n, count}`, `adjacentAttempts {min}`(MC-GEO-DIAGONAL-ADJACENT "거부 반복" 감지), `duplicateAttempts {min}`.
   - A1-3(육각형 9)·A1-4(칠각형 14)의 수 답은 응답 숫자 칸이다. 엔진은 `diagonalsComplete {n:6}`으로 확인만 돕는다.
   - 이벤트: `diagonal-drawn {n, count}`, `diagonal-rejected {n, reason}`.
4. **`geoboard`의 `fixed-perimeter` 제약 (g5s1u6.A2):**
   - **설정:** `constraint?: { type: 'fixed-perimeter'; value: number; shape: 'rectangle' }`, `log?: boolean`(기본 false). `value`가 짝수 정수(4 이상)이고 격자 안에 들어가는 직사각형이 하나라도 있을 때만 켜진다. 아니면 제약 없음(일반 geoboard)으로 보고 메모에 적는다. `shape`는 `'rectangle'`만.
   - **표현:** 반둘레 `half = value / 2`. 직사각형은 왼쪽 위 꼭짓점을 못 `[0, 0]`에 고정한 축 방향 직사각형이고, 상태에서는 보통 고무줄 하나로 둔다: `bands = [{ id: 'b1', pegs: [[0,0],[w,0],[w,h],[0,h]], closed: true }]`, `h = half − w`. 그래서 T100의 `shapes` 관찰(넓이·꼭짓점)과 오버레이가 그대로 쓰인다.
   - **범위:** `w ∈ [max(1, half − (rows − 1)), min(half − 1, cols − 1)]`. 처음 `w = max(최소, floor(half / 3))`로 시작(20이면 3×7). 5×5·1×9 같은 과제 답으로 시작하지 않는다.
   - **Action:** `resize-rect {width, height}` — `width + height === half`이고 범위 안일 때만 받는다. `log-rect` — `log`가 켜져 있으면 현재 (가로, 세로)를 기록표에 더한다(같은 순서쌍은 다시 넣지 않음, 최대 12줄). 제약이 있으면 `start-band`·`add-peg`·`close-band`·`undo-peg`·`delete-band`·`move-peg`는 무시한다(둘레가 깨지므로).
   - **조작:** 오른쪽 아래 꼭짓점에만 64px 손잡이. 끌면 View가 가까운 못을 구하고, 지금 꼭짓점에서 가로 변화와 세로 변화 중 큰 쪽을 따라 `w`(또는 `h`)를 정하고 나머지를 `half −`로 계산해 `resize-rect`를 보낸다. 범위 밖이면 가장자리로 자른다.
   - **화면:** 고무줄 직사각형, 옆에 "둘레 20"(설정 값 — 문제 조건)과 "넓이 21"(지금 넓이, 명세가 요구하는 실시간 표시), 가로·세로 변 옆에 "가로 3"·"세로 7". "기록하기" 단추와 기록표(`data-testid="perimeter-log"`, 열: 가로·세로·넓이 — 학생이 기록한 것만). 가장 큰 넓이·정답 행 강조는 하지 않는다.
   - **키보드:** 캔버스 포커스에서 →/← 가로 ±1, ↓/↑ 세로 ±1(다른 쪽은 자동), Enter `log-rect`.
   - **Observation(geoboard에 추가):** `constraint: { type, value } | null`, `rect: { width, height, perimeter, area } | null`(정수), `log: { width, height, area }[]`.
   - **Predicates:** `loggedDistinctRects {count}`(서로 다른 순서쌍 수 ≥ count, g5s1u6.A2-1), `loggedRect {width, height}`(순서 무관, A2-2·3), `currentRect {width, height}`(순서 무관).
   - **이벤트:** `rect-logged {width, height, area}`.
   - A2-4(넓이 24 고정, 둘레 최소)는 명세가 "예측 입력 기록 — 탐구용"이라 엔진 제약(`fixed-area`)을 만들지 않는다. 응답 칸 몫이다(메모).
5. **CPA:** C — 레이저 빔·고무줄 끌기. P — 검은 선, 개수 표·기록표. A — 엔진은 그림만(대개 `showEngine: false`).
6. **다각형 카드 고르기(곡선·열린 도형) — 엔진 모드로 만들지 않는다:**
   - g4s2u6.A1-1·A1-5는 응답 `choice`(`multiple: true`) 위젯의 선택지 `figure`(읽기 전용 엔진 그림)로 한다. 판정은 응답의 선택 집합이다.
   - 그림이 필요한 것만 엔진에 더한다(그리기 전용, Observation에 넣지 않음, 학생이 고칠 수 없음):
     - `geoboard` 설정 `openShapes?: Peg[][]` — 열린 꺾은선
     - `geoboard` 설정 `curvedShapes?: { pegs: Peg[]; curved: number[] }[]` — 닫힌 외곽인데 `curved`에 적은 변 번호(i번 = i→i+1)는 바깥으로 부푼 2차 베지어 곡선(조절점 = 변 중점에서 바깥 법선으로 간격 0.35배)
     - 정육각형처럼 격자에 없는 정다각형 카드는 `{ engine: 'E09', mode: 'diagonal', config: { polygons: [6] } }` 그림을 쓴다(읽기 전용 그림이라 긋기 없음).
   - 위 결정을 이 카드 메모에 적는다. 카드 그림 목록(8장)은 콘텐츠 카드 몫이다.
7. **오버레이 (힌트 ②, 학생이 만든 것만, 전체 대각선·정답 개수·최대 넓이 직사각형을 그리지 않는다, 모두 `CanvasAlignedOverlay` + `svg[data-testid="geo-canvas"]`):**
   - `side-glow` (MC-GEO-DIAGONAL-ADJACENT): `lastRejected`가 이웃(adjacent)이면 그 변을 굵게 빛나게(굵기 + 점선 무늬) 하고 "변" 이름표. 없으면 아무것도 그리지 않는다.
   - `merge-beams` (MC-GEO-DIAGONAL-COUNT-DOUBLE): 현재 다각형에서 학생이 그은 대각선마다 양 끝에서 가운데로 오는 화살표 두 개를 그려 한 선분으로 합쳐짐을 보이고, `lastRejected`가 중복이면 그 대각선을 강조하고 "같은 선분 하나" 글자.
   - `unit-squares` (MC-PERIMETER-AREA-SAME): 지금 직사각형 안에 단위 정사각형을 점 무늬로, 기록표의 마지막 기록(지금과 다른 것)이 있으면 같은 `[0,0]` 기준 점선 외곽 + 빗금 단위 정사각형으로 겹쳐 그린다. 개수 숫자는 쓰지 않는다.
   - `curve-gap` (MC-GEO-POLYGON-CURVE): geoboard 그림의 `curvedShapes` 곡선 변을 빨강 + 물결 무늬로, `openShapes`의 열린 두 끝 사이를 점선 원으로 강조한다(콘텐츠가 그 카드를 따로 띄운 E09 슬롯에서 쓴다).
