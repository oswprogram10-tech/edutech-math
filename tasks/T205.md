### 1. 공통
- **수 (AGENTS 규칙 2)**
  - 길이·위치·들이 같은 측정값은 상태와 Observation에서 `Rational` 문자열로 둔다. 단위는 cm, 들이는 "컵" 같은 정수 단위다.
  - 화면 좌표만 number로 둔다.
  - 위치는 0.5cm 격자에 붙인다(`"7/2"` 등).
- **판 맞춤:** 논리 1000×600 SVG, `layout:'fit'`, 최소 배율 0.6 + 스크롤, 조작 칸은 T199 원칙을 따른다.
- **입력·접근성**
  - 단추는 48px 이상이고, 저학년은 `--touch-target`을 따른다.
  - 끌기는 Pointer Events로 한다.
  - 모든 조작에 키보드 또는 단추 대체가 있다.
  - 색만으로 전달하지 않는다. 틈은 빨간 줄 + 빗금 + "틈" 글로, 겹침은 진한 색 + 줄무늬 + "겹침" 글로 보인다.
- **정답 노출 금지**
  - 물건의 실제 길이·들이 값과 어느 쪽이 긴지는 Observation에만 둔다.
  - 화면·DOM·aria·data-에는 두지 않는다. 학생이 만든 단위 개수 표시는 괜찮다.
  - 그림은 실제 비율대로 그린다. 그림이 곧 측정 대상이기 때문이다.
- **물건 그림:** 외부 자산 없이 SVG 도형으로 단순하게 그린다(연필, 밧줄, 손수건, 책, 컵, 책상).
- 문구는 `strings.ko.ts`에 두고, 물건 이름 목록도 거기에 둔다. 학년 표시와 점수는 없다.

### 2. `compare-direct`
- **설정:** `{ mode:'compare-direct', attribute:'length'|'area'|'capacity', items:[…], baseline?:boolean, straighten?:boolean, pour?:boolean }`
  - **length 항목:** `{ id, label, kind:'rope'|'pencil'|'ribbon', shape:'curvy'|'straight', length: 정수 1~12, offset?: 정수 0~3 }`
    - 2~3개다. `offset`은 왼쪽 끝이 출발선에서 떨어진 칸 수다.
    - 곡선은 펼친 길이(호 길이)가 `length` 칸이 되게 그린다. 한 칸은 논리 60px다.
    - `straighten`이 true일 때만 곡선 밧줄에 [펴기] 단추를 둔다. 오른쪽 끝을 끌어 당겨도 펴진다.
    - `baseline`이 true이면 왼쪽에 세로 출발선을 그린다. 물건을 끌어 출발선 가까이(1칸 안) 놓으면 자석처럼 붙는다.
  - **area 항목:** `{ id, label, kind:'handkerchief'|'book'|'paper', w, h }` 정수 칸, 정확히 2개
    - 하나를 끌어 다른 것 위에 놓는다. 왼쪽 위 모서리가 1칸 안이면 모서리를 맞춰 붙인다.
    - 위에 놓인 것은 반투명이다.
  - **capacity 항목:** `{ id, label, kind:'cup', shape:'tall'|'wide', capacity: 정수 1~10 }` 정확히 2개
    - `pour`가 true이면 컵마다 [같은 수조에 붓기] 단추를 둔다.
    - 누르면 그 컵 아래의 똑같은 투명 수조에 물 높이가 보간 애니메이션(400ms, reduced-motion이면 바로)으로 차오른다.
    - 수조 눈금은 없다.
- **Action:** `straighten {id}`, `place {id, x, y}`(칸 격자, 판 안), `pour {id}`, `reset`
  - 이미 편 것을 다시 펴거나 이미 부은 것을 다시 부으면 거절한다.
- **Observation:**
  - 공통: `mode`, `attribute`, `misconceptions: []`
  - length: `straightened: string[]`, `aligned: string[]`(출발선에 붙은 것), `allStraight`, `allAligned`, `longest: string`, `order: string[]`(긴 것부터)
  - area: `overlapped: boolean`(모서리를 맞춰 겹침), `larger: string`
  - capacity: `poured: string[]`, `pouredAll`, `more: string`
- **Predicates:** `allStraight`, `straightened {id}`, `allAligned`, `overlapped`, `pouredAll`, `poured {id}`
- **판정 방식:** 엔진은 "고르기"를 하지 않는다. 고르기와 순서는 콘텐츠의 응답 칸(choice·order)이 맡는다. 콘텐츠는 `all [엔진 predicate, 응답]`으로 판정한다.
- **오버레이**
  - **`endpoint-lines`**(MC-MEASURE-ENDPOINT ②)
    - length 물건마다 왼쪽 끝에 세로 점선을 긋는다.
    - 출발선과 어긋난 만큼 가로 괄호와 "어긋남" 글을 단다.
    - 모두 맞춰져 있으면 그리지 않는다.
  - **`half-straighten {id}`**(MC-MEASURE-CURVE ②)
    - 곡선 밧줄의 앞쪽 절반을 곧게 편 미리보기를 점선으로 그린다.
    - 나머지 반은 곡선 그대로다.
    - id가 없거나 이미 폈으면 그리지 않는다.
  - **`same-tank`**(capacity, MC-SIZE-IS-WEIGHT ②)
    - 두 컵 아래 같은 크기의 빈 수조 윤곽을 점선으로 그린다.
    - 컵에서 수조로 화살표를 긋고 "같은 수조에 부어 봐요" 글을 단다.
    - 물 높이는 그리지 않는다.

### 3. `length` (단위 반복)
- **설정:** `{ mode:'length', object:{ name, lengthCm }, units:[unit id…], iteration?:'manual', showGapOverlap?:boolean, buildRuler?:boolean, demoSpans?:{ objectName, objectCm } }`
  - **단위 목록**(`units.ts`, 길이 Rational cm):
    | id | 길이 |
    | --- | --- |
    | `hand-span-a` | 15cm |
    | `hand-span-b` | 12cm |
    | `clip-3cm` | 3cm |
    | `cm-block` | 1cm |
    | `eraser-5cm` | 5cm |
  - `object.lengthCm`는 Rational 문자열이고 0.5 격자다. 화면에는 물건 그림만 있고 길이 글은 없다.
  - `showGapOverlap`의 기본값은 true다.
- **조작**
  - 오른쪽 상자(트레이)에서 단위를 골라 물건 아래 띠로 끌어 놓는다.
  - 마지막 조각 끝에서 1cm 안에 놓으면 붙는다(자석). 그 밖이면 놓은 자리(0.5 격자)에 그대로 둔다.
  - 조각을 다시 끌어 옮기거나, 띠 밖으로 끌어 지운다.
  - 키보드
    - 트레이 단추로 고르고 Enter를 누르면 끝에 붙여 놓는다.
    - Backspace는 마지막 조각을 지운다.
    - 조각에 초점을 두면 ←→로 0.5cm씩 옮긴다.
- **Action:** `add {unit, start}`, `move {index, start}`, `remove {index}`, `reset`
  - 조각은 최대 40개다. 띠 범위는 0~(물건 길이 + 15cm)다.
- **틈·겹침:** 조각을 시작 위치 순으로 놓고 이웃끼리 비교한다.
  - 첫 조각 시작이 0이 아니면 "앞 틈"이다.
  - 틈과 겹침은 `showGapOverlap`일 때 화면에 표시한다(1번 공통 표기).
- **Observation:**
  - `pieces: {unit, start}[]`
  - `count`, `countByUnit: Record<string, number>`
  - `gaps: number`, `overlaps: number`
  - `startsAtZero`
  - `reachesEnd`: 마지막 조각 끝이 물건 끝과 같다.
  - `exact`: 틈·겹침이 없고, 0에서 시작하고, `reachesEnd`다.
  - `misconceptions`: 조각이 2개 이상이고 gaps 또는 overlaps가 0보다 크면 `['MC-MEASURE-GAP']`
- **Predicates:** `countIs {n, unit?}`, `exact`, `noGapOverlap`
- **뼘 시연(`demoSpans`):**
  - 판 위쪽에 두 캐릭터(사람 이름 없이 "가 친구", "나 친구")가 같은 물건(책상)을 자기 뼘(a 15cm, b 12cm)으로 잰 결과를 그린다. 뼘 그림을 이어 그리고 각자 센 수를 단다.
  - 이 수(예: 60cm면 4와 5)는 시연 결과라 보여 줘도 된다.
  - 학생 조작과는 상관없다.
- **자 만들기(`buildRuler:true`):**
  - `cm-block`이 0부터 틈 없이 10개 붙으면 [자 만들기] 단추가 켜진다. 누르면 블록 경계 11곳에 눈금 칸이 생긴다.
  - 학생은 0~10 숫자 카드를 끌어 눈금에 놓는다. 키보드로는 눈금을 고르고 숫자를 누른다.
  - **Action:** `make-ruler`, `label {tick, value}`
    - `make-ruler`는 조건이 안 맞으면 거절한다.
    - `label`은 0~10 정수이고, 같은 눈금에 다시 놓으면 바꾼다.
  - **Observation:** `rulerMade`, `labels: Record<string, number>`, `labelsCorrect`(모든 눈금 i에 i가 있음)
  - **Predicates:** `rulerMade`, `labelsCorrect`
- **오버레이**
  - **`gap-marks`**(MC-MEASURE-GAP ②): 틈마다 빨간 세로 띠와 "틈", 겹침마다 진한 줄무늬와 "겹침"을 크게 다시 그린다. 둘 다 없으면 그리지 않는다.
  - **`span-compare`**(MC-MEASURE-UNIT-SIZE ②): `demoSpans`의 두 뼘을 왼쪽 끝을 맞춰 위아래로 겹쳐 그리고 "두 뼘의 크기" 글을 단다. 길이 숫자는 쓰지 않는다. `demoSpans`가 없으면 그리지 않는다.

### 구현 메모 (Sonnet, 2026-11-20)
- **구조**: `src/engines/E13-measure-lab/`에 `compare/`(compare-direct)와 `length/` 두 모드 폴더, 공용 `Frame.tsx`·`Btn.tsx`·`View.module.css`·`rat.ts`·`units.ts`·`strings.ko.ts`, 모드 분배 `modes.ts`·`ModeView.tsx`, 오버레이 어댑터 `overlays/adapt.tsx`, `index.ts`. 엔진 등록은 `import.meta.glob` 자동이라 `src/core/`를 건드리지 않았다. fit-canvas `ENGINES`에 E13을 더하고 `outerScrollY` 목록에도 넣었다.
- **샌드박스 기본**: 설정이 `mode`뿐이면(모든 키가 `mode`) 각 모드의 결정서 기본을 쓴다. 콘텐츠가 설정 키를 하나라도 주면 일반 검증이다.
- **자석은 Action이 아니라 화면 쪽 도우미**: `snapPlacement`(출발선 1칸 안 → 0, 넓이 모서리 1칸 안 → 맞춤)와 `snapStart`(마지막 조각 끝 1cm 안 → 붙임, 조각이 없으면 0)가 끌어 놓을 때만 쓰이고, `place`·`add`·`move` Action에는 최종 위치만 실린다. 키보드 이동(←→ 0.5cm, 방향키 1칸)은 자석 없이 그 자리로 간다(자석이 reduce에 있으면 붙은 조각을 키보드로 뗄 수 없다). reduce는 범위·격자만 검사한다.
- **구현 결정에서 정하지 않은 것을 메운 것**
  - 위치·길이·들이는 모두 Rational 문자열이다. compare-direct의 칸 위치는 정수 칸(`"2"`), length의 시작은 0.5 격자(`"5/2"`). `lengthCm`·`length`는 숫자도 받아 문자열로 바꾼다(0.5 격자만).
  - `straightened`는 처음부터 곧은 물건과 펴기로 편 물건을 모두 담는다(`allStraight`가 "지금 모두 곧은가"가 되게). `aligned`는 출발선이 있으면 왼쪽 끝 x가 0인 것, 출발선이 없으면 모두 같은 x일 때만 전부(아니면 빈 배열).
  - `larger`·`more`는 같으면 빈 문자열이다. 넓이 물건은 w·h 1~8칸, 한 칸 50px(길이 물건은 60px). 컵은 2차원 넓이가 들이에 비례하게 그리고 수조 물 높이는 컵 넓이 ÷ 수조 너비라 실제 비율이다.
  - 곡선 호 길이: 물결 수·진폭을 길이에 맞춰 정하고 가로 폭을 이분법으로 풀어 호 길이를 `길이×60px`에 맞춘다(전 길이 1~12칸에서 1% 안을 단위 테스트로 확인).
  - length의 `noGapOverlap`은 조각이 하나 이상 있어야 참이다(빈 판에서 헛참이 되지 않게). 자 만들기 조건은 "시작 위치 순 앞 10개가 cm-block이고 시작이 0~9"라서 블록을 더 놓았어도(12개 등) 앞 10개가 맞으면 만들 수 있다. 자를 만든 뒤에는 add·move·remove를 거절하고 [처음으로]만 자를 지운다.
  - 틈은 앞 틈 포함, 겹침은 지금까지의 최대 끝(reach)과 비교해 센다(이웃 비교와 같고, 짧은 조각이 긴 조각 속에 들어가도 센다).
  - 자 만들기 눈금 칸은 블록 경계(32px 간격, 연필 12cm 기준)에 그대로 두면 너무 좁아서, 블록 경계에서 88px 간격 칸으로 펼쳐 내려 칸을 크게 했다(터치 타깃). 숫자 카드를 끌어 놓으면 가장 가까운 칸에 들어간다.
  - 입력: 트레이·카드 단추는 눌러도 되고(Enter 포함) 끌어도 된다(끌기와 누름은 8논리px로 가른다). 눈금에는 숫자 키(10은 1·0), 카드를 고른 뒤 눈금에서 Enter. Backspace는 화면 어디서든 마지막 조각 지우기, Delete는 초점 조각 지우기.
- **정답 노출**: 물건 길이·칸 수·들이와 비교 결과는 Observation에만 있다. DOM·aria·`data-`에는 두지 않는 것을 단위 테스트로 확인했다(길이 7·6, 12, 칸 수 숫자 전부, "더 긴" 계열 글). `data-x`·`data-y`·`data-start`·`data-index`·`data-tick`은 학생이 놓은 자리(화면 좌표)라 제외했다. 뼘 시연의 "4번·5번"만 글로 보인다(결정서가 허용한 시연 결과).
- **틈·겹침 표기**: 본 판은 틈이 빨간 점선 + 빗금 + "틈", 겹침이 진한 줄무늬 + "겹침"이고 `pointer-events: none`이다(처음에는 겹침 표시가 아래 조각의 끌기를 가로챘다). 오버레이 `gap-marks`는 같은 자리에 위아래로 더 길고 글이 큰 띠를 그린다.
- **E2E**(`measure-lab.spec.ts`): 판 좌표는 상자 너비로만 배율을 구한다(T222 메모: 논리 높이 가정 금지). 오버레이 정렬은 svg 상자 1px 검사에 더해 요소 중심을 1.5px 안으로 비교한다. 본 판 svg에 1px 테두리가 있어 가장자리 요소는 1px 남짓 어긋나 보이는 기존 특성이고, 선 굵기가 달라 상자 크기는 비교하지 않고 중심으로 본다.
- **기준 이미지(신규 6장)**: `measure-compare`·`measure-length`·`measure-length-gap`(뼘 시연과 틈 포함) × 크롬북·아이패드. 직접 열어 보니 그림·글이 잘리지 않았다. 아이패드(768×1024)에서는 판 칸이 낮아 바깥 상자가 스크롤되며 첫 화면 맨 아래 조작 단추 줄이 반쯤 잘려 보인다(E14 T222 메모와 같은 T199 원칙의 결과이고, 맨 위에서 스크롤하면 닿는다).
- **범위 밖 요청**: 없음. 콘텐츠 카드(T207·T209)에서 정할 것: 곡선 밧줄 아래 `label`·응답 칸 문구, `demoSpans.objectName`이 `desk` 외일 때의 그림(지금은 일반 사각형).
