## 구현 결정 (2026-11-03 Claude 작성 — 여기 적힌 대로 하고, 바꿔야 하면 메모에 이유를 적고 질문한다)
1. **경로:** 새 경로 `#/demo`(시연 모드)를 만든다. 교사 화면(`#/teacher`)에 들어가는 버튼을 둔다. 시연 모드에는 학생 기록이 없으므로 PIN 없이 열린다. 학생 화면처럼 "○학년"을 표시하지 않는다(전자칠판은 학생이 본다).
2. **고르기:** 탭이 두 개다. ① **엔진**: 등록된 엔진(`listEngineIds`) 카드. 카드 그림은 그 엔진의 기본 상태 View를 작게 그린 읽기 전용 화면(T016 `FigureView`와 같은 방식)과 엔진 이름이다. 고르면 모드 선택 → 빈 교구. ② **과제에서 열기**: `contentUnitIds()`의 단원 → 활동 → 과제 목록. 고르면 그 과제의 엔진 설정(`views`가 있으면 모든 슬롯과 `links`)을 **채점 없이** 자유 조작으로 연다(발문·정답 판정·힌트 없음). 단원 표시는 콘텐츠 `title`만 쓰고 단원 ID는 보이지 않게 한다.
3. **조작 기록:** 시연 화면은 실행기와 같은 슬롯 기록(`createSlotHistories`, `applyActionWithLinks`, 되돌리기 묶음)을 쓴다. 기록은 화면 안 상태로만 두고 **저장소에 쓰지 않는다**(학습 기록이 아니다).
4. **도구 막대:** 펜 3색(검정·빨강·파랑, 색 이름 라벨 포함), 지우개, 확대 1×/1.5×/2×, 되감기 슬라이더, 되돌리기·다시 하기, 초기화, 2분할. 펜 주석은 교구 위 별도 레이어에 그린다. Pointer Events를 쓰고, 펜 모드에서는 교구에 입력이 가지 않는다. **주석은 저장하거나 기록하지 않는다**(화면 좌표 궤적 저장 금지 — AGENTS 규칙 9). 초기화하면 교구와 주석이 모두 지워진다. 확대는 무대 영역 CSS 변환 + 스크롤이다.
5. **되감기 슬라이더:** 0 ~ 지금까지의 Action 수. 슬라이더 위치 k = 처음 상태에 Action k개를 재생한 상태(`replaySlots` 재사용). 되감기 중에는 교구가 읽기 전용이다. '지금으로' 버튼으로 끝으로 돌아온다. 되감은 상태에서 조작하면 그 뒤 기록을 버리고 거기서 이어 간다(되돌리기와 같은 규칙).
6. **공유 코드 내용(새 형식):** `{ v: 1, views: [{ slot, engine, mode, cpa, config }], links, actions: [...] }`. actions는 실행기 기록과 같은 모양(`{slot, action, group}` 또는 `{control}`)이다. **학생 번호·과제 ID·시각은 넣지 않는다.** 만들기·읽기는 `src/core/storage`의 `encodeShareCode`/`decodeShareCode`를 그대로 쓴다. 이 형식의 타입·검증(zod 금지, 손으로 좁히기)·재생 함수는 `src/core/runner/share.ts`에 둔다. 4,000자를 넘으면 기존 `TOO_LONG` 안내를 보여 준다.
7. **학생 '보여 주기' 버튼(S3, docs/06-screens.md):** 활동 화면(`ActivityRunner`) 도구 줄에 '보여 주기' 버튼을 둔다. 누르면 지금 과제의 공유 코드와 그 코드를 담은 링크(기존 `shareHash` 형식 그대로 `…#s=<code>` — 라우터가 이 해시를 시연 모드 + 코드로 연다)를 보여 준다. QR 표시는 QR 라이브러리를 동적 import한다(T004와 같은 방식). 응답 슬롯(T016)은 엔진 상태가 아니므로 공유 코드에 넣지 않는다. 정답·판정 결과도 넣지 않는다.
8. **2분할:** 왼쪽·오른쪽 칸마다 '코드 붙여넣기' 입력이 있다. 붙여 넣으면 그 상태를 재생해 **읽기 전용**으로 보여 주고, 칸마다 되감기 슬라이더를 둔다. 칸 제목은 'ㄱ', 'ㄴ'뿐이다(학생 번호·이름 없음). 잘못된 코드는 칸 안에 오류 문구만 띄운다. 링크(`#s=<code>`)로 열면 시연 모드가 열리고 그 상태가 왼쪽 칸으로 들어간다. **QR 스캔(카메라)은 이 카드 범위 밖**이다(전자칠판에 카메라가 없는 경우가 많다). 메모에 2단계 후보로 적는다.
9. **화면 크기:** 1920×1080에서 도구 막대와 교구가 스크롤 없이 보여야 한다. 아이패드·크롬북에서도 쓸 수 있어야 한다(도구 막대 줄바꿈). 터치 타깃은 64 이상이다(전자칠판 기준. 시연 화면 기본 `targetSize` 64).
10. **문구:** 앱 문구는 `src/app/strings.ko.ts`, 실행기 쪽 문구는 `src/core/runner/strings.ko.ts`에 둔다.
11. **테스트:** 단위 테스트로 다음을 확인한다. 공유 코드 형식(만들기→읽기 왕복, 학생 번호·과제 ID 키 없음, 잘못된 모양 거부, 4,000자 초과), 되감기 재생(k=0, 중간, 끝, 되감은 뒤 조작하면 뒤 기록 버림). 컴포넌트 테스트로 '보여 주기'가 응답 슬롯과 판정 결과를 넣지 않는지 확인한다. E2E(board 1920×1080 필수, 다른 두 뷰포트도 통과)는 다음 흐름이다. `#/demo` → E00 고르기 → 셈돌 놓기 → 펜으로 긋기·지우기 → 확대 2× → 되감기 처음·중간·끝 → 코드 만들기 → 2분할 두 칸에 서로 다른 코드 붙여넣기 → 나란히 읽기 전용, 화면에 학생 번호 없음. 그리고 `#/activity/demo.A1`의 '보여 주기' 링크로 `#/demo`를 열면 같은 상태가 나오는지 확인한다.

## 메모
- **QR 스캔(카메라)은 결정 8에 따라 이 카드 범위 밖**이다. 2분할은 코드 붙여넣기만
  지원한다. 전자칠판 카메라 유무가 달라 2단계 후보로 남긴다.
- 결정 5에 따라 되감기 중에는 교구가 읽기 전용이라 화면에서 새 조작이 들어가지
  않는다. "되감은 뒤 조작하면 뒤 기록을 버린다" 규칙은 `appendShareAction` 순수
  함수와 단위 테스트로 고정했고, 재생은 실행기 기록과 같은 group/control 규칙을 쓴다.
- 엔진 모드 이름은 엔진이 제공하는 식별자(`free`, `partition` 등)를 그대로 보여 준다.
  학생·교사용 한국어 모드 이름표가 필요하면 엔진 SDK에 mode label을 더하는 별도
  카드가 필요하다.
- 첫 화면 `index-CCfswqwD.js`는 51.13 kB gzip이다(빌드 결과). QR 라이브러리는
  `qrcode-*.js`(7.29 kB gzip)로 따로 지연 로딩된다.
- `src/core/runner/share.ts`에 공유 코드 형식·수동 좁히기·재생을 모았고,
  `ShareDialog`는 학생 '보여 주기'와 시연 모드가 함께 쓴다.
