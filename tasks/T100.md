   - 엔진 ID는 `E09`, 이름은 "기하판"이다. `modes`는 `['geoboard', 'construct']`이고, `layout`은 기본값(`fit`)을 쓴다.
   - `classify`·`drag-test`는 T101, `circle`·`angle`은 T102, `diagonal`·`fixed-perimeter`는 T103이 만든다. 이 카드에서는 만들지 않는다.

2. **core 기하 도우미 (`geometry.ts`):** 모든 값은 `Rational`이고 number 연산은 쓰지 않는다. E10·E11·E17도 이 파일을 쓰므로 이름과 동작을 아래대로 맞춘다.
   - **기본:**
     - `export interface GPoint { readonly x: Rational; readonly y: Rational }`
     - `gp(x: bigint | number, y: bigint | number): GPoint`: 정수 좌표로 만든다.
     - `vsub(a, b)`, `dot(u, v)`, `cross(u, v)`
     - `dist2(a, b): Rational`: 길이의 제곱이다.
   - **방향·선분:**
     - `orientation(a, b, c): -1 | 0 | 1`: 외적의 부호다.
     - `collinear(a, b, c)`
     - `pointOnSegment(p, a, b)`: 양 끝점을 포함한다.
     - `pointOnRay(p, origin, through)`, `pointOnLine(p, a, b)`
     - `segmentsIntersect(a, b, c, d)`: 끝이 닿는 경우도 true다.
   - **다각형:**
     - `simplifyPolygon(points)`: 이어진 같은 점을 지우고, 꺾이지 않는 점(앞뒤 점과 한 직선 위)을 지운다. 첫 점과 끝 점이 같으면 하나로 본다.
     - `isSimplePolygon(points)`: 점 3개 이상, 이웃하지 않은 변끼리 만나지 않음, 넓이가 0이 아님.
     - `polygonArea(points): Rational`: 신발끈 공식의 절댓값이다.
   - **각:**
     - `isRightAngle(a, vertex, b)`: `dot(a−v, b−v) = 0`.
     - `angleKind(a, vertex, b): 'acute' | 'right' | 'obtuse' | 'straight'`: 내적의 부호와 외적이 0인지로 정한다.
   - **합동:** `congruentPolygons(p, q): boolean`
     - 단순화한 두 다각형의 꼭짓점 서명 열을 비교한다.
     - 꼭짓점 서명은 (그 꼭짓점에서 나가는 변의 길이², 그 꼭짓점의 내적, 다각형 방향 기준 꺾임 부호)이다.
     - 시작점 회전과 뒤집기(역순)를 모두 허용한다.
   - **테스트** (경계값을 꼭 넣는다):
     - 넓이 0인 일직선 세 점, 길이 0인 변
     - 기울어진 정사각형 (0,0)(2,1)(1,3)(−1,2)의 넓이 5와 네 직각
     - 거울상 L자 합동, 넓이는 같지만 합동이 아닌 두 도형
     - 일직선 위 점이 섞인 사각형을 단순화하면 꼭짓점 4개
     - 좌표 10⁹ 큰 수, 꼬인 사각형(나비 모양)은 단순 다각형이 아님
3. **좌표와 그리기:**
   - 못·점의 수학 좌표는 정수 격자 `(i, j)`이고 i는 오른쪽, j는 아래쪽이다. 상태에는 `[number, number]` 정수 쌍으로 둔다(정수 격자 번호라 number 허용). 계산할 때 `gp`로 바꾼다.
   - 화면은 SVG 하나다. `data-testid="geo-canvas"`, 논리 크기 1000×1000, `preserveAspectRatio` 기본(meet)이다.
   - 격자 간격은 `layout.ts`가 격자 크기로 정한다. 누른 위치는 SDK `pointerToLogical`로 바꾸고, 가장 가까운 못에 `snapToPoints`로 붙인다.
   - 못의 터치 반경은 `minTouchRadius(targetSize)` 이상이다.
   - 오버레이는 모두 `CanvasAlignedOverlay`에 selector `svg[data-testid="geo-canvas"]`와 같은 논리 크기를 넘겨 그린다.
4. **`geoboard` 모드:**
   - **설정:**
     - `grid: [cols, rows]`(기본 [5, 5], 각 값은 3~12로 자른다)
     - `showCounts: 'never' | 'always'`(기본 `never`). 명세의 `'after-submit'`은 실행기가 제출 결과를 엔진에 알리지 않으므로 `never`로 취급한다(T040과 같음, 메모에 적는다).
     - `maxShapes`(기본 4)
     - `shapes?: [number, number][][]`: 처음부터 놓인 고무줄이다(학생이 고칠 수 있다).
     - `allowCurves`: 받기만 하고 무시한다(곡선은 만들지 않는다).
   - **상태:** `bands: { id, pegs: [number, number][], closed: boolean }[]`, `activeBand: string | null`
   - **Action:**
     - `start-band {peg}`, `add-peg {peg}`: 같은 못을 연달아 넣으면 무시한다.
     - `close-band`: 못이 3개 이상일 때만 된다. 활성 고무줄의 첫 못을 다시 고르면 View가 `close-band`를 보낸다.
     - `undo-peg`, `delete-band {id}`
     - `move-peg {band, index, peg}`: 닫힌 도형의 꼭짓점을 끌어 옮긴다.
   - **조작:**
     - 못에서 못으로 끌면 `start-band` + `add-peg`가 된다. 이어서 다음 못으로 끌거나 다음 못을 누르면 `add-peg`다.
     - 고무줄은 색으로 구분한다. C 단계에서는 색에 더해 선 굵기·점선 무늬도 다르게 한다(색만으로 구분 금지). P 단계는 검은 점·선이다.
   - **키보드:**
     - 방향키로 못 커서를 옮긴다. Enter는 `start-band`/`add-peg`이고, 첫 못에서 누르면 `close-band`다.
     - Backspace는 `undo-peg`, Delete는 활성 고무줄 지우기다.
     - Tab은 고무줄 사이를 옮긴다. 고무줄이 선택된 상태에서 꼭짓점 번호(1~9)를 누르면 그 꼭짓점을 방향키로 옮긴다(`move-peg`).
   - **도형 판정:**
     - 닫힌 고무줄이 `isSimplePolygon`이 아니면(꼬임·넓이 0) 도형이 아니다. 화면에 "선이 서로 겹쳐요" 같은 상태 문구만 띄운다.
     - 꼭짓점·변 수는 `simplifyPolygon` 뒤의 점 수다. 일직선 위 못은 세지 않는다.
   - **수 표시:** `showCounts: 'always'`일 때만 도형 옆에 "꼭짓점 n개 · 변 n개"를 쓴다. 도형 이름(삼각형 등)은 어떤 설정에서도 쓰지 않는다. 이름 맞히기가 과제이기 때문이다.
5. **`construct` 모드:**
   - **설정:**
     - `grid`(정사각 못 수, 기본 9, 5~12)
     - `tools: ('segment' | 'ray' | 'line' | 'set-square')[]`(기본 앞의 셋)
     - `points?: { label: string; at: [number, number] }[]`: 이름 붙은 점(ㄱ, ㄴ …)이다. 이름은 콘텐츠가 준다. 학생이 고른 못에는 이름을 붙이지 않는다.
     - `targets?: [number, number][]`: 과녁 별이다.
     - `showExtension`(기본 false)
     - `given?: { id, kind: 'segment' | 'ray' | 'line', from, to }[]`: 미리 그려진 선이다(분류 과제용, 학생이 지울 수 없다).
     - `angles?: { id, vertex, a, b }[]`: 직각 찾기용 각이다. 각마다 두 변을 그린다.
   - **상태:** `tool`, `pendingStart: [number, number] | null`, `objects: { id, kind, from, to }[]`, `squareOn: string | null`(직각삼각자를 댄 각), `marked: string[]`(학생이 "직각" 표시한 각 id)
   - **Action:**
     - `select-tool {tool}`
     - `pick {at}`: 첫 번째는 시작점, 두 번째는 객체 생성이다. 같은 점이면 무시한다. 반직선은 `from`이 시작점이다.
     - `remove-object {id}`, `place-square {angle}`, `remove-square`, `toggle-mark {angle}`
   - **`showExtension`:** 반직선은 `from`에서 `to`를 지나 캔버스 끝까지, 직선은 양쪽 끝까지 그린다. 연장 부분은 레이저처럼 밝게 그리고 끝에 화살표를 둔다. `prefers-reduced-motion`이면 애니메이션 없이 그린다. 연장선을 그리는 화면 계산만 number다.
   - **과녁 맞힘:** 별 좌표가 객체 위에 있는지(`pointOnSegment` / `pointOnRay` / `pointOnLine`)로 정확히 판정한다. 맞힌 별은 채워진 별 + 체크 무늬로 바꾼다(학생 조작의 결과라 정답 노출이 아니다).
   - **직각삼각자 (`set-square`):**
     - 각으로 끌어 놓거나, 각에 포커스한 뒤 Enter를 누르면 `place-square`다.
     - 직각이면 삼각자가 각의 두 변에 맞게 돌아가 붙고 ㄴ자 표시와 "꼭 맞아요"가 나온다. 아니면 삼각자 한 변을 각의 한 변에 맞춰 놓고, 다른 변과의 틈을 빗금으로 보여 준다.
     - 삼각자는 학생이 댄 각에만 결과를 보인다. 다른 각의 직각 여부는 미리 보이지 않는다.
     - 표시는 학생이 `toggle-mark`로 따로 한다.
6. **CPA:**
   - C: 색 고무줄·레이저 연출
   - P: 점·선만 쓰고 끝점 점·화살표로 구분
   - A: 엔진이 그림만 그리고 이름 입력은 응답 칸 몫이다(대개 콘텐츠가 `showEngine: false`)
7. **Observation:**
   - **공통:** `mode`
   - **geoboard:**
     - `shapes: { id, closed, simple, vertices, sides, pegCount, area }[]`. `area`는 Rational 문자열, `pegCount`는 단순화 전 못 수다.
     - `closedShapes`: 단순 다각형 수
     - `distinctBy: Record<string, number>`: 꼭짓점 수별로 서로 합동이 아닌 도형 수. 키는 "3", "4" …
   - **construct:**
     - `objects: { kind, from, to }[]`: 이름 있는 점은 이름, 없으면 "i,j"
     - `targetsHit: number[]`: 한 객체가 맞힌 별의 번호 목록 중 가장 긴 것
     - `allTargetsHit: number[]`
     - `squareOn`, `marked: string[]`(정렬)
     - `rightAngles: string[]`: `angles` 중 실제 직각인 id. Observation에만 있고 화면 문구에는 쓰지 않는다.
8. **Predicates:**
   - `shapeWithVertices {count}`: 그 꼭짓점 수의 단순 다각형이 하나 이상
   - `distinctShapes {vertices, count}`: 서로 합동이 아닌 도형이 count개 이상
   - `hasObject {kind, from, to}`: 선분·직선은 양 끝을 순서 없이 비교하고, 반직선은 순서대로 비교한다.
   - `oneObjectHits {kind, targets}`: 그 종류의 객체 하나가 나열한 별을 모두 맞힘
   - `distinctRayStarts {count}`: 서로 다른 시작점을 가진 반직선 수
   - `markedAre {ids}`: 표시한 각 집합이 정확히 같음
9. **이벤트:** `shape-closed {vertices}`, `object-created {kind}`
10. **오버레이 (힌트 ②, 학생이 만든 것만 강조하고 목표 도형·정답을 그리지 않는다):**
    - `straight-run`: 학생 도형에서 일직선 위에 있는 못 구간을 한 선분으로 굵게 잇고, 꺾이지 않는 못에 작은 × 표시를 한다. MC-SHAPE-VERTEX-COUNT용이다.
    - `upright-ghost`: 학생이 마지막으로 닫은 도형을 가장 긴 변이 수평이 되도록 돌린 반투명 그림을 옆에 그린다. MC-SHAPE-ORIENTATION용이다.
    - `laser-extent`: 학생이 그린 객체마다 끝이 없는 쪽에 화살표 레이저, 끝이 있는 쪽에 끝점 점을 그린다. MC-GEO-RAY-LINE-CONFUSE용이다.
    - `square-turn`: 직각삼각자를 마지막으로 댄 각(`squareOn`)에 맞춰 돌아가는 삼각자 그림을 그린다. 그 각이 없으면 아무것도 그리지 않는다. MC-GEO-RIGHT-ANGLE-ORIENT용이다.

2. **given을 학생 객체에서 분리**
   - 고른 방식: `state.objects`에서 given을 빼고 `state.settings.given`에만 둔다. `ConstructView`는 given을 `[data-given]` 그룹으로 따로 그리고 지우기·키보드 삭제 대상에서 뺀다. 그래서 `observe.ts`의 `objects`·`objectPoints`·`targetsHit`·`allTargetsHit`, 판정 `hasObject`·`oneObjectHits`·`distinctRayStarts`, 화면 별 맞힘 표시가 모두 학생 객체만 센다. 별도 `givenObjects` 관찰 키는 두지 않았다.
   - 단위 테스트: given 반직선이 별을 지나도 `objects`·`objectPoints`·`targetsHit`·`allTargetsHit`가 비고, `hasObject`·`oneObjectHits`·`distinctRayStarts`가 false다. 화면 테스트: given은 `[data-given]` 1개로 그려지고 `[data-hit="true"]`는 0개다.
