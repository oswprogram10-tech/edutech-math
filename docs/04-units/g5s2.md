## g5s2u1 수의 범위와 어림하기
| 항목 | 내용 |
| --- | --- |
| 영역 | 수와 연산 |
| 엔진 | E03 수직선 |
| 선수 단원 | g4s1u1 큰 수 |
| 차시 규모(참고) | 교과서 약 8차시 중 앱 활용 3차시 |

**핵심 아이디어:** 이상·이하·초과·미만은 *경계의 수를 포함하는지*의 약속이고, 수직선의 속 찬/빈 동그라미로 볼 수 있다. 올림·버림·반올림은 계산 기술이 아니라 *상황에 따라 고르는 결정*이다.

### 활동
#### g5s2u1.A1 롤러코스터 탑승 게이트 — E03 `range` · C→P→A
- **원 계획서:** 수직선 경계점(속 찬/빈 동그라미) 롤러코스터 탑승 게이트 필터
- **화면과 조작:** 놀이공원 게이트 그림 위에 키(cm) 수직선. 학생이 수직선 위에 경계점을 놓고 동그라미를 눌러 속 찬/빈을 토글, 구간 방향 화살표를 끈다. "게이트 열기"를 누르면 키가 적힌 캐릭터 10명이 줄지어 지나가며 구간 안이면 통과, 밖이면 막힌다. 경계값(정확히 130cm) 캐릭터가 꼭 포함된다.
- **설정 예시:**
  ```json
  { "mode": "range", "min": 100, "max": 160, "unit": 1, "subdivisions": 10, "story": "rollercoaster", "riders": [118, 125, 129, 130, 131, 140, 145, 150, 151, 155] }
  ```
- **과제:**
  1. "키 130cm 이상 탈 수 있어요" 게이트 만들기 / 판정: 경계 130, 속 찬 동그라미, 오른쪽 방향
  2. "150cm 초과는 탈 수 없어요"(어린이 기차) / 판정: 경계 150, 이하 구간 = 150 포함 속 찬, 왼쪽
  3. 두 조건: "130 이상 150 미만" / 판정: 양 끝점 상태와 구간 일치
  4. 게이트를 보고 말로 쓰기(카드 고르기) / 판정: 선택한 표현 카드 조합 일치
- **CPA 페이딩:** C: 캐릭터 통과 애니메이션 / P: 수직선만 / A: 조건을 보고 범위에 드는 수 고르기

#### g5s2u1.A2 어림 의사결정 시뮬레이터 — E03 `rounding` · P→A
- **원 계획서:** 실생활 올림·버림·반올림 의사결정 시뮬레이터
- **화면과 조작:** 상황 카드(① 학생 243명이 10인승 버스를 탄다 ② 사탕 243개를 10개씩 봉지에 담아 판다 ③ 키 143.6cm를 일의 자리까지)와 수직선. 학생이 올림/버림/반올림 버튼을 고르면 점이 해당 눈금으로 미끄러지고, 결과가 상황에 적용된 장면(버스에 못 탄 학생 3명이 남는 장면 등)이 재생된다.
- **설정 예시:**
  ```json
  { "mode": "rounding", "value": 243, "place": 10, "scenarios": ["bus-seats", "candy-bags", "height"], "showConsequence": true }
  ```
- **과제:**
  1. 버스 몇 대? 방법 고르고 수 입력 / 판정: 올림 선택, 25
  2. 팔 수 있는 봉지 수 / 판정: 버림, 24
  3. 4,537을 백의 자리까지 반올림 / 판정: 4,500
  4. 직접 상황 고르기: 3개 상황에 방법 짝짓기 / 판정: 짝 일치
- **CPA 페이딩:** P: 결과 장면 / A: 장면 없이 수만

## g5s2u2 분수의 곱셈
| 항목 | 내용 |
| --- | --- |
| 영역 | 수와 연산 |
| 엔진 | E05 분수 모델, E04 배열·넓이 모델 |
| 선수 단원 | g5s1u5 분수의 덧셈과 뺄셈 |
| 차시 규모(참고) | 교과서 약 9차시 중 앱 활용 4차시 |

**핵심 아이디어:** (자연수)×(분수)는 "그만큼의 몇 배", (분수)×(분수)는 "~의 ~만큼"이다. 진분수를 곱하면 *일부분만 취하므로* 작아질 수 있다. 넓이 모델에서 두 분할의 겹친 부분이 곱이다.

### 개념 노드
| ID | 개념 | 선수 개념 |
| --- | --- | --- |
| g5s2u2.whole-times-fraction | (분수)×(자연수), (자연수)×(분수) | g5s1u5 |
| g5s2u2.fraction-of-fraction | (분수)×(분수) = 부분의 부분(넓이 교집합) | g5s2u2.whole-times-fraction |
| g5s2u2.scaling-smaller | 진분수를 곱하면 작아진다(곱셈 결과 크기 예측) | g5s2u2.fraction-of-fraction |
| g5s2u2.cross-simplify | 계산 중 약분 | g5s1u4.simplify |
| g5s2u2.mixed-multiply | 대분수의 곱셈 | g5s2u2.fraction-of-fraction, g3s2u4 |

### 활동
#### g5s2u2.A1 이중 알파 블렌딩 넓이 교집합 — E05 `multiply` + E04 `fraction-area` · C→P→A
- **원 계획서:** 이중 알파 블렌딩 넓이 교집합 모델
- **화면과 조작:** 1×1 정사각형. 학생이 세로 슬라이서로 2/3을 노랑으로 칠한다. 그다음 "그것의 3/4"을 위해 가로 슬라이서로 3/4을 파랑으로 칠하면 두 반투명 색이 겹친 부분이 초록으로 진해진다. 전체 칸 수(12)와 초록 칸 수(6)가 세어진다. 대분수 곱셈은 정사각형 여러 개로 확장.
- **설정 예시:**
  ```json
  { "engine": "E05", "mode": "multiply", "a": "2/3", "b": "3/4", "layout": { "a": "vertical", "b": "horizontal" }, "blend": "alpha", "showCounts": true }
  ```
- **과제:**
  1. 4 × 2/3 (막대 4개 모으기) / 판정: 결과 8/3 = 2 2/3
  2. 2/3 × 3/4 넓이 모델 만들기 / 판정: 겹친 칸 6, 전체 12, 결과 입력 1/2
  3. 1/2 × 1/5 (단위분수끼리) / 판정: 1/10, 규칙 카드 "분모끼리 곱한다" 선택
  4. 1 1/2 × 2/3 / 판정: 1
  5. A 단계: 3/5 × 5/6 계산 중 약분 / 판정: 결과 1/2, 줄 동치
- **CPA 페이딩:** C: 슬라이서 직접 / P: 겹친 그림 자동 / A: 식 입력, 그림은 힌트 ②

#### g5s2u2.A2 축소 스케일러 — E04 `fraction-area` · P→A
- **원 계획서:** 진분수 곱셈 축소 스케일러 + 대각선 약분 크로스 슬라이더
- **화면과 조작:** 길이 12m 리본 그림. 곱하는 수 슬라이더(1/4 ~ 2, 분수 눈금)를 움직이면 리본이 늘거나 줄며 결과 길이가 표시된다. 슬라이더가 1을 지날 때 색이 바뀐다. 계산 전 예측 버튼("12보다 클까 작을까")을 먼저 눌러야 슬라이더가 열린다. 약분 크로스 슬라이더: `3/8 × 4/9` 식에서 대각선 두 수(3과 9, 8과 4)를 손가락으로 이으면 공약수로 나눈 값이 위에 겹쳐 적힌다.
- **설정 예시:**
  ```json
  { "mode": "fraction-area", "variant": "scaler", "base": 12, "multipliers": ["1/4", "1/2", "3/4", "1", "5/4", "3/2", "2"], "predictFirst": true }
  ```
- **과제:**
  1. 12 × 3/4 예측 후 확인 / 판정: 예측 "작다" + 결과 9
  2. 12 × 5/4 / 판정: 예측 "크다" + 15
  3. 결과가 12보다 작아지는 곱하는 수 3개 고르기 / 판정: 모두 1 미만
  4. 크로스 약분 `3/8 × 4/9` / 판정: 연결 쌍 (3,9),(8,4), 결과 1/6
- **CPA 페이딩:** P: 리본 / A: 크기 비교 문제만(`□ × 7/8`은 □보다?)

## g5s2u3 합동과 대칭
| 항목 | 내용 |
| --- | --- |
| 영역 | 도형과 측정 |
| 엔진 | E10 도형 이동·대칭 |
| 선수 단원 | g4s1u4 평면도형의 이동 |
| 차시 규모(참고) | 교과서 약 8차시 중 앱 활용 4차시 |

**핵심 아이디어:** 합동은 "포개어 완전히 겹치는 것"이고, 겹칠 때 짝이 되는 점·변·각이 있다. 선대칭은 접어서, 점대칭은 한 점을 중심으로 180° 돌려서 자기 자신과 겹치는 도형이다.

| g5s2u3.point-symmetry | 점대칭도형과 대칭의 중심 | g5s2u3.congruence |
| g5s2u3.draw-symmetric | 대칭도형 완성하기(대응점 거리 같음) | g5s2u3.line-symmetry, g5s2u3.point-symmetry |

### 활동
#### g5s2u3.A1 포개기와 데칼코마니 — E10 `congruence`·`line-symmetry` · C→P→A
- **원 계획서:** 데칼코마니 접기
- **화면과 조작:** ① 합동: 두 도형 중 하나를 밀기·뒤집기·돌리기 버튼과 드래그로 옮겨 다른 하나에 포갠다. 완전히 겹치면 대응점·변·각이 같은 색 선으로 연결된다. ② 데칼코마니: 종이 절반에 물감 점을 찍고 "접기"를 누르면 접는 선을 축으로 접혀 반대편에 찍힌다. 도형 대칭축 찾기에서는 학생이 직선을 그어 "접어 보기"를 누르면 접힌 반쪽이 겹치는지 보여 준다(어긋나면 빨간 빈틈).
- **설정 예시:**
  ```json
  { "mode": "line-symmetry", "shapes": ["rectangle", "parallelogram", "regular-hexagon", "isosceles-trapezoid"], "allowDrawAxis": true, "foldPreview": true }
  ```
- **과제:**
  1. 합동인 두 사각형 포개기 + 대응변 짝짓기 / 판정: 포개짐 성공, 짝 목록 일치

| 항목 | 내용 |

**핵심 아이디어:** 소수의 곱셈은 자연수 곱셈과 같은 수를 쓰되 *자릿값*이 바뀐다. 0.1을 곱하면 각 숫자가 한 자리씩 오른쪽으로 이동한다. 소수점 위치는 어림으로 확인할 수 있다.

### 활동
#### g5s2u4.A1 1×1 정사각형 안의 소수 곱셈 — E04 `decimal-area` + E03 `decimal` · C→P→A
- **원 계획서:** (분수 곱셈 넓이 모델 연계) + 소수 곱셈 넓이
- **화면과 조작:** 1×1 정사각형을 10×10 모눈으로 나눈다. 가로 0.6, 세로 0.3을 슬라이더로 정하면 겹친 18칸이 진해지고 "1칸 = 0.01"이 표시된다. 1보다 큰 소수(1.2 × 0.4)는 정사각형 두 개로 확장. 결과는 아래 수직선 위 점으로도 찍힌다.
- **설정 예시:**
  ```json
  { "engine": "E04", "mode": "decimal-area", "a": "0.6", "b": "0.3", "grid": 10, "linkedNumberLine": { "engine": "E03", "mode": "decimal", "min": 0, "max": 1 } }
  ```
- **과제:**
  1. 0.3 × 4 (막대 4개) / 판정: 1.2
  2. 0.6 × 0.3 / 판정: 겹친 칸 18, 결과 0.18
  3. 1.2 × 0.4 / 판정: 0.48
  4. 0.5 × 0.5가 0.5보다 작은 이유 카드 고르기 / 판정: 선택 일치
- **CPA 페이딩:** C: 슬라이더로 직접 / P: 그림 / A: 식만

#### g5s2u4.A2 소수점 기둥 시프트와 어림 검증 — E07 `decimal`·`estimate` · P→A
- **원 계획서:** 어림값 타당성 검증기 + ×0.1, ×10 소수점 기둥 숫자 시프트 애니메이션
- **화면과 조작:** 자릿값 기둥(백·십·일·소수 첫째·둘째·셋째)에 숫자 카드가 꽂혀 있다. ×10을 누르면 소수점은 그대로, *숫자들이* 한 기둥 왼쪽으로 미끄러진다(×0.1은 오른쪽). 그다음 세로셈 격자에서 `2.4 × 1.3`을 자연수처럼 계산하고, 소수점 칸에 점을 놓기 전에 어림값(2 × 1 = 약 2, 3 × 1 = 약 3)을 먼저 입력해야 한다. 결과와 어림이 맞지 않으면 신호등이 빨강.
- **설정 예시:**
  ```json
  { "mode": "decimal", "op": "mul", "a": "2.4", "b": "1.3", "requireEstimate": true, "shiftDemo": { "value": "3.75", "ops": ["×10", "×100", "×0.1", "×0.01"] } }
  ```
- **과제:**
  1. 3.75 × 10, × 0.1 시프트 결과 / 판정: 37.5, 0.375
  2. 2.4 × 1.3 세로셈 + 어림 / 판정: 어림 입력 존재, 결과 3.12
  3. 0.25 × 0.4 / 판정: 0.1(=0.100), 소수점 위치 정확
  4. 계산 결과 중 소수점이 잘못된 것 찾기(31.2, 3.12, 0.312) / 판정: 어림 근거로 3.12 선택
- **CPA 페이딩:** P: 기둥 애니메이션 / A: 세로셈만, 힌트 ②에서 기둥

### 활동
#### g5s2u5.A1 엑스레이 겨냥도 — E12 `xray` · C→P→A
- **원 계획서:** 엑스레이(X-Ray) 점선 투시기
- **화면과 조작:** 3D 직육면체를 손가락으로 돌린다. "엑스레이" 토글을 켜면 뒤쪽 모서리가 점선으로 비친다. 면을 누르면 그 면과 평행한 면이 같은 색, 수직인 면이 줄무늬로 표시된다. 학생이 2D 등각 격자 위에 겨냥도를 따라 그리면(선분 도구) 실선/점선 구분을 판정.
- **설정 예시:**
  ```json
  { "mode": "xray", "solid": { "type": "cuboid", "w": 4, "d": 3, "h": 2 }, "faceQuery": true, "sketchGrid": "isometric" }
  ```
- **과제:**
  1. 면·모서리·꼭짓점 수 세기(누르면 표시) / 판정: 6, 12, 8
  2. 색칠된 면과 평행한 면 누르기 / 판정: 대응 면
  3. 한 면에 수직인 면 모두 / 판정: 4개
  4. 겨냥도 완성(보이지 않는 모서리 3개 점선) / 판정: 점선 선분 집합 일치
- **CPA 페이딩:** C: 3D 회전 / P: 고정된 겨냥도 + 엑스레이 / A: 겨냥도만 보고 답

#### g5s2u5.A2 전개도 그리기와 자동 폴딩 — E12 `net-fold` · C→P→A
- **원 계획서:** 모눈종이 2D 전개도 직접 그리기 및 3D 자동 폴딩·면 충돌 검증기
- **화면과 조작:** 모눈 위에 칸을 눌러 정사각형(직사각형) 면을 추가해 전개도를 그린다. "접기"를 누르면 3D 회전 관절로 접히는 애니메이션이 재생되고, 면이 겹치면 겹친 면이 빨간색, 비어 있는 면이 깜빡이는 점선 구멍으로 보인다. 성공하면 접힌 입체를 돌려 볼 수 있고, 마주 보는 면 쌍이 같은 색으로 칠해진다.
- **설정 예시:**
  ```json
  { "mode": "net-fold", "target": "cube", "grid": [6, 6], "faceSize": 1, "collisionHighlight": true, "pairColors": true }
  ```
- **과제:**
  1. 정육면체 전개도 하나 그려 접기 / 판정: 유효한 전개도(면 6, 겹침 0, 빈 면 0)
  2. 서로 다른 정육면체 전개도 3개 / 판정: 회전·뒤집기로 같은 것 제외한 서로 다른 3개
  3. 주어진 전개도에서 접었을 때 ★면과 마주 보는 면 고르기(접기 전 예측) / 판정: 예측 기록 + 정답 면
  4. 직육면체(4×3×2) 전개도 / 판정: 면 크기·배치 유효
  5. 접히지 않는 전개도 고르고 이유 / 판정: 선택 + 이유 카드("면이 겹친다")
- **CPA 페이딩:** C: 접기 애니메이션 / P: 접기 전에 마주 보는 면 예측 필수 / A: 애니메이션 없이 판단만

## g5s2u6 평균과 가능성
| 항목 | 내용 |
| --- | --- |
| 영역 | 자료와 가능성 |
| 엔진 | E19 평균·가능성 실험실 |
| 선수 단원 | g4s1u5 막대그래프 |
| 차시 규모(참고) | 교과서 약 9차시 중 앱 활용 4차시 |

**핵심 아이디어:** 평균은 자료를 *고르게 했을 때의 값*이자 *균형점*이다. 하나의 극단값이 평균을 크게 끌어당길 수 있다. 일이 일어날 가능성은 말(불가능하다 ~ 확실하다)과 수(0 ~ 1)로 나타낼 수 있고, 시행을 많이 할수록 실험 결과가 그 가능성에 가까워진다.

### 개념 노드
| ID | 개념 | 선수 개념 |
| --- | --- | --- |
| g5s2u6.mean-as-leveling | 평균 = 고르게 하기 | g4s1u5 |
| g5s2u6.mean-as-balance | 평균 = 균형점(무게중심) | g5s2u6.mean-as-leveling |
| g5s2u6.mean-compute | 평균 = 자료 값의 합 ÷ 자료 수 | g5s2u6.mean-as-leveling |
| g5s2u6.outlier-effect | 극단값이 평균에 주는 영향 | g5s2u6.mean-as-balance |
| g5s2u6.likelihood | 가능성을 말과 수로 표현, 많은 시행 | g5s2u6.mean-compute |

### 활동
#### g5s2u6.A1 블록 기둥 평탄화와 평균 시소 — E19 `leveling`·`seesaw`·`outlier` · C→P→A
- **원 계획서:** 블록 기둥 평탄화 및 시소 무게중심 평균 실험기 + 이상치 드래그
- **화면과 조작:** ① 5명의 줄넘기 기록이 블록 기둥(7, 4, 9, 3, 7)으로 서 있다. 학생이 높은 기둥 맨 위 블록을 끌어 낮은 기둥에 옮겨 모두 같은 높이로 만든다(옮긴 횟수 기록). ② 같은 자료가 수직선 시소 위 추(점)로 바뀐다. 받침점을 끌어 균형이 맞는 위치를 찾으면 시소가 수평이 된다. ③ 이상치: 점 하나를 오른쪽 끝으로 끌면 평균선이 얼마나 따라 움직이는지 실시간 표시.
- **설정 예시:**
  ```json
  { "mode": "leveling", "data": [7, 4, 9, 3, 7], "label": "줄넘기(번)", "next": [{ "mode": "seesaw" }, { "mode": "outlier", "dragIndex": 4 }] }
  ```
- **과제:**
  1. 기둥 고르게 하기 / 판정: 모든 기둥 높이 6
  2. 시소 균형점 찾기 / 판정: 받침점 = 6
  3. 계산으로 평균(합 ÷ 수) 입력 / 판정: 6
  4. 한 명의 기록을 30으로 바꾸면 평균은? 예측 후 끌기 / 판정: 예측 기록 + 결과 확인(10.6, 즉 53/5 — 정확 유리수로 표시)
  5. 평균이 같은 두 모둠 중 기록이 더 고른 모둠 고르기 / 판정: 선택 일치
- **CPA 페이딩:** C: 블록 옮기기 / P: 시소 / A: 표만 보고 계산

#### g5s2u6.A2 가상 데이터 확률 공장 — E19 `spinner`·`simulate`·`words` · C→P
- **원 계획서:** 가상 데이터 확률 공장(TinkerPlots 형) 10,000회 시뮬레이터
- **화면과 조작:** ① 말 카드(불가능하다·~아닐 것 같다·반반이다·~일 것 같다·확실하다)를 0~1 수직선에 배치. ② 회전판(칸 수·색 조절)이나 주머니(구슬 색·개수)를 조립해 "공장"을 만든다. 1회씩 돌리기 → 10회 → 1,000회 → 10,000회 버튼. 결과는 막대그래프(상대도수)로 쌓이며, 회차가 늘수록 막대가 기대 비율 선에 가까워지는 모습을 비교 패널에 나란히 둔다. 대량 시행은 Web Worker.
- **설정 예시:**
  ```json
  { "mode": "simulate", "device": { "type": "spinner", "sectors": [{ "color": "red", "size": 1 }, { "color": "blue", "size": 1 }] }, "batches": [10, 1000, 10000], "showExpected": true }
  ```
- **과제:**
  1. 상황 카드(주사위 눈 7 나오기, 동전 앞면, 내일 해 뜨기) 말 표현 배치 / 판정: 위치 일치
  2. 빨강이 나올 가능성 "반반"인 회전판 만들기 / 판정: 빨강 비율 1/2
  3. 10회 결과와 10,000회 결과 비교 문장 고르기 / 판정: "많이 할수록 1/2에 가까워진다" 선택
  4. 빨강 가능성 0인 주머니, 1인 주머니 / 판정: 구성 일치
- **CPA 페이딩:** C: 직접 돌리기 / P: 그래프 / A: 상황만 보고 수로 표현
