## W3 평면 도형
엔진 카드(T100~T108)와 오개념 레지스트리 카드(T109)를 먼저 하고, 단원 콘텐츠 카드(T110~T121)는 선행 엔진 카드와 T109가 병합된 뒤 한다. T100이 E09와 함께 core 기하 도우미(`src/core/math/geometry.ts`)를 만들므로 E10·E11·E17 카드도 T100 뒤에 한다. Action은 `toggle-example-mark`, 상태 키는 `exampleMarks`, `exampleIndex` 0은 내 그래프다. `visualRatio`는 물결선이면 물결 칸 1칸을 더해 잰다. 기본 `yStartOptions`에는 45 같은 값이 없으니 콘텐츠가 정한다. 검수 중 T163 물결선 E2E가 전자칠판에서 한 번 실패했고 15번 다시 돌려 모두 통과했다.
T168은 소넷 구현 → 검수(수정 없음)를 거쳐 main에 병합했다(2026-11-19). 에이전트가 보고 전에 멈춰 전체 검사는 검수자가 다시 돌렸다. A2.T2는 아무것도 안 해도 통과하지 않게 `yStart: 45`에서 시작한다. 크롬북 A2.T1(응답 칸 두 칸 배치)에서 distortion 막대그래프가 최소 높이 200px로 눌려 기사 제목 줄이 세로축 0과 가로축 이름을 덮는 엔진 배치 문제는 T169로 넘긴다.
T169는 소넷 구현 → 검수(수정 없음)를 거쳐 main에 병합했다(2026-11-19). `.distBody`·`.distBoard`의 `min-height`를 200px로 두어 두 칸 판에서 그래프가 줄지 않고 `.wrap`이 세로 스크롤한다(크롬북 g6s1u5.A2.T1 58px). 그래서 기사 제목 카드 단추는 스크롤해야 닿는다. 이 카드부터 E2E는 바뀐 엔진·단원 spec만 돌리고, 전체 E2E는 core 변경과 웨이브 끝에 돌린다.
