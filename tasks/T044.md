## 구현 결정 (2026-11-04 Claude 작성 — 여기 적힌 대로 하고, 바꿔야 하면 메모에 이유를 적고 질문한다)
1. **폴더:** `src/engines/E04-array-area/`, E05·E07과 같은 구조. 엔진 ID `E04`, 이름 "배열판", modes 순서 `dot-array`, `split`, `area-model`, `times-table`. 명세의 `rotate`는 **모드가 아니라 dot-array의 설정 `rotate: true`**로 만든다(단원 명세 g2s1u6.A2의 설정 예시와 같음 — 메모에 docs/03 수정 제안으로 남긴다). 확장(`tiling`, `decimal-area`, `fraction-area`, area-model `puzzle`)은 T045 몫이다.
2. **수:** 행·열·부분곱은 정수(number). 소수·분수 넓이는 T045에서 `Rational`로 들어온다 — 넓이 계산은 `area.ts` 한 곳에 모은다. 논리 캔버스 1000×600, 누른 위치는 SDK `pointerToLogical`.
3. **dot-array:** 설정 `rows`, `cols`(처음 배열, 기본 0×0이면 학생이 만든다), `maxRows`(기본 10), `maxCols`(기본 10), `icon`(`dot` 기본 / `tree` / `candy` / `strawberry` — E04 폴더 안 인라인 SVG, 다른 엔진 아이콘을 import하지 않는다), `rotate`(boolean), `showSentence`(`"none"` 기본 / `"dims"`), `factFamily`(boolean), `factHide`(`"product"` / `"rows"` / `"cols"` / null), `showSplitLines`(boolean). 조작: 배열 오른쪽 아래 손잡이를 끌어 행·열을 정한다(격자에 스냅, `resize {rows, cols}`), 행·열 옆 −/+ 버튼과 키보드(방향키)로 같은 Action. `rotate`: "돌리기" 버튼 → `rotate` Action(행·열이 바뀌고 90° 회전 애니메이션은 CSS, `prefers-reduced-motion`이면 생략). **"기록하기" 버튼**(`record-arrangement`) — 지금 (행, 열)을 `recorded`에 쌓는다(같은 배열 중복 제거, **회전한 같은 배열도 하나로 본다**) — "서로 다른 두 배열" 판정용. `showSentence:"dims"`는 "○줄 ○개씩"처럼 행·열만 쓴다(곱 결과는 쓰지 않는다). `factFamily`: 배열 옆 삼각형 카드(꼭짓점: 곱, 행, 열), `factHide`로 가린 꼭짓점은 "?"(가려진 수를 화면에 쓰지 않는다). `showSplitLines`: 배열 위에 가로 자르기 선 하나·세로 묶음 표시 하나를 끌 수 있고, 각각 "몇 줄로 나누기(등분)", "몇 개씩 묶기(포함)" 해석 강조 그림을 낸다(`set-split-line {orientation, at}`).
4. **split:** 설정 `rows`, `cols`, `maxSplits`(기본 1, 최대 3), `orientation`(`"rows"` / `"cols"` / `"either"`), `snapHints`(약한 자석 위치 목록, 예 `[5]`), `showPartials`(`"color"` 기본 / `"dims"` / `"none"`), `allowExtend`(boolean — 빼기 분할용). 분할선은 행 사이 또는 열 사이에만 놓인다(정수 위치로 스냅, `snapHints` 근처는 반경을 넓힌다). Action `place-split {orientation, at}`, `remove-split {index}`. `showPartials:"color"`: 나뉜 조각마다 색 + 무늬(빗금 방향이 다름)와 "7×5"처럼 조각의 **크기와 곱**을 쓴다(학생이 고른 분할의 부분곱이다). **전체 곱은 어디에도 쓰지 않는다.** `allowExtend`: 배열 아래에 "한 줄 늘이기" 손잡이 → 늘린 줄은 흐린 점으로 그리고, 그 줄을 "지우기 조각"으로 표시해 `10×6 − 1×6` 꼴 부분곱(부호 −)을 만든다. **"기록하기"**(`record-split`) — 지금 분할(정렬한 위치 목록)을 쌓는다(서로 다른 분할 2개 판정용).
5. **area-model:** 설정 `a`, `b`(두 자리×한 자리부터 세 자리×두 자리까지), `splitA`·`splitB`(`"free"` / `"place-value"`(자릿값 경계에 미리 놓음) / `"none"`), `showGrid`(`"always"` / `"C-only"` 기본 / `"never"`), `showPartials`(4번과 같음). 직사각형 가로 = a, 세로 = b. 그림 비율은 실제 비율을 따르되 조각이 너무 얇아지지 않게 최소 너비 40 논리 단위로 펴서 그린다(그 경우 변에 길이 숫자를 쓴다). 분할선은 정수 위치로 스냅하고 자릿값 경계(예 23 → 20|3)에 약한 자석. 모눈은 a×b ≤ 1200칸일 때만 그리고 넘으면 10단위 굵은 선만. 조각 = 분할로 생긴 직사각형마다 `{rows, cols, product}`.
6. **times-table:** 설정 `size`(기본 `[9, 9]`), `prefill`(`"none"` / `"rows-2-5"` / 칸 목록), `symmetryReveal`(boolean), `colorSameValue`(boolean), `includeZero`(boolean — 0행·0열 추가). 칸을 누르면 엔진 안 숫자 키패드(0~9, 지우기, 두 자리 입력 후 확인)로 값을 쓴다(`set-cell {r, c, value}`). `symmetryReveal`: 학생이 (r, c)를 쓰면 (c, r) 칸 테두리가 반짝인다(**값은 쓰지 않는다**). "접어 보기" 버튼: 대각선 접기 애니메이션(정지 그림 두 장 사이 전환, 값은 학생이 쓴 칸만 보임). `colorSameValue`: 색칠 도구(색 4가지 + 무늬)로 칸 칠하기 `paint {r, c, color}`. 칸 고르기(`select-cell`)는 "같은 값의 칸 찾기" 판정용.
7. **Observation:** `mode`. dot-array: `rows`, `cols`, `total`, `rotations`, `recorded`, `distinctArrangements`, `splitLine`. split: `rows`, `cols`, `splits`, `partials: {rows, cols, product, sign}[]`, `partialSum`(부분곱 합 — Observation에만, 화면 표시 금지), `recordedSplits`, `distinctSplits`. area-model: `a`, `b`, `splitsA`, `splitsB`, `pieces`, `partialSum`. times-table: `cells`(학생이 쓴 값 맵 `"r,c" → value`), `wrongCells`(목록만 — 화면에 맞음·틀림 표시 금지), `selected`, `painted`.
8. **Predicates:** `dimsAre {rows, cols, either?}`(either면 회전 허용), `totalIs {value}`, `distinctArrangementsAtLeast {count, total}`, `splitAt {orientation, at}`, `partialsAre {products, ordered?}`, `partialSumIs {value}`, `distinctSplitsAtLeast {count}`, `piecesAre {products}`, `cellsMatch {cells}`(지정 칸 값이 모두 맞음), `selectedAre {cells}`.
9. **이벤트:** `partial-product-changed {parts: {a, b, product, colorIndex}[]}`(area-model·split에서 분할이 바뀔 때 — T046에서 E07이 같은 색으로 받는다), `value-changed {value}`(dot-array total).
10. **정답 노출 금지:** 전체 곱·나눗셈 몫·times-table의 빈칸 값은 어디에도 그리지 않는다. 부분곱 표시는 학생이 만든 분할의 결과일 때만(분할이 없으면 아무 숫자도 없다). `factHide`로 가린 꼭짓점은 "?".
11. **색:** 부분곱 색 4가지는 무늬(빗금 방향·점)와 함께 쓴다. 같은 `colorIndex`를 E07이 쓸 수 있게 팔레트 순서를 `types.ts`에 `PARTIAL_PALETTE`로 export한다(E07은 import하지 않고 같은 값을 복사해 쓴다 — 메모에 적는다).
12. **입력·접근성:** Pointer Events, 손잡이·분할선 터치 반경 ≥ `targetSize`/2(SDK `minTouchRadius`). 키보드: Tab으로 손잡이·분할선·칸 이동, 방향키로 한 칸씩, Enter로 놓기·기록, Delete로 분할선 지우기.
13. **오버레이(힌트 ②):** `row-count`(행마다 1, 2, 3 … 번호), `known-fact`(분할 조각 중 학생이 고른 하나를 강조하고 그 조각만 다시 묶어 보임), `fold-diagonal`(times-table 대각선 강조), `missing-strip`(area-model에서 학생이 빠뜨린 조각 자리에 빗금 — 그 조각의 곱은 쓰지 않는다).
14. **테스트:** reduce 단위(resize 한계, rotate 두 번 원상복귀, 회전 배열 중복 제거, split 위치 스냅·maxSplits, allowExtend 부호, area-model 3분할 312×3 조각, times-table 대칭 반짝임 대상), observe·predicates, `assertSerializable`, View 테스트(분할 전에는 숫자가 없음, 전체 곱이 DOM에 없음), `#/sandbox/E04` E2E 3개 뷰포트: 키보드로 3×4 배열 만들고 돌리기 → 4×3, split 7×8을 5|3으로 → partials 35·21, area-model 23×4를 20|3으로(좌표는 `tests/e2e/canvas-point.ts`의 `logicalToScreen`).

- **area-model 라벨 순서:** 조각 라벨은 가로×세로(`20×4`, `3×4`)로 씁니다. 내부 `Piece`는 `{rows: 세로, cols: 가로, product}`라서 화면에서만 순서를 바꿉니다.
- **편차 1 — 조각 최소 너비(결정 5):** "조각이 너무 얇아지지 않게 최소 너비 40 논리 단위로 펴서 그린다"는 대신 **실제 비율을 지켜** 그립니다. 얇은 조각은 라벨을 생략(폭 54·높이 30 미만)하고 변에 `가로 312`·`세로 3` 길이 숫자를 항상 씁니다. 비율을 펴면 분할선 좌표·끌기 역산·오버레이 좌표가 모두 어긋나서, 정확한 좌표를 우선했습니다. 최소 너비 표시가 꼭 필요하면 별도 카드로 요청해 주세요.
- **편차 2 — Sandbox 모드:** `#/sandbox/E04`는 다른 엔진처럼 첫 모드(`dot-array`)로 시작하고 URL의 `mode`를 덮어씁니다. E2E는 `모드` select로 `split`·`area-model`을 고른 뒤 URL 설정(rows/cols/a/b)을 그대로 씁니다.
- **분할선 끌기:** `lineTarget`을 ref 대신 state로 두어 렌더 중 ref 접근 린트(`react-hooks/refs`)를 피했습니다. 드래그 중 미리보기는 dot-array·area-model에만 그리고, split은 손을 떼면 위치가 바뀝니다.
- **자석:** `snapHints` 반경 2로 붙습니다(예: 6 → 5).
- **times-table 키패드:** 칸을 누르면 엔진 안 키패드가 열리고, 숫자 키를 바로 눌러도 입력이 시작됩니다. `symmetryReveal`은 `(c, r)` 칸을 반짝이게만 하고 값을 쓰지 않습니다.
- **E2E 좌표:** 좁은 뷰포트에서 5:3 캔버스가 뷰포트보다 길어져 페이지를 스크롤한 뒤 `tests/e2e/canvas-point.ts`의 `logicalToScreen`으로 좌표를 잽니다(T042와 같은 방식).
