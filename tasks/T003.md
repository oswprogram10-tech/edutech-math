## 구현 결정 (2026-11-02 Claude 추가 — 여기 적힌 대로 하고, 바꿔야 하면 메모에 이유를 적고 질문한다)
1. **파일:** SDK는 `src/core/engine-sdk/`(공개 API는 `index.ts`), 예제 엔진은 `src/engines/E00-demo/`(AGENTS.md 엔진 폴더 구조 그대로), 테스트는 각 폴더의 `__tests__/`.
2. **타입:** `docs/02` §3의 타입 + `docs/05` §4의 `HintRule`을 `types.ts`에 옮긴다. `Observation`은 `Record<string, JsonValue>`(JSON 값만)로 정의하고 `JsonValue` 타입도 여기 둔다. `Rational`은 JSON에서 문자열이므로 Observation에는 `Rational`을 직접 넣지 않고 `toJSON()` 문자열로 넣는다. 타입을 보강하면 `docs/02` §3 코드 블록도 같이 고친다(docs는 이 절만 수정 가능).
3. **좌표:** 엔진 상태와 Action에는 **화면 픽셀이 아닌 엔진 자체의 논리 좌표**(예: SVG viewBox 0~1000 단위나 격자 칸)를 저장한다. 기기·`scale`이 달라도 상태가 같아야 미러링·되감기가 된다. 픽셀 → 논리 좌표 변환 유틸을 SDK에 둔다.
4. **Action 기록 단위:** 드래그 중 움직임은 화면에만 반영하고(로컬 UI 상태), Action은 **놓을 때 한 번**(`{type:'move', id, to}`) 디스패치한다. 이동 궤적은 Action에 넣지 않는다(AGENTS 규칙 9).
5. **되돌리기:** `withHistory(definition)` 또는 `useHistory(reduce, initial)` 형태의 일반 도구. 상태 스냅숏 스택(최대 100개). 엔진의 `reduce`는 되돌리기를 몰라도 된다.
6. **직렬화 검사:** `assertSerializable(state)` — `JSON.parse(JSON.stringify(s))`가 깊은 비교로 같지 않으면(함수·BigInt·undefined·Map·순환 참조) 오류. E00 테스트에서 모든 Action 후 상태에 적용한다.
7. **오버레이:** `EngineDefinition`에 선택 필드 `overlays?: Record<string, React.ComponentType<OverlayProps<Config, State>>>`. `OverlayProps = { config, state, args?: unknown, scale }`. 엔진 View 위에 겹치는 SVG/HTML 레이어로 그린다. `HintRule.show.overlay`가 이 이름을 가리킨다. 오버레이는 정답을 보여 주면 안 된다(AGENTS 규칙 3).
8. **크기 규약:** `EngineViewProps`에 `targetSize: 48 | 64`(저학년 모드 64)를 추가한다. 엔진은 조작 가능한 모든 요소의 터치 영역을 이 값 이상으로 만든다.
9. **키보드:** Tab/Shift+Tab으로 조작 요소 사이 이동, 방향키로 한 칸(격자 한 칸) 이동, Shift+방향키로 다섯 칸, Space로 다중 선택 토글, Enter로 확정(올가미 대신 선택한 것 묶기), Ctrl+Z/Ctrl+Y(맥 Cmd)로 되돌리기/다시하기, `+`/`-`로 확대·축소(핀치 대체). 포커스 테두리는 눈에 보이게.
10. **핀치:** 두 손가락 포인터 + 휠(Ctrl+휠) + 화면 버튼(+/−) 세 가지를 모두 지원한다.
11. **레지스트리:** `src/core/engine-sdk/registry.ts`에서 `import.meta.glob('../../engines/E*/index.ts')`(lazy)로 엔진을 자동 등록한다. **엔진을 추가할 때 중앙 파일을 고치지 않는다**(여러 에이전트가 동시에 엔진을 만들어도 충돌이 없게). `loadEngine(id)`가 `EngineDefinition`을 돌려준다.
12. **샌드박스 화면(E2E용):** `src/app/`에 URL 해시 `#/sandbox/E00`이면 해당 엔진을 레지스트리로 불러 빈 config로 띄우는 최소 화면을 둔다(되돌리기·확대 버튼, `targetSize` 전환 포함). 학생 메뉴에는 노출하지 않는다. 나중에 T007 교사 시연 모드가 이것을 대체·확장한다.
13. **E00-demo:** 셈돌 놓기(빈 곳 탭), 옮기기(드래그), 올가미로 묶기, 묶음 풀기. `observe()`는 `{ count, groups: number[] }`(묶음별 개수). 문구는 `strings.ko.ts`. 다른 엔진의 본보기이므로 파일마다 짧은 설명 주석을 단다.
14. **테스트 도구:** 훅 단위 테스트용으로 `jsdom`과 `@testing-library/react`를 devDependency로 추가해도 된다(해당 테스트 파일에만 `// @vitest-environment jsdom`). Playwright에서는 아이패드 프로젝트도 `page.mouse`로 드래그·올가미를 검증한다(다중 터치 핀치는 Playwright로 못 하므로 단위 테스트로).
