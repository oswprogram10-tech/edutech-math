## g6s2u1 분수의 나눗셈
| 항목 | 내용 |
| --- | --- |
| 영역 | 수와 연산 |
| 엔진 | E05 분수 모델, E03 수직선 |

| 차시 규모(참고) | 교과서 약 8차시 중 앱 활용 4차시 |

**핵심 아이디어:** (분수)÷(분수)는 "나누는 수가 몇 번 들어가는가"(포함제)로 볼 수 있다. 분모가 같으면 분자끼리 나누면 되고, 분모가 다르면 통분해서 같은 단위로 잰다. 이를 일반화하면 "÷ c/d = × d/c"(역수 곱셈)가 나온다. 1보다 작은 수로 나누면 몫이 커진다.

### 활동
#### g6s2u1.A1 나누는 수 막대로 재기 — E05 `divide-measure` · C→P
- **원 계획서:** (분수 ÷ 분수 측정 모델)
- **화면과 조작:** 3/4 막대(피제수)와 1/8 "자" 막대(제수). 학생이 자 막대를 피제수 막대 위에 이어 놓을 때마다 1, 2, 3… 번호가 찍힌다. 끝에 자가 다 들어가지 않으면 남는 부분이 "자의 몇 분의 몇"으로 표시된다(3/4 ÷ 2/3이면 1번 + 자의 1/8).
- **설정 예시:**
  ```json
  { "mode": "divide-measure", "dividend": "3/4", "divisor": "1/8", "showRemainderFractionOfDivisor": true }
  ```
- **과제:**
  1. 3/4 ÷ 1/8 / 판정: 6
  2. 6/7 ÷ 2/7 / 판정: 3, 규칙 카드 "분모가 같으면 분자끼리 나눈다"
  3. 3/4 ÷ 2/3 / 판정: 1 1/8 (남는 부분 = 자의 1/8)
  4. 2 ÷ 1/3이 2보다 큰 이유 카드 / 판정: "1/3이 2 안에 6번 들어간다"
- **CPA 페이딩:** C: 자 막대 직접 이어 놓기 / P: 자동 반복 그림 / A: A2로

#### g6s2u1.A2 이중 수직선 역수 곱셈 증명 스튜디오 — E03 `double` + E05 `divide-measure` · P→A
- **원 계획서:** 이중 수직선 단위분수 재측정을 통한 역수 곱셈(× d/c) 증명 스튜디오 + 풀이 영상(Thinklet) 타임스탬프 피어 리뷰
- **화면과 조작:** 위 수직선: 원래 양(0 ~ 3/4), 아래 수직선: "자 2/3로 잰 횟수"(0 ~ ?). 문제 `3/4 ÷ 2/3`. ① 아래 수직선에서 자 2/3이 1에 대응. ② 학생이 "자를 2로 나누기" 버튼을 누르면 위 1/3 ↔ 아래 1/2(단위분수 재측정) 대응선이 생긴다. ③ "3배" 버튼으로 위 1 ↔ 아래 3/2. ④ 그러면 위 3/4 ↔ 아래 3/4 × 3/2. 각 단계가 대응선으로 남고, 위쪽 식 칸에 단계별 식이 쌓여 `÷ 2/3 = × 3/2`가 완성된다.
- **설정 예시:**
  ```json
  { "engine": "E03", "mode": "double", "top": { "label": "양", "max": "3/4" }, "bottom": { "label": "자 2/3로 잰 횟수" }, "anchors": [["2/3", "1"]], "ops": ["divide", "multiply"], "goal": "reciprocal" }
  ```
- **과제:**
  1. 위 1/3에 대응하는 아래 값 / 판정: 1/2
  2. 위 1에 대응하는 아래 값 / 판정: 3/2
  3. 3/4 ÷ 2/3을 곱셈식으로 / 판정: `equivalent-expr` 3/4 × 3/2, 값 9/8
  4. 다른 수로 일반화: 5/6 ÷ 3/5 / 판정: 25/18
  5. A 단계: 1 1/2 ÷ 3/4, 4 ÷ 2/5 / 판정: 2, 10
- **CPA 페이딩:** P: 이중 수직선 / A: 식 줄 입력(수식 키패드), 이중 수직선은 힌트 ②

## g6s2u2 소수의 나눗셈
| 항목 | 내용 |
| --- | --- |
| 영역 | 수와 연산 |

| 선수 단원 | g6s1u3 소수의 나눗셈 |
| 차시 규모(참고) | 교과서 약 8차시 중 앱 활용 3차시 |

**핵심 아이디어:** 나누어지는 수와 나누는 수에 같은 수(10, 100)를 곱해도 몫은 변하지 않는다. 그래서 (소수)÷(소수)를 (자연수)÷(자연수)로 바꿀 수 있다. 하지만 *나머지*는 원래 크기 단위로 돌아가 읽어야 한다.

### 활동
#### g6s2u2.A1 동시 10배 확대경 — E07 `div`·`decimal` + E03 `decimal` · P→A
- **원 계획서:** 피제수·제수 동시 10배·100배 확대경
- **화면과 조작:** 문제 `1.68 ÷ 0.24`. 확대경 버튼 ×10, ×100을 누르면 두 수가 *동시에* 같은 배수로 커지며 수직선 위 두 막대(1.68, 0.24)도 같은 비율로 늘어난다. "막대 0.24가 몇 번 들어가는지는 그대로" 카운터가 7을 유지한다. 한쪽만 키우는 버튼(실험용)을 누르면 카운터가 바뀌어 반례가 된다. 그다음 세로셈 격자에서 168 ÷ 24 계산.
- **설정 예시:**
  ```json
  { "mode": "div", "decimal": true, "dividend": "1.68", "divisor": "0.24", "magnifier": [10, 100], "allowOneSideScale": true, "linkedNumberLine": "E03" }
  ```
- **과제:**
  1. 1.68 ÷ 0.24에서 자연수 나눗셈이 되는 배수 / 판정: 100, 몫 7
  2. 한쪽만 10배 했을 때 몫 / 판정: 관찰값 기록 + "달라진다" 선택
  3. 4.5 ÷ 0.15 / 판정: 30
  4. 2.73 ÷ 1.3 (나누는 수 소수 한 자리) / 판정: 2.1
  5. 5 ÷ 0.4 / 판정: 12.5
- **CPA 페이딩:** P: 확대경 + 수직선 / A: 세로셈만

#### g6s2u2.A2 리본 자르기와 나머지 레이저 가이드 — E03 `decimal` + E07 `div` · C→P→A
- **원 계획서:** 리본 자르기 '나머지 원래 소수점 위치' 수직 레이저 가이드
- **화면과 조작:** 리본 7.4m를 1.5m씩 자른다. 학생이 가위로 자를 때마다 조각이 아래로 떨어지고, 남은 리본이 수직선에 표시된다. 세로셈(74 ÷ 15)의 나머지 칸 14에서 위쪽 수직선으로 세로 레이저가 올라가 실제 남은 길이 1.4m 지점에 꽂힌다(14가 아님). 몫을 반올림해 나타내는 과제에서는 몫 소수 둘째 자리까지 계산 후 E03 `rounding` 위젯.
- **설정 예시:**
  ```json
  { "engine": "E03", "mode": "decimal", "story": "ribbon", "total": "7.4", "piece": "1.5", "remainderLaser": true }
  ```
- **과제:**
  1. 몇 도막, 남는 길이 / 판정: 4도막, 1.4m
  2. 세로셈 나머지를 원래 단위로 쓰기 / 판정: 1.4 입력(14 아님)
  3. 검산식 쓰기: 1.5 × 4 + 1.4 = 7.4 / 판정: 식 동치
  4. 10 ÷ 3 몫을 소수 첫째 자리까지 반올림 / 판정: 3.3
- **CPA 페이딩:** C: 가위로 자르기 / P: 레이저 / A: 식만

- **화면과 조작:** 화면 4분할(태블릿 가로 기준): 왼쪽 큰 3D 뷰(중앙), 오른쪽에 위·앞·옆 직교 투영 뷰 3개. 3D 뷰에서 바닥 격자(5×5)나 기존 쌓기나무 윗면을 누르면 쌓기나무가 놓이고, 길게 누르면 제거. 손가락 두 개로 회전(마우스: 오른쪽 드래그), 회전 스냅 버튼(위·앞·옆·대각). 놓을 때마다 투영 3개가 즉시 갱신된다. 투영 뷰 칸을 누르면 그 칸에 영향을 주는 3D 기둥이 강조된다. 숨은 쌓기나무를 보려면 "반투명" 토글. 바닥 격자에 "앞" 표시가 늘 있어 방향 혼동을 막는다.
  - 반응성: 쌓기나무 100개까지 30fps(저가 크롬북). 미달 시 등각 2D 렌더로 자동 전환(조작 동일, 회전은 90° 단위).
- **설정 예시:**
  ```json
  { "mode": "cubes", "grid": [5, 5], "maxHeight": 5, "views": ["top", "front", "side"], "sideDirection": "right", "frontMarker": true, "translucentToggle": true, "fallback": "isometric-2d" }
  ```
- **과제:**
  1. 자유 쌓기 후 앞에서 본 모양 고르기(보기 4개) / 판정: 선택 = 실제 투영
  2. 주어진 3D 모양(10개, 1개 숨음)의 개수 / 판정: 10 (숨은 칸 포함)
  3. 앞에서 본 모양이 주어진 투영과 같도록 쌓기 / 판정: Observation `front` 투영 = 목표
  4. 위·앞 두 투영을 동시에 만족하도록 쌓기 / 판정: 두 투영 모두 일치
  5. 회전 없이(3D 뷰 고정) 옆에서 본 모양 예측 → 회전해 확인 / 판정: 예측 기록 + 정오
- **CPA 페이딩:** C: 3D 자유 조작 / P: 3D 회전 잠금, 투영 뷰 중심 / A: 3D 숨김(A2·A3로)

#### g6s2u3.A2 위에서 본 모양에 수 쓰기와 층별 슬라이서 — E12 `cubes` · P→A
- **원 계획서:** 층별 슬라이서
- **화면과 조작:** ① 수 쓰기: 위에서 본 모양 격자의 각 칸에 숫자를 입력하면(키패드) 3D 뷰에 기둥이 그 높이로 솟아오른다. 반대로 3D 모양을 보고 숫자를 채우는 과제도 있다. ② 층별 슬라이서: 3D 뷰 옆 세로 슬라이더로 1층, 2층, 3층을 고르면 그 층만 남고 나머지가 반투명해지며, 아래 층별 그림 패널(층마다 위에서 본 2D 격자)에 같은 칸이 칠해진다. 학생이 층별 그림을 직접 칠하면 3D가 그에 맞게 생성된다.
- **설정 예시:**
  ```json

  ```
- **과제:**
  1. 3D를 보고 위에서 본 모양에 수 쓰기 / 판정: 격자 = target
  2. 수가 쓰인 위에서 본 모양 → 개수 / 판정: 합 = 10
  3. 2층 그림 칠하기 / 판정: 2층 칸 집합 일치
  4. 층별 그림 3장만 보고 3D 만들기 / 판정: 복셀 집합 일치
  5. 층별 그림이 불가능한 경우 찾기(2층에 칸이 있는데 그 아래 1층 칸이 비어 있음) / 판정: 불가능 그림 선택 + 이유 카드 "공중에 뜬다"
- **CPA 페이딩:** P: 3D와 2D 동시 / A: 2D만, 3D는 확인 버튼 누른 뒤에만

#### g6s2u3.A3 투영 탐정: 최소·최대 개수 — E12 `cubes` · P→A

- **화면과 조작:** 위·앞·옆 투영 3장만 주어지고 3D 뷰는 비어 있다. 학생이 3D에 쌓아 세 투영을 모두 만족시키면 초록 테두리. 그다음 "더 적게(최소)", "더 많이(최대)" 도전: 같은 투영을 유지하면서 쌓기나무 수를 바꿔 본다. 기록 패널에 시도한 개수가 쌓이고, 최소·최대를 찾으면 별 표시.

  2. 최소 개수 / 판정: 엔진이 계산한 최솟값과 일치
  3. 최대 개수 / 판정: 엔진 최댓값과 일치
  4. 위에서 본 모양에 수까지 주어지면 모양이 하나로 정해짐을 확인 / 판정: "하나뿐" 선택

### 활동
#### g6s2u4.A1 외항·내항 격자 넓이 동치 저울 — E06 `proportion` + E20 `proportion-grid` · C→P→A
- **원 계획서:** 외항·내항 격자 넓이 동치 저울
- **화면과 조작:** 비례식 `2 : 3 = 4 : 6` 카드. 외항(2, 6)으로 만든 직사각형 격자와 내항(3, 4)으로 만든 직사각형 격자가 저울 양쪽 접시에 올라간다. 넓이(칸 수)가 같으면 수평. □가 있는 비례식(`3 : 5 = □ : 20`)에서는 □ 직사각형의 한 변 슬라이더를 움직여 저울을 수평으로 만든다. 비례식이 아닌 두 비(2 : 3과 3 : 4)를 넣으면 기울어진다.
- **설정 예시:**
  ```json
  { "engine": "E06", "mode": "proportion", "equation": "3 : 5 = □ : 20", "visual": "grid-area", "unknownSlider": { "min": 1, "max": 20 } }
  ```
- **과제:**
  1. 비례식인 것 고르기(카드 3장) / 판정: 저울 수평 카드 선택
  2. 3 : 5 = □ : 20 / 판정: 12, 저울 수평
  3. 0.4 : 1.2를 간단한 자연수 비로 / 판정: 1 : 3
  4. 1/2 : 1/3을 간단한 자연수 비로 / 판정: 3 : 2
  5. A 단계: 7 : □ = 21 : 27 / 판정: 9
- **CPA 페이딩:** C: 슬라이더 / P: 격자 그림 / A: 식만

#### g6s2u4.A2 문장제 형광펜과 막대 모델 — E20 `bar-model` · P→A
- **원 계획서:** 문장제 형광펜 연동 싱가포르식 막대 모델(Bar Model) 분할 빌더
- **화면과 조작:** 문장제("사탕 35개를 형과 동생이 3 : 4로 나누어 가지려고 한다…")가 위에 있다. 학생이 문장 속 수와 낱말을 형광펜으로 칠하면(전체=노랑, 비=초록) 아래 막대 모델에 연결된다: 전체 막대 35, 형 막대 3칸, 동생 막대 4칸. 막대 한 칸의 크기를 구하는 칸(35 ÷ 7) 입력 후 각자 몫이 채워진다.
- **설정 예시:**
  ```json
  { "mode": "bar-model", "problem": "사탕 35개를 형과 동생이 3 : 4로 나누어 가지려고 합니다. 각각 몇 개씩 가질까요?", "highlightTargets": { "total": "35", "ratio": ["3", "4"] }, "parts": ["형", "동생"] }
  ```
- **과제:**
  1. 형광펜으로 전체와 비 찾기 / 판정: 칠한 토큰 = 목표 토큰
  2. 막대 한 칸 크기 / 판정: 5
  3. 각자 몫 / 판정: 15, 20
  4. 전체 48cm 끈을 5 : 3으로 / 판정: 30, 18
  5. 거꾸로: 형이 24개, 비 3 : 5일 때 전체 / 판정: 64
- **CPA 페이딩:** P: 막대 모델 / A: 막대 숨김, 식 `35 × 3/7` 입력

### 활동
#### g6s2u5.A1 굴렁쇠 물감 굴리기 — E13 `length` · C→P→A
- **원 계획서:** 굴렁쇠 물감 굴리기 원주율(π ≈ 3.14) 발견 실험
- **화면과 조작:** 지름을 슬라이더로 정한 굴렁쇠 둘레에 물감 점이 하나 찍혀 있다. 굴리기 버튼(또는 손가락으로 밀기)으로 한 바퀴 굴리면 바닥 자 위에 물감 자국 두 개가 찍히고, 그 사이 거리(원주)가 측정된다. 바닥 자 위에 지름 막대를 이어 붙이기 도구로 원주에 지름이 몇 번 들어가는지 잰다(3번 + 조금). 결과는 기록표(지름, 원주, 원주 ÷ 지름)에 쌓인다.
- **설정 예시:**
  ```json
  { "mode": "length", "variant": "roll-circle", "diameters": [2, 3, 5, 8, 10], "unit": "cm", "precision": "0.01", "diameterStickTool": true, "log": true }
  ```
- **과제:**
  1. 지름 2, 5, 10인 굴렁쇠 굴려 기록 / 판정: 기록 3개 이상
  2. 원주에 지름이 몇 번 들어가나 / 판정: "3번과 조금" 선택
  3. 원주 ÷ 지름 값의 공통점 / 판정: "모두 약 3.14" 선택
  4. 지름 7cm 원의 원주(원주율 3.14) / 판정: 21.98
  5. 원주 31.4cm인 원의 지름 / 판정: 10
- **CPA 페이딩:** C: 굴리기 / P: 기록표 / A: 식만

#### g6s2u5.A2 원 등분 극한 직사각형 — E11 `circle-sectors` · C→P→A
- **원 계획서:** 원 8 → 256등분 극한 직사각형(πr × r) 수렴 시뮬레이터
- **화면과 조작:** 반지름 r인 원. 등분 슬라이더 8 → 16 → 32 → 64 → 128 → 256. 8등분에서는 학생이 부채꼴 조각을 직접 끌어 위아래 엇갈려 붙인다(자석 스냅). 16등분 이상은 "자동 배열" 애니메이션. 등분 수가 커질수록 윗변이 평평해지며 직사각형에 가까워지고, 가로(원주의 절반)와 세로(반지름) 표시선이 나타난다. 넓이 식을 단계별로 채운다.
- **설정 예시:**
  ```json
  { "mode": "circle-sectors", "radius": 5, "divisions": [8, 16, 32, 64, 128, 256], "manualUpTo": 8, "showDimensions": true }
  ```
- **과제:**
  1. 8조각을 엇갈려 붙이기 / 판정: 배열 완료(조각 교대 배치)
  2. 등분을 늘리면 어떤 도형에 가까워지나 / 판정: "직사각형"
  3. 직사각형의 가로 = 원주의 □ / 판정: 1/2 (반)
  4. 넓이 식 완성: (원주 × 1/2) × 반지름 → 반지름 × 반지름 × 원주율 / 판정: 식 동치
  5. 반지름 6cm 원의 넓이 / 판정: 113.04
- **CPA 페이딩:** C: 조각 끌기 / P: 애니메이션 / A: 식만

#### g6s2u6.A1 회전 물레와 레이저 단면 — E12 `lathe`·`cross-section` · C→P
- **원 계획서:** 평면도형 360° 고속 회전 물레(LatheGeometry) 및 레이저 단면 절단기
- **화면과 조작:** 축(세로선) 옆에 평면도형(직사각형·직각삼각형·반원·기타 모양) 카드를 붙인다. 회전 핸들을 돌리면 도형이 축을 따라 돌며 잔상이 쌓이고 360°에서 입체가 완성된다. 레이저 절단기: 수평 레이저(축에 수직)와 수직 레이저(축을 포함)를 위아래로 움직이면 단면 모양이 옆 패널에 2D로 표시된다.
- **설정 예시:**
  ```json
  { "mode": "lathe", "profiles": ["rectangle", "right-triangle", "semicircle", "custom"], "axis": "vertical", "crossSection": { "planes": ["perpendicular", "through-axis"] } }
  ```
- **과제:**
  1. 원기둥이 되는 평면도형 고르고 돌리기 / 판정: 직사각형 + 결과 원기둥
  2. 원뿔 / 판정: 직각삼각형(직각을 낀 변이 축)
  3. 구 / 판정: 반원(지름이 축)
  4. 원뿔을 축에 수직으로 자른 단면 / 판정: "원" 선택
  5. 원기둥을 축을 포함하도록 자른 단면 / 판정: "직사각형" 선택
- **CPA 페이딩:** C: 직접 회전 / P: 결과 입체와 단면 그림 / A: 그림 없이 예측

#### g6s2u6.A2 원기둥 굴려 옆면 펼치기 — E12 `net-fold` · C→P→A
- **원 계획서:** 원기둥 밑면 원주-옆면 가로 롤링 매칭
- **화면과 조작:** 원기둥 옆면에 물감을 바르고 바닥 위로 한 바퀴 굴리면 직사각형 자국이 찍힌다. 그 직사각형의 가로 위로 밑면 원을 굴리면 정확히 한 바퀴에 끝난다(매칭 하이라이트). 전개도 조립: 원 2개 + 직사각형 1개를 학생이 크기를 조정해 맞추고 접기.
- **설정 예시:**
  ```json
  { "mode": "net-fold", "target": "cylinder", "radius": 2, "height": 5, "rollPaint": true, "editablePieces": ["circle", "circle", "rect"] }
  ```
- **과제:**
  1. 옆면 직사각형 가로와 밑면 원주 비교 / 판정: "같다" 선택
  2. 반지름 2cm, 높이 5cm 원기둥 전개도 옆면 가로 / 판정: 12.56
  3. 크기를 맞춰 전개도 조립 후 접기 / 판정: 유효(옆면 가로 = 원주, 허용 오차)
  4. 원기둥 vs 각기둥 비교 표 채우기 / 판정: 항목 일치
- **CPA 페이딩:** C: 굴리기 / P: 전개도 조립 / A: 치수만 보고 계산
