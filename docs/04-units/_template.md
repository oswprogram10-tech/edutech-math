# 단원 명세 템플릿과 작성 규칙

`docs/04-units/g{학년}s{학기}.md` 파일 하나에 그 학기 단원을 모두 적는다(12개 파일, 71개 단원).
단원 ID·제목·엔진·선수 단원은 반드시 `data/units.json`과 일치해야 한다(검사 스크립트가 확인).

## 이름 규칙
- **단원 ID:** `g5s1u4` = 5학년 1학기 4단원
- **활동 ID:** `g5s1u4.A1`, `g5s1u4.A2` …
- **개념 노드 ID:** `g5s1u4.common-denominator` (단원 ID + 영문 kebab-case). 다른 단원의 개념을 선수로 걸 때는 그 단원의 개념 ID 또는 단원 ID 전체(`g4s2u1`)를 쓴다.
- **오개념 코드:** `MC-주제-요약` 대문자 (예: `MC-FRAC-ADD-DENOM` 분모끼리 더함). 여러 단원에서 같은 오개념이면 같은 코드를 재사용한다.

## 힌트 사다리 (모든 활동 공통)
정답을 보여 주지 않는다. 같은 과제에서 막히면 단계가 올라간다.
1. **발문** — 학생이 지금 본 것에 대해 묻는다. ("조각 크기가 모두 같아?")
2. **시각적 반례/부분 시연** — 엔진이 학생의 답이 왜 성립하지 않는지 *그림으로* 보여 준다. 정답 상태로 바꿔 주지 않는다.
3. **역추적 부스터** — 선수 개념의 짧은(2~3분) 마이크로 활동으로 보낸다. 학년 표시 없음. 끝나면 원래 과제로 돌아온다.
