## 목표
g6s2u6.A2 「원기둥 굴려 옆면 펼치기」를 위해 E12에 원기둥 전개도를 더한다.
- **굴리기:** 물감을 바른 원기둥을 바닥에 눕혀 굴리면 직사각형 자국이 찍힌다. 한 바퀴를 다 굴리면 밑면 원 위 표시점이 다시 바닥에 닿고, 자국 끝과 맞는다(매칭 강조).
- **맞추기:** 학생이 직사각형 1개와 원 2개의 크기를 단추로 바꿔 전개도를 만든다.
- **접기:** 접으면 옆면이 밑면을 감싼다. 옆면 가로가 모자라면 틈이, 남으면 겹침이 보인다.

설정은 `{"mode":"net-fold","target":"cylinder",…}`이고 상태·관찰의 `mode`는 `'cylinder-net'`이다(T143 `prism-net`과 같은 방식).

### 2. 설정 `CylinderNetConfig`
| 키 | 형식 | 기본 | 뜻 |
| --- | --- | --- | --- |
| `mode` | `'net-fold'` | — | |
| `target` | `'cylinder'` | — | |
| `radius` | 정수 또는 0.5 단위 수(1~5) | 2 | 원기둥 밑면 반지름(cm) |
| `height` | 정수(1~10) | 5 | 원기둥 높이(cm) |
| `pi` | 문자열 `"3.14"`·`"3.1"`·`"3"` | `"3.14"` | 원주율(Rational로 읽는다) |
| `steps` | `('roll'\|'assemble')[]` | `["roll","assemble"]` | 보일 단계. 빈 배열이면 원기둥 그림만 보인다 |
| `rollPaint` | boolean | true | `roll` 단계에서 자국을 찍을지 |
| `showDims` | boolean | true | 원기둥 그림에 반지름·높이 치수 글을 쓸지(주어진 재료라 써도 된다) |
| `start` | `{width?, radius?, height?}` | `{width:"6", radius:"1", height:"3"}` | 맞추기 조각의 처음 크기(문자열 소수) |
| `editablePieces` | 배열 | 무시 | 명세 예시 호환용. 읽기만 하고 쓰지 않는다 |
- 숫자 범위를 벗어나면 기본값으로 돌린다. `pi`가 위 셋이 아니면 `"3.14"`로 한다.

### 3. 수 다루기(절대 규칙 2)
- 상태에는 정수만 둔다.
  - `rollEighths`: 0~8, 굴린 양을 1/8바퀴 단위로 센다.
  - `widthTenths`: 10~400, 옆면 가로를 0.1cm 단위로 센다.
  - `pieceRadiusHalves`: 1~10, 원 조각 반지름을 0.5cm 단위로 센다.
  - `pieceHeightHalves`: 2~20, 옆면 세로를 0.5cm 단위로 센다.
- 판정 계산은 `cylnet/model.ts`에서 `Rational`로 한다.
  - `circumference(r, pi) = 2 × pi × r`
  - 옆면 가로 맞음: `|width − 2 × pi × pieceRadius| ≤ 1/10`
  - 전개도 맞음(`valid`)은 세 가지가 모두 참일 때다.
    - 조각 반지름 = 설정 `radius`
    - 옆면 세로 = 설정 `height`
    - 옆면 가로 맞음
- 화면 좌표(픽셀)만 number로 계산한다. `toNumber` 같은 변환은 그리기에서만 쓴다.

### 4. 상태·Action
```ts
interface CylinderNetState {
  mode: 'cylinder-net';
  settings: {radiusHalves, heightHalves, pi: string, steps, rollPaint, showDims};
  step: 'roll' | 'assemble' | null;      // steps가 비면 null
  rollEighths: number;
  widthTenths: number; pieceRadiusHalves: number; pieceHeightHalves: number;
  folded: boolean;
  viewYaw: number;                       // 화면용(0~345, 15 단위), 판정에 안 씀
}
```
| Action | 하는 일 |
| --- | --- |
| `cn-set-step {step}` | 단계 바꾸기. 설정 `steps`에 없는 단계면 무시 |
| `cn-roll {by: 1}` / `cn-roll {by: -1}` | 1/8바퀴 굴리기·되돌리기(0~8로 자름). `roll` 단계에서만 |
| `cn-roll-full` | 0이면 8로, 8이면 그대로. `roll` 단계에서만 |
| `cn-roll-reset` | 0으로 |
| `cn-width {by}` | `by`는 ±10(1cm) 또는 ±1(0.1cm). 범위로 자름. `assemble`에서만. `folded`면 무시 |
| `cn-radius {by: ±1}` | 0.5cm씩 |
| `cn-height {by: ±1}` | 0.5cm씩 |
| `cn-fold` / `cn-unfold` | 접기·펴기. `assemble`에서만 |
| `cn-rotate-view {by}` | 화면 돌리기(15° 단위) |
- `rollPaint`가 false면 자국을 그리지 않는다. 그래도 `rollEighths`는 센다.

### 5. 화면
**바깥 틀**
- 단계 단추 '① 굴려 보기', '② 전개도 맞추기'. 설정 `steps`에 있는 것만 보인다.

**`RollStage`**(굴리기)
- 앞에서 본 그림이다. 원기둥이 바닥에 누워 있고, 밑면 원이 보인다. 원기둥의 길이 방향은 비스듬히 보이게 한다.
- 굴리면 원기둥이 오른쪽으로 `rollEighths/8 × 원주`만큼 간다. 화면 비율은 실제 비율 그대로다.
- 밑면 원 위의 표시점이 그만큼 돈다. 이 점은 색과 모양(채운 삼각형) 둘 다로 구별한다.
- 바닥에 찍히는 자국 직사각형:
  - 가로 = 지나간 거리, 세로 = 원기둥 높이를 비스듬히 그린 것
  - 자국 끝에 세로 점선 표시가 있다.
- `rollEighths=8`이면 다음을 한다.
  - 표시점이 다시 바닥에 닿은 자리와 자국 끝 점선을 같이 굵게 강조한다.
  - 강조 글은 "한 바퀴"만 쓴다. "같아요", 길이 수는 쓰지 않는다.
- 단추:
  - '▶ 조금 굴리기'(1/8), '◀ 되돌리기', '한 바퀴 굴리기', '처음으로'
  - 움직임 연출은 `shapesMotion`의 방식을 따른다. 움직임 줄이기 설정이면 바로 끝 위치로 간다.
- 자국과 원기둥에 길이 수를 쓰지 않는다. `showDims`면 원기둥 그림에 "반지름 2cm", "높이 5cm" 글만 쓴다.

**`CylNetBoard`**(맞추기·접기)
- 왼쪽: 학생이 만드는 전개도.
  - 옆면 직사각형이 가운데 있고, 원 두 개가 직사각형 위·아래 변에 붙는다.
  - 비율은 실제 크기 그대로이고, 전체가 판에 들어오게 같은 배율로 줄인다.
  - 조각 옆에 학생이 정한 값을 쓴다. 학생이 넣은 값이라 노출이 아니다.
- 오른쪽: 조절 단추.
  - 옆면 가로: −1, −0.1, +0.1, +1
  - 옆면 세로: −0.5, +0.5
  - 밑면 반지름: −0.5, +0.5
  - 접기·펴기
- 접으면 비스듬히 본 원기둥 그림이 된다.
  - 옆면이 밑면 원 둘레를 감싼다.
  - 모자라면 틈을 빗금 띠로, 남으면 겹침을 진한 띠로 그린다. 띠의 폭은 실제 차이에 비례하고, 최소 4px로 보이게 한다.
  - 높이가 다르면 옆면이 밑면보다 짧거나 길게 보인다.
  - 맞으면 이음선이 실선 하나로 닫힌다.
  - 틈·겹침·맞음을 글로 쓰지 않는다. 그림의 띠와 이음선만으로 보여 주고, 색만으로 구별하지 않는다(빗금·진한 띠).
  - `aria-label`도 "접은 모습"까지만 쓴다.
- 반지름·세로가 설정과 달라도 접을 수 있다. 접은 그림은 학생 조각 그대로 그린다.

**공통**
- 터치 타깃은 48px 이상이다(6학년).
- 키보드:
  - `→`/`←` 굴리기·되돌리기, `Space` 한 바퀴, `1`/`2` 단계
  - `A`/`D` 가로 ±0.1, `Shift+A`/`Shift+D` 가로 ±1
  - `W`/`S` 세로, `R`/`F` 반지름, `Enter` 접기·펴기
  - 단축키 안내 한 줄을 판 아래에 둔다(다른 모드와 같다).
- 크롬북 `?stage=fit`에서 굴리기 무대, 단추, 전개도 판, 조절 단추가 `ratio:1`이어야 한다.
  - 반지름 2, 높이 5 기준으로 본다.
  - 원주 12.56cm가 가장 넓게 펼쳐지는 상황인 반지름 5, 높이 10도 넘치지 않아야 한다.

### 6. Observation(`cylinder-net`)
```ts
{ mode:'cylinder-net', radius: string, height: string, pi: string,
  step, rollEighths, rolledFull: boolean,
  net: { width: string, radius: string, height: string },   // 소수 문자열("12.6")
  widthFits: boolean, radiusMatches: boolean, heightMatches: boolean, valid: boolean,
  folded: boolean, seam: 'gap' | 'overlap' | 'closed' }
```
- 수는 `Rational`의 `toDecimalString()` 결과다.
- `seam`은 가로만 보고 정한다. 맞음이면 `closed`, 모자라면 `gap`, 남으면 `overlap`이다.

### 7. predicate
| 이름 | 뜻 |
| --- | --- |
| `rollComplete` | `rolledFull` |
| `netValid` | `valid` |
| `netFoldedClosed` | `folded && valid` |
| `netWidthIs {value}` | `net.width`가 `value`(소수 문자열)와 Rational로 같음. 오개념 감지용(예: 지름 4) |
- 다른 모드 관찰에서는 모두 false다.
- 다른 모드 predicate는 이 모드 관찰에서 false다. 단위 테스트로 확인한다.

### 8. 오버레이 `roll-match` (MC-CYL-NET-WIDTH-DIAMETER, 힌트 ②)
- 굴리기 무대 위에 다음을 그린다.
  - 밑면 원이 한 바퀴 굴러 바닥에 남긴 선(원주 길이)
  - 그 아래에 지름 길이의 막대 하나를 나란히 둔다.
- 지름 막대가 한 바퀴 선보다 훨씬 짧은 것이 보이면 된다. 수는 쓰지 않는다.
- 정렬 기준(앵커):
  - `roll` 단계에서는 굴리기 무대 svg에 맞춘다.
  - `assemble` 단계에서는 전개도 판 svg에 맞추고, 옆면 가로 아래에 그린다.
  - 앵커 선택자는 `HelperDiagramBox`/`CanvasAlignedOverlay` 방식을 따르고 svg를 가리켜야 한다(T148 10번 교훈).
- E2E: 두 단계에서 각각 1px 정렬을 확인하고, 단추와 겹치지 않는지 본다.

### 9. 테스트
**단위**
- `cylnet-model`
  - 원주 값: r=2, pi=3.14 → 12.56. r=0.5, pi=3 → 3. r=5, pi=3.1 → 31.
  - 가로 맞음의 경계(model 함수에 Rational을 바로 넣어 본다): 12.46과 12.66은 맞음, 12.45와 12.67은 아님.
  - 0.1 단위 상태에서는 12.5와 12.6이 맞음, 12.4와 12.7은 아님.
  - `seam` 세 경우
  - 반지름·세로 불일치
- `cylnet-engine`
  - 각 Action의 범위 자르기, 단계 막기, `folded` 중 가로 바꾸기 무시
  - 관찰 모양, predicate 4개, 모드 사이 false
  - JSON 직렬화 왕복
- `cylnet-view`
  - 화면 글에 원주·자국 길이 수가 없는지. "12.56", "12.5", "4π"가 들어가지 않는다.
  - 접은 그림의 `aria-label`에 틈·겹침 낱말이 없는지

**E2E** `solid-3d-cylnet.spec.ts`(Sandbox 설정으로)
- 굴리기
  - 키보드로 8번 굴리면 한 바퀴 강조가 보인다.
  - 되돌리면 사라진다.
- 맞추기
  - 키보드로 반지름 2, 세로 5, 가로 12.6으로 맞추고 접으면 `netFoldedClosed`가 된다.
  - 가로 4로 접으면 틈 띠가 보인다.
  - 가로 20으로 접으면 겹침 띠가 보인다.
- `roll-match` 정렬 1px(두 단계)
- 세 기기 `?stage=fit` ratio:1(크롬북 필수)
- 스냅샷(세 기기)
  - `cn-roll-half`: 4/8 굴린 화면
  - `cn-folded-gap`: 가로 4로 접은 화면
- 기존 스냅샷은 바뀌면 안 된다.
