## 구현 결정 (2026-11-05 Claude 작성 — 여기 적힌 대로 하고, 바꿔야 하면 메모에 이유를 적고 질문한다)
1. **폴더:** `src/engines/E07-column-calc/`와 `tests/e2e/column-calc.spec.ts`만 고친다. 새 파일은 `keyboard.ts` 하나(아래 4번). 다른 엔진·`src/core/`·콘텐츠 JSON·단원 E2E(`tests/e2e/units/`)는 고치지 않는다. 단원 E2E는 고치지 않은 채 그대로 통과해야 한다(화면 기준 이미지가 바뀌면 아래 7번).
2. **버그 1 — 나누어지는 수의 소수점(`DivView.tsx` 나누어지는 수 줄, 지금 510행 근처):**
   - 원인: 칸에 `data-point`만 달고 점을 그리지 않는다(`.cell[data-point='true']`는 z-index만 준다). 그래서 8.16 ÷ 4가 "8 1 6"으로 보인다.
   - 고침: `MulView.tsx`의 `pointMarker`와 같은 모양(`<span className={styles.pointDot} data-point-mark="true" aria-hidden="true">.</span>`)을 열 0 칸 안에 그린다(점은 그 칸 오른쪽 아래, 결과 줄과 같은 CSS).
   - 조건을 넓힌다: 지금 `numbers.G.fracDigits > 0 && column === 0`이라 3 ÷ 4처럼 G가 자연수이고 0을 붙인 경우("3.00")에 점이 없다. **`state.decimal && numbers.decimal && numbers.low < 0 && column === 0`**으로 바꾼다(G에 소수 자리가 있거나 0을 붙였으면 — T078 결정 3 그대로).
   - 읽기: 나누어지는 수 줄에 줄 이름표 aria-label을 둔다. `strings.ko.ts`에 `dividendRowLabel(text)` = "나누어지는 수 8.16"을 더하고, text는 지금 격자 수(G에 붙인 0을 더한 것, 예 `"3.00"`, `"168"`)를 문자열로 만든다. 이것은 문제에 주어진 수라 정답이 아니다. 칸마다의 aria-label은 지금 그대로 둔다.
3. **버그 1 — 몫의 소수점(`DivView.tsx` 몫 줄, 지금 450행 근처):** 몫 칸도 `data-point`만 달고 점을 그리지 않는다(점 놓기 줄 버튼 색만 바뀐다). `state.quotientPoint === column`인 몫 칸 안에 같은 `pointDot`을 그린다. 점 놓기 줄은 그대로 둔다. 몫 소수점 위치는 학생이 놓은 것이라 보여도 된다.
4. **버그 2 — 키 입력 범위(`keyboard.ts` 새 파일):**
   - 원인: E07 뷰 4개(`AddSubView`·`MulView`·`EstimateView`·`DivView`)가 `window`의 `keydown`을 듣고, 입력 요소(`INPUT`·`TEXTAREA`·`SELECT`·contentEditable)만 건너뛴다. 실행기 응답 수 칸(`src/core/runner/response/widgets/NumberWidget.tsx`)은 `tabIndex`가 있는 `div`라서 건너뛰지 못하고, 학생이 응답 칸에 친 숫자가 격자 칸에도 들어간다(크롬북 키보드, g4s2u3·g6s1u3 A2 T4·g6s2u2 A2 T2·T4).
   - 고침: `keyboard.ts`에 순수 함수 `isForeignKeyTarget(target: EventTarget | null, root: HTMLElement | null): boolean`을 둔다. 규칙: target이 `Element`이고, `document.body`도 `document.documentElement`도 아니고, root가 있고 `root.contains(target)`가 거짓이면 true. 그 밖(대상 없음, body에 초점, 엔진 안)은 false. 기존 입력 요소 검사도 이 파일의 `isTextEntryTarget(target)`으로 옮긴다.
   - 4개 뷰의 키 처리기 맨 앞에서 `if (isTextEntryTarget(event.target) || isForeignKeyTarget(event.target, rootRef.current)) return;`. root는 각 뷰의 가장 바깥 `div`(`styles.wrap`)에 `ref`를 단다(없으면 새로 만든다). 다른 조건·키 동작은 바꾸지 않는다.
   - 이 때문에 **초점이 엔진 밖 버튼(예: '보여 주기', '확인하기')에 있을 때 친 숫자도 격자에 들어가지 않는다**. 의도한 동작이다(학생은 칸을 눌러 고른 뒤 친다). 메모에 적는다.
   - 실행기(`src/core/runner/`)와 NumberWidget은 고치지 않는다.
5. **버그 3 — `-0` 열(`grid-div-decimal.ts` 127행 근처):**
   - 원인: `const baseLow = -G.fracDigits;`가 G가 자연수일 때 `-0`을 만든다. 열 반복이 `-0`에서 시작해 몫·점 칸의 `column`이 `-0`이 되고, `place-point {column: -0}`이 JSON 왕복에서 `0`이 되어 개발 모드 직렬화 경고가 뜬다(5 ÷ 0.4를 ×10 하면 G = 50).
   - 고침: `const baseLow = 0 - G.fracDigits;`처럼 `-0`이 나오지 않는 식으로 바꾸고, `grid-div-decimal.ts`·`grid-decimal.ts`·`DivView.tsx`·`MulView.tsx`에서 열 번호를 음수로 만드는 다른 곳(`-x` 꼴)도 같은 방식으로 정리한다(`grid-decimal.ts` 83·102행 `-parsed.fracDigits + …`는 더하기 결과가 `+0`이라 괜찮지만, 읽기 쉽게 `… - parsed.fracDigits`로 바꿔도 된다).
6. **정답 노출 금지:** 새로 그리는 점·aria-label에 몫·나머지·곱을 쓰지 않는다. 나누어지는 수 줄 이름표는 문제의 수(격자 수)만 쓴다.
7. **화면 기준 이미지:** 소수점이 새로 그려지므로 `tests/e2e/units/g6s1u3.spec.ts-snapshots/`·`g6s2u2.spec.ts-snapshots/`의 A2/A1 이미지가 달라질 수 있다. 달라지면 `--update-snapshots`로 **그 이미지만** 다시 만들고, 바뀐 이미지를 열어 나누어지는 수에 점이 보이는지 확인한 뒤 메모에 파일 이름을 적는다(스펙 코드는 고치지 않는다).
8. **테스트:**
   - **keyboard.ts 단위:** body·null → false, 엔진 root 안 버튼 → false, root 밖 `div[tabindex]` → true, root가 null → false, INPUT → `isTextEntryTarget` true.
   - **View(DivView):** 8.16 ÷ 4 시작 화면의 나누어지는 수 줄 열 0 칸에 `[data-point-mark]`가 하나 있음. 3 ÷ 4(decimal, `extendZeros` 2)는 0을 붙이기 전에는 점이 없고, 0을 하나 붙인 뒤 생김. 몫 점을 열 0에 놓으면 몫 줄에 `[data-point-mark]`가 생김. 1.68 ÷ 0.24 ×100(G = 168)은 나누어지는 수 줄에 점이 없음.
   - **View(키 범위):** 격자 옆에 엔진 밖 `div tabIndex=0`을 붙여 초점을 두고 `3`을 누르면 몫 칸이 그대로, 격자 칸에 초점을 두고 누르면 들어감. MulView·AddSubView도 같은 테스트 하나씩.
   - **-0:** `divGridNumbers`(5 ÷ 0.4, scale both 1)의 `low`·`baseLow`가 `Object.is(…, 0)`이 참. DivView에서 점 놓기 버튼을 눌러 나온 Action이 `isSerializable`(core engine-sdk)을 통과.
   - **E2E `tests/e2e/column-calc.spec.ts`(3개 뷰포트):** 8.16 ÷ 4에서 나누어지는 수 열 0 칸에 점 표시가 보임. 응답 칸 대신 엔진 밖 요소에 초점을 둔 채 숫자를 쳐도 몫 칸이 비어 있음(sandbox에는 응답 칸이 없으므로 `page.evaluate`로 엔진 밖 `div tabIndex=0`을 만들어 초점을 준다).
   - **기존:** E07 단위·View 테스트 전부, `tests/e2e/units/` 전부 그대로 통과.
