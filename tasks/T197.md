## 목표
E20 비·비율 실험실에 `bar-model` 모드를 더한다.
- 문장제의 수와 낱말에 형광펜을 칠한다(전체·비).
- 막대 모델에서 한 칸 크기와 각자 몫, 또는 전체를 구한다.

이 모드는 g6s2u4.A2(T198)에 쓴다.

## 구현 결정 (2026-11-20 Claude 작성 — 여기 적힌 대로 하고, 바꿔야 하면 메모에 이유를 적고 멈춰서 묻는다)

### 1. 설정
```ts
interface BarModelConfig {
  mode: 'bar-model';
  problem: string;                       // 문장. 띄어쓰기 단위로 토큰을 나눈다. 수는 붙은 조사·단위와 분리("35개를" → "35" + "개를")
  highlight?: { total?: string; ratio?: string[] } | null;  // 형광펜 목표 토큰 글자. null/생략이면 형광펜 단계 없음
  parts: string[];                       // 2~3개, 예: ["형", "동생"]
  ratio: number[];                       // parts와 같은 길이, 1~12 정수
  total?: number | null;                 // 전체(알려진 경우)
  known?: { part: number; value: number } | null;  // 거꾸로 문제: 한 사람 몫이 알려짐(total은 null)
  look?: 'bars' | 'symbols';             // P 막대 / A 막대 숨김 + 식 칸, 기본 'bars'
}
```
- `total`과 `known`은 둘 중 정확히 하나만 준다.
- total은 비의 합으로 나누어떨어져야 한다. known.value는 그 항으로 나누어떨어져야 한다. 아니면 설정 오류다(정수 칸만).
- 엔진은 설정으로 정답(한 칸 크기, 각자 몫, 전체)을 계산할 수 있다. 하지만 **그 값을 화면·DOM·aria에 쓰지 않는다.** Observation에는 학생이 쓴 값과 맞았는지(boolean)만 둔다.

### 2. 상태·Action
- **상태**
  - `marks: Record<tokenIndex, 'total'|'ratio'>`
  - `tool: 'total'|'ratio'|'erase'`
  - `unit: string|null`, `partValues: (string|null)[]`, `totalValue: string|null`
  - `expr: string|null`(symbols look의 식 칸)
- **Action**
  - `mark {index}`: 지금 도구로 칠하기·지우기. 수가 아닌 토큰도 칠할 수 있다.
  - `set-tool {tool}`
  - `set-unit {value}`
  - `set-part {index, value}`
  - `set-total {value}`
  - `set-expr {value}`
  - `reset`
- **값 칸:** 정수만 받는다. 식 칸은 숫자·`× ÷ + − ( ) /`만 받는다(E20 안의 작은 파서, core `parse`가 쓸 수 있으면 그것을 쓴다).

### 3. 화면
- **문장 줄:** 위에 둔다. 토큰마다 누를 수 있는 단추(48px 높이)다.
  - 칠한 토큰은 배경색과 함께 테두리 모양으로 표시한다. 전체는 굵은 실선, 비는 점선이다.
  - 앞에 "전체"·"비" 글 꼬리표를 붙인다. 색만으로 구별하지 않는다.
  - 도구 단추: [전체 칠하기] [비 칠하기] [지우기]
- **막대(bars)**
  - 사람마다 한 줄씩 둔다. 비의 항만큼 같은 크기 칸을 그린다. 모든 줄이 같은 칸 크기다.
  - 위에 전체 막대(모든 칸 합) 괄호와 전체 글을 둔다. 전체 글은 알려진 total이면 그 수이고, 아니면 "?"다.
  - 형광펜 단계가 있으면, 형광펜 목표를 맞히기 전에는 막대를 흐리게 둔다("문장에서 전체와 비를 먼저 찾아요").
  - 막대 한 칸 안에 학생이 쓴 한 칸 크기를 쓴다. 쓰기 전에는 빈칸이다. 줄 끝에 학생이 쓴 몫을 쓴다.
- **symbols:** 막대를 숨긴다. 식 칸(예: `35 × 3/7`)과 몫 칸만 둔다.
- **값 입력:** 숫자 키패드(0–9, ⌫) + 지금 고른 칸, 또는 물리 키보드
  - [한 칸 크기] [형 몫] [동생 몫] [전체] 칸을 Tab으로 오간다.
  - 칸은 과제 종류에 맞게 보인다. total이 있으면 전체 칸을 숨긴다. known이면 그 사람 몫 칸에 값을 고정해 보인다.

### 4. Observation·Predicates
- **Observation**
  - `mode:'bar-model'`
  - `marks`: `{total: number[], ratio: number[]}` 토큰 번호 목록
  - `highlightCorrect: boolean|null`: 칠한 토큰 글자 집합 = 목표 글자 집합. 형광펜 단계가 없으면 null
  - `unit`, `unitCorrect: boolean|null`
  - `partValues`, `partsCorrect: boolean[]`
  - `totalValue`, `totalCorrect: boolean|null`
  - `expr`, `exprValue: string|null`(식 칸 값, Rational 문자열), `exprMatchesPart: number|null`(식 값이 몫과 같은 사람 번호)
  - `partsSumMatches: boolean|null`(학생이 쓴 몫이 모두 있을 때 합 = 전체)
  - `misconceptions`
- **MC-PROPORTION-DIVIDE-BY-RATIO-TERM:** 다음 중 하나면 기록한다.
  - 학생 unit = total ÷ (어느 한 항)이다. 나누어떨어지지 않는 수를 쓰면 정수 칸이라 받을 수 없으므로, '그 몫의 정수 부분'도 포함한다.
  - 모든 몫을 쓴 뒤 합이 전체와 다르다.
  - expr 값 = total ÷ 한 항이다.
- **Predicates:** `highlightCorrect`, `unitCorrect`, `partCorrect {index}`, `allPartsCorrect`, `totalCorrect`, `exprMatchesPart {index}`, `hasMisconception {code}`

### 5. 오버레이
- **`unit-count`**(MC ②): 막대의 모든 칸에 1부터 번호를 매기고, 전체 괄호 위에 "모두 n칸"을 쓴다. n = 비의 합이다. 이는 막대 칸 수라 답(한 칸 크기)이 아니다.
- **`share-bracket`**(일반 ②): 한 사람 줄의 칸들을 괄호로 묶고 "a칸"을 쓴다. 그 사람 몫 = 한 칸 크기 × a가 보이게 한다. 값은 쓰지 않는다.
- symbols look에서는 둘 다 그리지 않는다.

### 6. 등록과 테스트
- `modes`에 `bar-model`을 더하고, fit-canvas E20 modes에 더한다.
- 샌드박스 기본: 사탕 35개 3 : 4 문제, highlight 있음
- 기존 mix·resize·rate·percent 기준 이미지가 샌드박스 모드 상자 너비 때문에 도구 줄만 밀리면, 그 이미지만 다시 찍고 메모에 적는다(Opus 허락). 엔진 그림이 달라졌으면 멈추고 묻는다.
- **단위**
  - 토큰 나누기("35개를" → "35","개를")
  - 형광펜 맞음·틀림
  - unit 5 → unitCorrect
  - unit 11(35 ÷ 3의 정수 부분) → MC
  - 몫 15·20 → allPartsCorrect
  - 몫 합 ≠ 35 → MC
  - 거꾸로(known 형 24, 3 : 5) → unit 8, total 64
  - expr `35 × 3/7` → exprMatchesPart 0
  - 설정 오류, JSON 왕복
  - View: 정답 수가 시작 화면 DOM에 없음
- **E2E**(`tests/e2e/ratio-lab.spec.ts`에 추가, 3 뷰포트)
  - 형광펜 → 막대 열림 → 값 넣기
  - 키보드만으로 한 번
  - symbols look
  - 오버레이 둘 1px 정렬
  - 첫 화면 스냅샷(bars·symbols)
  - 크롬북 좁은 판
- **E2E 범위:** `npx playwright test ratio-lab fit-canvas overlay-alignment --workers=3 --reporter=line`
