2. **core 기하 도우미 추가 (`src/core/math/geometry.ts`, 추가만, `index.ts` export 추가):** number 연산 없이 `Rational`로만.
   - **이차 무리수 `Surd`:** 원과 원의 교점 좌표는 대개 무리수다(정삼각형 꼭짓점은 √3). 부동소수 오차 판정 대신 `a + b√d` 꼴을 정확히 계산한다.
     - `export interface Surd { readonly a: Rational; readonly b: Rational; readonly d: Rational }` — `b = 0`이면 유리수이고 `d`는 0으로 둔다.
     - `surdOf(a: Rational): Surd`, `makeSurd(a, b, d): Surd`(d가 유리수 제곱이면 유리수로 접는다), `rationalSqrt(r: Rational): Rational | null`(분자·분모가 완전제곱일 때만, BigInt 정수 제곱근)
     - `surdAdd`, `surdSub`, `surdMul`, `surdDiv(x, y): Surd | null` — 두 무리 부분의 근호가 맞지 않으면(`d1·d2`가 유리수 제곱이 아니면) null. 맞으면 `√d2 = (√(d1·d2) / d1)·√d1`로 바꿔 계산한다. `surdNeg(x): Surd`
     - `surdSign(x): -1 | 0 | 1`(a·b 부호가 다르면 `a²`와 `b²d` 비교), `surdEquals(x, y): boolean`(근호가 안 맞으면 둘 다 유리수이고 같을 때만 true — 1, √d1, √d2의 일차독립)
     - `export interface SPoint { readonly x: Surd; readonly y: Surd }`, `toSPoint(p: GPoint): SPoint`, `sDist2(p, q)`, `sDot(u, v)`, `sCross(u, v)`, `sSub(p, q)` — 모두 `Surd | null`(SPoint는 null 가능)
   - **교점·회전:**
     - `circleCircleIntersections(c1: GPoint, r1sq: Rational, c2: GPoint, r2sq: Rational): SPoint[]` — 0·1·2개. `D² = |c2−c1|²`, `k = (r1sq − r2sq + D²) / (2D²)`, `s = r1sq/D² − k²`. s<0이면 [], s=0이면 1개, 아니면 `c1 + k·(dx,dy) ± √s·(−dy, dx)`. 순서: 0번은 `+√s`, 1번은 `−√s`. 중심이 같으면 [].
     - `lineLineIntersection(p1, p2, q1, q2): GPoint | null` — 평행이면 null.
     - `rationalRotate(v: GPoint, t: Rational): GPoint` — 각 `2·atan(t)`만큼 수학 방향 회전: `((1−t²)x − 2t·y, 2t·x + (1−t²)y) / (1+t²)`. 길이²가 정확히 보존된다.
     - `signedCos2(a, vertex, b): Rational` — `dot·|dot| / (|u|²|w|²)`. 두 각(0°~180°)이 같은 것과 이 값이 같은 것은 동치다. `sSignedCos2(a, vertex, b: SPoint): Surd | null`도 둔다.
   - **테스트(`src/core/math/__tests__/geometry.test.ts`에 추가):** `1 − √2 < 0`, `(√3)·(√3) = 3`, `√8`과 `2√2`가 같음(근호 맞추기), `√2 + √3`은 null, (0,0)·(2,0) 반지름² 4인 두 원의 교점 (1, ±√3), 접하는 원 1개, 떨어진 원 0개, 같은 중심 0개, `rationalRotate((1,0), 1) = (0,1)`, 큰 수(10⁹) 회전의 길이² 보존, 평행선 교점 null, 정삼각형 두 각의 `sSignedCos2`가 같음.
3. **좌표·표 (`rational-turns.ts`):**
   - `T_HALF: readonly (readonly [number, number])[]` — 24개 `[분자, 분모]` 리터럴. k번(0~23)은 `tan(3.75k°)`를 분모 48로 반올림한 값이다. 단 `T_HALF[0] = [0, 1]`, `T_HALF[12] = [1, 1]`(정확히 90° 회전)이다. 표는 스크립트로 한 번 만들어 리터럴로 적는다(실행 때 `Math.tan`으로 만들지 않는다 — 기기마다 반올림이 달라질 수 있다). 테스트: 각 값이 `tan(3.75k°)`와 0.011 안, 0번·12번 정확.
   - `turnT(index: number): Rational`, `T_INDEX_90 = 12`.
   - `circlePoint(center: GPoint, radiusVector: GPoint, pos: number): GPoint` — `pos` 0~47. 0~23은 `center + rationalRotate(radiusVector, turnT(pos))`, 24~47은 `center − rationalRotate(radiusVector, turnT(pos − 24))`. 그래서 `pos`와 `pos+24`는 정확히 지름의 양 끝이다. 화면 각은 약 `7.5·pos`°다(표가 근삿값이라 정확히 7.5°는 아니다 — 표시만 반올림).
   - `S_TABLE`: 비율 표 `1/4, 2/4, …, 12/4`(12개, 인덱스 3이 1). 
   - 화면 변환은 `layout.ts`에 `ratToScreen(r: Rational): number`(`Number(n)/Number(d)`), `surdToScreen(s: Surd): number`(`a + b·Math.sqrt(d)`)를 더한다. 화면에만 쓴다.
4. **성질 계산 (`properties.ts`):**
   - `figureProperties(points: readonly SPoint[]): FigureProps | null` — 단순화가 끝난 꼭짓점 목록을 받는다. 계산 중 근호가 안 맞아 null이 나오면 전체 null(성질 "알 수 없음").
   - `FigureProps`: `vertices`, `rightAngles`, `acuteAngles`, `obtuseAngles`, `reflexAngles`(내각 기준, 오목 꼭짓점은 다각형 방향과 꺾임 부호로 판단 — Rational 다각형만, 삼각형은 0), `parallelPairs`(이웃하지 않은 변 쌍 중 `cross = 0`인 수), `equalSides`(같은 길이²인 변 묶음 중 가장 큰 묶음의 크기, 모두 다르면 1), `equalAngles`(같은 `signedCos2` 묶음의 최대 크기), `convex`, `regular`(모든 변 같고 모든 각 같음), `names: FigureName[]`.
   - `FigureName`(포함 정의): 삼각형 `'triangle'`, `'isosceles'`(equalSides≥2, 정삼각형 포함), `'equilateral'`, `'scalene'`, 그리고 `'acute-triangle' | 'right-triangle' | 'obtuse-triangle'` 중 하나. 사각형 `'quadrilateral'`, `'trapezoid'`(평행 1쌍 이상, 포함 정의), `'parallelogram'`(2쌍), `'rhombus'`(네 변 같음), `'rectangle'`(직각 4개), `'square'`(둘 다). 모든 다각형 `'regular-polygon'`(regular일 때). 배타 정의 사다리꼴은 콘텐츠가 `parallelPairs == 1`로 판정한다.
   - `propertyKeys(props): string[]` — 흔들기 비교용 키: `equal-sides-2`, `equal-sides-3`, `equal-sides-4`, `equal-angles-2`, `equal-angles-3`, `right-angle`(1개 이상), `right-angles-4`, `obtuse-angle`, `all-acute`, `parallel-1`, `parallel-2`. 사각형은 대각선 키 `diagonals-bisect`, `diagonals-equal`, `diagonals-perpendicular`도 더한다(꼭짓점 0-2, 1-3 대각선으로 정확 계산).
   - **이름은 Observation·이벤트에만 쓴다. 어떤 설정에서도 학생 화면 글자로 쓰지 않는다.**
5. **`classify` 모드 (g3s1u2.A2 과제 2·3, g4s2u2.A2 과제 3의 E09 연동):**
   - **설정 `ClassifyConfig`:** `mode: 'classify'`(필수), geoboard와 같은 `grid`·`maxShapes`·`shapes`, `tools?: ('geoboard-band' | 'set-square')[]`(기본 `['geoboard-band']`, `geoboard-band`는 항상 켜짐), `showProperties?: ('rightAngles' | 'parallelSides' | 'equalSides' | 'angles')[]`(기본 `[]`), `rotatedShapes?`(받기만 하고 무시 — 판정은 방향과 무관하다).
   - **상태 `ClassifyState`:** `mode: 'classify'`, `bands`, `activeBand`, `nextId`, `squareOn: { band: string; index: number } | null`, `settings`(`grid`, `maxShapes`, `showCounts: 'never'`, `tools`, `showProperties`). 고무줄 Action은 `reduceBands`를 그대로 쓴다.
   - **Action 추가:** `place-square-at {band, index}`(닫힌 단순 도형의 단순화 전 못 번호), `remove-square`(construct와 같은 이름, 상태 모드로 나뉜다). 고무줄이 바뀌면(`move-peg`, `delete-band`) 그 고무줄의 `squareOn`은 null로.
   - **`showProperties`가 보여 주는 것(학생이 닫은 단순 도형에만, 닫은 뒤에만):**
     - `rightAngles`: 직각 꼭짓점에 ㄴ자 표시 + 옆 목록에 "직각 n개"
     - `parallelSides`: 평행한 변에 같은 수의 화살촉(`>`, `>>`) + "평행한 변 n쌍"
     - `equalSides`: 같은 길이 변 묶음마다 같은 수의 눈금(한 줄, 두 줄 …, 2개 이상인 묶음만) + "같은 길이 변 n개"(가장 큰 묶음)
     - `angles`: 모든 내각에 종류 표시만 — 직각 ㄴ자, 예각 호 한 줄, 둔각 호 두 줄, 오목 각 점선 호. **각도 숫자는 쓰지 않는다.**
     - 목록은 캔버스 옆 `data-testid="classify-properties"` 안에 고무줄별로 쓴다. 도형 이름(삼각형, 직사각형 등)은 쓰지 않는다. 기본 `[]`이면 아무것도 쓰지 않는다.
   - **직각삼각자:** `tools`에 `set-square`가 있을 때만. 꼭짓점에 대면 T100과 같은 그림(`setSquareShape`)으로 꼭 맞음/틈을 보인다. 학생이 댄 꼭짓점에만 결과를 보인다.
   - **키보드:** geoboard와 같다. 추가로 고무줄을 고르고 1~9로 꼭짓점을 고른 상태에서 `S`는 `place-square-at`, `Shift+S`는 `remove-square`(GeoboardView의 `onVertexKey`로 받는다).
   - **Observation:** geoboard의 `shapes`·`closedShapes`·`distinctBy`에 더해 `shapes[]`마다 `rightAngles`, `acuteAngles`, `obtuseAngles`, `reflexAngles`, `parallelPairs`, `equalSides`, `equalAngles`, `convex`, `regular`, `names`(단순 도형이 아니면 0·false·[]), 그리고 `squareOn`, `squareFits: boolean | null`.
   - **Predicates:**
     - `shapeHas {vertices?, rightAngles?, equalSides?, parallelPairs?, acuteAngles?, obtuseAngles?, convex?}` — 준 값이 모두 정확히 같은 단순 도형이 하나 이상
     - `shapesWith {count, distinct?, ...shapeHas와 같은 조건}` — 조건을 만족하는 도형이 count개 이상(`distinct: true`면 서로 합동이 아닌 것만 센다)
     - `shapeNamed {name}` — `names`에 그 이름이 있는 도형이 하나 이상
     - 예) g3s1u2.A2-3: `all[shapesWith {count:2, distinct:true, vertices:4, rightAngles:4}, shapeHas {vertices:4, rightAngles:4, equalSides:4}, shapeHas {vertices:4, rightAngles:4, equalSides:2}]`
   - **이벤트:** classify에서도 `shape-closed`를 내고 payload에 `names`를 더한다(E17 연동용, E09 화면에는 쓰지 않음).
6. **`drag-test` 모드 — 작은 의존 그래프 (g4s2u2.A1):**
   - **설정 `DragTestConfig`:** `mode: 'drag-test'`(필수), `construction?: 'free' | 'from-diagonals' | 'quad-conditions'`(기본 `free`), `lattice?: number`(자유점 격자 칸 수, 12~36, 기본 24), `tools?: DragTool[]`(기본 `['free-point','segment','compass','intersection']`, `move`는 항상 맨 앞에 붙는다), `measure?: ('sideLengths' | 'angles')[]`(기본 `[]`), `shakeButton?: boolean`(기본 false), `seed?: number`(uint32, 기본 1), `shakeRadius?: number`(1~6, 기본 3), `diagonalToggles?`, `quadToggles?`(7번), `classifyLive?: boolean`(기본 false), `goal?`(받기만 하고 무시 — 판정은 GoalSpec 몫).
   - `DragTool = 'move' | 'free-point' | 'segment' | 'compass' | 'intersection' | 'point-on-circle' | 'perpendicular' | 'parallel'`
   - **노드(`state.nodes`, 만든 순서):**
     - `{ id, kind: 'free', label, at: [i, j] }` — 정수 격자점(0~lattice). 점판 못은 그리지 않고 옅은 모눈(2칸마다)만 그린다.
     - `{ id, kind: 'on-circle', label, circle, pos }` — 원의 중심 c, 반지름 벡터 `to − from`으로 `circlePoint(c, to − from, pos)`
     - `{ id, kind: 'intersection', label, of: [id, id], which: 0 | 1 }` — 원×원(`which` 0·1)과 선×선(선분·수선·평행선, `which` 0)만. 원×선은 이번 카드에서 만들지 않는다(W3 명세에 필요 없음, 메모).
     - `{ id, kind: 'segment', a, b }`, `{ id, kind: 'circle', center, from, to }`(반지름² = `dist2(from, to)` — 실제 컴퍼스처럼 두 점으로 벌리고 중심에 침을 꽂는다. 조작 순서: 폭 점 두 개 → 중심 점. 중심이 `from`과 같으면 `to`를 지나는 원이다), `{ id, kind: 'perpendicular' | 'parallel', base, through }`(base는 선분 id, 그 점을 지나는 끝없는 직선)
     - 점 이름표는 만든 순서대로 ㄱ, ㄴ, ㄷ, ㄹ, ㅁ, ㅂ, ㅅ, ㅇ, ㅈ, ㅊ, ㅋ, ㅌ(최대 12개). 학생이 만든 점의 이름표는 정답이 아니므로 그린다.
   - **정확성 규칙(무리수는 한 번만):**
     - 계급 0(유리수 점): free, on-circle, 선×선 교점. 계급 1(Surd 점): 원×원 교점.
     - 원의 `center`·`from`·`to`, 수선·평행선의 `through`·`base` 끝점, 교점의 입력 객체(정의 점 전부), on-circle의 원은 **계급 0만** 받는다. reduce가 거절하고, View는 그 도구에서 계급 1 점을 흐리게 그리고 "이 점으로는 할 수 없어요"를 띄운다.
     - 선분 끝점과 도형 꼭짓점은 계급 1도 된다. 그래서 컴퍼스 이등변·정삼각형은 정확히 판정된다. 서로 다른 근호가 섞인 도형은 `figureProperties`가 null → `figure.exact: false`, 성질 목록 빈 배열(메모에 적는다).
     - 그래프 평가는 `graph.ts`의 `evaluate(nodes): Map<id, SPoint | Shape | null>` 하나로 한다. 어떤 교점이 사라지면(원이 안 만남) 그 Action은 거절한다(상태 그대로).
   - **Action:** `select-drag-tool {tool}`, `add-point {at}`, `add-segment {a, b}`, `add-circle {center, from, to}`, `add-on-circle {circle, pos}`, `add-intersection {of, which}`, `add-line {kind, base, through}`, `move-point {id, at}`(free) / `move-point {id, pos}`(on-circle), `remove-node {id}`(의존하는 노드도 함께 지움), `shake`, `toggle-angle-pick {point}`, 그리고 7번의 `set-quad-param`, `toggle-condition`. 같은 선분·원·교점을 두 번 만들면 무시. 점 12개·객체 16개가 넘으면 무시.
   - **도형(figure):** 세 점이 선분으로 서로 이어진 삼각형 중 마지막에 만든 선분을 포함하는 것(여럿이면 이름표 순으로 첫째). 없으면 null. 7번 구성에서는 그 사각형이다.
   - **흔들기 (`shake.ts`):**
     - PRNG는 mulberry32다. 씨앗 = `(settings.seed + Math.imul(shakeCount + 1, 0x9E3779B1)) >>> 0`. 정수 뽑기는 `nextUint32() % n`(부동소수 나눗셈을 쓰지 않는다).
     - 자유점마다(만든 순서) `dx, dy ∈ [−shakeRadius, shakeRadius]`(둘 다 0이면 다시 뽑음), 격자 안으로 자른다. on-circle 점은 `pos`를 ±1~4 바꾼다.
     - 검사: 모든 교점이 존재(원×원은 `s > 0`), 길이 0인 선분 없음, 도형이 넓이 0이 아님. 실패하면 같은 생성기로 다시 뽑아 최대 10번. 모두 실패하면 위치는 그대로 두고 `shakeCount`만 늘리고 `lastShakeMoved: false`.
     - reduce 안에서 하므로 되감기·재생·미러링이 같은 결과다. 시간·`Math.random`을 쓰지 않는다.
     - `preShake`: 흔들기 직전의 `nodes`(와 7번의 `quad`) 사본. 그 뒤 기하가 바뀌는 Action(add·move·remove·set-quad-param·toggle-condition)이 오면 null로 비운다. `toggle-angle-pick`은 비우지 않는다.
     - View는 이전 위치에서 새 위치로 0.6초 움직임(화면 number 보간만). `prefers-reduced-motion`이면 바로 바꾼다.
   - **측정 표 (`measure`):** `data-testid="drag-measure"` 표. `sideLengths`는 도형 변마다 "ㄱㄴ 3.6"(격자 2칸 = 1, `Math.sqrt(surdToScreen(길이²))/2`을 소수 첫째 자리 반올림), `angles`는 꼭짓점마다 "∠ㄱ 62°"(`Math.acos`로 계산해 정수 반올림). 비교·판정은 하지 않는다(표시만). 정확히 같은 변에는 같은 눈금 수를 그림에 그린다(반올림 때문에 같아 보이는 것과 구별되게). 기본 `[]`이면 표가 없다.
   - **`classifyLive`:** 도형의 성질 목록(직각 수, 평행한 변 쌍, 같은 길이 변 수, 대각선 성질)을 실시간으로 옆에 쓴다. **이름은 쓰지 않는다** — g4s2u6.A2의 과제가 이름을 묻기 때문이다(메모).
   - **각 고르기:** 도형 꼭짓점을 누르면(또는 키보드 Enter) `toggle-angle-pick`. 최대 2개, 고른 각에 호 표시. g4s2u2.A1-4 "어떤 두 각이 항상 같아?"용이다.
   - **키보드:** 캔버스에서 방향키는 격자 커서 1칸, `Space`/`Shift+Space`는 커서를 다음/이전 점으로 점프, Enter는 도구 동작(free-point: 커서에 점, 나머지: 커서 위 점 고르기, move: 잡기/놓기 — 잡은 동안 방향키가 `move-point`). 원 위 점은 잡은 동안 ←/→가 `pos` ±1. 교점은 도구 패널의 "교점 후보 n" 단추 목록(Tab·Enter)으로 만든다. Delete는 커서 위 점(없으면 마지막 노드) `remove-node`. 도구·흔들기·토글은 모두 Tab으로 가는 단추다.
7. **사각형 구성 (g4s2u6.A2 `from-diagonals`, g4s2u4.A2 `quad-conditions`) — `quad.ts`:** 자유 끌기 대신 매개변수로 정확히 유지한다.
   - **공통:** View가 끌기를 표 값으로 바꾸어(number 계산은 View에서만) `set-quad-param {param, value}`를 보낸다. `value`는 벡터면 정수 `[i, j]`, 표 값이면 정수 인덱스다. reduce는 범위를 검사하고, 켠 조건을 적용하고, 결과가 단순 사각형이고 격자 안에 있을 때만 받는다. 그래서 Action에는 정확한 값만 남는다.
   - **`from-diagonals`:** O = 격자 가운데(고정). `p: [i,j]`(A − O), `t`(T_HALF 인덱스 1~23, OA에서 OB로 도는 각), `beta`·`gamma`·`delta`(S_TABLE 인덱스). `A = O + p`, `C = O − γp`, `B = O + β·R(p)`, `D = O − δ·R(p)`, `R = rationalRotate(·, turnT(t))`.
     - 토글 `diagonalToggles` 중 켠 것(`state.toggles`): `bisect-each-other` → γ = 1, δ = β. `perpendicular` → t = 12. `equal-length` → `1 + γ = β + δ`(이등분과 함께면 β = δ = 1, 아니면 끈 쪽 값을 맞추고 표 밖이면 거절).
     - 손잡이: A → `p`, B → `t`와 `beta`, C → `gamma`(OA 직선 위로 사영), D → `delta`.
     - 처음 모양은 특별한 성질이 없는 사각형(`names = ['quadrilateral']`)으로 구현자가 정하고 테스트로 고정한다.
   - **`quad-conditions`:** A 고정(격자 왼쪽 아래 1/4 자리). `u: [i,j]`(B − A), `t`, `s`(|AD|/|AB|), `kappa`, `c: [i,j]`(조건 없을 때 C). `D = A + s·rationalRotate(u, −turnT(t))`(y가 아래라서 부호를 뒤집어야 화면에서 AB 위쪽이다. 테스트: u=(4,0), t=12, s=1 → D−A=(0,−4)).
     - C: `two-parallel-pairs`면 `B + (D − A)`, `one-parallel-pair`만이면 `D + κ·u`, 둘 다 아니면 `c`.
     - 토글 `quadToggles`: `one-parallel-pair`, `two-parallel-pairs`, `equal-sides`(→ s = 1), `right-angle`(→ t = 12). 켤 때 함의를 같이 켠다(`equal-sides` ⇒ `two-parallel-pairs` ⇒ `one-parallel-pair`). 끌 때 그것을 함의하는 것도 끈다. 그래서 `state.toggles`는 늘 닫혀 있다.
   - **Action:** `toggle-condition {condition}` — 설정에 있는 토글만.
   - 흔들기는 매개변수를 PRNG로 다시 뽑는다(`p`·`u` 각 성분 −6~6, |·|² ≥ 4, `t` 2~22, 표 인덱스 0~11) → 조건 적용 → 검사, 최대 10번.
   - 트리 화면은 E17 몫이다. E09는 이벤트로만 알린다(아래 9번).
8. **Observation (drag-test):** `mode`, `construction`, `points: {label, rank}[]`, `toolsUsed: string[]`(만든 노드 종류, 정렬), `figure: { kind: 'triangle' | 'quad', labels: string, exact: boolean, props: string[], names: string[] } | null`, `toggles: string[]`(정렬), `shakeCount`, `lastShakeMoved`, `lastShake: { before: string[], after: string[], kept: string[], lost: string[], gained: string[] } | null`(`preShake`가 있을 때 같은 도형을 두 기하에서 계산), `pickedAngles: string[]`, `pickedAnglesEqual: { before: boolean, after: boolean } | null`.
