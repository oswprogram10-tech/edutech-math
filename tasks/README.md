엔진 카드(T100~T108)와 오개념 레지스트리 카드(T109)를 먼저 하고, 단원 콘텐츠 카드(T110~T121)는 선행 엔진 카드와 T109가 병합된 뒤 한다. T100이 E09와 함께 core 기하 도우미(`src/core/math/geometry.ts`)를 만들므로 E10·E11·E17 카드도 T100 뒤에 한다.
