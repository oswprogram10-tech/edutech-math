### 1. 공통 설정과 규칙
- **과제 설정**
  - 과제마다 `engine:"E12"`, `submit:"button"`.
  - A1은 `mode:"xray"`, A2는 `mode:"net-fold"`.
  - config에는 엔진 `XrayConfig`·`NetFoldConfig`에 있는 키만 쓴다. `sketchGrid`·`stage`·`fallback`·`variant`는 쓰지 않는다.
  - 5학년이라 48px이고 자동 읽기는 없다(따로 설정하지 않음). 발문은 두 문장 안쪽이다.
- **힌트 규칙**
  - 일반 규칙의 `when`은 `{"kind":"equals","path":"mode","value":"xray"}`(A1) 또는 `"net-fold"`(A2)다.
  - 규칙 순서는 오개념 규칙 → 상태 규칙 → 일반 규칙이다. 각 규칙에 level 1·2·3을 모두 둔다.
- **오개념 코드** 3개(MC-3D-HIDDEN-UNCOUNTED, MC-NET-ANY-SIX, MC-NET-ADJACENT-AS-OPPOSITE)는 레지스트리에 없다.
  - 그래서 T136처럼 predicate나 응답 경로 `equals`/`any`로 건다.
  - `{misconception}` 규칙과 `diagnose`는 쓰지 않는다.
  - 레지스트리 등록은 이 카드 범위가 아니다.
- **③ 역추적**
  - 오개념 규칙의 ③은 명세 오개념 표의 ③ 열이다.
  - 일반 규칙의 ③은 그 과제 개념의 선수 개념이다:

    | 개념 | 선수(③) |
    | --- | --- |
    | cuboid-parts | `g4s2u4.perpendicular-parallel` |
    | parallel-perpendicular-faces | `g5s2u5.cuboid-parts` |
    | sketch-hidden-edges | `g5s2u5.cuboid-parts` |
    | nets | `g5s2u5.parallel-perpendicular-faces` |
- **응답 경로**
  - 수 응답은 `response.<id>.value`(정수 문자열)이고 `{"kind":"number","id":…,"label":…,"forms":["integer"]}`로 쓴다.
  - 고르기 응답은 `response.<id>.selected`(배열)이다.
  - 카드·선택지 id는 `ga`/`na`/`da`, label은 "가"/"나"/"다"다.
- **정답 노출 금지(T111 공통 3)**
  - 발문·힌트에 6·12·8, "3쌍", "4개", "맞은편" 같은 답이나 풀이 규칙을 쓰지 않는다.
  - `faceQuery`(면 관계 보기)는 평행·수직 면을 바로 보여 주므로 A1.T2에서만 켠다.
  - `display:"sketch"`는 숨은 모서리를 점선으로 보여 준다. 그래서 겨냥도 그리기 과제에는 쓰지 않고 A1.T7(읽기)에서만 쓴다.
- **오버레이**
  - 이 단원 오버레이는 `xray-peek`, `fold-collision`, `fold-path` 셋이다.
  - 그 상태에서 실제로 그리는지 E2E로 확인한다.
  - 그리지 않으면 `say`만 두고 "보여 줬어요"를 빼며, 메모에 적는다(T111 공통 4).
- **E2E 조작**
  - 무대 면·모서리·꼭짓점은 엔진 test id·data 속성(T139 8번)으로 고른다.
  - 겨냥도 선은 키보드(방향키·Enter·L) 또는 점 test id로 긋는다.
  - 전개도 면 놓기는 T138 E2E와 같은 방법(키보드 또는 칸 좌표)으로 한다.

### A1 `g5s2u5.A1` "엑스레이 겨냥도" (7과제)
**공통 입체:** `{"type":"cuboid","w":4,"d":3,"h":2}`(T1~T5, T7). 처음 시점은 기본 `{30,30}`이다.

2. **A1.T1 면·모서리·꼭짓점 수 세기 (C).** concepts `["g5s2u5.cuboid-parts"]`.
   - 발문: "직육면체를 돌려 보며 면, 모서리, 꼭짓점을 눌러 표시해 보세요. 각각 몇 개인가요?"
   - config: `{"mode":"xray","solid":S,"xrayToggle":false,"tools":["face","edge","vertex"]}`
     - 엑스레이는 끈다. 엑스레이를 보여 주는 것은 ②의 역할이다.
   - 응답은 수 세 칸이다.
     - `faces` "면의 수"
     - `edges` "모서리의 수"
     - `vertices` "꼭짓점의 수"
     - 판정: `all`(`faces`="6", `edges`="12", `vertices`="8").
   - **MC-3D-HIDDEN-UNCOUNTED**
     - `when`: `any`(`edges`="9", `vertices`="7", `faces`="3")
     - level 1: "뒤쪽으로 돌려 보면 보이지 않던 모서리가 있을까요?"
     - level 2: `show {"engine":"E12","overlay":"xray-peek"}` + `say` "숨어 있는 모서리와 꼭짓점을 점선과 빈 동그라미로 비춰 보았어요."
     - level 3: `g5s2u5.sketch-hidden-edges`
   - 일반 규칙
     - ①: "표시한 것과 아직 표시하지 않은 것을 나누어 세어 볼까요?"
     - ②: `say`만 "무대를 여러 방향으로 돌려 표시가 없는 곳을 찾아봐요."
     - ③: `g4s2u4.perpendicular-parallel`
   - E2E
     - 6·9·8 입력 → MC ①
     - 다시 6·9·8 → MC ② 문구, `xray-peek` 보임, **오버레이 정렬 1px(이 단원의 정렬 테스트)**
     - 6·12·8 → 통과
     - 하나 더: 모서리 도구로 모서리 하나를 눌러 `markedCount.edge`가 1이 되는지 확인

3. **A1.T2 평행한 면 쌍 찾기 (C).** concepts `["g5s2u5.parallel-perpendicular-faces"]`.
   - 발문: "'면 관계 보기'로 면을 하나씩 눌러 보세요. 서로 평행한 면은 모두 몇 쌍인가요?"
   - config: `{"mode":"xray","solid":S,"tools":[],"faceQuery":true}`
     - `tools:[]`로 표시 도구를 숨기고 면 관계 보기만 남긴다.
     - 이때 면 관계 보기 도구가 보이는지 확인하고, 보이지 않으면 멈추고 묻는다.
   - 응답: 수 `pairs` "평행한 면의 쌍 수". 판정: equals "3".
   - 일반 규칙
     - ①: "한 면을 눌렀을 때 함께 칠해지는 면은 몇 개인가요?"
     - ②: `say`만 "앞, 옆, 위 면을 차례로 눌러 보고 짝을 적어 봐요."
     - ③: `g5s2u5.cuboid-parts`
   - E2E: "6" → 일반 ①, "3" → 통과.

4. **A1.T3 색칠된 면과 평행한 면 (P).** concepts `["g5s2u5.parallel-perpendicular-faces"]`.
   - 발문: "색칠된 면과 평행한 면을 찾아 눌러 표시해요."
   - config: `{"mode":"xray","solid":S,"tools":["face"],"highlightFace":"front"}`
     - 정답 면(back)은 처음 시점에서 보이지 않는다. 돌리거나 엑스레이를 켜야 찾는다.
   - 판정: `{"kind":"predicate","name":"markedFacesParallelTo","args":{"face":"front"}}`
   - **상태 규칙**(일반 앞)
     - `when`: `{"kind":"predicate","name":"markedCountIs","args":{"kind":"face","n":0}}`
     - level 1: "색칠된 면의 뒤쪽에는 무엇이 있을까요?"
     - level 2: `say`만 "무대를 돌려 뒤쪽을 살펴봐요."
     - level 3: `g5s2u5.cuboid-parts`
   - 일반 규칙
     - ①: "색칠된 면과 만나지 않는 면은 어디일까요?"
     - ②: `say`만 "두 면을 아무리 늘여도 만나지 않는지 생각해 봐요."
     - ③: `g5s2u5.cuboid-parts`
   - E2E
     - 아무것도 표시하지 않고 확인 → 상태 ①
     - 윗면(top) 표시 → 일반 ①
     - 지우고 돌려서(back이 `visibleFaces`에 들어올 때까지) back 표시 → 통과

5. **A1.T4 한 면에 수직인 면 모두 (P, 완료 기준 보조).** concepts `["g5s2u5.parallel-perpendicular-faces"]`.
   - 발문: "색칠된 면과 수직인 면을 모두 찾아 눌러 표시해요."
   - config: `{"mode":"xray","solid":S,"tools":["face"],"highlightFace":"top"}`
   - 판정: `{"kind":"predicate","name":"markedFacesPerpendicularTo","args":{"face":"top"}}`
   - **MC-3D-HIDDEN-UNCOUNTED**
     - `when`: `{"kind":"all","of":[{"kind":"predicate","name":"markedCountIs","args":{"kind":"face","n":2}},{"kind":"predicate","name":"xrayUsedIs","args":{"value":false}}]}`
       - 보이는 옆면 2개만 고르고, 엑스레이를 한 번도 켜지 않은 경우다.
     - level 1: "뒤쪽으로 돌려 보면 색칠된 면과 만나는 면이 더 있을까요?"
     - level 2: `show xray-peek` + `say` "숨어 있는 모서리를 점선으로 비춰 보았어요."
     - level 3: `g5s2u5.sketch-hidden-edges`
   - 일반 규칙
     - ①: "색칠된 면과 모서리를 함께 쓰는 면을 하나씩 짚어 볼까요?"
     - ②: `say`만 "색칠된 면의 모서리마다 붙어 있는 면을 찾아봐요."
     - ③: `g5s2u5.cuboid-parts`
   - E2E
     - front·right만 표시 → MC ①
     - 엑스레이를 켜고 back·left까지 4면 → 통과
     - 하나 더: bottom을 더 표시한 5면 → 일반 ①

6. **A1.T5 겨냥도 완성하기 (P, 완료 기준).** concepts `["g5s2u5.sketch-hidden-edges"]`.
   - 발문: "보이는 모서리는 그려 두었어요. 보이지 않는 모서리를 그려 겨냥도를 완성해요."
   - config: `{"mode":"xray","solid":S,"sketch":{"prefill":"visible"}}`
   - 판정: `{"kind":"predicate","name":"sketchComplete","args":{}}`
   - **상태 규칙**(일반 앞)
     - `when`: `{"kind":"predicate","name":"sketchHiddenDrawnSolid","args":{}}`
     - level 1: "보이지 않는 모서리는 어떤 선으로 그릴까요?"
     - level 2: `show xray-peek` + `say` "엑스레이로 숨은 모서리를 비춰 보았어요."

### A2 `g5s2u5.A2` "전개도 그리기와 접기" (7과제)

  - 세 `given` 모두 faceCount 6, valid true. E2E의 이웃 오답 ㄱ·ㄴ·ㄱ은 `predictedAdjacent`로 MC가 걸린다.

- **A1.T5 숨은 모서리 좌표** (3,3)-(11,3), (0,0)-(3,3), (3,3)-(3,7)과 **A1.T6 정육면체(한 변 2) 12개 모서리 좌표**는 사투상 `(2x+y, 2z+y)`로 계산했고 E2E 통과로 확인했다.
