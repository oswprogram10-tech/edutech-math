## 목표

### 1. 공통
- **수**
  - 자료 값은 0 이상의 정수 `number`로 둔다.
  - 평균·받침점·예측은 `Rational`로 계산한다.
  - Observation에는 기약분수 문자열로 둔다(예: `"6"`, `"53/5"`).
- **자료**
  - `data: number[]`(2~8개), `label?: string`(예: "줄넘기(번)"), `names?: string[]`
  - `names`를 생략하면 "1번"…으로 둔다. 사람 이름은 콘텐츠가 넣지 않는다.
- **판 맞춤:** 논리 1000×600 SVG, `layout:'fit'`, 최소 배율 0.6 + 스크롤. 조작 칸은 스크롤 상자 밖에 둔다.
- **입력·접근성**
  - 단추는 48px다.
  - Pointer Events로 끈다.
  - 키보드로 모든 조작을 한다(아래 모드별).
  - 색만으로 전달하지 않는다.
- **정답 노출 금지:** 평균값은 Observation에만 둔다. 화면·DOM·aria에 쓰지 않는다. 예외는 `outlier`에서 예측을 잠근 뒤뿐이다.
- 문구는 `strings.ko.ts`에 둔다. 학년 표시·점수는 두지 않는다.
- `next` 같은 모드 이어 가기는 이 카드에서 하지 않는다. 콘텐츠가 과제마다 모드를 따로 둔다.

### 2. `leveling`
- **설정:** `{ mode:'leveling', data, label?, names?, maxHeight? }`
  - `maxHeight`의 기본값은 `max(data) + 2`다.
  - 합이 자료 수로 나누어떨어지지 않으면 설정 오류다(블록을 쪼개지 않는다).
- **Action:** `move {from, to}`(from 기둥 맨 위 블록 하나를 to 기둥 위로), `reset`
  - from 높이가 0이면 거절한다.
  - to 높이가 maxHeight이면 거절한다.
  - from = to이면 거절한다.
- **화면**
  - 기둥마다 블록을 쌓는다. 아래에 이름을, 위에 높이 숫자를 쓴다(학생이 만든 상태라 괜찮음).
  - 끌기: 기둥 맨 위 블록을 다른 기둥 위로 놓는다.
  - 키보드: ←→로 기둥 고르기 → Enter로 집기 → ←→ → Enter로 놓기, Esc로 취소
- **Observation:** `heights: number[]`, `moves: number`, `leveled: boolean`, `level: string|null`(leveled일 때 그 높이), `mean: string`, `misconceptions: []`
- **Predicates:** `leveled`, `levelIs {value}`, `movesAtMost {n}`

### 3. `seesaw`
- **설정:** `{ mode:'seesaw', data, label?, min?, max?, step? }`
  - `min`·`max`의 기본값은 자료 최소−1 ~ 최대+1이다.
  - `step`은 받침점이 움직이는 간격이다. 문자열 Rational이고 기본값은 `"1"`이다.
- **상태:** 받침점 `fulcrum: string`. 처음 값은 min이다.
- **Action:** `set-fulcrum {value}`(step 격자, 범위 안), `reset`
- **화면**
  - 수직선 위에 자료 값마다 추(같은 값은 위로 쌓기)를 놓는다. 아래에 삼각형 받침점을 둔다.
  - 판자는 돌림힘 합 Σ(x − f)의 부호로 기운다. 각도는 `4° + 8° × min(1, |Σ| / (n × (max − min)))`이고 최대 12°, 수평이면 0°다.
  - 받침점 끌기는 step에 붙는다. 키보드 ←→는 step씩 움직인다.
  - 결과 글: "왼쪽으로 기울어요", "오른쪽으로 기울어요", "수평이에요"
  - 받침점 위치 숫자를 받침점 아래에 쓴다(학생이 옮긴 값).
- **Observation:** `fulcrum`, `balanced`, `tilt: 'left'|'right'|'level'`, `mean`, `moves`
- **Predicates:** `balanced`, `fulcrumIs {value}`

### 4. `outlier`
- **설정:** `{ mode:'outlier', data, label?, dragIndex, min?, max?, predict? }`
  - `dragIndex`는 끌 수 있는 점 하나다.
  - `max`의 기본값은 `max(data) × 4`다.
  - `predict`의 기본값은 false다.
- **Action:** `set-value {value}`(dragIndex 점, 정수, 범위 안), `predict {value}`(Rational 문자열, 잠그기 전 한 번), `reset`
- **예측 잠금:** `predict:true`이면 예측 전에는 끌기를 거절한다. 평균선도 그리지 않는다. 예측 칸은 숫자·소수점·분수 `/` 키패드와 [예측하기] 단추로 받는다.
- **화면**
  - 수직선 위에 점들을 놓고, 끌 점은 다른 모양(◆)과 "끌 수 있어요" 글로 보인다.
  - 평균선은 세로 점선 + "평균" 이름표 + 값 글이다. 값은 대분수와, 유한소수이면 소수를 함께 쓴다. 예: "10과 3/5 (10.6)".
  - 처음 평균 자리는 흐린 점선으로 남겨 움직인 거리가 보이게 한다.
  - 예측을 잠갔으면 예측 자리에 "내 예측" 표시를 둔다.
- **Observation:** `values: number[]`, `mean`, `initialMean`, `meanShift`(mean − initialMean), `dragged: boolean`, `prediction: string|null`, `predictionLocked`
- **Predicates:** `valueAt {index, value}`, `meanIs {value}`, `dragged`, `predictionLocked`, `predictionIs {value}`(Rational 비교)

### 5. 오버레이 (`CanvasAlignedOverlay`)
- **`level-try {value}`**(leveling, MC-MEAN-MIDDLE-VALUE ②)
  - 높이 value에 가로 점선을 긋는다.
  - 그 선보다 위 블록은 빗금으로, 선까지 모자란 칸은 점선 빈 칸으로 그린다.
  - "남는 블록 a개 / 모자란 칸 b개"를 쓴다(학생 오답 기준이라 답이 아니다).
  - value가 없으면 그리지 않는다.
- **`sum-tower`**(leveling, MC-MEAN-SUM-ONLY ②): 모든 블록을 한 기둥으로 쌓은 탑을 판 오른쪽에 그리고 "모두 합친 기둥" 이름표를 단다. 그 옆에 기둥 수만큼 빈 자리 테두리를 그린다(높이 없음, 숫자 없음).
- **`arms`**(seesaw 일반 ②)
  - 받침점에서 각 추까지 거리를 판자 아래 막대로 그린다. 왼쪽 막대들의 합 길이와 오른쪽 막대들의 합 길이를 두 줄로 나란히 그린다.
  - 길이 글은 쓰지 않는다.
- **`mean-pull`**(outlier ②): 처음 평균에서 지금 평균까지 화살표를 그리고, 끈 점에서 처음 자리까지 화살표를 그린다. "점이 움직인 거리"와 "평균이 움직인 거리" 글만 쓰고 값은 쓰지 않는다.

### 6. 등록과 테스트
- `index.ts`: `id:'E19'`, `modes:['leveling','seesaw','outlier']`, `layout:'fit'`, 오버레이 넷을 등록한다. fit-canvas ENGINES에 더한다.
- 샌드박스 기본: data `[7,4,9,3,7]`, outlier `dragIndex 4`, `predict true`
- **단위**
  - leveling: move, 거절 셋, leveled·level, 합이 나누어떨어지지 않으면 설정 오류
  - seesaw: 받침점 5.5(step "1/2")·6·7의 tilt, 범위 밖·step 밖 거절
  - outlier
    - 30으로 끌면 mean "53/5", meanShift "23/5"
    - 예측 잠금, predictionIs "10.6" = "53/5"
  - 경계값: 2개 자료, 0 값, maxHeight
  - JSON 왕복, predicates
  - View: 시작 화면 DOM에 평균("6")이 기둥 높이 숫자 말고는 없음. outlier는 예측 전 평균선 없음
- **E2E**(`tests/e2e/chance-lab.spec.ts`, 3 뷰포트, 샌드박스)
  - leveling 끌기·키보드로 고르게 하기
  - seesaw 받침점 끌기·키보드로 수평
  - outlier 예측 → 끌기 → 평균선 이동
  - 오버레이 넷 1px 정렬
  - 모드별 첫 화면 스냅샷
  - 크롬북 좁은 판 최소 배율·스크롤
- **E2E 범위:** `npx playwright test chance-lab fit-canvas overlay-alignment --workers=3 --reporter=line`
