### 1. 공통
- **과제 설정**
  - 과제마다 `engine:"E12"`, `mode:"shapes-sort"`, `submit:"button"`
  - 일반 규칙의 `when`은 `{"kind":"equals","path":"mode","value":"shapes-sort"}`
- **1학년 문구**
  - 짧고 쉬운 말로 쓴다. 한 문장은 25자 안팎이다.
  - 모양 이름은 교과서 말 그대로 "상자 모양", "둥근기둥 모양", "공 모양"이다.
  - 고르기 보기는 이 세 낱말이다(id `box`·`cylinder`·`sphere`).
- **오개념**
  - `MC-SHAPE-ORIENTATION`은 레지스트리에 있다. `diagnose` trapChoice로 건다(g2s1u2와 같다).
  - `MC-SHAPE-BY-COLOR-SIZE`는 A1(분류) 몫이라 이 카드에서는 쓰지 않는다.
- **③ 역추적:** 모든 과제가 `g1s1u2.shape-families`다.
  - 이 개념은 선수 개념이 없으므로 자기 단원의 첫 개념으로 돌아간다.
  - `check:specs`나 content-files 검사가 자기 단원 개념을 ③으로 받지 않으면 멈추고 보고한다.
- **정답 노출 금지:** 발문, 힌트, 라벨에 "공 모양이 굴러가요", "상자 모양만 쌓여요" 같은 결론을 쓰지 않는다. 힌트는 해 볼 조작을 권한다.
- **화면 확인**
  - 저학년 모드 64px 타깃이 콘텐츠 실행기 안에서도 유지되는지 E2E로 본다.
  - 크롬북 두 칸 배치(엔진 판 + 응답 칸)에서 장면, 선반, ▶, 응답 칸, '확인하기'가 닿는지 본다. `expectContentPanelsReachable` 기준이고 측정값은 메모에 적는다.
  - 장면이 너무 작아지면 멈추고 보고한다(장면 높이 200px 미만).

### A2 `g1s1u2.A2` "굴리고 쌓아 보기" (4과제)
2. **A2.T1 잘 굴러가는 모양 (C).** concepts `["g1s1u2.shape-properties"]`
   - 발문: "경사로에 모양을 올리고 ▶를 눌러 봐요. 어느 쪽으로 놓아도 잘 굴러가는 모양은 무엇일까요?"
   - config: `{"mode":"shapes-sort","scene":"ramp","objects":["box","cylinder","sphere"]}`
   - 응답: 고르기 `shape`(한 개)
   - 판정: `all`(`shape`=["sphere"], `triedKind {kind:"sphere"}`)
   - **상태 규칙**(일반 앞)
     - when: `shape`=["cylinder"]
     - ①: "둥근기둥 모양을 세워서도 굴려 볼까요?"
     - ②: `say`만 "세우기 단추를 누르고 ▶를 눌러 봐요."
     - ③: 공통
   - 일반: ① "모양마다 경사로에 올려 굴려 볼까요?" / ② `say`만 "▶를 누르고 끝까지 가는지 지켜봐요." / ③ 공통
   - E2E
     - 굴려 보지 않고 공 → 일반 ①
     - 둥근기둥 → 상태 ①
     - 공을 굴린 뒤 공 → 통과
3. **A2.T2 높이 쌓기 (C).** concepts `["g1s1u2.shape-properties"]`
   - 발문: "높이 쌓을 수 있는 모양 3개로 탑을 만들어요."
   - config: `{"mode":"shapes-sort","scene":"tower","towerMax":4,"objects":[{"id":"b1","kind":"box","color":"red","size":"large"},{"id":"s1","kind":"sphere","color":"blue","size":"large"},{"id":"b2","kind":"box","color":"yellow","size":"small"},{"id":"c1","kind":"cylinder","color":"green","size":"large"},{"id":"s2","kind":"sphere","color":"red","size":"small"},{"id":"b3","kind":"box","color":"blue","size":"small"}]}`
     - 상자 3개와 둥근기둥 1개가 있어 답이 여럿이다. 세운 둥근기둥도 허용한다.
   - 응답 칸이 없는 과제다. 실행기가 엔진 판정만 하는지 확인한다(T111 공통 6).
   - 판정: `all`(`towerHeightIs {n:3}`, `towerAllFlatStackers`)
   - **상태 규칙**(일반 앞, 이 순서로)
     1. when: `towerHeightIs {n:3}`
        - 판정이 실패했다면 누운 둥근기둥이 들어간 경우다.
        - ①: "누운 둥근기둥 위에 더 쌓을 수 있을까요?"
        - ②: `show {"engine":"E12","overlay":"turn-same"}` + "둥근기둥을 세워서 다시 쌓아 봐요."
        - ③: 공통
     2. when: `fallenAtLeast {n:1}`
        - ①: "떨어진 모양은 어떤 모양이었나요?"
        - ②: `say`만 "평평한 곳이 위아래에 있는 모양을 골라 봐요."
        - ③: 공통
   - 일반: ① "모양을 하나씩 탑에 올려 볼까요?" / ② `say`만 "탑에 올리기를 세 번 눌러 봐요." / ③ 공통
   - E2E
     - 상자 2개만 쌓기 → 일반 ①
     - 공을 올려 떨어짐 → 상태 2 ①
     - 상자 2개 + 누운 둥근기둥 → 상태 1 ①
     - 다시 확인 → ②와 `turn-same`이 보임, 정렬 1px
     - 상자 3개 → 통과
     - 상자 2개 + 세운 둥근기둥 → 통과
4. **A2.T3 눕히면 구르고 세우면 서는 모양 (C).** concepts `["g1s1u2.shape-properties","g1s1u2.ignore-irrelevant"]`
   - 발문: "눕히면 굴러가고 세우면 안 굴러가는 모양은 무엇일까요? 세워 보고 눕혀 보며 굴려 봐요."
   - config: `{"mode":"shapes-sort","scene":"ramp","objects":["box","cylinder","sphere"]}`
   - 응답
     - 고르기 `shape`(한 개)

   - 판정: `all`(`shape`=["cylinder"], `same`=["yes"], `cylinderTriedBothPoses`)
   - **MC-SHAPE-ORIENTATION**
     - diagnose: `{"code":"MC-SHAPE-ORIENTATION","args":{"trap":"no"},"path":"response.same.selected.0"}`
     - ①: "둥근기둥을 돌려 놓으면 다른 물건이 될까요?"

     - ③: `g1s1u2.ignore-irrelevant`(명세 표의 ③)
   - 일반: ① "둥근기둥 모양을 세워서 한 번, 눕혀서 한 번 굴려 볼까요?" / ② `say`만 "세우기와 눕히기 단추를 번갈아 눌러 봐요." / ③ 공통
   - E2E
     - 둥근기둥·다른 물건 → MC ①
     - 다시 → MC ②와 `turn-same`이 보임, 정렬 1px
     - 세워서만 굴리고 둥근기둥·같은 물건 → 일반 ①

5. **A2.T4 만져서 맞히기 (C→P).** concepts `["g1s1u2.shape-families"]`
   - 발문: "천 속 물건을 만져 보고, 어떤 모양인지 골라 봐요."
   - config: `{"mode":"shapes-sort","scene":"mystery","mystery":{"kind":"cylinder","shadow":"side"}}`

   - 응답: 고르기 `shape`(한 개)
   - 판정: `all`(`shape`=["cylinder"], `cluesShownAtLeast {n:2}`)
   - **상태 규칙**(일반 앞)
     - when: `shape`=["box"]
     - ①: "뾰족한 곳이 있었나요?"
     - ②: `say`만 "만져 보기를 한 번 더 눌러 봐요."
     - ③: 공통
   - 일반: ① "만져 보기를 눌러 무엇이 느껴지는지 볼까요?" / ② `say`만 "그림자와 만진 느낌을 함께 생각해 봐요." / ③ 공통
