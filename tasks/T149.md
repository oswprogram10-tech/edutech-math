## 목표
g6s2u6.A1 「회전 물레와 레이저 단면」을 위해 E12에 확장 모드 `lathe`를 더한다.
- 학생은 평면도형 카드(직사각형·직각삼각형·반원)를 고르고, 어느 변을 세로 축에 붙일지 정한 다음 회전 손잡이를 돌린다.
- 도형이 축을 따라 돌며 잔상이 쌓이고, 360°에서 입체가 완성된다.
- 완성된 입체(또는 설정으로 처음부터 주어진 입체)를 수평 레이저(축에 수직)나 수직 레이저(축을 포함)로 자르면, 옆 패널에 단면이 그려진다.

### 2. 도형·붙이는 변·결과 (`lathe/profiles.ts`)
| 도형 `profile` | 크기(칸) | 붙일 수 있는 변 `edge` | 결과 `solid` |
| --- | --- | --- | --- |
| `rectangle` | 가로 2 × 세로 4 | `long`(세로 변), `short`(가로 변) | `cylinder`(둘 다. 높이와 반지름만 다름) |
| `right-triangle` | 밑변 2 × 높이 4 | `leg-vertical`(높이 변), `leg-horizontal`(밑변), `hypotenuse`(빗변) | 높이 변·밑변: `cone` / 빗변: `double-cone`(팽이 모양) |
| `semicircle` | 반지름 2 | `diameter`(지름) | `sphere` |

- 붙인 변은 늘 세로 축 위에 놓인다. 화면에서는 붙인 변이 세로가 되도록 도형을 돌려 축 오른쪽에 놓는다.
- 결과 입체의 모양 수치(반지름, 높이)는 그림용이다. 판정은 이름(`solid`)으로 한다.
- **단면 `sectionOf(solid, plane, t)`** (t는 0~1, 수평 레이저의 높이 비율):
  | 입체 | 축에 수직(`perpendicular`) | 축을 포함(`through-axis`) |
  | --- | --- | --- |
  | cylinder | `circle` | `rectangle` |
  | cone | `circle`(꼭짓점에서는 `point`) | `isosceles-triangle` |
  | sphere | `circle`(맨 위·아래에서는 `point`) | `circle` |
  | double-cone | `circle`(양 끝에서는 `point`) | `rhombus` |
- 수평 레이저 높이 `t`는 0~10의 정수 단계이고, `t/10`으로 쓴다. 끝(0·10)에서 `point`가 되는 입체는 표대로 한다.

### 3. 설정 `LatheConfig`
| 키 | 형 | 기본 | 뜻 |
| --- | --- | --- | --- |
| `mode` | `'lathe'` | — | 필수 |
| `profiles` | `('rectangle'\|'right-triangle'\|'semicircle')[]` | 셋 모두 | 고를 수 있는 도형 카드. 명세의 `'custom'`은 받기만 하고 무시한다(경고) |
| `axis` | `'vertical'` | | 받기만 한다 |
| `preset` | `{ profile, edge } \| null` | null | 처음부터 붙여 360° 돌린 상태로 시작(단면 과제용) |
| `crossSection` | `{ planes: ('perpendicular'\|'through-axis')[] } \| false` | false | 레이저 |
| `showSection` | boolean | true | false면 단면 패널에 그림 대신 "?"를 보인다(예측 과제) |
| `rotateHandle` | boolean | true | false면 회전 손잡이를 숨긴다(preset 과제) |

### 4. 상태·Action
```ts
LatheState = { mode:'lathe'; settings; profile: string|null; edge: string|null; angle: number /*0~360, 30 단위*/; laser: { plane: 'perpendicular'|'through-axis'; t: number } | null; view: {yaw, pitch} }
```
| Action | 동작 |
| --- | --- |
| `lt-pick-profile {profile}` | 허용된 도형일 때. `edge=null`, `angle=0`이 된다 |
| `lt-attach {edge}` | 지금 도형에 있는 변일 때. `angle=0` |
| `lt-set-angle {angle}` | 붙인 뒤에만. 0~360을 30 단위로 맞춘다 |
| `lt-reset` | 도형·변·각을 비운다. preset이면 preset으로 되돌린다 |
| `lt-set-laser {plane, t}` | `crossSection`에 있는 면이고 입체가 완성(360°)되었을 때. `through-axis`면 t는 무시한다 |
| `lt-clear-laser` | |
| `set-view`·`rotate-view` | 완성된 입체를 돌려 볼 때(T139 규칙, pitch만 −30~60) |

- 상태는 JSON 직렬화가 되어야 한다.

### 5. 화면 `LatheView`
- **배치:** 왼쪽 무대 `LatheStage`, 오른쪽에 도형 카드·붙일 변 단추·회전 손잡이·레이저 조작, 그리고 `crossSection`이면 단면 패널 `SectionPanel`.
- **무대:**
  - 가운데 세로 축(굵은 점선)을 그린다.
  - 도형을 붙이면 축 오른쪽에 도형을 그리고, 붙인 변을 굵게 칠한다.
  - 회전 각도 θ만큼 30°마다 잔상(옅은 같은 도형, 3D로 돌린 모습을 정사영)을 그린다.
  - 360°가 되면 잔상을 지우고 완성 입체를 매끈한 윤곽(위아래 타원, 옆선, 옅은 음영)으로 그린다.
  - 입체 이름은 쓰지 않는다. 이름 고르기는 콘텐츠 응답이 한다.
- **도형 카드:** 그림 단추, 64px 이상이 아니어도 48px 이상.
- **붙일 변 단추:** 도형 그림 위에 변마다 굵은 손잡이를 둔다. 또는 변 이름 단추(예: "세로 변", "가로 변", "빗변")를 둔다. 빗변이라는 말은 6학년에게 쓸 수 있다.
- **회전 손잡이:** 원형 다이얼이다.
  - Pointer Events로 끌어 각을 정한다. 놓으면 30°에 맞춘다.
  - 다이얼 옆 "한 바퀴 돌리기" 단추는 0→360을 1.5초 연출로 돌린다. reduced-motion이면 바로 360이다.
  - 다이얼에 각도 숫자(예: 120°)를 써도 된다(답이 아니다).
- **레이저:**
  - 수평 레이저: 무대 위 가로 빨간 선과 오른쪽 세로 슬라이더(0~10)
  - 수직 레이저: 축을 지나는 세로 면을 빗금 사각형으로 표시
  - 두 단추 "가로로 자르기"·"세로로 자르기"(`crossSection.planes`에 있는 것만)
- **단면 패널:**
  - `showSection`이면 지금 단면을 2D로 그린다(원, 직사각형, 이등변삼각형, 마름모, 점).
  - 단면 이름 글자는 쓰지 않는다. 그림만 둔다.
  - `showSection:false`면 "?" 카드를 보인다.
- **키보드:**
  - 1·2·3: 도형 고르기
  - Tab + Enter: 변 붙이기
  - ←/→: 회전 30°
  - Space: 한 바퀴
  - H/V: 가로/세로 레이저
  - ↑/↓: 레이저 높이
  - Q/E: 완성 입체 돌려 보기
- **test id:** `lt-profile-{p}`, `lt-edge-{e}`, `lt-dial`(`aria-valuenow`), `lt-spin`, `lt-stage`, `lt-laser-h`, `lt-laser-v`, `lt-laser-t`(slider), `lt-section`(`data-shape`는 넣지 않는다), `lt-reset`
- 문구는 `strings.ko.ts`의 `solid3dStrings.lathe`에 둔다.

### 8. 오버레이(힌트 ②)
- **`axis-compare`** (MC-REVOLVE-AXIS-WRONG):
  - 같은 직각삼각형을 두 번 그린다. 왼쪽은 빗변을 축에 붙여 돌린 모습(팽이 모양 윤곽), 오른쪽은 높이 변을 축에 붙여 돌린 모습(원뿔 윤곽)이다. 축은 점선이다.
  - 문구: "축을 어느 변에 붙이면 꼭짓점이 하나로 모일까요?"
  - 입체 이름은 쓰지 않는다. 직각삼각형을 고르지 않았으면 그리지 않는다.
- **`n-grow`** (MC-CONE-AS-PYRAMID):
  - 각뿔의 밑면 변의 수를 3 → 4 → 6 → 12로 바꾸며 그린 그림 네 개를 한 줄로 놓고, 끝에 원뿔을 둔다.
  - 그림은 정지 그림 4장이고 애니메이션은 없다. 각뿔 그림은 `prism/geometry.ts`를 import해서 쓴다(고치지 않는다).
  - 문구: "원뿔의 밑면은 다각형일까요?"
- 두 오버레이를 `index.ts`의 `overlays`에 등록하고 단위 테스트(그림/안 그림)를 둔다.
