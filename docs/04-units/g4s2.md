### 활동
#### g4s2u1.A1 조각 세기 덧셈·뺄셈 — E05 `add-sub` + E03 `fraction` · C→P→A
- **원 계획서:** (대분수 자연수 막대 쪼개기 스튜디오의 진분수 단계 + 수직선)
- **화면과 조작:** 1/5 막대 조각이 담긴 상자 두 개(2/5와 4/5). 학생이 조각을 하나의 막대 틀로 끌어 모으면 틀이 꽉 차는 순간 "1" 상자로 융합되고 남은 조각이 1/5이 된다. 화면 아래 수직선에서 같은 덧셈을 1/5 칸씩 점프하는 화살표로 동시에 보여 준다. 뺄셈은 조각을 "빼기 접시"로 덜어 낸다.
- **설정 예시:**
  ```json
  { "mode": "add-sub", "op": "add", "a": "2/5", "b": "4/5", "shape": "bar", "fuseWhole": true, "numberLine": { "mode": "fraction", "min": 0, "max": 2, "subdivisions": 5, "showJumps": true } }
  ```
- **과제(쉬운 것 → 어려운 것):**
  1. 2/7 + 3/7 / 판정: 결과 5/7 + 모은 조각 5개
  2. 2/5 + 4/5 (1보다 큼) / 판정: 6/5 또는 1 1/5 (동치 허용)
  3. 5/6 − 2/6 / 판정: 3/6 (약분은 5학년이므로 3/6 그대로 정답, 1/2도 허용)
  4. 1 − 3/8 / 판정: 5/8 + "1을 8/8로 바꾸기" 조작 기록
  5. 수직선만 보고 4/9 + 7/9 (A) / 판정: 11/9 또는 1 2/9
- **CPA 페이딩:** C: 조각 모으기 / P: 수직선 점프 / A: 식만, 막히면 수직선 힌트

#### g4s2u1.A2 대분수 막대 쪼개기 스튜디오 — E05 `mixed` + `add-sub` · C→P→A
- **원 계획서:** 대분수 자연수 막대 쪼개기 스튜디오
- **화면과 조작:** 대분수 3 1/4은 꽉 찬 막대 3개 + 1/4 조각 1개로 나타난다. 3 1/4 − 1 3/4에서 1/4에서 3/4을 덜 수 없으므로, 학생은 꽉 찬 막대 하나를 망치로 두드려 1/4 조각 4개로 쪼갠다(→ 2와 5/4). 그다음 자연수 막대 1개와 조각 3개를 덜어 낸다. 덧셈에서는 조각이 넘치면 자동 융합한다. 학생은 "자연수끼리·분수끼리" 방법과 "가분수로 바꾸기" 방법 중 하나를 고를 수 있다.
- **설정 예시:**
  ```json
  { "mode": "add-sub", "op": "sub", "a": "3 1/4", "b": "1 3/4", "shape": "bar", "allowBreakWhole": true, "fuseWhole": true, "strategyChoice": ["separate", "improper"] }
  ```
- **과제:**
  1. 2 3/8 + 1 4/8 / 판정: 3 7/8
  2. 1 4/5 + 2 3/5 (분수 부분 합이 1 넘음) / 판정: 4 2/5 + 융합 이벤트
  3. 4 5/7 − 2 2/7 / 판정: 2 3/7
  4. 3 1/4 − 1 3/4 (받아내림) / 판정: 1 2/4 (1 1/2 허용) + 풀기 이벤트 1회
  5. 5 − 2 2/3 / 판정: 2 1/3 + 풀기 이벤트
- **CPA 페이딩:** C: 막대 쪼개기·융합 / P: 막대 그림과 칸 입력 / A: 식 계산만

#### g4s2u1.A3 줄 단위 풀이 진단(Math Doctor) — E08 `lines` + `fraction-steps` + `debug` · P→A
- **원 계획서:** 분모 합산 오개념(a/c + b/c = (a+b)/2c) 반례 팝업 + 줄 단위 필기 디버깅(OCR → 수식 키패드 입력으로 대체)
- **화면과 조작:** 학생이 수식 키패드(분수 틀, 대분수 틀)로 한 줄씩 풀이를 쓴다. 각 줄은 이전 줄과 동치인지 즉시 판정된다. 동치가 깨진 줄은 빨간 테두리가 생기고, `diagnose`가 찾은 오개념 코드에 맞는 반례 팝업이 뜬다. 예: `2/5 + 1/5 = 3/10`이면 "2/5보다 작아졌네? 무언가를 더했는데?"와 함께 두 막대 그림(3/10 막대가 2/5 막대보다 짧음)이 나타난다. `debug` 과제에서는 가상 친구의 틀린 풀이를 보고 틀린 줄을 찾는다.
- **설정 예시:**
  ```json
  { "mode": "lines", "start": "3 1/4 - 1 3/4", "keypad": ["digits", "fraction", "mixed", "+", "-", "="], "checkEachLine": true, "stepLabels": ["자연수 1 풀기", "계산", "정리"], "debugSamples": [{ "lines": ["2/5 + 1/5", "= 3/10"] }, { "lines": ["3 1/4 - 1 3/4", "= 2 2/4"] }] }
  ```
- **과제:**
  1. 3/8 + 4/8을 두 줄 이상으로 풀기 / 판정: 마지막 줄 = 7/8, 모든 줄 동치
  2. 친구 풀이 "2/5 + 1/5 = 3/10"의 틀린 곳 찾고 고치기 / 판정: 둘째 줄 선택 + 고친 값 3/5
  3. 친구 풀이 "3 1/4 − 1 3/4 = 2 2/4" 고치기 / 판정: 틀린 줄 선택 + 1 2/4
  4. 2 1/6 − 5/6을 단계 이름표(자연수 1 풀기 → 계산 → 정리)에 맞게 / 판정: 모든 줄 동치 + 최종 1 2/6 (1 1/3 허용)
  5. 스스로 □/9 + □/9 = 1 3/9 이 되는 식 2가지 만들기 / 판정: 두 식 모두 값 12/9, 서로 다른 식
- **CPA 페이딩:** P: 반례 팝업에 막대 그림 / A: 그림 없이 문장 발문만(②단계에서 그림)

### 활동
#### g4s2u2.A1 드래깅 테스트 작도 — E09 `construct` + `drag-test` · C→P
- **원 계획서:** 컴퍼스 원 기반 드래깅 불변성 이등변·정삼각형 작도 테스트
- **화면과 조작:** 과제 1: 눈대중으로 이등변삼각형을 그린다(점판 아님, 자유점). "흔들기" 버튼을 누르면 꼭짓점이 무작위로 움직이고, 눈대중 삼각형은 변 길이 표시가 달라져 무너진다. 과제 2: 컴퍼스로 선분 양 끝에서 같은 반지름 원 두 개를 그리고 교점을 꼭짓점으로 삼으면, 흔들어도 두 변(또는 세 변)이 항상 같다. 각도 표시로 "두 각도 항상 같다"를 관찰한다.
- **설정 예시:**
  ```json
  { "mode": "drag-test", "tools": ["free-point", "segment", "compass", "intersection"], "measure": ["sideLengths", "angles"], "shakeButton": true, "goal": "isosceles-invariant" }
  ```
- **과제:**
  1. 눈대중 이등변삼각형 그리고 흔들어 보기 / 판정: 흔들기 후 `equalSides` 성질 사라짐 이벤트(관찰 과제)
  2. 컴퍼스로 이등변삼각형 작도 / 판정: 흔들기 후에도 두 변 같음 유지
  3. 정삼각형 작도 / 판정: 흔들기 후 세 변 같음 유지
  4. 이등변삼각형의 각 관찰: "어떤 두 각이 항상 같아?" / 판정: 같은 변 사이 각이 아닌 밑각 쌍 선택
- **CPA 페이딩:** C: 컴퍼스 작도 / P: 성질 측정 표

#### g4s2u2.A2 변·각 2차원 분류판 — E17 `venn` · P→A
- **원 계획서:** 변·각 2차원 벤다이어그램 실시간 셰이더 분류기
- **화면과 조작:** 가로축(이등변·정삼각형·세 변이 다른 삼각형) × 세로축(예각·직각·둔각) 3×3 표에 삼각형 카드를 끌어 넣는다. 카드를 칸에 넣으면 그 칸 조건과 카드 성질이 맞는지 칸 색이 실시간으로 바뀐다. 마지막에 "불가능한 칸"(예: 둔각 정삼각형)을 찾고, 가능한 칸은 직접 삼각형을 만들어 채운다(E09 연동).
- **설정 예시:**
  ```json
  { "mode": "venn", "layout": "grid", "rows": ["acute", "right", "obtuse"], "cols": ["equilateral", "isosceles-only", "scalene"], "cards": "auto-generate-12", "allowCreate": { "engine": "E09", "mode": "geoboard" } }
  ```

### 활동
#### g4s2u3.A1 10×10 모눈 중첩 색칠기 — E05 `decimal-grid` + E03 `decimal` · C→P→A
- **원 계획서:** 10×10 모눈종이 중첩 색칠기
- **화면과 조작:** 1을 나타내는 10×10 모눈. 한 줄(10칸) 색칠 = 0.1, 한 칸 = 0.01. 두 소수를 서로 다른 색으로 겹쳐 칠하면 어느 쪽이 넓은지 바로 보인다(0.3 vs 0.25). 수직선 0~1을 0.1 → 0.01로 줌인하며 같은 점을 찍는다. 0.3과 0.30을 칠하면 똑같은 영역이 됨을 확인한다.
- **설정 예시:**
  ```json
  { "grid": { "mode": "decimal-grid", "size": 10, "layers": [{ "value": "0.3", "color": "blue" }, { "value": "0.25", "color": "orange" }], "overlayAlpha": 0.5 }, "numberLine": { "mode": "decimal", "min": 0, "max": 1, "zoom": { "from": "1/10", "to": "1/100" } } }
  ```
- **과제:**
  1. 0.47 색칠 / 판정: 4줄 + 7칸 = 47칸
  2. 0.3과 0.25 겹쳐 칠하고 비교 / 판정: 0.3 > 0.25
  3. 0.3과 0.30 비교 / 판정: 같다(=)
  4. 수직선에 0.68 / 판정: 점 값 = 68/100
  5. 1.207에서 숫자 7이 나타내는 수 (A) / 판정: 0.007
- **CPA 페이딩:** C: 모눈 색칠 / P: 수직선 / A: 자릿값 표와 부등호

#### g4s2u3.A2 소수점 자석 정렬 세로셈 — E07 `decimal` · P→A
- **원 계획서:** 세로셈 소수점 일직선 자석 정렬 코치
- **화면과 조작:** 두 소수 카드(예: 3.5와 1.27)를 세로셈 격자 위로 끌어 놓는다. 카드는 소수점이 격자의 소수점 열에 자석처럼 붙는다(C·P). A 단계에서는 자석이 꺼지고 학생이 자리를 정한다. 빈 자리에는 0을 채울지 선택할 수 있다. 계산은 칸 입력, 받아올림·받아내림 칸 포함.
- **설정 예시:**
  ```json
  { "mode": "decimal", "op": "add", "a": "3.5", "b": "1.27", "magnetAlign": "C-P", "padZeros": "optional" }
  ```
- **과제:**
  1. 3.5 + 1.27 / 판정: 정렬 정답 + 4.77
  2. 6.4 − 2.75 / 판정: 3.65 (0.40으로 보고 받아내림)
  3. 12.08 + 0.9 / 판정: 12.98
  4. 5 − 1.36 (A, 자석 없음) / 판정: 3.64
  5. 어림: 7.9 + 2.15는 약 10일까? / 판정: 예
- **CPA 페이딩:** C: 모눈으로 보기 버튼 / P: 자석 정렬 / A: 자석 끔
