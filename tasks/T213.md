## 목표
E13에 모드 둘을 더한다. 이 두 모드는 g3s2u5(T214)에 쓴다.
- `capacity`: 들이를 다룬다.
  - 같은 컵으로 몇 번 들어가는지 세어 들이를 비교한다.
  - 눈금 없는 두 비커로 채우기·비우기·옮겨 붓기만 해서 정해진 양을 만든다.
- `weight`: 무게를 다룬다.
  - 윗접시저울로 무게를 비교하고, 클립 몇 개와 무게가 같은지 센다.
  - 용수철저울 눈금을 읽는다.
  - 저울을 쓰기 전에 무게를 예측한다.

### 2. `capacity`
- **설정:** `{ mode:'capacity', variant:'cup-count'|'puzzle', … }`
- **`cup-count`:** `{ containers:[{ id, label, kind:'bottle'|'bowl'|'beaker', shape:'tall'|'wide', capacityMl }], cupMl }`
  - containers는 1~2개다.
  - 그릇마다 [컵으로 붓기] 단추를 둔다. 누르면 컵 하나만큼 수위가 오르고, 그 그릇 옆에 "컵 n번"(학생 행동 수)을 쓴다.
  - 가득 차면 그 이상 붓기를 거절한다. 마지막 컵이 넘치는 경우는 이 카드에서 다루지 않는다. 콘텐츠는 capacityMl이 cupMl의 배수인 것만 쓴다(설정 검사).
  - [비우기]를 누르면 그 그릇 수를 0으로 되돌린다.
  - **Action:** `pour-cup {id}`, `empty {id}`, `reset`
  - **Observation:** `cups: Record<id, number>`, `full: Record<id, boolean>`, `allFull`, `moreId`(들이가 큰 그릇, 같으면 "")
  - **Predicates:** `allFull`, `full {id}`, `cupsIs {id, n}`
- **`puzzle`:** `{ containers:[{ id, capacityMl, marks:false }], source:'infinite', targetMl }`
  - containers는 정확히 2개다.
  - 수도꼭지(무한)와 개수대(버리기)가 있다. 그릇마다 [채우기]·[비우기]·[다른 비커로 붓기] 단추를 둔다. 끌어서 붓기도 된다(비커를 다른 비커 위로 끌어 놓기).
  - 붓기는 받는 쪽이 가득 차거나 주는 쪽이 빌 때까지다(정확한 Rational 계산).
  - **Action:** `fill {id}`, `empty {id}`, `pour {from, to}`, `reset`. 바뀌지 않는 Action(이미 가득·이미 빔)은 거절한다.
  - **Observation:** `amounts: Record<id, string>`(mL), `steps`, `reached`(어느 그릇이든 targetMl과 같음), `reachedIn: string|null`
  - **Predicates:** `reached`, `amountIs {id, ml}`, `stepsAtMost {n}`
  - **판정 메모:** 400mL는 두 비커 합으로 만들 수 없다(최대 500). 그래서 명세 과제 4의 400mL는 "어느 비커에 400mL"로 정의한다. 500·300으로 400은 가능하다(500 채움→300에 부음(200)→300 비움→200 옮김→500 채움→300에 100 부음 → 500에 400). 단위 테스트로 도달을 확인한다.
- **오버레이**
  - `same-beaker`(MC-MEAS-CAPACITY-SHAPE ②): 두 그릇 아래에 같은 모양 비커 윤곽 둘을 점선으로 그린다. "같은 모양 비커에 옮겨 담으면?" 글을 단다. 수위는 그리지 않는다.
  - `liter-cups`(MC-MEAS-UNIT-CONVERT ②): 1L 병 하나와 100mL 컵 10개를 나란히 그리고 "1L = 100mL 컵 10번 = 1000mL" 글을 단다. 고정 그림이다.
  - `ml-merge`(MC-MEAS-MIXED-UNIT-CALC ②): 1000칸 mL 막대(100칸 단위 10묶음)가 1L 병 하나로 바뀌는 그림을 화살표 하나로 그린다. 고정 그림이다.

### 3. `weight`
- **설정:** `{ mode:'weight', tools:('pan-balance'|'spring-scale')[], objects:[{ id, kind, g, visualSize? }], springMaxG?:정수, unitObjects?:{ clip:정수 g }, predict?:boolean }`
  - `kind`는 beachball, iron-ball, book, apple, pencil-case, bag 등이다. 그림은 SVG로 그리고 이름은 strings에 둔다.
  - `springMaxG` 기본은 1000이다.
  - `tools`에 둘 다 있으면 판을 좌우로 나눈다. 좁은 화면이면 위아래로 나눈다.
- **윗접시저울**
  - 물건을 끌어 접시에 놓는다. 한 접시에 물건은 하나다.
  - `unitObjects.clip`이 있으면 [클립 하나 더]·[클립 하나 빼기] 단추를 둔다. 오른쪽 접시에 클립을 쌓고 "클립 n개"(학생 행동)를 쓴다.
  - 기울기는 E06 compare와 같은 규칙이다. 결과 글("왼쪽이 더 무거워요" 등)을 보인다.
- **용수철저울**
  - 물건 하나를 끌어 고리에 건다. 늘어난 길이는 g에 비례한다.
  - 눈금은 0~springMaxG다. 100g마다 숫자를 쓰고, 10g마다 작은 눈금을 긋는다.
  - 바늘이 가리키는 자리가 측정값이다. 숫자 글로 따로 쓰지는 않는다.
  - 눈금 확대 단추는 두지 않는다(3학년, 10g 눈금). 판 배율이 작아 눈금이 6px 아래로 좁아지면 메모에 적는다.
- **예측(`predict:true`)**
  - 저울을 쓰기 전에 조작 칸에서 "어느 쪽이 더 무거울까?"를 물건 단추로 고르고 [예측하기]를 누른다.
  - 예측하기 전에는 저울 놓기를 거절한다.
- **Action:** `place {id, pan:'left'|'right'|'shelf'}`, `clip {delta:1|-1}`, `hang {id|null}`, `predict {id}`, `reset`. `reset`은 예측을 남긴다.
- **Observation:**
  - `left`, `right`, `clips`, `tilt`, `balanced`
  - `hung`, `springG: string|null`(건 물건 g)
  - `prediction`, `predictionLocked`
  - `heaviest`
  - `compared {a,b}`용 쌍 목록
  - `misconceptions: []`
- **Predicates:** `predictionLocked`, `predictionIs {id}`, `compared {a,b}`, `hungIs {id}`, `balanced`, `clipsIs {n}`
- **오버레이 `size-weight-bars`**(MC-MEAS-WEIGHT-SIZE ②)
  - 저울에 올린 두 물건 옆에 크기 막대와 무게 방향 막대를 그린다(E06 `size-vs-weight`와 같은 생각). 숫자는 쓰지 않는다.
  - 두 접시에 물건이 하나씩 있어야 그린다.

### 4. 테스트
- **단위**
  - cup-count
    - 붓기·가득 참·거절
    - 배수가 아닌 설정은 오류다.
    - moreId
  - puzzle
    - 100mL 도달 순서: 300 채움 → 500에 부음 → 300 채움 → 500에 부음(500 가득, 300에 100)
    - 400mL 도달 순서(위 메모)
    - 거절 경계, JSON 왕복
  - weight
    - 기울기, 클립 수
    - 용수철 g
    - 예측 잠금 전 놓기 거절
    - compared
  - View
    - capacity DOM에 capacityMl·amounts 값이 없다.
    - weight DOM에 g 값이 없다. 용수철 눈금 숫자는 예외로 하고, 물건 쪽만 검사한다.
- **E2E**(`measure-lab.spec.ts`에 더함, 3 뷰포트, 샌드박스)
  - cup-count 붓기
  - puzzle 100mL를 단추로, 끌어서 붓기 한 번
  - 저울: 예측 → 놓기 → 기울기
  - 용수철 걸기
  - 키보드 경로 하나씩
  - 오버레이 넷 1px 정렬
  - 새 화면 스냅샷 × 크롬북·아이패드
- **E2E 범위:** `npx playwright test measure-lab fit-canvas overlay-alignment --workers=3 --reporter=line`
