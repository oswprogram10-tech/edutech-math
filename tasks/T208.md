## 목표
E13(T205)에 세 가지를 더한다.
- `estimate` 모드: 물건 옆에 놓인 자가 0이 아닌 눈금에서 시작할 수 있다. 학생은 자를 끌어 영점을 맞추거나, 칸 수를 센다. 재기 전에 어림값을 먼저 넣는다.
- `length`의 `mergeRule`: 10cm 막대 10개를 이으면 1m 줄자 하나로 합쳐진다.
- `length`의 `variant:'unit-train'`: m 칸과 cm 칸으로 된 기차다. 승격(100cm → 1m)과 풀기(1m → 100cm)를 한다.

이 셋은 g2s1u4.A2(T209)와 g2s2u3(T210)에 쓴다.

- 새 코드는 모드·변형별 파일(또는 폴더)에 둔다. T205 파일은 등록과 모드 나누기 줄만 고친다.
- **샌드박스 모드 상자:** "어림하기"를 더한다.
  - 모드 상자 폭이 바뀌어 E13 기준 이미지에서 도구 줄만 밀리면 다시 찍어도 된다. 그렇게 했으면 메모에 적는다.

### 2. `estimate`
- **설정:** `{ mode:'estimate', object:{ name, lengthCm }, ruler?:{ offsetCm?, draggable? }, estimateFirst?:boolean }`
  - `lengthCm`: Rational, 0.1 격자다(예: `"6.7"`). 1~20cm다.
  - `offsetCm`: 정수 0~5, 기본 0이다. 물건 왼쪽 끝이 자의 이 눈금에 놓인다.
  - `draggable`: 기본 true다.
  - `estimateFirst`: 기본 false다.
  - 자는 0~25cm이고 1cm 큰 눈금과 숫자, 1mm 작은 눈금이 없는 일반 자다. 2학년이라 mm는 그리지 않는다.
- **자 끌기**
  - `draggable`이면 자를 좌우로 끈다. 0.5cm 격자에 붙고, 영점 1cm 안이면 물건 끝에 붙는다.
  - 키보드: 자에 초점을 두고 ←→로 0.5cm씩 옮긴다.
- **어림 먼저(`estimateFirst`)**
  - 조작 칸에 0~9 키패드, [어림 넣기] 단추, "어림: □cm" 칸을 둔다.
  - 어림을 넣기 전에는 자를 그리지 않고 자 끌기도 거절한다. 칸에는 "먼저 어림해 보세요"를 보인다.
  - 넣으면 잠긴다(`estimateLocked`). 그 뒤 판에 "내 어림" 점선 표시가 생긴다. 물건 왼쪽 끝에서 어림 길이만큼의 막대다.
  - 어림 막대와 물건 끝 사이의 차이는 그림으로만 보인다. 숫자는 쓰지 않는다.
- **Action:** `move-ruler {offsetCm}`(자 시작에 대한 물건 끝 위치, Rational), `estimate {value}`(정수 1~99, 한 번만), `reset`
  - `reset`은 자 위치만 되돌리고 잠긴 어림은 남긴다.
- **Observation:**
  - `mode`, `lengthCm`
  - `rulerOffset`: 물건 왼쪽 끝이 놓인 자 눈금 값, Rational
  - `zeroAligned`(rulerOffset = 0)
  - `endTick`(rulerOffset + lengthCm)
  - `nearestCm`(lengthCm를 반올림한 정수)
  - `estimate: number|null`, `estimateLocked`
  - `misconceptions: []`
- **Predicates:** `zeroAligned`, `estimateLocked`, `rulerMoved`
- **오버레이 `count-cells`**(MC-MEASURE-ENDPOINT ②)
  - 물건 아래, 물건이 시작한 눈금부터 1cm 칸마다 색과 빗금으로 번갈아 칠한다.
  - 칸 번호와 개수 글은 쓰지 않는다.
  - 마지막 칸이 1cm보다 짧으면 그 부분은 점선으로 칠한다.

### 3. `length`의 `mergeRule`
- **설정:** T205 `length` 설정에 `mergeRule?:{ from:'cm-10-rod', count:10, to:'m-tape' }`를 더한다. 단위 목록에 둘을 더한다.
  - `cm-10-rod`: 10cm, 안에 1cm 눈금 10칸
  - `m-tape`: 100cm, 10cm마다 굵은 눈금
- **판 배율:** 물건이 길면(예: 칠판 320cm) 물건 길이 + 여유가 논리 폭 안에 들어가게 배율을 정한다. 조각 끌기 격자는 그 배율에서 10cm다.
- **합체:** 0부터 틈 없이 이어진 `cm-10-rod` 10개가 생기면 자동으로 그 10개를 `m-tape` 하나로 바꾼다.
  - 연출은 말리기 400ms이고, reduced-motion이면 바로 바꾼다.
  - 합체는 reduce 안에서 `add`/`move`의 결과로 일어난다(Action 하나).
  - Observation `merges`가 1 오르고, 이벤트 `merged`를 낸다.
  - 합체 뒤 이어지는 조각도 같은 규칙을 따른다(200cm에서 두 번째 합체).
- **트레이:** `m-tape`가 `units`에 있으면 트레이에서 바로 꺼낼 수도 있다. 다만 콘텐츠 T1은 `units`에 `cm-10-rod`만 넣어 합체를 겪게 한다.
- **Observation 추가:** `merges`, `meters`(m-tape 조각 수), `restCm`(m-tape 뒤 cm 조각 길이 합, Rational)
- **Predicates 추가:** `merged`(merges ≥ 1), `measuredAs {m, cm}`(`exact`이고 meters·restCm이 같음)
- **오버레이 `meter-100`**(MC-LENGTH-UNIT-MIX ②)
  - 판 위쪽에 1m 줄자를 100칸으로 펼쳐 그린다. 10칸마다 굵은 선이고, 10·20…100 숫자를 쓴다.
  - "1m" 이름표를 단다. 과제 값과 상관없는 고정 그림이다.

### 4. `length`의 `variant:'unit-train'`
- **설정:** `{ mode:'length', variant:'unit-train', op:'add'|'sub', a:"Xm Ycm", b:"Xm Ycm" }`
  - 길이 문자열을 파싱한다: `"1m 70cm"`, `"205cm"`, `"3m"`. 결과는 Rational cm다.
  - 0 ≤ 값 < 10m, cm 부분은 정수다.
  - sub에서 a < b이면 설정 오류다.
- **화면:** 두 줄짜리 기차다.
  - m 칸 줄: 1m 큰 칸
  - cm 칸 줄: 10cm 막대 + 1cm 작은 블록. cm 값을 10cm 막대와 1cm 블록으로 나눈다.
  - add이면 a와 b의 칸을 처음부터 한 기차에 합쳐 놓는다. 이때 m과 cm는 따로 더해진 정규화 전 상태다(예: 1m 70cm + 2m 50cm → 3m 120cm).
  - sub이면 a만 놓는다. 위에 "뺄 길이 b" 표를 둔다. 글로 b 값을 쓰는 것은 문제 그대로라 괜찮다.
- **조작**
  - [승격]: cm 줄이 100cm 이상이면 10cm 막대 10개를 1m 칸 하나로 바꾼다.
  - [풀기]: 1m 칸 하나를 10cm 막대 10개로 바꾼다.
  - [빼기](sub만): cm 줄과 m 줄에서 b만큼을 덜어낸다. 칸이 모자라면 거절하고 "칸이 모자라요" 안내를 낸다.
    - 1cm 블록이 모자랄 때 10cm 막대를 1cm 블록으로 푸는 것은 [작게 풀기] 단추로 따로 한다. 명세 과제 값은 모두 10의 배수라 대개 쓰지 않는다.
  - 키보드: 단추에 초점을 두고 Enter/Space를 누른다.
- **Action:** `promote`, `unpack`, `unpack-small`, `take-away`, `reset`
  - 조건이 안 맞으면 거절한다.
- **Observation:**
  - `mode`, `variant`, `op`
  - `m`, `cm`: 현재 기차, 정수
  - `totalCm`
  - `normalized`(cm < 100)
  - `promotes`, `unpacks`
  - `tookAway`(sub에서 빼기를 함)
  - `misconceptions`: `['MC-LENGTH-NO-PROMOTE']`는 add에서 cm ≥ 100인 동안이다.
- **Predicates:**
  - `trainIs {m, cm}`
  - `normalized`
  - `promotedAtLeast {n}`, `unpackedAtLeast {n}`
  - `tookAway`
- **오버레이 `meter-outline`**(MC-LENGTH-NO-PROMOTE ②)
  - cm 줄의 처음 10cm 막대 10개 둘레에 1m 칸 크기의 점선 상자를 그리고 "1m"을 쓴다.
  - cm < 100이면 그리지 않는다.

### 5. 테스트
- **단위**
  - estimate
    - offset 3, 길이 7이면 endTick 10이다.
    - 자 끌기 자석, zeroAligned
    - estimateFirst 잠금 전에는 자 이동을 거절한다. 어림은 한 번만 넣는다.
    - nearestCm: 6.7은 7, 6.5는 7(반올림)
  - mergeRule
    - 10개면 합체한다. 9개와 틈이면 합체하지 않는다.
    - 두 번째 합체, measuredAs 3m 20cm
  - unit-train
    - 파싱 경계값: "0cm", "9m 99cm", 잘못된 형식
    - add 1m 70cm + 2m 50cm → 승격 1회 → 4m 20cm, normalized
    - sub 5m 20cm − 2m 60cm → 풀기 1회 → 빼기 → 2m 60cm
    - 모자람 거절, MC-LENGTH-NO-PROMOTE 기록
  - JSON 왕복, predicates
  - View
    - estimate 시작 화면 DOM에 lengthCm 값이 없다.
    - estimateFirst이면 자가 그려지지 않는다.
- **E2E**(`tests/e2e/measure-lab.spec.ts`에 더함, 3 뷰포트, 샌드박스)
  - estimate: 어림 넣기 → 자 끌어 영점 맞추기
  - mergeRule: 10cm 막대 10개 → 합체
  - unit-train: 키보드로 승격·풀기·빼기
  - 오버레이 셋 1px 정렬
  - 새 화면 스냅샷 × 크롬북·아이패드
- **E2E 범위:** `npx playwright test measure-lab fit-canvas overlay-alignment g1s1u4 --workers=3 --reporter=line`
